# 监管框架：欧盟、美国、英国、韩国

> 4个主要监管制度界定了2026年独立自主治理格局:欧盟独立自主法(2024年8月1日生效)——从2025年2月2日起禁止做法和独立自主治理;《全球公共管理倡议》义务自2025年8月2日起全面适用和第50条透明度;《全球公共管理倡议》遗留下来的高风险系统,2027年8月2日;最高罚款15万欧元或全球营业额的3%。 《全球行动计划》业务守则(2025年7月10日):三章——透明度、版权、安全和安保——12项承诺;执行始于2026年8月,联合王国AISI -- -- > AI安全研究所(2025年2月):改名为范围较窄的信号。美国AISI -- -- > CAISI(2025年6月):NIST下的AI标准和创新中心;转向有利于增长的态势。韩国AI框架法(2024年12月通过,2026年1月生效):第12条根据MSIT建立了AISI;授权外国AI公司的地方代表、风险评估、高影响和基因化AI的安全措施。

**类型:** 学习
**语言:** 无
**先修要求:** 阶段18 18(边境框架),阶段18 27(数据管理)
**时间:** ~75分钟

<a id="learning-objectives"></a>

## 学习目标

- 说明欧盟《AI法》的风险等级(禁止、高风险、通用、有限风险)和2025年8月/2026年8月/2027年8月时间表。
- 说明《政府采购和保险业务守则》的三章,以及每一章的提供者。
- 描述2025年的重新命名:英国AISI - > AI安全研究所;美国AISI - > CAISI;每个重新命名对政策方向意味着什么。
- 说明韩国《大赦国际框架法》的核心规定。

<a id="the-problem"></a>

## 问题

实验室框架(Lesson 18)是自愿的,监管框架是强制性的,2024-2026年期间,AI全面法规的第一波生效,部署者必须绘制技术控制与监管义务的地图;绘图因管辖区而异。

<a id="the-concept"></a>

## 概念

<a id="eu-ai-act"></a>

### 欧盟大赦国际法

**2024年8月1日生效** 风险级别结构:

- **违禁做法** (第5条)社会评分、在公共场合(除执法例外)实时进行远程生物鉴别、剥削性操纵弱势群体,2025年2月2日适用。
- **高风险系统** 就业、教育、信贷、执法、司法、移徙,要求进行合规评估、风险管理、伐木、透明度。
- **通用大赦国际(GPAI)模型**2025年8月2日应用。所有GPAI供应商都负有义务;系统风险GPAI(>1e25 FLOP培训计算)也负有额外义务。
- **有限风险系统**第50条下的透明度义务(大赦国际生成的内容标签),2026年8月2日适用。

Timeline:
- 2025年2月2日:违禁做法+大赦国际扫盲。
- 2025年8月2日:GPAI+治理。
- 2026年8月2日:全面适用+第50条透明度+最高1 500万欧元/3%的全球营业额的处罚。
- 2027年8月2日:遗留的GPAI+嵌入式高风险。

委员会提议,在2025年底将高风险时间表调整为16个月。

<a id="gpai-code-of-practice"></a>

### GPAI 业务守则

2025年7月10日发表。

- **Transparency.** 所有的GPAI供应商。
- **Copyright.** 所有的GPAI供应商。
- **安全和安保。** 系统风险GPAI供应商(估计有5-15家公司)。

由大赦国际办公室主持的签字工作队负责管理执行工作,2026年8月2日开始执行;在此之前,接受诚意遵守。

<a id="transparency-code-for-article-50"></a>

### 第50条透明度守则

2025年12月17日草案初稿,2026年3月草案第二稿,2026年6月最后版本,包括AI产生的内容标签,包括深假——管理层,需要23课的水印技术。

<a id="uk-ai-security-institute-february-2025"></a>

### 联合王国AI安全研究所(2025年2月)

重命名自 AI 安全研究所。 重新命名范围狭窄: 减少算法偏差和自由发言框架; 侧重于边框能力安全。 开源检查 evaluation 与Redwood(Lesson 10)合作处理控制安全案例。

<a id="us-caisi-june-2025"></a>

### 美国国际审计学会(2025年6月)

Trump 管理将NIST的AI安全研究所转变为AI标准和创新中心。 转向VP Vance 巴黎AI行动峰会的“ 有利于增长的AI政策 ” 。 降低对部署前部署的重视度。 evaluation国内对欧盟《大赦国际法》监管态势的反制。

<a id="korean-ai-framework-act"></a>

### 韩国大赦国际框架法

2024年12月通过,2025年1月颁布,2026年1月生效,合并了19项独立的AI法案。

第12条规定,在科学与信通技术部之下设立一个AISI。
- 在韩国经营的外国大赦国际公司的地方代表。
- “高影响”AI系统的风险评估。
- 基因性人工智能和高影响人工智能的安全措施。

具有全面横向大赦国际条例的第一个亚洲管辖区。

<a id="cross-jurisdiction-dynamics"></a>

### 跨法域动态

- 欧盟:严格、风险程度高、严厉处罚。隐私相邻监管基准。
- 美国:创新-促进、分散化的州(例如加利福尼亚州2013年-27课)填补了联邦的空白。
- 联合王国:安全重点狭窄,强 evaluation infrastructure.
- 韩国:MSIT以外国提供者为主。

监管理念竞争:多个管辖区的部署人员必须遵守最严格的规则,2026年,这通常是欧盟《独立法》。

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|------|-----------------|------------------------|
| 欧盟大赦国际法 | 条例 | 风险层次的人工智能横向监管;2024年8月生效 |
| GPAI | "一般用途的AI" | 大型基础模型;系统风险子集有额外义务 |
| 第 50 条 | “透明度义务” | AI 生成的内容标签; 应用 2026年8月 |
| 联合王国 | "美国安全研究所" | 2025年2月重命名;边界安全重点较窄 |
| CAISI | "美国AI标准中心" | 2025年6月从AI安全研究所重新命名;促进增长的态势 |
| 韩国大赦国际框架法 | “管理信息系统横向监管” | 首部亚洲综合大赦国际法;2026年1月生效 |
| 系统风险 | "1e25FLOP门槛" | 额外债务等级;估计有5-15家公司受约束 |
