# 公平性标准：群体、个体与反事实

> 3个家庭组成了公平文献。群体公平:人口均等、均等率、有条件使用准确性平等——受保护群体平均比例平等。个人公平(Dwork等人,2012年):类似个人得到类似的决定;Lipschitz在决定地图上的条件。 反事实公正(Kusner等人,2017年):如果敏感属性发生反实际改变时,决定对个人来说是公平的。 2024年理论结果(NeurIPS 2024年):存在固有的CF-vs-cureal-off:一种模式的不可否认方法转换了一种模式-不可否认的方法。 最佳但不公平的预测器, 进入一个具有约束性精确度损失的 CF 。 反事实的后追(arXiv: 2401.13935, 2024年1月 ) : 避免要求干预受法律保护属性的新模式 。 哲学对账( ICLR Blogposs 2024): 用因果图, 满足某些群体公平措施意味着反事实公正性 。

## 学习目标

- 说明三个群体公平标准(人口均等、均等率、有条件使用准确性平等)和一项不可能的结果。
- 通过Dwork等人2012年的Lipschitz 表述,描述个人公平。
- 描述反事实公正性及其因果关系。
- 解释反事实的反向跟踪,以及为什么它们回避了保护性干预归属问题。

<a id="the-problem"></a>

## 问题

20课是关于衡量偏向的。21课是关于界定衡量应达到的公平标准。三个家庭给出了结构上不同的标准 — — 一种模式可以是群体公平和个人不公平、反事实公正和群体不公平。选择标准是一种政策决定;没有一项标准是普遍最佳的。

<a id="the-concept"></a>

## 概念

<a id="group-fairness"></a>

### 群体公平

- **人口均等。** P(Y=1 | A=a) = P(Y=1 | 对所有群体来说,A=a'。
- **赔率相等** P(Y=1 | Y*=y, A=a) = P(Y=1 | Y*e. 各个群体之间的平等TRR和FPR。
- **有条件的使用精确度相等。** P(Y*=y | Y=y, A=a) = P(Y*=y | Y=y, A=a'. 各个组的预测值相等。

不可想象性(Chouldechova, Kleinberg-Mullinathan-Raghavan 2017年):在基本利率不平等的情况下,这三者不能同时得到满足。

<a id="individual-fairness"></a>

### 个人公平

Dwork等人,2012年。 决定地图f 单独地对任务特定相似度指标而言是公平的d |f(x) - f(x)' 键| L * d(x,x') 对于一些Libschitz常数L. 类似个人也得到类似的决定。

需要界定d. 政策问题,而不是统计问题。

<a id="counterfactual-fairness"></a>

### 反事实公平

Kusner等人,2017年。 一项裁决对个人而言是反实际的,即如果根据人口因果模式,当我的敏感属性被反实际地改变时,该决定就保持不变。

需要因果的 DAG。 DAG 是模拟选择。 反事实公正与 DAG 一样合理。

<a id="the-cf-vs-accuracy-trade-off"></a>

### CF-vs-准确性交易

NeurIPS 2024 理论:反事实公正和预测准确性之间有着内在的权衡。 模型不可知性方法可以将最佳但不公平的预测器转换成CF1, 其成本是约束性的。 精确性成本取决于最佳不公平预测器中的敏感归因系数大小。

<a id="backtracking-counterfactuals"></a>

### 反向跟踪

传统反事实要求干预敏感属性,“如果此人是不同的性别,决定会改变吗?”从法律上讲,这有问题:在分类法中,受保护属性不能干预。

反事实反向反转方向: 不要干涉属性, 询问个人实际的组合 features 这会产生相反的结果,这会回避法律上的反对。

<a id="philosophical-reconciliation"></a>

### 哲学和解

ICLR Blog poss 2024。 有了因果图,满足某些群体公平措施就意味着反事实公正。 这三个家庭不是正统的,而是同一根本因果结构的不同方面。

这并不能解决不可能的理论(不平等的基准率仍然阻碍同时实现群体公平 ) 。 但这表明“群体”和“个人/反事实”之间的明显反对部分是无法明确解释因果关系模型的手工艺品。

## 实际应用

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|------|-----------------|------------------------|
| 人口均等 | "等价" , 等价 | P(Y=1 | A=a) 不同组别平等 |
| 平均概率 | "平等TR/FPR" | 不同群体之间真实和虚假的正比 |
| 有条件使用准确度 | "平等PPV/NPV" | 不同组的等值预测值 |
| 个人公平 | "利普施茨状态" | 类似个人也得到类似的决定 |
| 反事实公平 | 改变因果的变迁 | 在反事实属性更改项下的决定不变 |
| 反向跟踪 | "通过真实的答案" | 反事实推理从结果退后,而不是从属性向前 |
| 不可移动性定理 | "三场冲突" | Chouldechova/KMR 2017:在不平等基率下,群体标准相互排斥 |
