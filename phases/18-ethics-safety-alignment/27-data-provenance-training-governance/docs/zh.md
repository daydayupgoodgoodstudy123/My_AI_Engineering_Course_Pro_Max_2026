# Data Provenance 与训练数据治理

> 欧盟《AI法案》要求到2025年8月(通过欧盟版权指令TDM例外),GPAI采用机器可读的选出标准。 2013年加利福尼亚州AB(签署2024年)——创用AI培训数据透明度要求开发商公布12个授权领域的数据集摘要。 alignment 爱尔兰民主党(2025年5月21日)接受Meta的 LLM 培训欧盟/欧洲电子产品管理局在EDPB意见后提供保障的一党公共内容; 科隆高等地区法院(2025年5月23日)驳回禁令; 《汉堡和平协议》不再紧迫; 联合王国国际竞争组织(2025年9月23日)对LinkedIn的AI培训保障措施(透明度、简化选择退出、扩大反对窗口)作出积极的监管反应,并继续监测——而不是正式批准。 巴西国家残疾人协会(2024年7月2日)暂停Meta因信息透明度不足而暂停处理;在Meta提交遵约计划后,2024年8月30日取消了预防措施。 weights手术擦除是不可能的, 受过训练的神经网络没有实际的GDPR权。 合规窗口正在收集时间 。 Data Provenance 大型审计显示, 出版商增加机器人限制, AI数据公有性迅速下降。

## 学习目标

<a id="the-problem"></a>

## 问题

培训数据治理是每个 model card 2024-2025年,监管格局围绕三项原则:选择退出的基础设施、按数据分列的披露和对公开数据的合法利益调整。 在收集时不遵守规定的供应商无法在下游补救。

<a id="the-concept"></a>

## 概念

<a id="california-ab-2013"></a>

### 加利福尼亚州,2013年

2024年1月1日或之前必须张贴2026年1月1日或之后发布的系统的文件。
1. 数据集的来源或所有者。
2. 说明数据集如何促进AI系统的预期目的。
3. 数据集中的数据点数(一般范围可接受;动态数据集估计数)。
4. 说明数据点的类型(标签数据集的标签类型;未标出的一般特性)。
5. 数据集是否包括受版权、商标或专利保护的任何数据,还是完全属于公共领域。
6. 数据集是购买还是获得许可。
7. 数据集是否包括个人信息(按Cal. Civ. code §1798.140(v)计算)。
8. 数据集是否包括消费者信息总量(按Cal. Civ. Code §1798.140(b))。
9. 开发商进行清洁、加工或其他修改,并有预期目的。
10. 收集数据的时间段,如果收集工作正在进行,则通知。
11. 数据集在开发过程中首次使用的日期。
12. 系统是使用还是持续使用合成数据生成。

第12项(合成数据)是相对于Gebru等人2018年的数据表而言的新内容,第7项(个人信息)触发了《隐私权法》规定的义务,该法规免除了安全/完整性、飞机操作和联邦专用国家安全系统(第3111(b)节)。

<a id="eu-ai-act-lesson-24-and-tdm-opt-out"></a>

### 欧盟《独立贸易法》(第24条)和TDM选择退出

欧盟版权指令文本和数据挖掘例外允许就公开内容进行培训,除非权利持有者选择退出。 欧盟AI法案《GPAI业务守则》版权章节要求GPAI供应商尊重机器可读的选出信号(robots.txt, C2PA“不使用AI培训”索赔等 ) 。

<a id="2025-dpa-convergence-on-legitimate-interest"></a>

### 2025年政治部在合法利益问题上的趋同

爱尔兰民主党(2025年5月21日):Meta计划培训在EDPB意见后获得保障的欧盟/欧洲经济区第一党公众成人用户内容,科隆高等地区法院(2025年5月23日)驳回了对Meta的禁令:选择退出就足够了。汉堡政治部放弃了全欧盟一致性的紧急程序。英国哈里发国(2025年9月23日)发布了积极监管对策,而不是正式许可,以恢复LinkedIn的大赦国际培训,同时提供类似的保障措施和不断监测。

一致原则:合法利益可以证明,对公开提供的首选当事人内容进行培训并选择退出是合理的,不需要同意。

<a id="brazilian-anpd-june-2024"></a>

### 巴西全国残疾人协会(2024年6月)

与欧盟的《政治协定》不同的结果是,“非专利产品”将透明度放在了合法利益可接受性之上。

<a id="the-irreversibility-problem"></a>

### 不可逆转问题

Cookie- conferent 是为实时可逆跟踪设计的。 训练数据不同: 一旦数据进入模型 weights手术擦除是不可能的。从零开始的再训练是唯一完整的治疗方法,而且费用太高了。

部分补救:
- **Unlearning.** 大约清除;由MIA测量(Lesson 22)。
- **影响基于功能的本地化。** Identify weights 受数据影响最大的;有选择地更新。
- **Fine-tune-suppression.** 训练模型拒绝数据产出。

没有完全解决问题。 合规窗口在收集时间 。

<a id="data-provenance-initiative"></a>

### Data Provenance Initiative

org. Longpre、Mahari、Lee等人,“危机中的同意”(2024年7月):对AI训练公用数据进行大规模审计。发现:出版商正在加速增加机器人.txt限制。可公开学习公用数据正在迅速收缩。 2023年 - > 2024年,看到25%的顶级训练来源增加了一些限制。 availability 取决于新的收购模式(许可证、合成代、激励参与)。

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|------|-----------------|------------------------|
| AB 2013年 纽约 | 加州法律 | 产生AI培训数据透明度;12个授权领域 |
| TDM 例外 | "text-and-data-mining" | 欧盟版权指令培训数据例外,但选择不适用 |
| 合法权益 | "欧盟的基础" | 第6条可证明开展公共内容培训是合理的依据 |
| 选择退出信号 | "机器可读的无轨列车" | 机器人,Txt,C2PA "没有AI训练,TDM. 保留 |
| Irreversibility | "不能不开火车" | 模型中的数据 weights 不可手术拆除 |
| Unlearning | "大概是搬家" | 培训后干预,以减少模式对具体数据的依赖 |
| 危机中的同意 | "新闻部的审计" | 2024年7月 发现加速的机器人限制 |
