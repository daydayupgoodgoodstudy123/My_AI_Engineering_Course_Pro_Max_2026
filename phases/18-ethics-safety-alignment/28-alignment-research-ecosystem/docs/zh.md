> 五个组织界定了2026年的非实验室 alignment 研究层。 Alignment 理论学者:527+研究人员,自2021年底以来,180+论文,10K+引文,h-index 47;Summer 2024组群,包括:501(c)(3),有~90名学者和40名导师;2025年前的校友安全/安保工作,有80%在2025年 Anthropic深沉的, OpenAI红木研究:应用 alignment 由Buck Shlegeris创立的实验室; 引入了 AI 控制( Lesson 10); 在控制安全案例方面与英国AISI合作。 Apollo 研究: 部署前计划 evaluations 用于边境实验室;撰写了《通则》的文稿(第8条)和《争取AI 计划的安全案例》。 Evaluation 威胁研究:基于任务的能力 evaluations自动任务时间光谱研究; “边界安全政策的共同要素”比较实验室框架。 evaluations (教训19); 进行 Claude 4号计划福利评估

<a id="the-concept"></a>

## 概念

<a id="mats-ml-alignment--theory-scholars"></a>

### MATS( ML) 生产 Alignment 理论学者( J)

2021年末开始。 研究辅导方案;学者与一位高级研究员一起,在特定领域进行为期10-12周的研究。 alignment problem.

比例( 2026) :
- 自建立以来,已有527名研究人员。
- 出版180多篇论文。
- 10K+引用。
- h -指数47。
- 2024年夏季:90名学者+40名导师;并入501(c)(3)。

职业成果:2025年前的毕业生中,有80%从事安全/安保工作。 Anthropic深沉的, OpenAI英国航空安全研究所 兰德 红木 METR 阿波罗

<a id="redwood-research"></a>

### 红木研究

Applied alignment 实验室,由Buck Shlegeris创办。引入了AI控制议程(Lesson 10) 。 与英国AISI合作处理控制安全案例。 咨询DeepMind和 Anthropic 在 evaluation design.

加纳文论文:格林布拉特、Shlegeris等人,“AI控制”(arXiv:2312.06942,ICML 2024); Alignment 假冒(格林布拉特、德尼森、赖特等人,ArXiv:2412.14093,与 Anthropic).

样式: 特定 threat models最坏的对手 具体协议 能够进行压力测试

<a id="apollo-research"></a>

### 阿波罗研究

部署前计划 evaluations 2025年,为边境实验室撰写了文稿内图(Lesson 8,arXiv:2412.04984)。 OpenAI 编写AI 系统安全案例(2024年)。

Style: agentic-setting evaluations 欺骗可能出现;三根柱子分解(不协调、目标导向、情况意识)。

<a id="metr-model-evaluation-and-threat-research"></a>

### METR (模型) Evaluation 威胁研究)

任务能力 evaluations自动任务完成时间- 视距研究。 “边界安全政策的共同要素”(Metr.org/common- elements, 2025)比较了实验室框架。

与阿波罗一起制作安全案件草图

样式: 长方位任务 evaluations经验性能力衡量、框架综合。

<a id="eleos-ai-research"></a>

### Eleos AI 研究

部署前福利模式 evaluations进行中 Claude 系统卡第5.3节记录的福利评估4,提供与福利有关的19项索赔的外部方法检查。

<a id="the-flow"></a>

### 流体

MATS培训研究人员。 Anthropic深沉的, OpenAI 或红木、阿波罗、METR、埃利奥斯(外部) evaluation外部评价员与实验室和英国AISI/CAISI合作,出版物为下一个组群向MATS反馈生态系统。

<a id="why-this-layer-matters"></a>

### 为何这层重要

Single-source evaluations 是不可靠的: 评估自己模型的实验室存在结构性利益冲突。 外部评估员可以提出和验证实验室可能低估的失败模式。 2024 Sleeper 2024 。 Agents 纸张(第7项) Anthropic + 红木; Alignment 假装 Anthropic +红木; 内文的图案是阿波罗; 反图案是阿波罗+ OpenAI。多功能结构是质量控制。

<a id="exercises"></a>

## 练习

1. 选取一篇7-15课的论文,并辨明所涉组织。

2. 阅读METR的“边界安全政策的共同要素”。 确定它们强调的三个交叉实验室的趋同点和两个最大的差异。

3. MATS职业成果为~80%的安全/保障。 质疑选择压力是适应性( 外延) 还是偏向( 过滤异正立场 ) 。

4. 红木和阿波罗都使用不同的风格来控制/制导。 选择一个失败模式, 描述每个模式如何调查它 。

5. Eleos AI是唯一纯净的模型福利组织。 设计一个假设性的第二个组织,侧重于不同的福利邻接问题(认知自由、机器人化等)并阐明其方法。
