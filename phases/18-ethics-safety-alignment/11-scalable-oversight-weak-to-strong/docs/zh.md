# 可扩展监督与弱到强泛化

> 伯恩斯等人(19岁)OpenAI 超匹配,“对压的弱点一般化 ” , 2023年提出一个超级匹配问题的替代物: 使用较弱模型生成的标签微调一个强大的模型。 如果强模型从不完善的监督中正确地概括, 当前的人标 alignment 系统可以扩展至超人系统。可扩展的监督和W2SG是互补的。可扩展的监督(辩论、递归性奖赏模型、任务分解)提高了监督员的有效能力,使其能够跟上受监督的模式。W2SG确保强型模型能够正确概括监督员所提供的任何不完善的监督。辩论帮助了W2SG(arXiv:2501.1124,2025年1月)将其结合起来。

**类型：** 了解
**语言:** Python (stdlib,W2SG差距模拟器)
**先修要求:** 第18阶段 · 01(指导性后续)、第18阶段 · 10(AI控制)、第09阶段(RL基金会)
**时间：** ~60 分钟

<a id="learning-objectives"></a>

## 学习目标

- 界定可扩展的监督,并界定薄弱至强的概括,解释这些方面如何相辅相成。
- 描述Burns等人2023年的实验设置:微调 GPT-4 使用标签 GPT-2.
- 解释回收的绩效差距衡量标准及其衡量标准。
- 说明三个主要可扩展监督机制(辩论、递归性奖赏模型、任务分解)和每个机制的一个强项。

<a id="the-problem"></a>

## 问题

每个 alignment 18阶段的技术假设监督员可以评估模型的行为。 当模型是超人时,监督员就是薄弱环节。 超匹配问题: 弱的主管能否可靠地生成一个更强、更一致的模式?

伯恩斯等人将这一点简化为实际操作的经验性设置:强力监督,强力模型的能力有多少能维持薄弱的监督。 这不是超力的解决方案 — — 它是一个可以让我们衡量进展的代理。

<a id="the-concept"></a>

## 概念

<a id="w2sg-the-burns-et-al-setup"></a>

### W2SG: 伯恩斯等人的设立

- 弱型号 : GPT- 2个班
- 强型: GPT-4课
- 目标:强 GPT- 任务上限4

Procedure:
1. 买些微弱的模特儿 zero-shot 任务预测
2. 精细调整标签不高数据的强型号 。
3. 测量强精细的模型的准确性。

基线:模型本身的精确度薄弱,模型在金标签上有严格的控制。

差距衡量标准:业绩差距回收=(调整良好-薄弱)/(上限-弱)1.0表示监督薄弱完全弥补了差距;0表示监督薄弱没有帮助。

<a id="burns-et-al-empirical-findings"></a>

### Burns等人的经验性调查结果

在整个NLP、象棋和奖赏模型任务中,PGR始终是积极的:强势模式超越了弱者主管的错误。 具体任务PGR的幅度从~20%到~80%不等。 强势模式“理解”了预期的任务,包括不完善的标签,并填充了经过预先培训的前科。

限制 Burns等人,注:
- 弱到强的差距是能力,不是 alignment弱模型是统一的;真正的超人模型可能是由人类来调整的,但能力差距大得多。
- 强势模式的概括性可能更多地涉及任务前科,而不是恢复地面真相的意图。
- 真正的问题是,如何使强势模型的潜在知识更能发挥作用;而国家总检察长办公室则衡量具体的运作。

<a id="scalable-oversight-three-mechanisms"></a>

### 规模可扩展的监督:三个机制

- **辩论(Irving等人,2018年)。** 英国的两个案例是相反的;弱小的法官决定。 假设:找到一个令人信服的真实答案比找到一个令人信服的错误答案容易。 最近2024-2025年的工作(Khan等人,Michael等人)表明辩论有时有帮助,有时没有,而且是否起作用取决于任务结构。
- **递归奖建模(Leike等人,2018年)。** U帮助人类火车 reward model U+1 监督员的有效能力随着模型的生长而增长。
- **任务分解(基督教、Shlegeris、Amodei 2018年)。** 将一项艰巨的任务分解为子任务, 人类可以反复检查。 假设是可分解的 。

每个机制都对任务或任务的结构有所设想。 alignment 中段。

<a id="why-scalable-oversight-and-w2sg-are-complementary"></a>

### 为何可扩展的监督和W2SG是相辅相成的

规模可变的监督提高了监督员的有效信号质量。
W2SG填补了与监督员所能提供的不完善信号的缺口。

Lang等人——辩论有助于削弱对压力的概括化(arXiv:2501.13124),它们合在一起:辩论协议提供了更好的薄弱标签,并且对这些标签进行了强势模型的训练。

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|------|-----------------|------------------------|
| 可缩放的监督 | 使监督员更强大 | 提高监督员评价更有能力的模式的能力的机制 |
| W2SG | 弱的监管力 | Fine-tuning 有关薄弱标签和计量恢复能力的强势模型 |
| PGR | "恢复了业绩差距" | (调整良好-弱)/(上限-弱);1.0 = 完全关闭,0 = 无帮助 |
| Debate | "两起U事件争吵" | 规模可扩展的监督机制,由弱小的法官在两名U维权者之间挑选 |
| RRM | 假造的回报 | U帮助训练 reward model U+1;监督员能力轨道U |
| 任务分解 | "次任务 人类检查" | 将一项艰巨的任务打破到子任务中, 使人类能够校验, 并循环 |
| Superalignment | "与超人 Aligning experman AI" (异人联盟) | 与人类无法直接评估的模型相匹配有关的研究议程 |
