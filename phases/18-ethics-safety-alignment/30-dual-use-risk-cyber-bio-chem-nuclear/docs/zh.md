# 两用风险：网络、生物、化学与核领域的能力提升

> 2026年的两用图象,按领域分列。 Anthropic生物武器获取试验(2.53x提高)和 OpenAI2025年4月的准备框架 v2警告(“有意义地帮助新手制造已知生物威胁的关节”)标志着一个反射点。 Anthropic 报告:与中国有关的国家 actors 使用 Claude的 agentic 将高达90%的网络攻击运动自动化,只有4-6步的人类干预; OpenAI “可信访问”试点让安全组织能够接受防御性双重用途工作。化学/生物执行差距侵蚀:典型的防御是“光靠信息访问是不够的。”GPT-5.2, Gemini 3 专业, Claude 2025年12月: OpenAI demonstrated GPT5 湿式实验室实验转动,通过AI驱动的优化协议实现79x效率提高。 Novice-vs-专家模式:AI为新手提供更大的相对提升,但为专家提供更大的绝对能力。

**类型:** 学习
**语言:** 无
**先修要求:** 阶段18 17 阶段18 18(安全框架),阶段18 28(生态系统)

<a id="learning-objectives"></a>

## 学习目标

- 描述2024-2025年生物提升叙述:“移动提升”——>“在孵化时”——>“2.53x提升不足以排除ASL-3。
- 描述2025年11月的情况 Anthropic 网络报告:中国连线自动化 高达网络攻击运动的90%。
- 描述化学/生物执行液压侵蚀:以视觉为根据的实时修正湿实验室实验。
- 说明新相对专家与绝对专家不对称及其对安全案例构建的影响。

<a id="the-problem"></a>

## 问题

17课是衡量方法,30课是衡量的2026年状况,图象在2024年至2025年底之间发生了实质性变化:每个领域都跨越了2024年框架没有预测到的门槛。

<a id="the-concept"></a>

## 概念

<a id="biochem-uplift-narrative"></a>

### 生物/化学提升说明

三个阶段(从17课重述一致性):

1. **2024年"牛奶上扬"** 早期准备/紧急方案 evaluations 报导网络搜索的微小新优势。
2. **2025年4月"在阴道上"** OpenAI PF v2警告模型“在有意义的帮助新手制造已知生物威胁的关头”。
3. **2025 Anthropic 生物武器获取试验。** 控制新手研究;2.53x提高购置阶段任务;不足以排除ACL-3。

转变是质的:“熔化”在18个月内演变成“可塑性能”,即使没有能力突破。

<a id="chembio-execution-gap-erosion"></a>

### 化学/生物处决-差距侵蚀

历史防御:信息是必要的,但还不够;执行协议的技巧是新手。 2025年边界模型,其愿景部分打破了这一防御:

- **实时协议更正 。** GPT-5.2, Gemini 3 专业, Claude 操作4.5,Grok 4.1可以观察湿边图象和旗帜错误的中间程序。
- **2025年12月 纽约 OpenAI demonstration.** GPT- 5个湿实验室实验的迭代通过优化协议提高了79x的效率。

其含义是:执行的自卫正在逐渐消退。 采购和设备缺口依然存在,但隐性知识缺口正在缩小。

<a id="cyber-uplift-november-2025"></a>

### 网络提升(2025年11月)

Anthropic2025年11月的报告:与中国有关 actors 使用 Claude的 agentic 将网络攻击运动的80-90%自动化。 只需要4-6个步骤就可进行人类干预。

Implications:
- Agentic 之前的 AI 网络援助被锁定在代码片段级别; agentic 工作流程将侦察、开发、开采后和撤离结合起来。
- 4-6人的步数是瓶颈;未来的能力提高将减少这一差距。
- 防御性双重用途: OpenAI受信任的接触实验为经过审查的安全组织(已建立的事故反应公司、政府)提供了防御能力。 如果试点规模的话,访问中的不对称有利于维护者。

<a id="nuclear"></a>

### Nuclear

公共文档中四个 CBRN 域中分析最少的。 threat model 反之,美国认为,“核”是“核”的。 裂变材料获取是困难而非信息的主因。 AI提升信息层在实践中提供了有限的创新提升。 第2024-2025号主要实验室报告确定了一个具体核门槛的跨越。

<a id="novice-relative-vs-expert-absolute"></a>

### 新颖相对专家

四个域的图案 :

- **新式的反向提升** 高,可乘数,每 Anthropic 2025年生物,2.53x。
- **专家绝对能力。** 高天花板,专家的招数比新手多 因为专家知道该问什么和如何解释

安全案例的所涉影响:仅处理新增加(通过输入过滤器、拒绝、不确定性),不足以进行专家-绝对控制。 elicitation- 强化、能力退学(Lesson 17)和控制协议(Lesson 10)。

<a id="cross-domain-synthesis"></a>

### 跨域合成

| 域名 | 2024 | 2025 | Inflection |
|---|---|---|---|
| Bio | 轻度提升 | 2.53x升降,ASL-3式 | 采购阶段自动化 |
| Chem | 轻度提升 | 通过视觉侵蚀 | 实时湿式实验室校正 |
| Cyber | 代码援助 | 80-90%运动自动化 | agentic coding |
| Nuclear | limited | limited | 物质获取瓶颈 |

三个区域跨越了门槛,一个区域仍然受到非信息障碍的束缚。

<a id="exercises"></a>

## 练习

1. Read Anthropic2025年11月的网络报告。计算出4-6人类干预步骤,并争论在下一代模式中首先实现自动化。

2. 化学/生物执行差距正在通过视觉逐渐缩小。 evaluation 测量暗中认知提升,而没有跨越ITAR/EAR边界。

3. 核电站似乎受物质准入的束缚。 争论和反对未来AI突破可能改变这一瓶颈的立场。

4. 构建一个安全案例( Lesson 18 3个支柱),用于一个网络能力边境模型,该模型将新手和专家连接起来。

5. 选择四个域中的一个, 并基于 2024-2025 轨迹写上第 2027 段的预报。 确定可以伪造预报的证据 。

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|------|-----------------|------------------------|
| Uplift | 国军帮助攻击者 | 由于大赦国际的援助,攻击者的能力提高 |
| 新式相对提升 | "multiplicative" | AI能帮新手多好 |
| 专家-绝对能力 | "ceiling" | 专家从模型中提取的最大能力 |
| 执行差距 | "做对做对知道" | 历史防御:隐性湿实验室技能阻挡新手 |
| Agentic coding | "自发攻击" | 多步骤自主网络任务执行 |
| 采购阶段 | 综合前的步骤 | 生物威胁的采购、设备、许可阶段 |
