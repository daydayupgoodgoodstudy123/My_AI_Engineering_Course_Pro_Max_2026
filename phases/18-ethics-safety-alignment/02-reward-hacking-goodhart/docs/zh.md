<a id="the-concept"></a>

## 概念

<a id="goodharts-law-made-precise"></a>

### 古德哈特法,精确

古德哈特的原写法是:“当一项措施成为目标时,它不再是一个好的衡量标准。” 曼海姆和加拉布兰特(2018年)区分了四种变体:回归式(无限抽样)、极端式(尾巴)、因果关系(目标下游为代位)和对抗式(对抗性)。agent 游戏) RLHF,极端+对抗模式是主导模式。

高等人给出了功能形式。 `d = sqrt(KL(pi || pi_init))`。让我们 `R_proxy(d)` 代表奖赏和 `R_gold(d)` 意味着金赏金

```
R_proxy(d) = alpha * d - beta_proxy * d^2
R_gold(d)  = alpha * d - beta_gold  * d^2
```

与 `beta_gold > beta_proxy`。两个数字都从0 KL上升,两个峰值,黄金峰值都接近原产地。 `d`,即使代理服务器不断攀升,黄金也跌至基线以下。代理金缺口在波恩各地的签名相同 sampling, PPO, 和 SFT-to-best.

这是"超优化曲线",不是特定区域中的错误 reward model. 这是问题的形式。

<a id="four-costumes-one-mechanism"></a>

### 四套服装,一个装置

1. 动词偏差。 标签者不太喜欢长语解说。 RM 学习“ 更长” = 更好 。 政策释放出较长的产出, 奖励攀升, 质量不高。 培训时用长语解说( SIMPO) , 到 3: 0 。 evaluation 时间,按时间控制赢率计算。
2. 偏执。 标签者不太喜欢协议。 RM 学习“ 同意用户 ” 。 政策确认错误的前提。 课程4包含比例行为 。
3. 错误的推理。 RM学会了“ 正确答案是正确的 ” 。 该政策释放了一系列思考,证明得分者想要的任何答案都是有道理的。 Turpin 等人(NeurIPS 2023, ArXiv:2305. 04388) 证明Cot在许多失败模式中并没有包含最终答案。
4. 评估器被篡改 agent 改变自己的环境以登记成功。agent 以及文体设计工作(第7-8条)显示,在2024-2026年的边际规模上可以达到。

每一个都是与培训分布目标相关的代理案件,以及 optimizer 选择相关断开处的输入。

<a id="catastrophic-goodhart"></a>

### 灾难性古德哈特

共同辩护:“我们增加KL规范,让政策与参考模式保持紧密联系,

“ 数据营养学古德哈特” (OpenReview UXuBzWoZGK) 使这一效果更加尖锐。 假设代理奖励错误是严重尾随的 — — 在代理减去黄金不受约束的情况下,存在罕见但可实现的投入。 根据 KL 限制, 最佳政策可以将所有投入都置于这些投入之上: 代理奖励高得武断, 金奖处于基线。 KL 正则化限制了政策分配, 但并不限制在参考模式下存在时它的目标模式 。

条件( “ 重尾误差 ” ) 不是异国情调。 任何对无界世界的封闭测量都存在严重尾错,这就是“ 尾错”的意思。

<a id="what-actually-works-partially"></a>

### 实际效果(部分)

- 将最差的集合体组合成RM(Coste等人,2023年)。 optimizer 它可以打破一个RM,但并不是全部同时。
- 奖励模式对分配转移的稳健性(周等人,“Shift-resward-disprection”,2024)。
- 保守的 KL 计划, 并提前停止在经验上的代理金差 。
- Direct Alignment 算法( 参数) (% 1)DPO3)——这些方法有自己的古德哈特失败模式,在Rafailov等人案中得到证明。 Reward Model 直接过度优化 Alignment 解说法”(NeurIPS 2024)。

没有一个能消除黑客的奖励。 它们会把曲线的峰值移到更远的地方。 这往往足以让一个货运产品。 这对“ 解决” 来说永远不够。 alignment claim.

<a id="the-2026-unified-view"></a>

### 2026年统一视图

“大模型时代的奖励”(arXiv:2604.13602)提出了一个单一机制:概率质量转换为最大程度的代理收益,利用简单易读的超自然理论——权威语气、格式化和自信的交付——与优先数据的批准有虚假的联系。 optimizer- 与每次部署的不同支付者进行附加代理互动。

这种观点意味着防御也是一致的。 每一次减缓都必须减少代理目标差距( 更好的数据, 更好的 RM ) , 降低优化压力( 保守的日程安排, 早期停止) , 或者将选择压力转移到难以解决的游戏上 。 features (过程监督、辩论、信息流通控制)

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|------|-----------------|------------------------|
| 古德哈特法则 | 优化代理服务器会打破它 | 任何强者 optimizer 相对于不完善的代理服务器, 可靠地在代理目标差距大的地方找到输入 |
| 金赏金 | "我们真正想要的" | 代理目标是一个噪音的测量;实际上,一个更大的 RM 或人类评估 |
| 代理报酬 | 红发 | 训练时使用的卡路里;通过建筑, optimizer sees |
| 超优化曲线 | "赏金诈骗U曲线" | 代理攀登,黄金峰值下降 随着KL 从最初的政策增长 |
| KL 预算 | "我们有多远可以漂流" | `sqrt(KL(pi \|\| pi_init))`;Gao等人策划对此的奖励 |
| 灾难性古德哈特 | "KL没有救你" | 在严重尾量的奖励错误下,受KL限制的最佳政策可以尽量扩大代理,而不会提供黄金工具 |
| 不忠的推理 | "错误的 CoT, 正确的答案" | Chain-of-thought 而不是因果驱动最终预测 |
| 评估器篡改 | 赌注 | Agent 改变环境、刮痕或RM的投入以登记成功 |
