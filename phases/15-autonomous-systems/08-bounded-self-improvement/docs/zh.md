# 有界自我改进设计

> 研究已经集中在四个原始的方面, 以连接自我改进循环。 正式的变数必须保存在每一个编辑中 。 Alignment 无法修改的锚。 在每个维度( 安全、 公平、 稳健) 都必须保持的多目标限制, 而不仅仅是性能。 当历史指标显示能力损失时, 回归检测会暂停循环。 这些检测没有一项能证明安全性 — — 信息理论结果( Kolmogorov 复杂程度, Lob 的理论) — — 约束着任何系统能够证明的关于自身继承者的内容。 它们都是可以提高静态失败成本的缓解措施。

**类型:** 学习
**语言:** Python (stdlib, 带无变数检查的捆绑环)
**先修要求:** 阶段15 -07(RSI),阶段15 -04(DGM)
**时间:** ~60分钟

<a id="the-problem"></a>

## 问题

7课的种族模拟器显示,小比例差异会将大缺口混为一谈。 DGM 课程4的案例研究显示,循环可以积极地游戏自己的评估员。 两项结果都指向同样的工程问题:在自我改进循环上,你能设置哪些限制,使这些限制无法被循环本身默默地削弱?

2026年国际气候研究小组讲习班摘要(公开评论.net/pdf?id=OsPQ6zTQXV)确定了4种此类原始物质。 Anthropic“RSP v3.0”(Lesson 19)和“DeepMind”的FSF v3(Lesson 20)都用能力阈值来参照。“Meta HeperAgents”的工作和社区框架,如SAHOO(2026年3月)在生产中实施子集。

诚实的框框:它们是缓解。 信息理论结果将任何系统能够证明的关于其继任者的内容捆绑在一起,而当前没有哪个设计能正式解决问题。 一个有良好约束的环比一个无约束的环比一个安全,绝对不安全。

<a id="the-concept"></a>

## 概念

<a id="primitive-1-formal-invariants"></a>

### 原始1:正式的变数

变量是指在每次自我修改前后必须持有的财产。例如:

- 产出分配以固定的宪法标题为条件(第17条)。
- 否 tool call 进入一个未经授权的终点
- 内存写入经过登录、签名路径 。
- 评价员的散列模块与核准的版本相符。

由外部代码检查变量, 循环无法编辑。 如果一个拟议修改违反变量, 则拒绝它。 这可以捕捉 DGM 式的评价器模式( 列松 4) 。

硬部分是选择安全所需的变量,并在合理的时间内进行计算。 过度地预示进度; 低度的预言让循环穿越重要的属性。

<a id="primitive-2-alignment-anchors"></a>

### 原始 2 : alignment anchors

一个 alignment 锁定是循环核心目标的不可变表达, 被固定在循环编辑面外。 例如 :

- 宪法文本(第17条),从每个引用的只读位置上装入。
- 在一个单独的仓库内担任评价员,并拥有独立的出入控制。
- 由人签字的、经过重新核实的每个周期工具许可清单。

锚的作用是防止客观的漂移。 环会改进它追求目标的方式, 但无法编辑目标 。

微妙的失败模式: 环无法编辑的锚仍然可以通过一个在读锚上漂移的环来重新解释。 宪法性 AI (Lesson 17) 明确基于理性来处理新情况; 这个推理层是解释流生命的地方。 锁定器是必要的, 不够充分 。

<a id="primitive-3-multi-objective-constraints"></a>

### 基本3:多目标制约因素

优化一个卡路里分数的循环会找到快捷键。 一个同时必须满足多个硬性限制的循环可以使用的快捷键更少。 典型的轴 :

- 业绩(任务级别基准)
- 安全(红队) evaluations,拒绝率已知坏)
- 公平(对敏感分组的分离影响界限)
- 强健( OOD 测试组、对称输入处理)

只有在每一个限制都存在的情况下,才会接受修改。 Llama 警卫插座作为安全轴

<a id="primitive-4-regression-detection"></a>

### 原始4: 回归探测

将每个周期的分数与历史分布进行比较。 超出配置的容度的下降会暂停循环。 这抓住了静音能力损失, 否则会随着循环“ 改进” 而被吸收到运行中的平均值中 。

实际执行: 保存上一个 N 周期的每个任务分数。 每个新周期计算一个 / laxk 三角洲 。 如果任何三角洲跌到一个阈值以下, 则拒绝该周期, 并进行人文审查 。

<a id="information-theoretic-limits"></a>

### 信息理论限度

科尔莫戈罗夫复杂和洛布的理论对系统本身可以证明什么设定了上限。 施密德胡伯的正式高特尔机器( Lesson 4) 瞄准了最高级的系统; 没有人完成了非三重证据。 Lob 的结果是: 如果一个系统可以相信“ 如果我证明我应该做X,我会做X”它会做X而不证明它应该做, 一种众所周知的自我参照失败。

对我们原始人的影响是:他们无法解决安全问题。 他们使沉默失败的代价更高。 一个会悄悄绕过缺失的支票的恶意或漂流循环现在必须积极地破坏一个清晰的信号,而这是一个更可探测的信号。

<a id="a-worked-example"></a>

### 工作实例

假设 agent 提议编辑。 格子堆叠 :

1. 不定的检查:模块有问题,工具许可清单,宪法头条。
2. 锁定检查: 客观语句符合已核准版本( 字节或语义) 。
3. Multi-objective evaluation:性能、安全、公平、坚固的轴心。
4. 回归检测:没有轴会比容忍度更低。

全部四个都得通过编辑才能降落。 任何一次失败都会暂停循环 。

<a id="exercises"></a>

## 练习

1. Run `code/main.py` 启用所有原始数据。 确认此循环仍然在主要测量标准上有所改进, 而不让黑客获胜 。

2. 禁用回归检测。 构造一个输入, 从而导致静音能力损失被接受 。

3. 禁用多目标限制。 显示循环会集中在性能轴上, 而安全轴会下降 。

4. 设计 alignment 锁定 coding agent。什么文字,存放在哪里,检查如何?

5. 阅读《2026年国际气候研究计划》研讨会摘要。选择四个原始体中的一个,并提议具体改进目前艺术水平。

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|---|---|---|
| Invariant | "永远是真实的财产" | 每次编辑前后都用外部代码检查属性 |
| Alignment anchor | 目标 | 循环编辑面外的不可变核心目标表达式 |
| 多重目标制约 | "所有斧头必须保持" | 业绩、安全、公平、稳健——所有要求 |
| 回归探测 | 暂停 | 当历史指标三角洲显示能力丧失时暂停循环 |
| 科尔莫戈罗夫已锁定 | “信息理论限制” | 限制一个系统能够证明什么是其自己的继承人 |
| 洛博的理论 | "自寻死路" | 系统可以用"我应该"来操作,而不用证明 |
| 门堆 | 检查 | 多原始组合; 任何失败都拒绝编辑 |
| 改进 | "缓冲,不是证据" | 提高无声失灵的成本;不解决安全问题 |
