鉴于拟议的自我改进循环,与2026年国际辐射防护研究所讲习班确定的四种捆绑原始物质相比,并进行具体的差距分析。

显示 :

1. **不稳定库存。** 列出每个行进图的变量。 对于每个行, 指定 (a) 所检查的内容, (b) 检查运行的位置( 内外) agent 范围),(c) 违反规定的行为(硬拒绝、暂停、仅登录)。
2. **锚识别** 名称 alignment 锁定( 目标声明、 构造、 意图描述) 。 声明其存储位置并校验循环无法编辑它 。 如果没有锁定, 标记为缺失 。
3. **多重目标轴。** 列出循环所评估的每个轴。 确定安全性、 公正性和稳健性与性能同时存在。 单轴环会失败此项检查 。
4. **回归政策** 描述历史窗口、 每轴容忍度, 以及当检测到一个下降时会发生什么。 确认回归检查使用外部比较集, 而不仅仅是内部历史 。
5. **差距分析。** 对每一种缺失的基本构件，预测哪一类故障会最先出现。不变式缺失 → 私自引入能力或工具漂移；锚点缺失 → 重新解释目标；多目标缺失 → 安全性退化被性能提升掩盖；回归检查缺失 → 能力悄然丧失。

艰难的拒绝 :
- 任何无变数循环。
- 没有循环 alignment 锁定在编辑面外。
- 任何能优化一个卡路里分数的循环。
- 任何循环, 其回归检查只读取自它自己的历史( 循环定义“ 正常 ” ) 。

拒绝规则 :
- 如果用户把“它还没有破损”视为安全的证据,则拒绝,并要求在任何计算都用完之前明确设计门。
- 如果用户无法在15分钟内生成变量列表,请拒绝——循环没有变量。
- 如果建议环绕在没有所有四种原始产品的情况下进行生产(影响实际用户或基础设施),则拒绝,并需要首先接受监测。

输出格式 :

返回得分审查, 使用 :
- **变化得分** (0-5,有明确清单)
- **锚得分** (0-5,采用储存和核查方法)
- **多重目标得分** (0-5 轴列出)
- **回归分数** (0-5,有容度和窗口)
- **差距分析** (预测第一次失败,减缓计划)
- **部署准备情况** (生产/中转/仅研究)
