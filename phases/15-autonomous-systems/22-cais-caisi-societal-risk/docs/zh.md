<a id="the-concept"></a>

## 概念

<a id="cais--center-for-ai-safety"></a>

### CAIS - AI安全中心

- 成立时间:2022年, 由Dan Hendrycks及同事在旧金山(“张”一词指早期合作者, 不是现任共同创始人;
- 现况:501(c)(3)非盈利。
- 2023年的显著产出:关于灭绝风险的声明,由数百名研究人员和首席执行官共同签名。 声明 : “ 从AI 中减少灭绝风险应该与其他社会规模的风险如流行病和核战争一起成为全球优先事项。 ”
- 2026年产出:AI边境模型设计板 evaluation远程劳工指数(与AI规模联合)、超级情报战略文件、AI Fronties通讯。

<a id="the-four-risk-framework"></a>

### 四种风险框架

CAIS的框架将灾难性的AI风险分为四大类:

1. **恶意使用**: 坏消息 actor 使用大赦国际造成伤害(生物武器合成、虚假信息、网络攻击)。
2. **人工智能赛跑**:实验室、公司或国家之间的竞争压力将部署推向安全地点。
3. **组织风险**内部实验室动态(安全培养失败、审计不足、安全资源不足)造成部署不良。
4. **流氓AIS**:一个能力充足的大赦国际追求的目标与人类福祉相冲突。

这并不是唯一的分类学,而是最引证的分类,这些类别并不相互排斥——一个组织以快速进行审计为交易,因此它生产了一个无赖的大赦国际。

<a id="where-organizational-risk-lives"></a>

### 组织风险存在的地方

在四个类别中,组织风险是从业人员最能采取行动的。 实验室的安全文化、审计规范、防御层和信息安全决定了它们拥有10-18课控制的模范船舶是否实际到位,或者这些控制是否为清单项目,没有人核实。

具体的组织风险杠杆:

- **安全文化**团队成员是否认为可以提高关注度而不增加职业成本?CAIS调查发现这是对其它杠杆的有力预测。
- **严格审计**外部和内部。只进行内部审计,就会产生乐观的报告。
- **多层次防御**:没有一层是足够的(第15阶段正在运行的主题)。
- **信息安全**: 模型 weights 泄漏, 电子数据泄漏, 监控路过技术泄漏。 RAND SL-4 课程19 是一个特定的标准 。

<a id="caisi--center-for-ai-standards-and-innovation"></a>

### CAISI - AI标准和创新中心

- 运行在 NIST 内。
- 与边境实验室签订自愿协议。
- 发布非分类能力 evaluations 重点是网络、生物和化学武器风险。
- 与 CAIS 不同; 缩略语相撞; 检查 URL (nist.gov) 以确认您正在读取的 。

该协会的作用是公开的、政府主导的与METR私人实验室合作(Lesson 21)的对应机构。 CAISI的报告不分类;它的报告往往由国家数据局负责。 阅读这两篇论文的执业者都得到了更全面的信息。

<a id="california-sb-53"></a>

### 加利福尼亚SB-53

加利福尼亚参议院法案(2025-2026年)涉及边界模式的灾难性风险。

- 触发国家一级义务的具体能力阈值。
- 保护AI实验室员工的举报人
- 灾难性故障报告事故的要求。

如果签署,这将是美国第一个州级灾难性风险监管。 不管签署状况如何,该法案的制定决定了其他州立法机构如何应对这一问题。 加利福尼亚州的执业者应该跟踪该法案的状况;其他地方的执业者应该阅读该法案,以了解美国州级监管可能是什么样子。

<a id="societal-scale-risk-is-not-a-single-layer-problem"></a>

### 社会风险不是单层问题

阶段15的运行主题 - defense in depth 没有一个单一的组织、规章或框架能够消除灾难性风险。

- 实验室船舶的升降政策(教训19、20)。
- 外部评价员进行计量(课程21)。
- 民间社会跟踪和宣传。
- 政府实施自愿方案和基线管理(CAISI, SB-53)。
- 从业人员建立多层控制(教训10-18)。

这是阶段的最后综合: 之前的每一个课都是堆叠中的一层, 完整性比任何一层都重要。

## 实际应用

`code/main.py` 执行一个小的风险清单工具。 根据一个拟议部署, 它给部署标记为四种风险类别, 并返回一个减轻风险清单。 它是一个框架的读辅助工具, 而不是替代人类判断 。

<a id="ship-it"></a>

## 交付成果

`outputs/skill-societal-risk-review.md` 评估社会风险态势的部署:它涉及的四类中哪类,有哪些缓解措施,组织风险风险是什么。
