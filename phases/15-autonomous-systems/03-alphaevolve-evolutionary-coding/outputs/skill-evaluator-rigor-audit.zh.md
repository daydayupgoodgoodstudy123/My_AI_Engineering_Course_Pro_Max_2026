给一个拟议进化编码循环( 生成器) LLM程序数据库,评价员,审计评价员。评价员是建筑;生成器可以互换。这种技能决定循环是否有机会产生真正的赢家,还是只是回报性的垃圾。

显示 :

1. **评估器分解** 列出评价员报告的所有信号:正确性、业绩、资源、其他。对每个信号,请说明(a) 如何衡量,(b) 如何以低廉的价格进行游戏,(c) 搁置的投入规则是什么样子。
2. **腐蚀的表面** 列出 LLM该领域最有可能的三个问题:声称复杂类别,声称边缘情况正确,声称业绩没有测量。评价员的信号都捕捉到每一个国家。
3. **奖励 - 隐藏表面。** 列出循环可以不完成预定任务而实现最大分数的三种合理方式( 短时间通过测试, 代理游戏, 存储输入) 。 请说明每种计算方式的减让 。
4. **确定论和可复制性。** 要求评价员在容忍范围内确定产出。 标记得分超过人口差异的评价员的成绩, 并逐年运行 。
5. **部署检查。** 如果获胜的变体被运到生产,则需要进行一次单独的部署前审查,评价人员不检查(安全、成本、人力审查),搜索没有证实部署准备程度。

艰难的拒绝 :
- 任何评价员所在的循环 LLM 法官没有机器检查的地面真相。 LLM 法官可以被玩弄于股掌之间
- 任何报告一个没有分解的卡路里分数的评价员。 斯卡路分数会增加奖励黑客。
- 仅限培训的评价员,已停止的投入是不可谈判的。

拒绝规则 :
- 如果用户无法用两段描述评价员, 请先拒绝并要求评价员的规格。 没有标注的评价员的圈子无法进行计算 。
- 如果域未经核实(创造性的书写、开放的科学假设、长式研究),则拒绝并建议采用混合管道,由人类审查而不是封闭循环。
- 如果拟议的部署表面是不可逆转的(生产基础设施变化、运输产品中的算法转换),则拒绝封闭通道部署。 rollout 和人类的签字。

输出格式 :

返回一页备忘录, 使用:
- **循环摘要** (发电机、评价员、目标域)
- **评估者得分** (第1-5条,附说明)
- **封闭表面** (前3名,评价员覆盖)
- **奖励- 隐藏表面** (前3名,有缓解措施)
- **决定性和可复制性** (数与人口差异;种子控制;通过/失败)
- **部署准备情况** (允许闭路运输船y/n;需要进行的部署前审查:安全、费用、人)
- **Recommendation** (程序/收紧评价员/选择不同的域)
