# Phase 05 自然语言处理 — NLP, Foundations to Advanced

[返回总目录](README.md) · [前一章](04-计算机视觉.md) · [后一章](06-语音与音频.md)

本章共 **29 节**。

**掌握目标**：理解文本表示、序列建模、信息抽取、检索与对话状态，能选择适合任务的基线。

**章节衔接**：承接朴素贝叶斯和神经网络；注意力连接 Phase 07，检索与结构化输出连接 Phase 11。

**为什么有用**：处于语言数据表示、语义理解与信息组织层。它连接早期文本分类、现代 embedding、检索和对话，为 LLM 应用提供输入处理与评估基础。

**章节练习**：为一组文档建立搜索与问答基线，分别检查切分、召回、答案依据与对话状态。

小节中的“衔接”说明知识如何复用，不代表必须按编号完成所有分支；原课的具体前置要求见教材。建议练习可配合原课代码完成，CoderPad 的实际题目范围以各自 `PROMPT.md` 为准。
