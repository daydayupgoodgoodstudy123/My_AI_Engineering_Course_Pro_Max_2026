# Phase 13 工具与协议 — Tools & Protocols

[返回总目录](README.md) · [前一章](12-多模态%20AI.md) · [后一章](14-Agent%20工程.md)

本章共 **31 节**。

**掌握目标**：能解释模型提议与主程序执行的边界，设计工具合同，并理解 MCP、技能和跨 Agent 通信。

**章节衔接**：承接 Phase 11 的函数调用与结构化输出，是 Phase 14 Agent 执行能力的接口基础。

**为什么有用**：处于模型决策与外部能力的接口及互操作层。Schema、协议、授权和技能合同把模型输出连接到受控执行，也让系统能追踪失败与变更。

**章节练习**：完成一个可校验的工具循环，逐步加入协议发现、超时、权限、trace 和负例；技能路线可单独学习 22、24–27。

小节中的“衔接”说明知识如何复用，不代表必须按编号完成所有分支；原课的具体前置要求见教材。建议练习可配合原课代码完成，CoderPad 的实际题目范围以各自 `PROMPT.md` 为准。
