# Phase 03 深度学习核心 — Deep Learning Core

[返回总目录](README.md) · [前一章](02-机器学习基础.md) · [后一章](04-计算机视觉.md)

本章共 **13 节**。

**掌握目标**：能解释并实现前向传播、损失、反向传播与参数更新，再映射到框架 API。

**章节衔接**：承接数学与机器学习评估，后续视觉、语言、音频和 Transformer 都复用本章训练机制。

**为什么有用**：处于神经网络学习机制层。理解计算图、梯度和训练稳定性后，视觉模型、Transformer 与 LLM 微调都能映射到同一套基本流程。

**章节练习**：先让小网络拟合一个 batch，再训练完整数据；记录梯度、训练曲线及泛化差距。

小节中的“衔接”说明知识如何复用，不代表必须按编号完成所有分支；原课的具体前置要求见教材。建议练习可配合原课代码完成，CoderPad 的实际题目范围以各自 `PROMPT.md` 为准。
