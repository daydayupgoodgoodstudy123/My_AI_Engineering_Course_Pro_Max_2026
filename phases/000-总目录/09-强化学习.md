# Phase 09 强化学习 — Reinforcement Learning

[返回总目录](README.md) · [前一章](08-生成式%20AI.md) · [后一章](10-从零构建大语言模型.md)

本章共 **12 节**。

**掌握目标**：能把任务写成 MDP，理解价值估计、策略优化与奖励建模的关系。

**章节衔接**：承接概率、随机过程和神经网络，连接 LLM 偏好训练、游戏搜索与具身控制。

**为什么有用**：处于从行动反馈优化策略的决策学习层。它连接游戏和控制，也为语言模型的奖励建模、偏好优化及可验证任务训练提供背景。

**章节练习**：在小环境比较随机策略与学习策略，记录回报分布，并检查终止状态和折扣处理。

小节中的“衔接”说明知识如何复用，不代表必须按编号完成所有分支；原课的具体前置要求见教材。建议练习可配合原课代码完成，CoderPad 的实际题目范围以各自 `PROMPT.md` 为准。

### 09.02 [动态规划](../09-reinforcement-learning/02-dynamic-programming/docs/en.md) — Dynamic Programming — Policy Iteration & Value Iteration

- **掌握**：理解 Bellman 更新、策略迭代和值迭代。
- **衔接**：在已知环境模型下求解 MDP，作为学习算法参照。
- **为什么有用**：位于已知环境模型下的规划层。Bellman 方程展示长期价值如何分解，为后续基于采样的学习方法提供参照。
- **建议练习**：手算小状态空间的价值更新并检查收敛。

### 09.03 [Monte Carlo 方法](../09-reinforcement-learning/03-monte-carlo-methods/docs/en.md) — Monte Carlo Methods — Learning from Complete Episodes

- **掌握**：理解整回合回报和基于采样的价值估计。
- **衔接**：去掉动态规划对已知转移模型的依赖。
- **为什么有用**：位于从完整经验估计价值的学习层。它不要求已知转移规律，能直观看到样本数量、回报波动与估计稳定性的关系。
- **建议练习**：比较不同回合数的估计均值与方差。

### 09.04 [TD、Q-Learning 与 SARSA](../09-reinforcement-learning/04-q-learning-sarsa/docs/en.md) — Temporal Difference — Q-Learning & SARSA

- **掌握**：掌握 bootstrapping、on-policy 和 off-policy。
- **衔接**：从回合结束更新转向每一步更新。
- **为什么有用**：位于逐步反馈与价值更新层。Bootstrapping 让学习不必等到回合结束，也引出目标估计偏差和策略分布的差别。
- **建议练习**：在同一路径计算两种 TD target，检查终止步。

- **掌握**：理解函数近似、经验回放与目标网络。

### 09.07 [Actor-Critic](../09-reinforcement-learning/07-actor-critic-a2c-a3c/docs/en.md) — Actor-Critic — A2C and A3C

- **掌握**：理解 actor、critic、baseline 与 advantage。
- **衔接**：结合价值学习与策略梯度以降低估计噪声。
- **为什么有用**：位于价值估计辅助策略优化的结合层。Critic 为动作提供相对收益信号，帮助理解为何 baseline 可以改变训练方差。
- **建议练习**：比较 return 和 advantage 的更新信号。

### 09.08 [PPO](../09-reinforcement-learning/08-ppo/docs/en.md) — Proximal Policy Optimization (PPO)

- **掌握**：理解概率比、裁剪目标和多轮 rollout 更新。
- **衔接**：在 actor-critic 上约束策略变化，连接 RLHF。
- **为什么有用**：位于受约束的策略更新层。概率比与裁剪控制一次更新偏离旧策略的程度，是连接 RL 理论与实际训练稳定性的实例。
- **建议练习**：构造概率比超过裁剪区间的例子，检查目标值。
