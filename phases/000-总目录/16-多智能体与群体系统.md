# Phase 16 多智能体与群体系统 — Multi-Agent & Swarms

[返回总目录](README.md) · [前一章](15-自主与长任务系统.md) · [后一章](17-基础设施与生产.md)

本章共 **25 节**。

**掌握目标**：能判断何时拆分 Agent，并设计角色、通信、共享状态、协调和成本评估。

**章节衔接**：以可靠的单 Agent 为前提，复用 MCP、A2A、持久执行和 RL；多 Agent 收益需要与单 Agent 基线比较。

**为什么有用**：处于多个 Agent 的任务分工与协调层。通信、共享状态和汇总机制决定协作成本，只有相同预算下的对照才能说明拆分带来的收益。

**章节练习**：先找出可独立的两个子任务，定义输入输出、汇总与失败恢复，再测正确性、延迟和总成本。

小节中的“衔接”说明知识如何复用，不代表必须按编号完成所有分支；原课的具体前置要求见教材。建议练习可配合原课代码完成，CoderPad 的实际题目范围以各自 `PROMPT.md` 为准。
