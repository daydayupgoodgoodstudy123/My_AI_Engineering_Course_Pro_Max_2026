# 11/03 分关面试题：FieldShape

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)；具体要求在测试、断言消息和 docstring 里。

内容来自本课：SchemaField、JSON Schema 的类型与约束、typed array/object 组合、应用侧验证和结构化抽取。所有抽取字符串都是本地回放数据，不需要 API key。validator、descriptor 声明与 tag codec 已给定；默认值只作为描述信息，不自动填入数据，也不表示 nullable。

快照保留大整数 metadata，同一个 store 在替换后读取新快照。模型名称只是标签；零长度上界和相等的 inclusive 数值界仍是有效约束。完成抽取保留 raw 空白与原数值，不修复 fence；错误树保留空字符串键和重复的相同错误。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 个 skipped 表示测试默认锁住。照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议共 60 分钟，含开场 2 分钟。五关参考分配为 10、11、16、11、10 分钟，合计 58 分钟。难度和时间分配尚未经过真人计时校准。
- 只改 `fieldshape/`。测试不能改，解除 skip 除外；可以另建自己的测试文件。
- 可以查 Python、json、pathlib、tempfile、os、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 不清楚的需求先问面试官。独练时先写下问题，再只看手册中的对应答案。

## 常用命令

```bash
python3 -m pytest -x
python3 -m pytest -k compiler -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

后两个开关由本目录 conftest.py 提供，真实面试里没有。维护验证器在完整临时副本中执行，不在课程题目目录留下缓存。
