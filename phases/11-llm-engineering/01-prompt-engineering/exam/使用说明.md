# 11/01 分关面试题：PromptBench

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)；具体要求在测试、断言消息和 docstring 里。

内容来自本课：具名变量模板、多轮 prompt、模板版本、四类 rubric、跨模型比较，以及测试报告。响应均来自本地回放数据，不需要 API key；Part 4 实现同步 score_rows，保留各模型原始响应、composite、token 与毫秒 latency 的对应关系；CSV codec 和完整异步驱动正确给定。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 个 skipped 说明测试默认锁住。照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：开场 2 分钟，Part 1 10 分钟，Part 2 12 分钟，Part 3 12 分钟，Part 4 14 分钟，Part 5 10 分钟。难度和时间分配还没有经过真人计时校准。
- 只改 `promptbench/`。测试不能改，解除 skip 除外；可以另建自己的测试文件。
- 可以查 Python、json、string、csv、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 不清楚的需求先问面试官。独练时先写下问题，再只看手册中对应的一条标准答案。

## 常用命令

```bash
python3 -m pytest -x
python3 -m pytest -k bank -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

后两个开关由本目录 conftest.py 提供，真实面试里没有。维护验证器会在临时副本中运行测试，不在课程题目目录留下缓存。

## 结束和重做

1. 到 60 分钟时停下，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没完成的关重写。
3. 先把自己的 `promptbench/` 另存，再恢复原始文件：

```bash
cp -R _starter/promptbench _starter/tests .
```
