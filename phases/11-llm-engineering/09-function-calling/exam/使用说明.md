# LocalToolBench 使用说明

11/09 原创 60 分钟结对练习，所有工具都是内存 fixture，不联网、不调用模型、不执行提交的代码。先开 README、localtoolbench/ 和 tests/test_parts.py；计时阶段不看 solution、INTERVIEWER 与 traps。

开场 2 分钟，五关 12、12、12、10、12 分钟，合计 60；未经真人校准。边做边解释，可以澄清与查文档。五个 skip 依次删除，一次只开一关，保留测试内容。

```bash
python -m pytest
python -m pytest -k test_local_dispatch_and_bound_scan
```

默认五关均跳过，通过当前关再推进。P1 收到已经绑定的合法比较条件；完整不可信 query 编译是 P3 独立任务，不能混成同一关。GIVEN 文件大小、严格 primitive、TAP driver/formatter 和关闭逻辑可以直接使用。

结束后在独立副本运行 `python -m pytest --solution --all-parts` 对照，再填 REVIEW_TEMPLATE.md。verification.txt 是本地自动检查摘要，不是正式面试标准。重做时递归用 `_starter/localtoolbench/`、`_starter/tests/` 覆盖同名目录，确认字节一致，再计时。

行为边界：相同工具和参数的不同 invocation 仍是不同历史记录；每张 allowed table 使用自己的字段布局；报告保留原 label，`error=False` 是正常结果；AST issues 按字段遍历顺序，位置保留 native metadata。按各关合同核对这些边界。
