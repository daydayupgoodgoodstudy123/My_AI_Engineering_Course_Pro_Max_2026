# 使用说明

本题以原课三类 MCP primitive 为来源，练习本地 surface compiler，不实现完整 MCP server。开场2分钟；五关12、10、16、10、10分钟，合计60分钟；没有真人用时校准。

作答在 `primitiveboard/`，测试是 `tests/test_parts.py` 的五个 skip。默认 `python -m pytest -q` 全跳过；每次仅移除当前 `@pytest.mark.skip("Part N")`，运行对应测试，保留全部断言。重做覆盖前，先把本人作答的 `primitiveboard/` 与 `tests/` 另存一份，保留当前解答和解锁状态。重置时递归复制 `_starter/primitiveboard/` 与 `_starter/tests/`。

- Part 1：`registry.py`；运行 `python -m pytest -q -k test_registration_inventory`。修复 callable 保存、三类注册身份及完整 inventory 响应速度。
- Part 2：`manifest.py`；运行 `python -m pytest -q -k test_named_handler_manifest`。manifest 只保存完整 spec 与安全的本地 handler 名称，重新打开后绑定给定 registry。
- Part 3：`surface.py`；运行 `python -m pytest -q -k test_three_primitive_compilation`。实现三类 descriptor/result 投影，保持嵌套 descriptor 容器与已注册元数据独立；注册 inventory 不等于完整协议 surface。
- Part 4：`changes.py`；运行 `python -m pytest -q -k test_registration_change_artifacts`。只实现本地 change audit 的 changed_fields、after descriptor 与 remove tombstone。真实 change 应用、当前身份、异步发布/关闭、最终 manifest 与 NDJSON 编码已给定。
- Part 5：`nested.py`；运行 `python -m pytest -q -k test_local_catalog_paths`。按完整本地 catalog 路径导出所有原语，保留各自 descriptor 与 handler。

`contracts.py`、`change_driver.py`、`invocation.py` 是正确给定边界；闭包绑定、primitive identity、JSON codec、shape/cycle guard 与 source capabilities 不需重写。metadata、transport、HTTP、MRTR、federation、TTL caching 都不是本题候选核。空 catalog 仍支持 source 声明的三种 primitive；不因 inventory 为空删 capability。

先定位 expected/actual 与调用边界，再逐步修复。卡住时使用面试官 H1/H2/H3；完成后填 REVIEW_TEMPLATE，再读 solution。NDJSON 是本地审计 artifact，不是新增 MCP method 或通知协议。
