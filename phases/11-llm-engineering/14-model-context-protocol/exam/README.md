# Three primitive surface board — 60-minute Python exam

Repair and extend an offline registry of tools, resources and prompts.
Python 3.10+, standard library and pytest; all handlers are local fixtures.
Work in `primitiveboard/` and unlock only the current Part in `tests/test_parts.py`.
The five parts cover registration, manifests, surface compilation, change audit
artifacts and nested local catalogs. Function docstrings define the scored contracts.
See `使用说明.md` for commands. Reference material is under `solution/`.
