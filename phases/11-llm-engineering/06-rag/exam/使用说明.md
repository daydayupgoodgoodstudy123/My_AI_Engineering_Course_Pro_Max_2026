# 11/06 分关面试题：SourceWeave

一个写好一半的本地 RAG 服务，五个测试按 Part 1–5 解锁。英文题面在 [README.md](README.md)，具体合同在 docstring、测试与行为断言里。

内容来自本课的 corpus chunk、TF-IDF、检索上下文、模拟抽取回答、引用与 recursive chunking。没有真实 LLM、embedding API 或网络。P1 结束于 Step5 context bundle；P3 才实现独立 Step6 抽句。分词、TF-IDF 后端、偏移映射、有限边界 parser 和 codec 已给定。SQLite snapshot 与 Markdown fragments 是明确的本地工程扩展。IDF/vector 的 binary64 字节、符号零和 mantissa 原样保存；保存的词表坐标顺序原样恢复，不在 load 时重拟合；stopword 不构成答案支持，恰好 10 字符的句子有效；空 fragment 原位保留由正确给定的回放驱动负责；Part 4 编写 citation_appendix，选择实际引用并构造完整 Markdown 附录。能放下的多句 paragraph 不继续拆分。

## 开始

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 skipped 表示默认锁住。按 README 注释掉 Part 1 的 skip，再运行 pytest。
