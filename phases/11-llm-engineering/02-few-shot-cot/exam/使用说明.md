# 11/02 分关面试题：CoTBallot

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)；具体要求在测试、断言消息和 docstring 里。

内容来自本课：带推理步骤的 few-shot 示例、相似性与标签覆盖、终值提取、self-consistency 投票，以及 Tree-of-Thought 轨迹。所有响应和轨迹都是本地给定数据，不需要 API key。示例库保留精确的六字段记录，轨迹用量遵守 docstring 的 score/token 范围。Part 4 实现同步 ballot_event，维护批内 reasoning 并投影累计票态；完整异步驱动正确给定。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 个 skipped 表示测试默认锁住。照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议共 60 分钟，含开场 2 分钟。五关参考分配为 10、12、12、13、11 分钟，合计 58 分钟。难度和时间分配尚未经过真人计时校准。
- 只改 `cotballot/`。测试不能改，解除 skip 除外；可以另建自己的测试文件。
- 可以查 Python、sqlite3、re、decimal、fractions、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 不清楚的需求先问面试官。独练时先写下问题，再只看手册中的对应答案。
