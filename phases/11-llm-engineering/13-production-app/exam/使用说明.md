# 使用说明

这是第11章第13课 production app 的本地服务练习，不调用真实模型或网络。开场读目录2分钟；五关分别12、10、16、10、10分钟，共58分钟，总60分钟。时间是练习分配，没有真人校准。

从 `rolloutlab/` 开始，测试在 `tests/test_parts.py`。默认五个测试各有 `@pytest.mark.skip("Part N")`；依次只移除当前关的 skip。先运行 `python -m pytest -q` 看当前行为，再修改对应模块。不要同时解锁全部关，也不要修改行为断言。需要重置时，把 `_starter/rolloutlab/` 与 `_starter/tests/` 递归复制回来。

- Part 1：`routing.py`、`prepare.py`、`ledger.py`。修复已有服务；首个异常发生在正确渲染消费者，后面还有独立行为与响应速度要求。运行 `python -m pytest -q -k test_prompt_preparation_and_observation_replay`。
- Part 2：`store.py` 的 `save_snapshot/load_snapshot`。保存完整 prompt 配置、用户与实验的 bucket、全部实际观测。运行 `python -m pytest -q -k test_rollout_snapshot`。
- Part 3：`experiment.py` 的 `execute_experiment`。复用修好的 Part 1；实现 rollout 与 shadow 的分工。运行 `python -m pytest -q -k test_rollout_shadow_execution`。
- Part 4：`events.py` 的 `project_branch_events`。正确 driver 已给定，负责实际异步拉取、当前身份、SSE 编码和关闭；只完成领域事件投影。运行 `python -m pytest -q -k test_role_aware_sse`。
- Part 5：`deployment.py` 的 `deployment_report`。遍历真实的 template→version→record 配置，给出实验引用与完整问题路径；这是静态一致性报告。运行 `python -m pytest -q -k test_deployment_registry_evidence`。

`contracts.py`、`primitives.py`、`wire_driver.py` 是正确给定边界。provider/guard/evaluator 都是注入的本地 fixture。Part 1 准备干净 miss；Part 3 才决定执行哪些角色并归属实际付费事实。cached/blocked 请求不进入实验执行。cost_text 与 token 数来自观测，不从最终展示文案倒推。

卡住时先写下 expected/actual、生产者与消费者、最小可解释改动，再逐级使用面试官提示。完成后用 REVIEW_TEMPLATE 复盘；`solution/` 含参考、出题说明与错修证据，不是作答位置。
