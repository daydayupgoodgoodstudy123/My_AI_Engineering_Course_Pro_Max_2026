# AdapterForge 使用说明

这是 11/08 的原创 60 分钟结对练习。源码用 torch；本题只用列表实现小矩阵与本地产物，不训练、不联网。先开 README、adapterforge/ 与 tests/test_parts.py。计时阶段不看 solution、INTERVIEWER 或 traps。

开场 2 分钟，五关建议 12、12、12、10、12 分钟，合计 60；未经真人校准。边读边解释，允许澄清和查文档。五个 skip 锁依次删除，一次只开一关，测试内容不改。

```bash
python -m pytest
python -m pytest -k test_adapter_forward_and_merge
```

默认五关都跳过。解锁后测试通过才进入下一关，保留过程中失败、提示次数和用时。所有 A/B 都按行向量约定，量化是均匀 signed-int4 教学近似，不是真正的 NF4。

练习后可在独立副本用 `python -m pytest --solution --all-parts` 对照答案，再填 REVIEW_TEMPLATE.md。验证摘要见 verification.txt，它代表本地自动检查，不代表真人面试校准。重做覆盖前，先把本人作答的 `adapterforge/` 与 `tests/` 另存一份，保留当前解答和解锁状态。重做时从 `_starter/adapterforge/` 和 `_starter/tests/` 递归覆盖同名目录，先确认文件逐字节一致，再重新计时。
