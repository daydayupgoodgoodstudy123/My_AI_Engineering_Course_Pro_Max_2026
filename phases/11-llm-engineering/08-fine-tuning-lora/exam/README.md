# AdapterForge

A local adapter artifact service. Python 3.10+, standard library and pytest only.

Keep the tests as written. Ask questions, explain your reasoning, and look up documentation when useful. Unlock one part at a time.

## Pt 1 `test_adapter_forward_and_merge`

Make adapter loading, evaluation and merging satisfy the service contract.

## Pt 2 `test_binary_adapter_archive`

Persist and reopen a complete named adapter artifact.

## Pt 3 `test_uniform_int4_blocks`

Implement the teaching block quantizer and its packed representation.

## Pt 4 `test_incremental_module_frames`

Publish each completed module artifact through the supplied framing tools.

## Pt 5 `test_targeted_module_graph`

Inject and merge adapters in the nested module graph.
