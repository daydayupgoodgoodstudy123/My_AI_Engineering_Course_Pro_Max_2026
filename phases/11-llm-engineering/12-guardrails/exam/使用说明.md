# PIISpan 使用说明

这是从本课 PII scrubbing 与 GuardrailReport 长出的离线练习。只处理给定的有限 regex fixture；不调用真实模型、检测 API 或网络，不承诺 PII 检出率或安全防护覆盖。

## 开始与规则

从 `piispan/` 和 `tests/test_parts.py` 开始。一次只移除当前 `@pytest.mark.skip("Part N")`，保留五个测试与全部断言。docstring 是精确合同；`solution/` 仅供计时结束后复盘。

```bash
python -m pytest -q
python -m pytest -q -k original_interval_scrub
```

开场 2 分钟；五关分别 12/10/16/10/10 分钟，合计 58 分钟；总计 60 分钟，未做真人用时校准。

## 五关交付

1. 保留完整匹配、原始 Unicode codepoint 偏移、指纹和正确输出决策。
2. 候选实现 redacted blob 与每 key 独立外层 manifest 的 save/load 组合；原文不落盘。完整 AuditSpan 字段 codec、校验与对象恢复正确给定，原始 confidence 词面由它保留。 读取时核对 manifest 的 blob digest；非法 audit 不得留下部分写入。
3. 对所有原始区间先做明确优先级/覆盖裁决，接受结果按原文顺序交给 P1 renderer；相邻与重复 occurrence 保留。
4. 正确 sandwich、当前 message 身份、NDJSON 与 async driver 全部给定；只投影精确 check 字段与原始 codepoint audit。
5. 验证实际两阶段报告：非输入拦截必须有 model_called 与一个 pii_scrubbing；按请求统计 blocked/passed/scrubbed。

偏移是原始字符串的 codepoint 索引；指纹为注入 salt 的本地短 SHA fixture 标识，没有密码学隐私保证。confidence 原始 Decimal 文本由 GIVEN audit codec 保留；候选不重写该 codec。P3 的 greedy priority policy 不是最大权区间调度。P4 仅在完整消息结束后发布，不处理任意 chunk 的早释放。
