# 11/05 分关面试题：ContextLoom

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)；具体要求在测试、断言消息和 docstring 里。

内容来自本课：context components、token budget、相关性过滤、历史压缩、lost-in-the-middle 重排与递归摘要。所有内容和 summarizer 都是本地确定性数据，不需要 API key。token 数采用本课的词数估计，不代表真实模型 tokenizer。组件记录保留文本内的 Unicode 分隔符；append 必须严格推进该组件 revision，重放按 checkpoint 与当前 live revision 的合同处理。已选中的零分文档仍参与 placement；SSE 由同步 `encode_revision` 组装当前更新后的完整状态与事件；正确给定的异步 driver 逐条发布并处理关闭。生成预留、live slot 布局与空内容都属于快照，digest 来源保留文档顺序。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 个 skipped 表示测试默认锁住。照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议共 60 分钟，含开场 2 分钟。五关参考分配为 12、12、10、12、12 分钟，合计 58 分钟。难度和时间分配尚未经过真人计时校准。
- 只改 `contextloom/`。测试不能改，解除 skip 除外；可以另建自己的测试文件。
- 可以查 Python、collections、json、pathlib、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 不清楚的需求先问面试官。独练时先写下问题，再只看手册中的对应答案。

## 常用命令

```bash
python3 -m pytest -x
python3 -m pytest -k zigzag -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

后两个开关由本目录 conftest.py 提供，真实面试里没有。维护验证器在完整临时副本中执行，不在课程题目目录留下缓存。

## 结束和重做

1. 到 60 分钟时停下，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没完成的关重写。
3. 先把自己的 `contextloom/` 另存，再恢复原始文件：

```bash
cp -R _starter/contextloom _starter/tests .
```
