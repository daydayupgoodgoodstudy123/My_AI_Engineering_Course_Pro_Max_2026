# 11/04 分关面试题：BitVecBank

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)；具体要求在测试、断言消息和 docstring 里。

内容来自本课：向量投影、cosine/dot/Euclidean/Hamming、二值量化、先粗排再全精度重打分，以及多层邻居图。binary64 文件使用声明的 little-endian 字节格式；P4 同步编码 BVS1 header 和完整 raw record，每条记录必须匹配 header dimension；async 拉取、发布与关闭 driver 已正确给定；图只沿给定有向邻接边做局部 greedy descent。稳定方向缩放、归一化与数值 norm primitive 已正确给定，有限坐标范围不用自行缩窄。所有向量、metadata 和邻居都是本地给定的数据；不需要 API key，不训练 embedding，不安装 numpy 或向量数据库。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 个 skipped 表示测试默认锁住。照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议共 60 分钟，含开场 2 分钟。五关参考分配为 10、11、15、12、10 分钟，合计 58 分钟。难度和时间分配尚未经过真人计时校准。
- 只改 `bitvecbank/`。测试不能改，解除 skip 除外；可以另建自己的测试文件。
- 可以查 Python、math、struct、json、pathlib、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 不清楚的需求先问面试官。独练时先写下问题，再只看手册中的对应答案。

## 常用命令

```bash
python3 -m pytest -x
python3 -m pytest -k rerank -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

后两个开关由本目录 conftest.py 提供，真实面试里没有。维护验证器在完整临时副本中执行，不在课程题目目录留下缓存。
