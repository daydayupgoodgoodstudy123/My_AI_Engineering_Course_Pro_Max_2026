# EvalPair 使用说明（11/10）

这是一套本地、离线、60 分钟的五关练习。开场 2 分钟，五关分别 12、12、14、10、10 分钟，合计 60；不是经过真人校准的耗时保证。

先读 README 和 tests/test_parts.py，逐关移除对应 `@pytest.mark.skip("Part N")`。只改 evalpair/，保留测试和断言。通常从 traceback 的正确 consumer 向 producer 查数据，边做边解释。P1 是已有服务调试，P2–5 是独立 TODO；P3 依赖明确数据合同，不把 P1 平均分或 ROUGE 重算一次当核心。

```bash
python -m pytest
python -m pytest -k test_typed_judge_and_sequence_metric
```

在自己的完整练习副本中运行。`--solution --all-parts` 是复盘开关，不代表 starter 成绩。计时期间不读 INTERVIEWER、solution 或 traps；标准库、pytest 和离线 fixture 足够，不需要模型、网络、GPU 或训练。

持久化使用 CSV observations 与独立 JSON run metadata，原文本（包括首尾空白）、decimal spelling 和大整数 seed 要保留。P3 明确匹配 case/criterion 和 category；bootstrap 对已配对差值有放回采样，不提前 round。P4 同步构造一个完成 case 的完整本地 JUnit XML；四态 outcome policy、suite envelope、async 拉取／发布／关闭 driver 均正确给定，P5 只报告同 case 同 criterion 的 coverage 和已有 category evidence，包括空 category 和各 criterion 的原路径，不重新做统计决策。

重做时从 `_starter/evalpair/` 和 `_starter/tests/` 恢复对应目录。复盘把原计时成绩、得到的提示和后来补完分开记在 REVIEW_TEMPLATE；“未观察”就写未观察。
