# 11/07 分关面试题：RerankDesk

形式照分关结对面试：五个测试各用 Part skip 锁住，按顺序解锁。英文题面在 [README.md](README.md)，具体要求在 docstring、测试及行为断言中。

本课来源是 advanced RAG 的 HyDE、candidate pool、metadata prefilter、lexical rerank 与 parent-child context。实际 source 是词法启发式，没有 cross-encoder/attention 模型。正确的 source-template HyDE generator 和本地 retrieval callback 已给定；HyDE 原文用于结果报告，pair scorer 接收原问题。query_hyde 是本地教学 adapter，源码没有这个集成 service。候选列表与合法非恒定 pair-score callback 都由本地 fixture 注入，P1 不提供完整 P3 scorer。dbm 持久化、UTF8 spans 与逐 query CSV 是本地工程扩展；raw source 的非索引空白与无 child 的来源也属于 catalog payload。大小写沿 source lower 语义，空 completed query 及时输出 header，同一 child 的多次 selected hit 保留各自 evidence。Part 4 同步 report_rows 投影原 rank、实际 rerank score 和 child 所属 parent/source；正确 CSV 编码、完整异步驱动与目录构造、检索底层已给定。BM25 使用当前 index generation 的拟合长度统计；P1 不重写其词频、DF、分词或评分公式。
