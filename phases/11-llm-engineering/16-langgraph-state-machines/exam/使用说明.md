# 使用说明

本题以课程的 checkpoint、historical fork、field reducer 与 Send 概念为来源，用标准库模拟明确的本地合同，不安装或执行LangGraph。开场2分钟，五关12/10/16/10/10分钟，总计60分钟；没有真人用时校准。

作答 `forkgraph/`；测试是 `tests/test_parts.py` 五个skip。默认 `python -m pytest -q` 全跳过；每次只移除当前 `@pytest.mark.skip("Part N")`，按下列命令运行，保留所有断言。重做覆盖前，先把本人作答的 `forkgraph/` 与 `tests/` 另存一份，保留当前解答和解锁状态。重置时以 `_starter/forkgraph/` 与 `_starter/tests/` 递归替换对应目录，恢复全部嵌套文件；两组目录的相对文件清单与字节须完全一致。

- Part 1：`forks.py`；`python -m pytest -q -k test_historical_fork_and_complete_ancestry`。修复指定历史点、分支嵌套隔离、单delta reducer、path-local重复祖先检测与完整ancestry响应速度。`memory.py`给定真实完整公开路径，不运行旧节点/LLM/外部工具。
- Part 2：`checkpoints.py`；`python -m pytest -q -k test_immutable_checkpoint_artifacts`。保存不可变checkpoint artifact，再发布scoped lineage index；重开保留完整state与commit顺序。全JSON codec、安全文件路径、atomic artifact writer和index framing已给定。
- Part 3：`superstep.py`；`python -m pytest -q -k test_send_superstep_barrier_and_reducers`。作答assemble_superstep：使用已包装workers和私有pre-state，先收齐、再按声明序合并，拒绝overwrite字段多个writer并保留完整update证据。完整输入/输出递归ownership由superstep_runtime.py给定，public run_superstep不需重写。给定completion_order模拟到达顺序，不声称真实并发或SDK运行。
- Part 4：`patches.py`；`python -m pytest -q -k test_committed_json_patch_stream`。将正确完整committed pair投影为本地有界add/replace patch，保持exact parent、JSON Pointer字段和重复append。JSON行、当前身份、异步拉取与关闭源真实给定。
- Part 5：`lineage.py`；`python -m pytest -q -k test_thread_scoped_branch_divergence`。报告同thread两条branch的最近共同祖先、完整路径和祖先之后的有序suffix，消费给定合法lineage。

`contracts.py`、`memory.py`、`patch_driver.py`、`superstep_runtime.py`和public run_superstep wrapper是给定代码。Checkpoint构造时进行完整有限JSON/state/reducer shape检查；公开fork API接收已经构造的typed records。后续状态作为只读snapshot证据，通过fork/commit接口推进，不承诺递归冻结任意Python对象。所有parent references按(thread_id,checkpoint_id)解析，input records顺序是commit顺序。MemoryBook以给定index_records完成所有typed/duplicate/scoped-parent校验并保留同一个索引；ancestry的scoped字典lookup已给定正确；当前path重复祖先必须拒绝，共享祖先的其他branch仍合法。独立查询不共享visited状态，每个祖先记录保留自己的完整state。load_all只接受已index且文件身份对应的完整记录。

本地append reducer是保持重复的list拼接，不等同完整LangGraph `add_messages` 的ID替换/删除语义。P1只处理一个delta，未提供P3的多worker barrier、声明顺序与overwrite冲突策略。P2允许相同完整记录重试；冲突同ID拒绝。writer失败不得发布悬空index，已写但未index的孤立artifact被忽略，不声称多writer或断电durability。

P4是本地JSON-line patch artifact，不是LangGraph wire protocol；每行一个已提交checkpoint，无partial worker状态。字段按child插入顺序；`~`和`/`按JSON Pointer编码，append用`/-`。只支持add/replace，没有delete。P5shape/parent/cycle guard给定，共享祖先是合法branch，不能因其他thread有同名ID而串线。

卡住时用H1/H2/H3，结束后填REVIEW_TEMPLATE再读solution。不运行source，不用真实SDK/API/网络，不重做短coderpad transition/topological_order。

Given ownership runtime先拥有caller state，包装每个worker的输入和已完成delta，再独立拥有发布state与各份delta证据；候选内核无需递归复制。每个已声明worker都有一次完成证据，包括空delta；发布证据不能重新调用worker。它不会替候选阻止提前归并：若内核在下一worker调用前修改prestate，后续worker仍会看到错误partial内容。完整ownership集成断言保留，但不是候选TODO的重复主核。
