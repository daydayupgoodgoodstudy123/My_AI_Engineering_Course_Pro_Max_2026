# Historical checkpoint forks — 60-minute Python exam

Repair and extend an offline checkpoint and super-step service.
Python 3.10+, standard library and pytest; workers/actions are local fixtures.
Work in `forkgraph/` and unlock the current Part in `tests/test_parts.py`.
The five stages cover historical forks, immutable artifacts, worker reductions,
committed patch records and branch lineage evidence. Function docstrings define
the scored contracts. See `使用说明.md`; reference material is under `solution/`.
