## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 输入层 / 隐藏层 / 输出层 | 输入层只放原始数据、不做计算；隐藏层做"加权和 + 偏置 + 激活"；输出层给出最终答案（二分类常用 1 个 sigmoid 神经元） |
| 2 | 神经元的三步 | 每个输入乘权重 → 求和加 bias → 过激活函数；一层就是很多个神经元并排 |
| 3 | 前向传播（forward pass） | 每层 `z = W·x + b`、`a = σ(z)`，上一层输出就是下一层输入；纯计算，**不学习** |
| 4 | 权重矩阵的形状 | 第 k 层 `W` 的形状是 `(本层神经元数, 上一层神经元数)`：行对应本层神经元，列对应上一层输入 |
| 5 | 参数量 | 每层 `n_in × n_out` 个权重 + `n_out` 个 bias；784-256-128-10 共 235,146 个参数 |
| 6 | sigmoid | `σ(z) = 1/(1+e^(−z))`，值域 (0,1)，`σ(0)=0.5`，处处可导；权重很大时近似阶跃函数 |
| 7 | 非线性的必要性 | 没有激活函数，多层线性变换叠加仍是一个线性变换，只能画直线 |
| 8 | 万能逼近定理 | 单隐藏层 + 足够多神经元 + 非线性激活可以任意精度逼近连续函数；但它不保证能"学到"，实践中更深的网络参数效率更高 |
| 9 | 结构 ≠ 能力兑现 | 结构决定能表示什么，权重决定实际做什么：随机权重的 2-8-1 网络在圆分类上只有 17.5% 准确率，需要反向传播来学 |

## 五、参考答案与解析

### Q1 — 答案：B

本节约定 `W` 的形状是 `(本层神经元数, 上一层神经元数) = (3, 5)`，每一行是一个神经元对 5 个输入的权重，`W·x` 得到 3 维输出。代码里 `Layer.__init__` 的列表推导外层 `for _ in range(n_neurons)`、内层 `for _ in range(n_inputs)` 正是这个形状。A 是"行向量 × 矩阵"（`x·W`）约定下的形状，也有框架这样存（例如很多 NumPy 教程、Keras 的 `kernel`），但不是本节代码的约定。

### Q2 — 答案：C

逐层计算：
- 784→256：`784×256 + 256 = 200,960`
- 256→128：`256×128 + 128 = 32,896`
- 128→10：`128×10 + 10 = 1,290`

合计 235,146，与 DEMO 4 的输出一致。B（234,752）只算了权重忘了 bias；A 是神经元个数之和；D 是 784-512-256-128-10 的参数量。

### Q3 — 答案：B

`W2(W1·x + b1) + b2 = (W2W1)·x + (W2b1 + b2)`，其中 `W2W1` 形状为 `(1, 2)`，整个网络等价于一个 2 输入 1 输出的线性模型（再加阈值就是感知器），决策边界只能是一条直线，XOR、圆形分类都做不到。隐藏层宽度再大也无济于事——"深度"的表达能力来自层与层之间的非线性。

### Q4 — 答案：C

万能逼近定理是一个**存在性**定理：存在这样一组权重。它**没有**说：怎么找到这组权重（A 错）、需要多少神经元（可能是天文数字）、深层是否更好（B 错）。D 错在"有限个神经元精确表示任何函数"——定理说的是任意精度的**逼近**，而且针对的是（有界区域上的）连续函数。

### Q5 — 答案：B

`σ(20·1 + 20·0 − 10) = σ(10) ≈ 0.99995`，`σ(−10) ≈ 0.00005`：输入的绝对值足够大，sigmoid 就几乎只输出 0 或 1，行为接近感知器的阶跃函数，于是可以照搬上一节"OR + NAND → AND"的思路。D 恰恰相反：饱和区的 sigmoid 导数几乎为 0（`σ'(10) ≈ 4.5e−5`），梯度很小——这正是用大权重初始化会让训练停滞的原因。C 不对，`exp(10)`、`exp(30)` 离溢出还很远。

### Q6 — 答案：B

反向传播计算 `∂L/∂W = δ · 输入ᵀ` 时需要该层前向时的输入（`last_input`），计算激活函数导数 `σ'(z) = a(1−a)` 时需要激活值（`last_output`）。这就是框架在训练时要"保存激活值"、训练显存远大于推理显存的原因。A 不对：它只保存最近一次调用，不是缓存；D 不对：串联只靠 `forward` 的返回值。

### Q7 — 答案：D

sigmoid 的输出恒为正、均值约 0.5，**不以 0 为中心**。这会导致下一层同一个神经元所有权重的梯度符号相同，参数更新只能"之"字形前进，收敛变慢——这是后面要讲的 tanh（以 0 为中心）的动机之一。A、B 正确；C 正确：`σ'(z) = σ(z)(1−σ(z))` 在 `σ = 0.5` 时取最大值 0.25。

### Q8 — 参考答案

(a)
- 输入 `[0,0]`：隐藏层 `z = [−10, 30]` → `Hidden: [0.000045, 1.000000]`；输出 `z = 20·0.000045 + 20·1.0 − 30 ≈ −9.999` → `Output: 0.000045 -> 0`。
- 输入 `[1,1]`：隐藏层 `z = [20+20−10, −20−20+30] = [30, −10]` → `Hidden: [1.000000, 0.000045]`；输出 `z ≈ 20·1.0 + 20·0.000045 − 30 ≈ −9.999` → `Output: 0.000045 -> 0`。

（对照：`[0,1]`、`[1,0]` 的隐藏层都是 `[0.999955, 0.999955]`，输出 `z ≈ 9.998` → `0.999955`。）

(b) 隐藏神经元 1：`20x1 + 20x2 − 10`，至少一个输入为 1 时为正 → **OR**；隐藏神经元 2：`−20x1 − 20x2 + 30`，只有两个都为 1 时为负 → **NAND**；输出：`20h1 + 20h2 − 30`，两个都为 1 时为正 → **AND**。合起来 `XOR = OR AND NAND`，和上一节完全相同，只是把阶跃换成了"放大版"sigmoid。

(c) 隐藏层 `2×2 + 2 = 6`，输出层 `2×1 + 1 = 3`，共 **9**。

### Q9 — 参考答案

(a) 准确率 = 35/200 = 圆内点数 / 总数，说明网络把**所有 200 个点都预测成了 1**（"在圆内"）。实际检查：这个随机网络在 200 个点上的输出全部落在约 `[0.642, 0.703]` 之间，全部 ≥ 0.5。

(b) 原因：
- 输入在 `[-1, 1]`、隐藏层权重在 `[-1, 1]`、bias 为 0，隐藏层的 `z` 都不大，sigmoid 输出都在 0.5 附近，不同输入之间差异很小；
- 输出层 bias 为 0，`z_out ≈ Σ wⱼ·hⱼ ≈ 0.5·Σ wⱼ`，本例输出层 8 个权重之和约为 1.44，于是 `z_out ≈ 0.72`、`σ ≈ 0.67`，对所有输入都差不多；
- 所以随机网络几乎是一个**常数函数**，整体偏向一边，预测全是同一类。

(c) 全猜 0（"在圆外"）的准确率是 165/200 = 82.5%，远高于随机网络。这说明：类别不平衡时，准确率要和"多数类基线"比较才有意义；还应看 precision / recall / F1 等指标。也印证了讲义的说法："随机权重的准确率往往比猜多数类还差"——结构再好，没训练的网络也没有用。

### Q10 — 参考答案

bug：第一层输出 4 维，第二层却声明 `n_inputs=3`，权重只有 3 列。`forward` 里 `zip(self.weights[neuron_idx], inputs)` 会**静默截断**到较短的长度 3，第 4 个隐藏神经元的输出被直接丢弃，程序照常输出一个数（例如 `[0.46...]`），没有任何报错。这种"不报错但结果错"的 bug 最难排查。

加上形状检查：

```python
class Layer:
    # __init__ 同原代码 ...

    def forward(self, inputs):
        n_in = len(self.weights[0])
        if len(inputs) != n_in:
            raise ValueError(
                f"Layer expects {n_in} inputs, got {len(inputs)}"
            )
        self.last_input = inputs
        self.last_output = []
        for neuron_idx in range(len(self.weights)):
            z = sum(w * x for w, x in zip(self.weights[neuron_idx], inputs, strict=True))
            z += self.biases[neuron_idx]
            self.last_output.append(sigmoid(z))
        return self.last_output
```

要点：①在入口处比较输入长度和权重列数，报错信息里写清楚"期望多少、实际多少"；②Python 3.10+ 的 `zip(..., strict=True)` 在长度不一致时直接抛 `ValueError`，是另一道保险；③还可以在 `Network.__init__` 里预先检查相邻两层 `len(layers[k].weights) == len(layers[k+1].weights[0])`，在构建时就发现问题。PyTorch 的 `nn.Linear` 在形状不匹配时会直接报错，正是这个思路。

### Q11 — 参考回答要点

- 线性层叠加：`h = W1x + b1`，`y = W2h + b2 = (W2W1)x + (W2b1 + b2) = W'x + b'`。无论叠多少层，整体仍是**一个**仿射变换，决策边界还是超平面，等价于单层模型。
- 非线性激活打破这种可合并性，让每层都能对空间做"弯折"：第一层把输入映射到新特征空间，后面的层在新空间里再划分，最终得到弯曲的决策边界（XOR、圆）。
- 万能逼近定理的前提也正是激活函数**非多项式**（如 sigmoid、ReLU）。
- 加分点：ReLU 是分段线性的，但整体仍然非线性——ReLU 网络是"分段线性函数"，片数随深度指数增长；常见误区是以为"ReLU 是线性的所以没用"。

### Q12 — 参考回答要点

- 说了什么：单隐藏层、足够多神经元、非多项式的激活函数（Cybenko 证明了 sigmoid 型；后来 Hornik 等推广到更一般的激活）的前馈网络，可以在紧集上以任意精度逼近任意连续函数。
- 没说什么：
  - 需要多少神经元——可能随精度要求和输入维度指数增长；
  - 如何找到权重——不保证梯度下降能找到，也不保证泛化；
  - 深度是否必要——它只说"宽"就能做到。
- 为什么用深层：
  - **参数效率**：有些函数用深网络只需多项式级别的神经元，用浅网络却需要指数级（深度分离结果）；
  - **层级特征**：深层网络能逐层组合特征（边缘 → 纹理 → 部件 → 物体；字符 → 词 → 短语 → 语义），符合真实数据的组合结构；
  - **泛化与优化**：实践中深而窄的网络往往泛化更好；配合残差连接、归一化，深层网络也能稳定训练。
- 常见误区：把"能表示"当成"能学到"；或者认为"层越多越好"——过深而没有残差/归一化会导致梯度消失、退化。

### Q13 — 参考回答要点

- 批量计算：`nn.Linear` 计算 `Y = X @ Wᵀ + b`，`X: (B, d_in)`，`W: (d_out, d_in)`，`Wᵀ: (d_in, d_out)`，输出 `Y: (B, d_out)`；`b: (d_out,)` 通过广播加到每一行。一次矩阵乘法同时处理整个 batch，GPU 上高度并行，远快于逐样本、逐神经元的 Python 循环。
- 更高维输入：`nn.Linear` 只作用于最后一维，`(B, T, d_in)` → `(B, T, d_out)`，这就是 Transformer 中对每个 token 独立做投影的方式。
- 为什么存成 `(out, in)`：与数学写法 `y = Wx` 一致（行 = 输出神经元），与本节 `Layer.weights` 的约定相同；每一行是一个输出神经元的完整权重向量，内存上连续，便于按输出神经元做初始化、剪枝等操作。
- 加分点：能指出讲义 mermaid 图中写的 `W1 (2x3)` 是"`x·W`"约定，而表格和代码是"`W·x`"约定 `(3, 2)`——两种约定都存在，读代码时一定先确认是哪一种。

### Q14 — 参考回答要点

- 原则：**先写出每一层期望的形状**，再对照实际形状。讲义说"跟踪维度是深度学习中最重要的调试技能"。
- 方法：
  1. 在 `forward` 里逐层打印 `x.shape`（或用 `torchinfo.summary` 一类工具），找到第一处与预期不符的层；
  2. 区分 batch 维和特征维：最常见的错误是忘了 batch 维、或者 `(B, C, H, W)` 展平后的维度算错；
  3. 检查转置：`x @ W` 还是 `W @ x`；
  4. 警惕"不报错的错误"：广播、`zip` 截断、`view` 和 `reshape` 打乱维度顺序等，都可能让形状"看起来对"但语义错误——这类问题要用 assert 显式检查；
  5. 用一个极小的输入（batch=2、特征维度各不相同的数字）做单元测试，不同维度用不同数字，错位一眼就能看出来。
- 加分点：使用 shape 注释（如 `# (B, T, D)`）或类型工具（如 jaxtyping）把形状写进代码；在模型构建阶段而不是运行到一半才检查。

### Q15 — 参考回答要点

- 一个合理的起点：`20 → 64 → 32 → 1`，隐藏层用 ReLU（或 GELU），输出层 1 个神经元 + sigmoid（训练时用 `BCEWithLogitsLoss`，直接输出 logit 更数值稳定）。
- 参数量：`20×64+64 = 1,344`，`64×32+32 = 2,080`，`32×1+1 = 33`，合计约 3,457。5 万样本对这个规模绰绰有余，过拟合风险可控。
- 考虑点：
  - 输入要标准化（均值 0、方差 1），否则 sigmoid / tanh 容易饱和；
  - 输出层与任务匹配：二分类 1 个 sigmoid；多分类 K 个 logit + softmax；回归线性输出；
  - 宽度先小后大，用验证集调；加 Dropout / weight decay / early stopping 防过拟合；
  - 表格数据上 GBDT（XGBoost/LightGBM）往往是很强的基线，MLP 不一定胜出，要先和它比较。
- 常见误区：一上来就堆很深很宽的网络；隐藏层用 sigmoid 导致训练慢；忘了特征缩放。
