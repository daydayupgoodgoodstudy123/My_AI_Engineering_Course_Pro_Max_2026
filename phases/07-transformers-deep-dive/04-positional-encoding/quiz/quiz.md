## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | attention 不知道顺序 | 打乱 X 的行，输出行被同样打乱（置换等变）；对语言、代码、音频这类"顺序即含义"的数据是致命的 |
| 2 | 正弦绝对位置编码 | `PE[pos,2i] = sin(pos/10000^(2i/d))`、`PE[pos,2i+1] = cos(...)`，在第一层前加到 embedding 上；无参数，但超过训练长度外推差 |
| 3 | 多频率 | 第 i 对维度的波长是 `2π·10000^(2i/d)`：低维变化快（精细位置），高维变化慢（粗粒度位置） |
| 4 | 可学习绝对位置 | GPT-2/GPT-3、BERT 用一张可学习的位置表，完全不能外推到表长之外 |
| 5 | RoPE | 把 Q、K 的每对维度 `(2i, 2i+1)` 旋转 `pos·θ_i`，`θ_i = base^(-2i/d)`；旋转是按绝对位置做的，但点积只依赖相对距离 `m − n` |
| 6 | RoPE 的 base | base 越大旋转越慢、波长越长；NTK-aware、YaRN、LongRoPE 等都是在调整 base 或各频率的缩放，用于扩展上下文 |
| 7 | ALiBi | 不碰 embedding，直接在分数上加 `-m_h·|i−j|`；每个头一个斜率（`m_h = 2^(-8h/H)`），距离越远惩罚越大，外推性能好 |
| 8 | 2026 年的格局 | 主流开源模型几乎都用 RoPE（Llama、Qwen、Mistral、DeepSeek-V3 等）；ALiBi 见于 BLOOM、MPT 等；正弦已成为历史 |
| 9 | 长上下文扩展 | 位置插值（PI）、NTK-aware、YaRN、LongRoPE；超过训练长度较多时通常需要一段长上下文微调，并用 NIAH 等测试验证 |

## 五、参考答案与解析

### Q1 — 答案：B

self-attention 是**置换等变**的：输入行被置换 P，输出就是 `P × 原输出`。所以每个 token 得到的表示与它在序列中的位置无关，只是输出行的顺序跟着变。对模型来说"The cat sat on the mat"和"mat the on sat cat the"是同一袋 token。D 错：embedding 只编码"是什么 token"，不包含"在哪里"。

### Q2 — 答案：B

第 i 对维度的角频率是 `1/10000^(2i/d)`，波长 `2π·10000^(2i/d)`。i = 0 时波长 2π ≈ 6.28（每 6 个位置左右转一圈）；最后一对 i = 255 时 `2i/d = 510/512`，波长接近 `2π × 10000 ≈ 62832`。这种几何级数分布的频率让编码既能区分相邻位置（高频），又能区分相距很远的位置（低频）。

### Q3 — 答案：B

RoPE 在**每一层**的 attention 内部旋转 Q 和 K，因为位置信息只需要进入打分 `q·k`；V 是"被取走的内容"，旋转它会把位置相位混进输出表示，并没有好处。A 是正弦/可学习绝对编码的做法；D 更接近 ALiBi（但 ALiBi 加在 softmax 之前）。

### Q4 — 答案：B

二维旋转矩阵满足 `R(mθ)ᵀ R(nθ) = R((n−m)θ)`，所以 `(R_m q)·(R_n k) = qᵀ R_{n−m} k`，只依赖相对距离。代码实测四对 gap = 2 的点积都是 `-6.530165`（甚至 `(0, 2)` 也是）。这个性质与 base、维度无关（C、D 错），只要求 q、k 用同一个 `apply_rope` 和同一个 base。

### Q5 — 答案：B

`2^(-8(h+1)/8) = 2^-(h+1)`，h = 0..7 得到 `0.5, 0.25, 0.125, …, 0.0039`（即 1/256）。这是一个几何级数：斜率大的头强烈偏好近处 token（局部头），斜率小的头几乎不受距离影响（全局头）。代码里 4 个头的斜率为 `0.25, 0.0625, 0.0156, 0.0039`。

### Q6 — 答案：B

`θ_i = base^(-2i/d)`，base 越大 θ 越小，旋转越慢，同一相位要更长的距离才会"绕回"，所以大 base 常用于长上下文（讲义："larger base = slower rotation"）。注意 i = 0 时 `base^0 = 1`，第 0 对维度永远以每位置 1 弧度旋转，与 base 无关——这也是为什么 `demo_rope_base_scaling` 中 base 增大到 100 万，分数也不会回到未旋转时的 `q·k`。D 错：改 base 会改变模型在训练时见过的所有角度，通常需要微调适配。

### Q7 — 答案：D

ALiBi 把 `-m·|i−j|` 加在 **softmax 之前**的分数上（讲义公式：`attn_score[i,j] = q_i·k_j/√d − m_h·|i−j|`），这样 softmax 后近处 token 的权重被相对放大，且整行仍然归一化。若加在 softmax 之后，权重和就不再为 1，也可能变成负数。A、B、C 都正确。

### Q8 — 参考答案

(a) `pos = 0` 时所有 `theta = 0`，`sin(0) = 0`、`cos(0) = 1`，所以偶数维全是 0，奇数维全是 1。

(b) `dim 2` 属于第 i = 1 对，`θ = pos / 10000^(2/8) = pos / 10`。`sin(x) ≈ x` 在 x 较小时成立，所以 `sin(0.1) ≈ 0.100`、`sin(0.2) ≈ 0.199`、`sin(0.3) ≈ 0.296`，看起来每步加 0.1。它的波长是 `2π × 10 ≈ 62.8` 个位置，比第 0 对（波长 2π）慢 10 倍。

(c) `pos = 5`：`sin(5) ≈ -0.959`、`cos(5) ≈ 0.284`、`sin(0.5) ≈ 0.479`、`cos(0.5) ≈ 0.878`，即 `[-0.959, 0.284, 0.479, 0.878]`（已用代码验证）。

(d) 对一对维度 `(sin(pω), cos(pω))`，利用和角公式：

```text
sin((p+k)ω) =  cos(kω)·sin(pω) + sin(kω)·cos(pω)
cos((p+k)ω) = -sin(kω)·sin(pω) + cos(kω)·cos(pω)
```

即 `[sin, cos]ᵀ_{p+k} = M(k) · [sin, cos]ᵀ_p`，其中 `M(k) = [[cos kω, sin kω], [−sin kω, cos kω]]` 只依赖 k。这是原论文选择正弦的动机之一：模型"有可能"通过线性变换学会相对位置。但这个性质只在 PE 本身上成立；PE 加到 embedding 之后再经过投影，相对关系并不会直接体现在 `q·k` 中——RoPE 正是把这个思想直接做进了点积。

### Q9 — 参考答案

(a) 设 `q' = R(mθ)q`、`k' = R(nθ)k`，展开：

```text
q'·k' = cos((m−n)θ)·(a₁b₁ + a₂b₂) + sin((m−n)θ)·(a₁b₂ − a₂b₁)
```

两项都只含 `m − n`，所以对每一对维度、进而对总和，点积只依赖相对距离。（用 `a = (0.3, −1.2)`、`b = (0.7, 0.5)`、`m = 3, n = 5, θ = 1` 数值验证：`apply_rope` 结果 `-0.7379`，与上式一致；只保留 cos 项会得到 `0.1623`，不一致。）

讲义的说法**不完整**：点积并不是简单地"乘上一个 `cos((m−n)θ_i)` 因子"，还有一个与 `sin((m−n)θ_i)` 相乘的"叉积"项 `a₁b₂ − a₂b₁`。正是这个 sin 项让 RoPE 能区分"在前 2 个位置"和"在后 2 个位置"——如果只有 cos 项，`m − n = 2` 和 `m − n = −2` 就无法区分了。

(b) 不相同。只旋转 q 时，点积是 `qᵀ R(−pos_q·θ) k`，依赖 q 的绝对位置。实测 `(3, ·)`、`(7, ·)`、`(100, ·)` 分别得到 `-5.94`、`3.66`、`-2.41`。这是实现 RoPE 时最常见的 bug 之一。

(c) 不会。gap 变成 −2，展开式中 `sin((m−n)θ)` 项变号，实测为 `-2.3199`。RoPE 编码的是**有方向**的相对位置。

### Q10 — 参考答案

(a) `n_heads = 2` 时斜率为 `2^(-4) = 0.0625` 和 `2^(-8) ≈ 0.0039`。head 0（causal）：

```text
[[-0.0,    -inf,    -inf,    -inf],
 [-0.0625, -0.0,    -inf,    -inf],
 [-0.125,  -0.0625, -0.0,    -inf],
 [-0.1875, -0.125,  -0.0625, -0.0 ]]
```

`j > i` 的位置是 `-inf`，相当于把因果 mask 合并进了偏置；对角线是 `-0.0`（`-m * 0` 在浮点中是负零，打印出来是 `-0.00`，数值上等于 0）。

(b) 实测：

| slope | 对 key 0..5 的权重 |
|-------|------------------|
| 0.25 | `[0.082, 0.105, 0.134, 0.173, 0.222, 0.285]` |
| 0.0039 | `[0.165, 0.166, 0.166, 0.167, 0.168, 0.168]` |

斜率大的头明显偏向最近的 token（局部 / n-gram 类信息），斜率小的头几乎均匀（全局信息）。ALiBi 用一组几何级数的斜率，让不同头天然覆盖从局部到全局的不同"感受野"，而且这个偏好与序列长度无关，所以外推时行为平滑。

(c) 参考实现：

```python
import math

def attention_with_alibi(scores, bias_h):
    n = len(scores)
    weights = []
    for i in range(n):
        row = [scores[i][j] + bias_h[i][j] for j in range(n)]   # softmax 之前相加
        m = max(row)                                            # 对角线不是 -inf，m 有限
        exps = [math.exp(v - m) for v in row]                   # exp(-inf) = 0.0
        s = sum(exps)
        weights.append([e / s for e in exps])
    return weights
```

要点：偏置必须在 softmax **之前**相加；如果用 `causal=True` 的偏置，被 `-inf` 屏蔽的位置自然得到 0 权重。

### Q11 — 参考回答要点

- **为什么需要**：attention 对输入顺序置换等变，本身不知道位置；顺序承载含义的数据必须显式注入位置信号。
- **四种方案**：

| 方案 | 做法 | 优点 | 缺点 | 代表 |
|------|------|------|------|------|
| 正弦绝对 | 固定 sin/cos 加到 embedding | 无参数、实现简单 | 外推差，相对位置不直接进入点积 | 原始 Transformer |
| 可学习绝对 | 可训练位置表 | 灵活 | 超过表长完全不可用 | GPT-2、GPT-3、BERT |
| RoPE | 按位置旋转 Q、K | 相对位置直接进入点积；不改结构；base 可调用于扩展上下文 | 超长外推仍需缩放 + 微调 | Llama、Qwen、Mistral、DeepSeek-V3 |
| ALiBi | 分数上加 `-m_h·|i−j|` | 无 embedding、零额外参数、外推好 | 强制的距离衰减先验，可能限制远距离精确检索 | BLOOM、MPT |

- **加分点**：指出 RoPE 胜出的原因（讲义："slots into attention without changing the architecture, encodes relative position, and its base hyperparameter gives a clean knob"）；能提到 T5 的相对位置偏置作为另一条路线。
- **常见误区**：说"BERT 用正弦编码"——BERT 用的是可学习的绝对位置 embedding。

### Q12 — 参考回答要点

- **推导**：把 d 维向量看成 d/2 个二维平面（或 d/2 个复数）。第 i 个平面上 `q'_m = R(mθ_i) q`、`k'_n = R(nθ_i) k`。旋转矩阵是正交的且 `R(α)ᵀR(β) = R(β − α)`，于是 `q'_m · k'_n = qᵀ R((n−m)θ_i) k`，只依赖 `n − m`。用复数写更简洁：`Re[(q·e^{imθ}) · conj(k·e^{inθ})] = Re[q·conj(k)·e^{i(m−n)θ}]`。
- **为什么不旋转 V**：位置只需要影响"谁关注谁"（打分），不需要改变"取走什么内容"；旋转 V 会让输出携带位置相位，下游层还要再学会"反旋转"，没有收益。
- **其他性质**：旋转保持向量模长不变；多频率设计让不同维度负责不同距离尺度；RoFormer 论文还讨论了随相对距离增大的远程衰减特性。
- **加分点**：指出 RoPE 在**每一层**都作用（不像正弦只在输入层加一次）；与 KV cache 配合时，K 在写入 cache 前就已经按其绝对位置旋转好，后续无需重算。

### Q13 — 参考回答要点

- **直接外推的问题**：4K 以外的位置会产生训练时从未见过的旋转角（尤其是低频维度会进入新的相位区间），attention 分数分布异常，困惑度通常急剧上升，长距离检索失败。
- **位置插值（PI）**：把位置按扩展倍数等比缩小（`pos' = pos × 4K/32K`），让所有角度都落回训练范围；需要少量长文本微调（讲义：1–5B tokens 量级）。缺点：高频维度也被压缩，相邻 token 的区分度下降。
- **NTK-aware**：不缩位置，而是放大 base：`base' = base · s^(d/(d−2))`，效果是高频维度几乎不变、低频维度被拉伸——兼顾局部分辨率与长程范围；可在不微调时就有一定效果。
- **YaRN**：按频率分段处理（高频外推、低频插值、中间平滑过渡），并调整 attention 温度以保持长序列下的 attention 熵；配合微调效果更好。
- **LongRoPE**：用搜索为每个维度挑选缩放因子（讲义提到 Phi-3 长上下文版本使用）。
- **加分点**：强调必须用 NIAH（大海捞针）和长文档困惑度在**完整目标长度**上验证；配套 skill 也要求超过 8× 训练长度必须有微调阶段。

### Q14 — 参考回答要点

- **两种配对**：
  - 相邻交错：`(x₀, x₁), (x₂, x₃), …`，本节 `apply_rope` 和 RoFormer 论文的写法；
  - `rotate_half`：前半与后半配对 `(x_i, x_{i+d/2})`，实现上把向量切成两半，`x·cos + rotate_half(x)·sin`，向量化更方便，HuggingFace 的 Llama 等实现采用这种方式。
- **数学上等价**：两者都是"把 d 维拆成 d/2 个平面分别旋转"，只是"哪两维算一个平面"的约定不同，相当于对 Q、K 的维度做了一次固定置换。
- **混用的后果**：权重是在某一种配对下训练的，换成另一种配对后，被一起旋转的维度不再是训练时的那两个，模型输出会严重劣化，而且**不会报错**。所以权重转换脚本需要对 `W_q`、`W_k` 的输出维度做相应的置换（HF 的 Llama 转换脚本就有这一步）。
- **加分点**：能主动提出"上线前用一个固定输入对比两个实现的 logits"这类回归测试。

### Q15 — 参考回答要点

- **方案**：
  1. 选扩展方法：64K / 8K = 8 倍，用 YaRN 或 NTK-aware（调整 base / 分频率缩放），或 PI；配套 skill 的规则是超过 8× 必须有微调，8× 处于临界点，稳妥起见也安排长上下文继续训练。
  2. 长上下文继续训练：混合真实长文档（书籍、代码仓库、长报告）与原分布短数据，避免短上下文能力退化；token 量参考讲义"1–5B tokens"的量级。
  3. 工程配套：Flash Attention（prefill 的 N² 显存）、GQA / KV cache 量化 / PagedAttention（decode 的 cache 显存），见第 03、12 节。
- **资源预估思路**：按第 03 节的公式算 64K 下每序列 KV cache；按"训练 token 数 × 每 token FLOPs"估算继续训练成本。
- **验证计划**：NIAH 在 8K、16K、32K、64K 各长度和不同插入深度的通过率；长文档困惑度不应明显劣于 8K 基线；短上下文基准（原有评测集）回归测试；真实业务样本的端到端评测。
- **回退方案**：评测不达标时，限制线上最大上下文（如 32K）、增大 base 重训、或采用 RAG 等检索手段缩短输入。
- **常见误区**：只改配置里的 `max_position_embeddings` 不做任何缩放与验证。
