## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 为什么直接参数化策略 | `argmax Q` 处理不了连续动作，也给不出随机策略；策略梯度直接对 `J(θ) = E_{π_θ}[G]` 做梯度上升 |
| 2 | 策略梯度定理 | `∇J(θ) = E_τ[Σ_t G_t · ∇_θ log π_θ(a_t\|s_t)]`，只需采样轨迹，不需要环境模型 |
| 3 | log-derivative 技巧 | `∇P(τ;θ) = P(τ;θ)∇log P(τ;θ)`；`log P(τ)` 中环境转移项与 θ 无关，求导后消失 |
| 4 | 基线（baseline） | 用 `G_t − b(s_t)` 代替 `G_t`；只要 b 不依赖 `a_t` 就无偏，因为 `E[b·∇log π] = 0` |
| 5 | Reward-to-go | 动作只影响它之后的奖励，用"从 t 开始的回报"代替整条轨迹的总回报，方差更低 |
| 6 | softmax 策略梯度 | `∇_z log π(a\|s) = e_a − π(·\|s)`（one-hot 减概率），这是离散策略梯度的核心公式 |
| 7 | 高斯策略 | 连续动作用 `N(μ_θ(s), σ_θ(s))`，`∇log N` 有闭式解 |
| 8 | 常见病 | 方差大、梯度爆炸（需归一化回报）、熵塌缩（加熵奖励）、on-policy 样本效率低 |
| 9 | 与 LLM RL 的关系 | `loss = −advantage · log_prob` 就是带基线的 REINFORCE；PPO、GRPO、RLOO 都是在它上面的方差控制 |

### 核心技能（能动手做到）

- [ ] 能实现滑动平均基线，并说清它为什么不引入偏差（以及什么写法会引入偏差）
- [ ] 能识别并修复"策略塌缩到确定性坏动作、梯度消失"的失败模式（降学习率 / 归一化回报）
- [ ] 能写出熵奖励对 logits 的梯度 `∂H/∂z_i = −π_i(log π_i + H)`
- [ ] 能把 REINFORCE 与 Actor-Critic、PPO、GRPO 的关系讲清楚

## 五、参考答案与解析

### Q1 — 答案：B

DQN 需要对动作取 `argmax`，7 维连续动作空间无法枚举；策略梯度可以让网络直接输出高斯分布的均值和方差，从中采样连续动作。讲义："which argmax over a 10-dimensional torque?" A、C 用表格 Q-learning 即可；D 与方法选择无直接关系。

### Q2 — 答案：B

`p(s₀)` 和 `P(s_{t+1}|s_t,a_t)` 由环境决定、与 θ 无关，求导为 0。剩下的只有 `Σ_t ∇log π_θ(a_t|s_t)`，策略是我们自己的网络，梯度能算。所以策略梯度是 model-free 的：只要能采样轨迹即可，环境可以是随机的（A 错）。

### Q3 — 答案：D

基线无偏的条件是**不依赖于当前动作** `a_t`：`E_a[b(s)∇log π(a|s)] = b(s) Σ_a ∇π(a|s) = b(s)∇Σ_a π(a|s) = b(s)∇1 = 0`。若 b 依赖 a_t，这一步就不成立。A、B、C 都只依赖状态（或与当前动作无关），都合法。注意 B 中"只用过去的回合"——若把**当前回合**的回报也混进基线再算优势，严格说会引入少量偏差。

### Q4 — 答案：B

`∇_z log π(a|s) = e_a − π = [0,1,0,0] − [0.1,0.6,0.2,0.1] = [-0.1, 0.4, -0.2, -0.1]`。直觉：增大采样到的动作的 logit，按概率比例减小其他动作的 logit；各分量之和为 0。讲义："Burn it into muscle memory."

### Q5 — 答案：B

`G_0 = (t 之前的奖励) + γ^t G_t`。t 之前的奖励在给定 `s_t` 后与 `a_t` 无关，它与 `∇log π(a_t|s_t)` 的乘积期望为 0（同 Q3 的基线论证），去掉后估计仍然无偏，却少了一大块噪声。讲义："past rewards contribute zero-mean noise."

### Q6 — 答案：B

策略梯度定理中的期望是对当前策略 π_θ 的轨迹分布取的，θ 一变，旧数据就"过期"了。讲义 Pitfalls："On-policy means you throw away every transition after one update… (PPO's ratio is a clipped IS weight)."

### Q7 — 答案：B

讲义 Use It 表："GRPO — REINFORCE with group-relative baseline, no critic"。对同一个 prompt 采样一组回答，用组内奖励的均值（通常再除以标准差）作基线，省掉了与 LLM 同规模的价值网络。

### Q8 — 参考答案

(a) **等价。** 每一步的更新量 `lr · adv · (e_a − probs) · x` 只依赖 rollout 时记录的 `probs`、`x`、`a`，以及预先算好的 `G`——都**不依赖**当前正在被修改的 `theta`。所以逐步加上去与先求和再一次性加上去结果完全相同，都是"在 θ_old 处计算的整条轨迹梯度"做一次梯度上升。如果代码在循环里用最新的 `theta` 重新计算 `probs`，就不再等价了。

(b) 关键在于"压低多少"不同：
- 越长的回合，前面步骤的 `G_t` 越负（例如走了 50 步的回合，第一步 G ≈ -39），压低的幅度越大；短回合（最优 6 步，G ≈ -5.85）压低得很少。
- softmax 是归一化的：压低被采样动作的 logit，等于相对抬高其他动作（`e_a − π` 中其他分量为负的 π_i，乘以负的 adv 后变为正）。
- 结果：导致长回合的动作被狠狠压低，导致短回合的动作只被轻轻压低，**相对而言**好动作的概率在上升。
- 这也说明了基线的价值：减去一个合适的基线后，好于平均的动作会被**主动抬高**，信号更清楚。但"全负回报 + 大学习率"也是一种危险组合，见 Q10。

### Q9 — 参考答案

(a) 不可能超过最优，是**口径不一致**：`returns_log` 记录的是 `returns[0]`，即 γ=0.99 的**折扣**回报；而 "-6.0" 是**未折扣**的最短步数。最优路径 6 步的折扣回报是 `-(1 + 0.99 + … + 0.99⁵) ≈ -5.85`。所以 -5.88 / -5.90 只是"非常接近最优的 -5.85"，比较基准应写 -5.85（或者把日志改成记录未折扣回报）。

(b) 训练后期策略几乎确定地沿 `(0,0)→(0,1)→(0,2)→(1,2)→(1,3)→(2,3)→终点` 这条路走，`(3,2)` **几乎从未被访问**。它的参数基本停留在初始化附近（`init_theta` 用 `N(0, 0.1)`），四个动作的概率都接近 0.25，argmax 只是在初始化噪声中挑出的最大值。这不影响从起点出发的回报，但如果起点改变（或环境有随机性把智能体推到那里），策略就会表现很差。这与 MC 控制（第 03 节）的现象相同：on-policy 方法只在**策略会访问的状态**上可靠。

### Q10 — 参考答案

(a) 回合上限是 `max_steps=100`。一直撞墙、到不了终点时，100 步每步 -1，折扣回报为 `-(1 − 0.99¹⁰⁰)/(1 − 0.99) ≈ -63.4`。

(b) 在 `(0,0)` 选 `up` 撞墙，留在原地，一直重复。每一步的梯度 `e_up − π`：`π(up)` 约为 0.99999，所以对 up 的 logit 的梯度约为 `1 − 0.99999 ≈ 10⁻⁵`，对其他 logits 的梯度约为 `−π_i ≈ −10⁻⁶`。虽然 adv ≈ −63 很大，乘上去仍然微乎其微——softmax **饱和**导致梯度消失，策略被"冻结"在一个确定性的坏动作上。

它是怎么进去的：训练初期回报的量级达到几十，`lr · |adv| ≈ 0.05 × 60 = 3`，一次更新就能让 logit 跳 3 左右；几个回合内某个动作的 logit 被推得远高于其他动作（这里是 11.3），softmax 立刻饱和。这正是讲义 Pitfalls 中"梯度爆炸"和"熵塌缩"两条叠加的结果。

(c) 修复：
- **降学习率**（实测 `lr=0.01`：10/10 收敛，约 250–550 回合，与讲义"约 500 回合"一致）；
- **回报归一化**（讲义："Always normalize G to ~N(0, 1)"；实测 10/10 收敛，但更慢）；
- 加合适的基线、梯度裁剪、用 PPO 式的信任域限制每次更新的幅度。

熵奖励救不回来的原因：熵对 logits 的梯度 `∂H/∂z_i = −π_i(log π_i + H)`，当 π 接近 one-hot 时 H ≈ 0、π_i ≈ 0 或 1，梯度同样趋于 0——熵奖励也被 softmax 饱和"冻住"了。它擅长**预防**塌缩（在策略还有一定随机性时把它往均匀拉），而这里每次更新的步子（约 3）远大于 β 带来的修正，塌缩在几个回合内就完成了。

### Q11 — 参考答案

推导：`H = −Σ_j π_j log π_j`，`∂π_j/∂z_i = π_j(δ_ij − π_i)`，

```
∂H/∂z_i = −Σ_j (∂π_j/∂z_i)(log π_j + 1)
        = −Σ_j π_j(δ_ij − π_i)(log π_j + 1)
        = −[π_i(log π_i + 1) − π_i Σ_j π_j(log π_j + 1)]
        = −π_i[(log π_i + 1) − (−H + 1)]
        = −π_i (log π_i + H)
```

代码（在原更新循环中加入熵项）：

```python
        for (x, a, _r, probs), G in zip(traj, returns):
            adv = G - (baseline if use_baseline else 0.0)
            H = -sum(p * math.log(p + 1e-12) for p in probs)
            for i in range(N_ACTIONS):
                grad = (1.0 if i == a else 0.0) - probs[i]
                grad_H = -probs[i] * (math.log(probs[i] + 1e-12) + H)   # ∂H/∂z_i
                for j in range(N_FEAT):
                    theta[i][j] += lr * (adv * grad + beta * grad_H) * x[j]
```

要点：
- 熵项是**确定性**的（不需要采样动作 a），对所有动作都有梯度：概率高于"平均水平"的动作（`log π_i > −H`）被压低，概率低的被抬高，把分布往均匀方向拉。
- `+ 1e-12` 防止 `log(0)`。
- β 的大小要与优势的量级匹配：本环境优势量级可达几十，β=0.01 几乎没有作用；通常先把优势归一化，再设 β ≈ 0.01。讲义练习 3 让你扫 `β ∈ {0, 0.01, 0.1, 1.0}` 找最佳点——β 太大，策略会一直接近随机，回报变差。

### Q12 — 参考回答要点

- **目标**：`J(θ) = E_{τ∼π_θ}[G(τ)] = Σ_τ P(τ;θ) G(τ)`。
- **推导**：
  1. `∇J = Σ_τ ∇P(τ;θ) G(τ) = Σ_τ P(τ;θ) ∇log P(τ;θ) G(τ) = E_τ[∇log P(τ;θ) G(τ)]`（log-derivative 技巧）；
  2. `log P(τ;θ) = log p(s₀) + Σ_t log π_θ(a_t|s_t) + Σ_t log P(s_{t+1}|s_t,a_t)`，环境项与 θ 无关，于是 `∇log P(τ;θ) = Σ_t ∇log π_θ(a_t|s_t)`；
  3. 得 `∇J = E[Σ_t G(τ) ∇log π_θ(a_t|s_t)]`，再用因果性换成 reward-to-go `G_t`。
- **不需要模型**：环境转移在求导中消失，只需从环境采样轨迹、对自己的策略网络求导。
- **加分点**：
  - 指出它是"得分函数（score function）估计器"，与 VAE 中的重参数化技巧是两类梯度估计方法；
  - 严格地说，对折扣目标 `J = E[G_0]`，每一项还应乘以 `γ^t`；实践中（包括本节代码和多数实现）通常省略这一项，等价于优化一个略有不同的目标，换来更大的后期梯度信号。

### Q13 — 参考回答要点

- **方差来源**：`G_t` 累积了整条轨迹上所有动作和转移的随机性；`∇log π` 本身也随采样到的动作变化；两者相乘，噪声很大。讲义："murderous variance"。
- **手段**：
  1. **Reward-to-go**：去掉与当前动作无关的过去奖励；
  2. **基线**：`G_t − b(s_t)`，最常用 `b = V̂(s_t)` → Actor-Critic；
  3. **优势估计**：用 TD 误差或 GAE 代替 MC 回报（偏差-方差折中）；
  4. **回报/优势归一化**、梯度裁剪；
  5. **大批量**：每次更新用更多回合求平均；
  6. **信任域 / 裁剪**（TRPO、PPO）：限制每步策略变化，防止一次坏估计毁掉策略。
- **基线无偏**：`E_{a∼π}[b(s)∇log π(a|s)] = b(s)∇Σ_a π(a|s) = 0`。基线改变的是方差而不是期望。最优的常数基线近似为回报的（梯度范数加权）均值，状态相关的 `V(s)` 通常更好。
- **常见误区**：认为任何"能降方差"的东西都可以当基线——依赖当前动作的量（如 Q(s,a)）不行，除非做额外校正。本节代码的滑动平均基线在算优势**之前**就混入了当前回合的回报（权重 0.05），严格说有轻微偏差；规范写法是先算优势、再更新基线。

### Q14 — 参考回答要点

- **REINFORCE**：`∇J ≈ Σ_t A_t ∇log π(a_t|s_t)`，实现时写成 `loss = −(advantage.detach() * log_prob).mean()`，对 loss 做梯度下降就是对 J 做梯度上升。
- **Actor-Critic / A2C**：学习 `V̂(s)` 作基线，优势用 TD 误差或 GAE 估计（下一节）。
- **PPO**：在 Actor-Critic 基础上，用旧策略的数据训练多轮，引入比值 `r = π_θ/π_old`（重要性权重），并裁剪到 `[1−ε, 1+ε]`，限制每次更新的步长；LLM RLHF 中还加对参考模型的 KL 惩罚（讲义："PPO with KL penalty, running on token-level policy"）。
- **GRPO**：去掉 critic，对同一 prompt 采样 G 个回答，用组内奖励标准化作为优势（组相对基线），保留 PPO 式裁剪与 KL 约束。
- **RLOO**：用"留一法"均值（其他样本的平均奖励）作基线，同样不需要 critic。
- **共同点**：都是 `advantage × ∇log π`，区别只在优势怎么估、更新幅度怎么限制。讲义："Entire papers (DPO, GRPO, RLOO) are variance-reduction tricks on top of this one line."
- **加分点**：指出 DPO 与此路线不同——它不做在线采样，而是从 KL 约束下的最优策略的闭式解出发，把偏好数据上的奖励学习改写成对策略的分类式损失；把它算作 "REINFORCE 的改写" 只是一种宽松的说法。

### Q15 — 参考回答要点

- **诊断**：
  1. 记录每步的策略熵、动作分布、`log π` 的范数、梯度范数；
  2. 看是否在训练早期就出现一次大幅更新（回报量级大、学习率大）导致 softmax 饱和——本节 Q10 就是例子；
  3. 检查优势的量级和符号（全负、未归一化？）；
  4. 检查是否有多步更新复用了过期数据（on-policy 被破坏）。
- **处理**：
  - 优势归一化、降低学习率、梯度裁剪；
  - 熵奖励 `β·H` 预防塌缩（讲义 skill：β=0 且熵 < 0.1 应标记为塌缩）；
  - PPO 式裁剪或 KL 约束限制每次策略变化；
  - 已经饱和时，熵奖励的梯度也会消失，往往需要回滚到检查点、调参后重训。
- **LLM 场景**：熵塌缩表现为输出多样性骤降、重复同一种答案模板；常见对策包括 KL 惩罚、温度、熵相关的正则或裁剪策略调整。

### Q16 — 参考回答要点

| | 基于价值（DQN） | 基于策略（REINFORCE / PG） |
|---|---|---|
| 学什么 | `Q(s,a)`，策略隐含为 `argmax Q` | 直接学 `π_θ(a\|s)` |
| 动作空间 | 离散、规模适中 | 离散、连续都可以 |
| 随机策略 | 不能直接表示（只有 ε-greedy） | 天然支持 |
| 数据效率 | off-policy，可用回放，效率高 | on-policy，效率低 |
| 稳定性 | 致命三角，可能发散 | 梯度无偏但方差大；收敛到局部最优 |
| 收敛性质 | 表格情形收敛到最优 | 平滑地改变策略，小步更新有收敛保证（局部） |

- **选择**：离散动作、可以大量模拟、追求样本效率 → DQN 系列；连续动作、需要随机策略、动作空间巨大（如 LLM 的词表）、需要直接约束策略（KL） → 策略梯度 / Actor-Critic / PPO。
- **加分点**：两条路线在 Actor-Critic 汇合——critic 学价值、actor 学策略；SAC 等方法同时用到 Q 函数和随机策略。
