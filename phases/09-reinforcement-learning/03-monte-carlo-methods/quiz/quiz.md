## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | MC 的核心思想 | 不需要模型，只需要能采样回合：`V^π(s) ≈ (1/N) Σ G⁽ⁱ⁾(s)`，用观测到的回报平均值估计期望 |
| 2 | 反向计算回报 | `G_t = r_{t+1} + γ G_{t+1}`，从回合末尾往前扫一遍，O(T) |
| 3 | First-visit vs every-visit | 前者每回合每个状态只用第一次出现的回报（样本独立、易分析），后者用所有出现（数据更多） |
| 4 | 增量均值 | `V ← V + (1/n)(G − V)`；把 `1/n` 换成常数 α 就能跟踪非平稳目标——这是通往 TD 的关键一步 |
| 5 | 探索问题 | MC 只能看到策略访问过的状态；确定性贪心策略会让大片状态-动作永远没有样本 |
| 6 | 三种探索方案 | exploring starts、ε-greedy、off-policy（重要性采样） |
| 7 | MC 控制 | 采样版的策略迭代：跑回合 → 更新 Q → 对 Q 做 ε-greedy → 重复 |
| 8 | 偏差-方差 | MC 回报无偏但方差大；TD 用自举降低方差、引入偏差；n-step / GAE 在两者之间插值 |
| 9 | 重要性采样 | 权重 `Π π(a\|s)/μ(a\|s)` 沿轨迹连乘，方差随视野爆炸；加权 IS 方差更低 |

def returns_from(trajectory, gamma):

## 五、参考答案与解析

### Q1 — 答案：B

DP 需要对每个 `(s, a)` 查询 `P(s'|s,a)`；MC 只需要 `reset()` 和 `step()`，即"能跑起来"就行。讲义说这是从"已知模型 + 精确备份"到"采样 rollout + 平均回报"的转变：方差变大，但适用范围大大扩展。A 错：表格还是神经网络与此无关；C 错：MC 既能评估也能控制；D 错：MC 有采样误差，DP 在模型已知时是精确的。

### Q2 — 答案：B

γ=1 时各时刻回报：`G₀ = -3`（从第一次访问 A 开始）、`G₁ = -2`（从 B 开始）、`G₂ = -1`（从第二次访问 A 开始）。first-visit 只用第一次出现的 `G₀ = -3`；every-visit 把 `-3` 和 `-1` **作为两个样本**都计入均值（计数加 2）。D 的错误在于把两次合并成一个样本——every-visit 是按访问次数计数的。

### Q3 — 答案：B

常数 α 相当于指数加权移动平均：第 k 个旧样本的权重按 `(1−α)^k` 衰减。当策略在变（MC 控制中 π 不断改进），旧回报来自旧策略，"忘掉"它们才能跟踪当前策略的价值。讲义说这一步"就是从 MC 跳到 TD、再到所有现代 RL 算法的全部跨越"。A 错：常数 α 的估计是有偏的（不是精确平均）；C 不一定；D 错：MC 仍需完整回合，TD 才不需要。

### Q4 — 答案：B

所有动作初始 Q 都为 0，`max` 平局时总是选第一个动作；纯贪心下，只要被选中的动作估计值不低于其他动作，其他动作就永远不被尝试，也就没有样本去更新它们的 Q。讲义 Pitfalls："Greedy MC on a fresh Q with ties will only ever try one action. You must explore."

结合本节 GridWorld 具体看：MC 只在回合**结束后**才更新 Q，所以第一个回合在 `(0,0)` 会一直选 up 撞墙，直到 `max_steps=200` 截断。之后 `Q((0,0), up)` 变成很大的负数，下一回合才会换成 Q 仍为 0 的动作——因为本任务奖励全是 -1，"初始化为 0"恰好是**乐观初始化**，会带来一些被动探索。但这种探索没有保证：一旦某个动作因运气好得到"不太差"的估计、其他动作因运气差被低估，被低估的动作就再也不会被尝试。所以仍然需要 ε-greedy 等主动探索机制。

### Q5 — 答案：B

`P(贪心动作) = (1 − ε) + ε/|A| = 0.9 + 0.1/4 = 0.925`。代码里探索分支用 `local_rng.choice(ACTIONS)` 在**全部**动作中选，也可能选到贪心动作本身。常见误区是答 A（忽略了探索时也可能选中贪心动作）。

### Q6 — 答案：C

每一步的比值是 `π(a|s)/μ(a|s) = 1/(1/4) = 4`，6 步连乘得 `4⁶ = 4096`。只要有一步与 π 不一致，π(a|s)=0，整条轨迹权重为 0。所以普通 IS 的估计由极少数"权重巨大"的轨迹决定，方差极大——这正是讲义说的"方差随视野爆炸"。

### Q7 — 答案：B

MC 用真实的完整回报 `G_t`，它的期望就是 `V^π(s)`（无偏），但它累积了整个回合所有随机性，方差大。TD 目标 `r + γV(s')` 只含一步随机性（方差小），但 `V(s')` 是当前估计、可能不准（有偏）。D 说反了：MC 需要回合能终止。

### Q8 — 参考答案

输出：

```
[-2.71, -1.9, -1.0]
```

反向扫描：从最后一步开始，`G = -1 + 0.9×0 = -1.0`；倒数第二步 `G = -1 + 0.9×(-1.0) = -1.9`；第一步 `G = -1 + 0.9×(-1.9) = -2.71`。

- **为什么反向**：利用递推 `G_t = r_{t+1} + γG_{t+1}`，每一步只需 O(1)，整条轨迹 O(T)。正向计算每个 `G_t` 都要重新求和后续所有奖励，总共 O(T²)。
- **为什么 `reverse()`**：反向扫描时 `append` 的顺序是 `G_{T-1}, …, G_0`，翻转后 `returns[t]` 才与 `trajectory[t]` 对齐，后面才能用 `zip(trajectory, returns)` 配对。`list.reverse()` 原地翻转，不建新列表（讲义版用 `list(reversed(returns))`，效果相同）。

### Q9 — 参考答案

(a) `-39.41` 是**第 01 节**（MDP 小节）用迭代策略评估算出的"均匀随机策略、确定性 GridWorld、γ=0.99"的 `V^π(0,0)`。第 02 节（动态规划）求的是**带滑动的环境中最优策略**的 `V*`，`V*(0,0) ≈ -6.43`。所以注释应为 "from lesson 01"。数值本身是对的——本节环境与第 01 节完全相同（确定性、每步 -1、终点 (3,3)）。

(b) 两个来源：
- **采样误差**：单回合 `G_0` 的标准差约 21，20000 个回合的标准误约 `21/√20000 ≈ 0.15`。换不同随机种子，估计值在 `-39.29 ~ -38.71` 之间波动；种子 1 恰好偏高一些。
- **截断偏差**：`rollout` 在 200 步时强制结束，但被截断的回合**并没有真正终止**，`returns_from` 却把它们当作"后面奖励为 0"处理，于是丢掉了 `γ²⁰⁰ × V(s₂₀₀) ≈ 0.134 × (-37) ≈ -5` 左右的尾部回报。实测约 2% 的回合被截断，带来约 `+0.1` 的系统性偏差（估计偏"乐观"）。

讲义 Pitfalls 正是提醒："If your policy can loop forever, cap `max_steps` … just make sure you count it correctly."

### Q10 — 参考答案

原因：
1. **采样平均 + 非平稳策略**：MC 控制用 `1/n` 的样本平均，所有历史回报权重相同。`(0,2)`、`(0,3)` 的样本主要来自训练**早期**——那时策略还很差，从这里出发的回报很糟（例如 `(0,3)` 处 `Q(up) ≈ -45`）。后来策略变好，但这些状态几乎不再被访问，早期的坏样本"永远留在平均值里"。这正是讲义 Pitfalls 的"Non-stationary policies：sample-average MC does not handle this"。
2. **访问稀少**：最终策略从 `(0,0)` 走 right→down→right→down→right→down，不经过 `(0,2)`、`(0,3)`；只有 ε=0.1 的探索偶尔把智能体带到那里，样本少、方差大。
3. 贪心策略只在**策略会访问的状态**上可靠——对 MC 控制来说，"路径外"状态的箭头本来就没人保证。

改进方法（任选两种以上）：
- 用常数 α 代替 `1/n`，让旧样本逐渐被遗忘；
- 用 exploring starts（每回合从随机的 `(s, a)` 出发），保证所有状态-动作都有足够样本；
- 适当增大 ε 或采用先大后小的 ε 衰减（GLIE），前期多探索、后期收敛；
- 增加训练回合数；
- 改用 TD 方法（下一节），用自举让好的价值信息更快"传染"到相邻状态。

### Q11 — 参考答案

```python
import random
from main import ACTIONS, rollout, uniform_policy


def target_action(state):
    """目标策略 π（确定性）：先沿第 0 行向右走到底，再沿最右列向下"""
    _, c = state
    return "right" if c < 3 else "down"


def off_policy_v00(episodes, gamma=0.99, seed=0):
    rng = random.Random(seed)
    num_ordinary = 0.0      # Σ ρ·G
    sum_rho = 0.0           # Σ ρ
    n_match = 0
    mu = 1.0 / len(ACTIONS)            # 行为策略 μ：均匀随机
    for _ in range(episodes):
        traj = rollout(uniform_policy, rng)
        rho, G, discount = 1.0, 0.0, 1.0
        for s, a, r in traj:
            pi = 1.0 if a == target_action(s) else 0.0
            rho *= pi / mu
            if rho == 0.0:
                break                   # 一旦偏离 π，整条轨迹权重为 0
            G += discount * r
            discount *= gamma
        if rho > 0.0:
            n_match += 1
            num_ordinary += rho * G
            sum_rho += rho
    ordinary = num_ordinary / episodes
    weighted = num_ordinary / sum_rho if sum_rho > 0 else float("nan")
    return ordinary, weighted, n_match


for seed in range(3):
    o, w, n = off_policy_v00(20000, seed=seed)
    print(f"seed={seed}: matched={n:2d}  ordinary IS={o:8.2f}  weighted IS={w:6.2f}")
```

实测输出：

```
seed=0: matched= 5  ordinary IS=   -5.99  weighted IS= -5.85
seed=1: matched= 6  ordinary IS=   -7.19  weighted IS= -5.85
seed=2: matched= 4  ordinary IS=   -4.79  weighted IS= -5.85
```

解读：
- 均匀随机策略恰好走出 π 的 6 步路径的概率是 `(1/4)⁶ = 1/4096`，20000 个回合期望只有约 4.9 条"匹配"轨迹，每条权重 4096。
- **普通 IS** = `Σ ρG / N`：结果直接正比于"这次碰巧匹配了几条"，在 -4.79 到 -7.19 之间大幅波动——无偏，但方差大。
- **加权 IS** = `Σ ρG / Σ ρ`：用权重之和归一化，只要有一条匹配，就得到 -5.85。它有偏（样本少时偏向少数轨迹），但方差小得多，实践中更常用。
- 这个例子也说明：目标策略和行为策略差得越远、视野越长，IS 越难用——这就是为什么 DQN 等方法转向不需要整条轨迹 IS 的 Q-learning。

### Q12 — 参考回答要点

| 维度 | DP | MC | TD |
|------|----|----|----|
| 需要模型？ | 需要 `P`、`R` | 不需要，只需完整回合 | 不需要，只需单步转移 |
| 自举（用估计更新估计）？ | 是 | 否，用真实回报 | 是，`r + γV(s')` |
| 偏差 / 方差 | 无采样误差 | 无偏、方差大 | 有偏、方差小 |
| 是否需要回合结束 | 不需要 | 需要 | 不需要，可在线、可用于连续任务 |

- **加分点**：把三者放到一张图里——"宽度"（对所有后继求期望 vs 采样一个）和"深度"（一步自举 vs 一直到回合结束）两个轴；n-step 回报和 GAE 在 MC 与 TD 之间插值，PPO 用的就是 GAE。
- **常见误区**：认为 MC 是"过时"的方法——REINFORCE、PPO 的回报、GRPO 的组内奖励本质都是 MC 估计。

### Q13 — 参考回答要点

- **定义**：一个回合中同一状态出现多次时，first-visit 只用第一次出现之后的回报，every-visit 用每一次出现之后的回报。
- **分析**：first-visit 每个回合对每个状态最多贡献一个样本，不同回合的样本独立同分布，直接用大数定律、标准误 `σ/√n` 分析。every-visit 同一回合内的多个样本彼此相关（后一次访问的回报是前一次回报的一部分），有限样本下有偏，但仍是一致估计。
- **实践**：every-visit 每回合用的数据更多、实现更简单（不用 `seen` 集合），讲义说通常收敛更快；需要严格的统计分析或置信区间时用 first-visit。两者在样本足够多时都收敛到 `V^π`。
- **加分点**：在本节代码中，去掉 `seen` 集合即可变成 every-visit；对 `(0,0)` 而言，20000 个回合会产生十几万个样本（实测约 14.5 万次访问），而 first-visit 只有 20000 个。

### Q14 — 参考回答要点

- **为什么需要**：数据由行为策略 μ 产生，但想评估目标策略 π。两者的轨迹分布不同，需要用 `ρ = Π_t π(a_t|s_t)/μ(a_t|s_t)` 把 μ 下的期望"改写"成 π 下的期望（环境转移概率在比值中相消，所以不需要模型）。
- **普通 IS**：`V = Σ ρᵢGᵢ / N`，无偏，但方差可能极大甚至无穷。
- **加权 IS**：`V = Σ ρᵢGᵢ / Σ ρᵢ`，有偏（渐近无偏），方差小得多，实践首选。
- **方差爆炸**：ρ 是 T 个比值的连乘，视野越长、π 与 μ 差异越大，ρ 的分布越"重尾"——绝大多数轨迹权重接近 0，极少数权重巨大。
- **缓解**：逐决策 IS（per-decision IS，奖励 `r_t` 只乘到 t 为止的比值）、加权 IS、截断/裁剪权重（如 V-trace、Retrace）、改用 TD 类的 off-policy 方法（Q-learning 不需要 IS）。
- **加分点**：PPO 的 `ratio = π_θ/π_old` 也是重要性比值，但只用**单步**比值并做裁剪，正是为了控制方差。

### Q15 — 参考回答要点

- **PPO**：讲义提到优势 `A_t = G_t − V(s_t)` 中的 `G_t` 是 MC 回报（实际常用 GAE，即 MC 与 TD 的插值）。在 LLM RLHF 中，奖励只在序列末尾给出，每个 token 位置的回报本质上就是 MC 回报。
- **GRPO**：对同一个 prompt 采样一组回答，用组内奖励的均值作基线、计算相对优势——这是一种用多次完整 rollout 估计期望的 MC 方法，省掉了价值网络。
- **评估**：讲义"LLM RL evaluation"——对给定策略采样多个补全、平均奖励，就是 MC 策略评估（例如 pass@k、平均奖励分）。
- **MCTS**：AlphaZero 风格的搜索中，从叶子节点做 rollout 估值（MC），用于引导选择。
- **加分点**：指出 LLM 场景天然适合 MC——回合（一次生成）一定会结束、长度有限，γ 取 1，没有"无限回合"问题。

### Q16 — 参考回答要点

- **不严格**：固定 ε=0.1 时，策略永远保留 10% 随机动作，on-policy MC 控制收敛到的是**最优的 ε-soft 策略**（在所有"每个动作至少有 ε/|A| 概率"的策略里最好的那个），而不是真正的 π*；它学到的 Q 也是该 ε-soft 策略的 Q，而不是 Q*。
- **得到 π\* 的条件**：GLIE（Greedy in the Limit with Infinite Exploration）——每个状态-动作对被无限次访问，同时 ε 逐渐衰减到 0（例如 `ε_k = 1/k`）；步长满足 Robbins-Monro 条件（`Σα = ∞`、`Σα² < ∞`）。
- **补充**：本节代码最后的平均回报 -6.54 比最优的 -5.85（γ=0.99 折扣后）更差，一部分正是 ε=0.1 的探索代价——即使 Q 已学好，执行时仍有 10% 的随机动作。
- **加分点**：知道 Sutton & Barto 中提到 MC-ES（exploring starts）的收敛性在一般情况下仍是开放问题；off-policy MC 控制（行为策略 ε-soft、目标策略贪心）可以直接学 π*，但要付出 IS 方差的代价。
