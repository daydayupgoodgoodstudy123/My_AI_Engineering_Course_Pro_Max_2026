# 13/20 分关面试题：GenAITrace

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：agent → LLM → tool → MCP 的 span 层级和整条链共用一个 trace id，CLIENT 与 INTERNAL 的区别，默认关闭、显式开启的内容捕获，`gen_ai.*` 必需属性，讲义列出的三个 GenAI 直方图，经 HTTP 头或 stdio 的 `_meta.traceparent` 跨 MCP 传播，Part 4 给定正确的 traceparent 格式解析器，要求按当前传输注入和提取本次调用的 context，保持原请求和另一载体不变；还包括 OTLP 导出，以及讲义开头那个“有时 30 秒、有时 3 秒，原来是 MCP server 冷启动”的排查。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 10 分钟，Part 2 12 分钟，Part 3 12 分钟，Part 4 14 分钟，Part 5 12 分钟。难度和用时还没有经过实测校准。
- 只改 `genaitrace/` 里的代码。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python 官方文档（json、re、bisect、dataclasses）和[本课讲义](../docs/en.md)。计时期间不要打开 `solution/`、`INTERVIEWER.md`，也不要看本课 `code/`、`quiz/` 和 `coderpad/` 里的内容。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。
- 后面几关会用到前面的代码：Part 3 的指标用的是 Part 1 修好的 agent，Part 4 的导出请求里装的是 Part 2 写的 `to_otlp`。按顺序做就不会碰到问题。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k span_log -x           # 只跑名字里带 span_log 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `genaitrace/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/genaitrace _starter/tests .
```
