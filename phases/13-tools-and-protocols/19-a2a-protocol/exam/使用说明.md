# 13/19 分关面试题：agentcard

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：writer agent 的 `tasks/send` 和后续消息（Task 生命周期、Message 与 Part、Artifact），调用方累积分片返回的 artifact，任务的持久化，Agent Card 的发现、结构校验和练习 2 的 HMAC 签名，按 inputModes 和 outputModes 选 skill，用长度前缀帧代替第二种绑定（gRPC）流式返回任务，以及练习 5 的多跳委托和不透明原则。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 10 分钟，Part 2 13 分钟，Part 3 13 分钟，Part 4 13 分钟，Part 5 11 分钟。难度和用时还没有经过实测校准。
- 只改 `agentcard/` 里的代码。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python 官方文档（sqlite3、json、hmac、base64、struct、asyncio）和[本课讲义](../docs/en.md)。计时期间不要打开 `solution/`、`INTERVIEWER.md`，也不要看本课 `code/` 和 `coderpad/` 里的实现。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k store -x              # 只跑名字里带 store 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `agentcard/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/agentcard _starter/tests .
```
