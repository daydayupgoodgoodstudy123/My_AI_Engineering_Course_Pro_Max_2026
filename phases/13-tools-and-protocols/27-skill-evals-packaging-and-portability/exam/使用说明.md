# 13/27 分关面试题：SkillEval

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课的发布工具链：重复运行的触发评估要看每一次运行，near miss 的误触发单独计数；安装后的副本按 SHA-256 manifest 校验，manifest 的键必须本来就是规范路径，`assets/manifest.json` 不进自己的清单；每次运行的原始 trace 要原样留下；发布闸门的阈值在看结果之前声明，每一层单独判定，`passed` 跟随 `productionReady`，要有带外可信的 attestation 绑定 evidence root；能力矩阵里每个宿主对每项能力给出 supported、adapter、degraded 或 unsupported，静默降级判失败。题里没有模型，路由器和宿主都是按脚本回答的替身。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 12 分钟，Part 2 10 分钟，Part 3 15 分钟，Part 4 12 分钟，Part 5 11 分钟。难度和用时还没有经过实测校准。
- Part 3 要用 Part 1 修好的 `trigger_report` 和 `verify_manifest`，Part 4 要用 `run_matched`，先做 Part 1。
- 只改 `skilleval/` 里的代码。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python 官方文档（csv、asyncio、xml.etree.ElementTree、hashlib、json、dataclasses）和[本课讲义](../docs/en.md)。计时期间不要打开 `solution/`、`INTERVIEWER.md`，也不要看本课 `code/` 和 `coderpad/` 里的实现。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k gate -x               # 只跑名字里带 gate 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `skilleval/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/skilleval _starter/tests .
```
