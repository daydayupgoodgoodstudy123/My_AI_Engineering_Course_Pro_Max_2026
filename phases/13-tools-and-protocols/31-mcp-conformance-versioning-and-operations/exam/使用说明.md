# 13/31 分关面试题：conformance

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：证据在离开内存前脱敏，键名先 casefold 再去掉分隔符才和黑名单比较；健康窗口和回滚证据是发布闸门的一部分，缺数据不算健康，回滚目标要精确的 `active` 状态和三个 SHA-256 pin；golden 与 negative transcript 夹具，选定的时代和每条 transcript 存在一起，易变的 id 和时间戳先归一化；未知的附加字段可以接受，未知的 `resultType` 必须拒绝，legacy 时代缺 `resultType` 才算 complete，判别字段之后还要查方法载荷；通知只能得到 HTTP 202 和空 body；代理的 ingress、origin、egress 三视图；以及原始结果和 SDK 归一化视图之间的差分。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 10 分钟，Part 2 11 分钟，Part 3 13 分钟，Part 4 14 分钟，Part 5 12 分钟。难度和用时还没有经过实测校准。
- 只改 `conformance/` 里的代码。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。`wire.py` 是给好的常量和规则名，一般不需要动。
- 可以查 Python 官方文档（json、hashlib、hmac、re、pathlib、dataclasses、asyncio）和[本课讲义](../docs/en.md)。计时期间不要打开 `solution/`、`INTERVIEWER.md`，也不要看本课 `code/` 和 `coderpad/` 里的实现。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k corpus -x             # 只跑名字里带 corpus 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `conformance/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/conformance _starter/tests .
```
