# 13/24 分关面试题：SkillCat

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：发现只看 scope 根目录的直接子目录，包里 examples/ 下的 `SKILL.md` 不单独发布；同名冲突按宿主声明的整数 rank 决定，被遮蔽的候选留在诊断里，同一 rank 上的重名报错；引用先按文件系统语义解析，再判断还在不在包里，包内的符号链接可以用，指向包外的不行；模型看到的目录按序列化后的精确文本计长度；发现结果存成 JSON 快照，按 `SKILL.md` 内容的 SHA-256 判断是否过期；目录预算照讲义里的 Codex 规则，已知上下文窗口时取 2%，未知时才用 8,000 字符，两者不叠加，超预算先缩短描述再省略条目；会话中的每次激活和读取记成一行 logfmt 事件，带原因和字节数，不带内容；从 `SKILL.md` 出发走引用图，检查一跳可达、死文件和整目录引用。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

Part 1 和 Part 4 的测试会创建符号链接。macOS 和 Linux 不需要额外设置；Windows 上要开启开发者模式，或者用管理员权限运行。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 12 分钟，Part 2 12 分钟，Part 3 12 分钟，Part 4 12 分钟，Part 5 12 分钟。难度和用时还没有经过实测校准。
- 只改 `skillcat/` 里的代码。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python、json、hashlib、os、pathlib、posixpath、re、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k cache -x              # 只跑名字里带 cache 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `skillcat/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/skillcat _starter/tests .
```
