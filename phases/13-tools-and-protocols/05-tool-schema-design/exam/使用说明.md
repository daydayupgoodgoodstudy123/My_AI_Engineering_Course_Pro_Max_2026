# 13/05 分关面试题：ToolLint

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：命名规则（snake_case、名字里不放参数值，`get_weather_for_city(city)` 可以、`get_weather_in_tokyo()` 不行）、"Use when … Do not use for …" 的描述模式和 1024 字符上限、block / warn / nit 三级 finding、Versioning 一节的四条规则（不改名、不改参数类型、可以随时加可选参数、删除前先发一版 `deprecated: true`）、练习 4 把 linter 接进 CI，以及 GOOD_REGISTRY 描述里那句指向别的工具的 "use notes_get instead"。题目里没有模型调用，也不联网。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 10 分钟，Part 2 13 分钟，Part 3 12 分钟，Part 4 13 分钟，Part 5 12 分钟。难度和用时还没有经过实测校准。
- 只改 `toollint/` 里的代码。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python、json、hashlib、pathlib、re、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k stream -x             # 只跑名字里带 stream 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `toollint/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/toollint _starter/tests .
```
