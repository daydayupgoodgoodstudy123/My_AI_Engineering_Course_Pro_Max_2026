# 13/25 分关面试题：SkillRoute

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：Eligibility must precede ranking 一节的 incident-triage / incident-review 例子；人类和模型调用组成的 2×2 矩阵，以及 `user-invocable: false`、`disable-model-invocation: true` 这两个宿主字段到底关掉了什么；Routing is classification with an abstain option，加上练习 4 的歧义边际；Context lifecycle 一节写给 skill 正文的三句恢复规则（读 `artifacts/release-readiness.json`、重新校验候选 commit、已记录幂等键的外部写入不再重复）；Arguments have three representations；五个调用阶段；Skill-to-skill invocation 一节要求请求带上的字段（目标、任务和产物路径、期望的回复契约、原因、fallback、最大深度），以及练习 5 的深度上限和环检测。题目里没有模型调用，也不联网：路由用的是本课那个词汇打分器，skill 都是测试里写死的脚本函数。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 11 分钟，Part 2 12 分钟，Part 3 12 分钟，Part 4 13 分钟，Part 5 12 分钟。难度和用时还没有经过实测校准。
- 只改 `skillroute/` 里的代码。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python 官方文档（json、os、tempfile、shlex、re、dataclasses、asyncio）和本课讲义。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k resume -x             # 只跑名字里带 resume 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `skillroute/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/skillroute _starter/tests .
```
