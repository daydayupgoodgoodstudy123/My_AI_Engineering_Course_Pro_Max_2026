一个写好一半的结果框架服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，逐关解锁，要求测试原样全部通过。英文题面见 [README.md](README.md)，具体要求在 docstring、测试和断言消息里。

## 开始

```bash
python3 -m pip install pytest

```
