**第一课:** [该 Agent Loop](01-the-agent-loop/docs/zh.md)

- [Agent- 辅助工程](../../learning-paths/using-coding-agents.json) 包括任务框架、存储证据、 harnesses、隔离、核查、审查和持久的反馈。

从存储库根目录运行此命令：

```bash

```
