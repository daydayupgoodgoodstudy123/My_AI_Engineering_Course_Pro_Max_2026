# Handoff Protocol

每届大会都以 handoff 包包含 :

- summary
- changed_files
- commands_run
- failed_attempts
- open_风险(严重性+细节)
- next_行动(一个具体步骤)
- verdict_指针(核查途径+审评报告)

包船是两者 handoff.(人类)和 handoff.json (next agent).
缺少的字段停止会话结束钩。
