# 可靠性政策

工作台吸收了五个行业经常故障模式:

1. 万圣节行动——由规则集所抓住+ verification gate.
2. 范围爬行——被 scope contract 检查。
3. 串联错误——被反馈记录所捕获+拒绝退出。
4. 失去背景——被回馈记忆吸收;聊天不是真相的来源。
5. 工具滥用——被审查员标注的核查方面所抓住。

这项政策由以下机构执行: verification gate。超文本路径被签名
并进行了审计; agents 无法自我控制
