# Agent 工作台包

任何想要可靠回报的投放工作台 agent work.

<a id="what-you-get"></a>

## 买什么?

- `AGENTS.md` 短路由器进入 rest 包的。 包的。
- `docs/` 规则,可靠性政策, handoff 协议,审查员标注。
- `schemas/` JSON 州级、董事会和 scope contract.
- `scripts/` 里面有反馈跑者 verification gate, handoff generator.
- `bin/install.sh` 功能强大的安装器

<a id="quickstart"></a>

## Quickstart

```
bin/install.sh
$EDITOR task_board.json
python3 scripts/init_agent.py
```
