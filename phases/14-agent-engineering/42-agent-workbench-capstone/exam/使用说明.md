# 14/42 分关面试题：WBPack

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)；具体要求在测试、断言消息和 docstring 里。

内容来自本课：可移植 workbench pack 的安装器、VERSION、清单校验、升级时保护本地修改，以及按组件打包时的取舍。所有文件操作都在测试创建的临时目标里，不联网，也不调用 LLM。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 个 skipped 说明环境正常。照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 12 分钟，Part 2 10 分钟，Part 3 15 分钟，Part 4 13 分钟，Part 5 10 分钟。难度和用时没有经过候选人实测校准。
- 只改 `wbpack/`。测试不能改（解除 skip 除外），可以另写自己的测试。
- 可以查 pathlib、csv、hashlib 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 不清楚时先写下澄清问题，自己练习时只查 INTERVIEWER.md 中对应的答案。

## 常用命令

```bash
python3 -m pytest -x
python3 -m pytest -k manifest -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

`--solution` 和 `--all-parts` 是 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 60 分钟时停下，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，关掉答案再补完。
3. 先另存自己的代码，再恢复原始文件：

```bash
cp -R _starter/wbpack _starter/tests .
```
