# 14/45 分关面试题：Delegate

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，测试原样全部通过。英文题面在 [README.md](README.md)，具体要求在测试、断言和 docstring 里。

内容来自本课：写所有权、只读调查、证据隔离、交接范围与真实 proof 输出、整合顺序、共享接口决策和依赖失效。没有真实 agent、LLM、网络、Git worktree 或 shell 执行。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

5 skipped 表示环境正常，照 README 解除第一关 skip。

## 规则

- 建议 60 分钟，自己计时：Part 1 12 分钟，Part 2 10 分钟，Part 3 16 分钟，Part 4 12 分钟，Part 5 10 分钟。难度和用时没有候选人实测校准。
- 只改 `delegate/`，测试只能解除 skip。可以另写自己的测试。
- 可查标准库官方文档，计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- `support.py` 的依赖检查与传递前置集合已给对；证据名使用给定的统一大写 Base32 编码，在大小写不敏感文件系统下也保持独立；NDJSON 行编码也已给对。
- 先记下澄清问题，自己练时只查面试官手册对应答案。
