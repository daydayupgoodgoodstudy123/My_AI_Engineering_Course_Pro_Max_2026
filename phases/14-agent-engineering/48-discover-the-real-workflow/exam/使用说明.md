# 14/48 分关面试题：FlowMap

一个写好一半的工作流证据服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，逐关解锁，测试原样全部通过。英文题面见 [README.md](README.md)，具体要求在 docstring、测试和断言消息里。

内容来自本课：按观察顺序重构工作流、四级证据梯子、friction/hidden state/authority/exceptions、等待和交接，以及保留用户工作流变体。录屏事件、证据和差异原因都是确定输入，不联网、不调用模型、不操控真实屏幕。

## 开始

```bash
python3 -m pip install pytest
python3 -m pytest
```

看到 5 个 skipped，再照 README 解开 Part 1。

## 规则

- 建议 60 分钟：Part 1 12 分钟，Part 2 10 分钟，Part 3 14 分钟，Part 4 12 分钟，Part 5 12 分钟。难度与时间没有真人校准。
- 只改 `flowmap/`，不改测试（解除 skip 除外）；可以另写测试。
- 可查 Python、dataclasses、sqlite3、csv、asyncio 官方文档；计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 有疑问先询问或记录；自练只看对应澄清答案。
- `_row` 的 CSV 序列化和 `key` 的身份归一是已给的正确 helper。

python3 -m pytest -x
