# 14/21 分关面试题：ComputerUse

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：截图进、鼠标键盘指令出的视觉型 agent 循环；截图、DOM 文本、工具输出都是不可信输入，只有用户的直接指令才算授权；每一步执行前都过一遍安全分类器（Gemini 2.5 Computer Use 的逐步安全服务）；导航目标走允许列表；登录、购买、CAPTCHA 这类敏感动作要人工确认，每次被拒都记下来；截图存到外部存储，trace 里只放引用；长程运行要有逐步轨迹，否则第 180 次点击失败时没法查；以及从缩放后的截图坐标还原到真实屏幕坐标。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 13 分钟，Part 2 11 分钟，Part 3 12 分钟，Part 4 13 分钟，Part 5 11 分钟。难度和用时还没有经过实测校准。
- 只改 `computeruse/` 里的代码。没有真实的模型、屏幕或网络：`FakeDesktop` 是虚拟显示器的替身，测试里的动作序列和 `model` 函数就是模型替身，人工确认也是测试里写好的函数。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python、hashlib、urllib.parse、asyncio 的官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k capture -x            # 只跑名字里带 capture 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `computeruse/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/computeruse _starter/tests .
```
