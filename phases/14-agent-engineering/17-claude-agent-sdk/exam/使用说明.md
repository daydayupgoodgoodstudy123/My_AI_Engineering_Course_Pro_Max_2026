# 14/17 分关面试题：Harness

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，要求测试原样全部通过。题面只有英文的 [README.md](README.md)，和真实面试一样；具体要求在测试、断言消息和 docstring 里。

内容来自本课：Claude Agent SDK 的 harness 形状。`PreToolUse` / `PostToolUse` 钩子拦截和审计工具调用，subagent 用自己的上下文、只把结果交回 orchestrator，session store 的五个方法（`append`、`load`、`list_sessions`、`delete` 级联到子会话、`list_subkeys`），`--session-mirror` 把转录边产生边写到外部文件。练习里用到两件事：练习 1 把 20 个任务分批交给 subagent（Part 3 按测验 Q12 比较不用 subagent、每个任务一个、分批这几种方案的 orchestrator 上下文和总 token，Part 4 最多 5 个同时跑），练习 3 用 `list_subkeys` 画出 subagent 树。会话过期清理来自课里的 Session bloat（`list_sessions` 加过期策略）。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest      # 只需一次
python3 -m pytest                  # 5 个 skipped 说明环境正常
```

然后照 README 注释掉 Part 1 的 skip，再运行 `python3 -m pytest`。

## 规则

- 建议 60 分钟，自己计时。参考分配：Part 1 12 分钟，Part 2 14 分钟，Part 3 10 分钟，Part 4 14 分钟，Part 5 10 分钟。难度和用时还没有经过实测校准。
- 只改 `harness/` 里的代码。工具调用由测试写好，subagent 是测试里的普通 async 函数（`Probe`），不调用真实的 LLM，也不联网。测试不能改（解除 skip 除外），可以另外新建自己的测试文件。
- 可以查 Python 官方文档（json、pathlib、asyncio、dataclasses）。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- 有需求不清楚的地方就问面试官。自己练的时候，先把问题写下来，再去 INTERVIEWER.md 的“澄清问题”一节里只看这一条的答案。

## 常用命令

```bash
python3 -m pytest -x                       # 跑已解锁的关，遇到第一个失败就停
python3 -m pytest -k mirror -x             # 只跑名字里带 mirror 的测试
python3 -m pytest --all-parts              # 不解除 skip，一次看所有关的状态
python3 -m pytest --solution --all-parts   # 计时结束后：参考答案应该 5 passed
```

`--solution` 和 `--all-parts` 是本目录 conftest.py 提供的练习开关，真实面试里没有。

## 结束和重做

1. 到 60 分钟时停下，记下每关的状态，填 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md)。
2. 再看 [solution/EXPLANATION.md](solution/EXPLANATION.md)，然后关掉答案，把没做完的关重写一遍。
3. 重做前把自己的 `harness/` 另存一份，再用 `_starter/` 里的原始文件覆盖：

```bash
cp -R _starter/harness _starter/tests .
```
