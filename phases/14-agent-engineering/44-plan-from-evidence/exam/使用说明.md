# 14/44 分关面试题：EvidPlan

形式照 Edison 那场面试：一个写好一半的服务，5 个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关，测试原样全部通过。题面是英文 [README.md](README.md)，具体要求在测试、断言和 docstring 里。

内容来自本课：证据计划的五项承诺、依赖波次、机械校验、可中断的进度、JSON 真源的 Markdown 视图，以及拆分多个证明义务。resolver 是人工明确标注的依赖，不替人判断真实风险。

## 开始

在本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

看到 5 skipped 后，照 README 解除 Part 1 的 skip。

## 规则

- 建议 60 分钟，自己计时：Part 1 12 分钟、Part 2 10 分钟、Part 3 15 分钟、Part 4 12 分钟、Part 5 11 分钟。难度和用时没有候选人实测校准。
- 只改 `evidplan/`；测试只能解除 skip，可以另写自己的测试。
- 可以查标准库官方文档。计时期间不要打开 `solution/` 和 `INTERVIEWER.md`。
- `support.py` 的 `_components` 提供正确的强连通分量划分，`ancestors` 和 `latest_records` 提供前置遍历与最新事件扫描；Part 1 的 `cycle_members` 属于待调试代码。`stream.py` 的 `_changes` 提供完整内容比较，直接复用。遇到需求不清先记问题，再查面试官手册对应答案。

## 常用命令

```bash
python3 -m pytest -x
python3 -m pytest -k resume -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

两个练习开关来自 conftest.py，真实面试里没有。

## 结束和重做

```bash

```
