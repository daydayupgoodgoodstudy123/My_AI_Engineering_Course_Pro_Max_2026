## 在 GitHub 上开始此阶段

**先决条件：** 第 2 阶段 ML 基础知识、第 3 阶段深度学习核心和
第 7 阶段第 14 课，从头开始构建 Transformer。

**第一课：** [生成模型分类和历史](01-generative-models-taxonomy-history/docs/zh.md)

从存储库根目录运行此命令：

```bash
python3 phases/08-generative-ai/01-generative-models-taxonomy-history/code/main.py
```

保留命令、退出代码、密度估计、生成的样本和一个
解释隐式生成器无法回答 `p(x)` 问题的句子。

**下一步行动：** 更改随机种子，比较密度估计，然后
继续[自动编码器和VAE](02-autoencoders-vae/docs/zh.md)。

浏览 [ 完整第 8 阶段课程列表](../../README.md#phase-8) 或
[跨阶段路线图](../../ROADMAP.md)。

可运行的 Python 演示、图表以及 agent 的命名技能。
