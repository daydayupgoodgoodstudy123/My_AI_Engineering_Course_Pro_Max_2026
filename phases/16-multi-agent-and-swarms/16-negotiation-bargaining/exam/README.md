# BargainKit pair session

BargainKit reviews supplied quotes, keeps private bargaining checkpoints beside public observations, and runs a deterministic offer mechanism. It also projects completed public events and audits nested multi-issue proposals using declared private utilities.

Write the application code so that every test in `tests/test_parts.py` passes as written. This is a finite local adapter with no real models, market or protocol transport.

## Pt 0 Setup

Use Python 3.10+ and pytest (`python3 -m pip install pytest`). Run `python3 -m pytest` from your working copy; every part starts skipped, and `--all-parts` and `--solution` are practice switches for after the staged attempt.

## Pt 1 `test_standing_clearing_inclusive_private_text_and_real_tick_encoding`

Comment out `@pytest.mark.skip("Part 1")`, run pytest, and repair the supplied-offer review pipeline.

## Pt 2 `test_private_continuation_and_ordered_public_dual_journals`

Save and reopen complete bargaining checkpoints with their ordered public history.

## Pt 3 `test_directional_concession_tick_progress_and_bounded_resume`

Implement the own-information concession policies and resume the alternating mechanism within its total round ceiling.

## Pt 4 `test_actual_numeric_offer_and_matching_narrative_ndjson`

Project actual public event phase fields and the matching narrative revision for the supplied NDJSON publisher.

## Pt 5 `test_nested_quantity_coverage_and_all_party_joint_utility`

Audit every nested proposal layer for inclusive quantity bounds, issue coverage and all-party joint feasibility.
