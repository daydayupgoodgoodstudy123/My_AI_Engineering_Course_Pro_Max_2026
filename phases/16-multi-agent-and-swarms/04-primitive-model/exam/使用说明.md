# PrimSwap 使用说明

这是一套约60分钟的本地结对编程练习。同一组脚本策略、同一初始状态，可以由静态顺序、消息返回的handoff或外部selector决定下一个agent。没有真实模型调用。

## 开始

先看 README.md、primswap/ 和 tests/test_parts.py。逐关注释skip锁，保留原测试与公共接口。建议分配：修15分钟、存10分钟、算15分钟、流10分钟、构10分钟。

```bash
python -m pytest -q
python -m pytest -q --all-parts -k test_owned_primitives_and_latest_review
python -m pytest -q --all-parts
```

P1提供单步消费者，不提供完整replay。P2只存不可变定义、policy名称和控制配置；运行时callable来自注入registry。P3的三个interpreter都要实现，用能区分控制来源的fixture验证，不要假设三种默认结果必须不同。

定义清单按给定顺序恢复，同一个registry策略可绑定多个agent。静态路径的重复位置分别执行；新一轮步数预算只计本轮调用。领域记录中的嵌套message payload也由接收者独立拥有；无环子树可以在不同scope中复用。

## 给定边界

models.py的形状/预算原语和config_support.py的dbm模式、UTF8/JSON和record-key编码可直接使用。P4的wire_support.py负责JSON Text Sequence序列化、源拉取/发布/关闭，候选只写领域记录。P5的stores是给定SharedState对象，引用相同id意味着刻意共享。

独立作答时保持solution/、INTERVIEWER.md及原课源码关闭。重做时用_starter/primswap和_starter/tests覆盖同名目录。复盘后再运行参考并填写REVIEW_TEMPLATE.md。

```bash
python -m pytest -q --solution --all-parts
```

本地结果不证明任何框架性能、真实并发行为、模型质量或实际部署效果。
