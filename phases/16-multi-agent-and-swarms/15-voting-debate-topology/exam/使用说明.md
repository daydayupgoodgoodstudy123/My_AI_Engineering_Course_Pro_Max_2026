# 16/15 分关面试题：CorrJury

这是一个写好一半的本地 jury 服务。五个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关。英文题面在 [README.md](README.md)，具体合同在代码 docstring、typed records 和测试里。

题目围绕共享错误来源与投票可靠性：同一 family 的所有 seats 共用一次模拟结果，不同 family 独立；服务记录实际 ticket 和投票，保存完整配置，计算精确分布，再审计嵌套 jury。family latent、exact integer tickets、声明式 read-cost、JSON 快照、精确概率 law、TSV 和 nested jury 都是本地显式适配。来源 demo 的 agent 原本独立抽签、线性计票，并用常量时间概率比较；本题预埋的回归不代表来源也有这些缺陷。

## 开始

先把整个 `exam/` 另存为自己的作答副本，在该副本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

五个 skipped 表示分关锁仍在。照 README 只解除 Part 1 的 skip，运行测试并从第一个失败开始。程序只用标准库与 pytest，不需要 API key、模型、网络或来源脚本。

## 规则与时间

- 总计 60 分钟：开场 2 分钟，Part 1–5 分别 12、11、15、10、10 分钟，共 58 分钟。这个分配没有经过真人面试校准；记录自己的实际时间。
- 只改 `corrjury/`。测试除解除对应 skip 外保持原样；不要改 Given、fixture、限时断言或测试期望来绕过失败。可以在作答副本另建自己的测试文件。
- 可以查 Python 官方文档；计时期间关闭 `solution/`、`INTERVIEWER.md` 和本题讲解。独立练习时先写下澄清问题，再只查看手册中对应的英文答案。
- 一边做一边说明输入、输出和修复依据。先修上游生产者的合同，再处理随后出现的失败。Part 3 的三个精确算法和 Part 5 的模型组合需要自行实现。
- 合法输入是有限 typed toy：exact `Fraction` 概率、正整数 family seats、正奇数总票数，以及非负声明 tokens 和有限非负 `Decimal` rates。`ReadExposure.reader/sender` 是 opaque cost labels，不能由它们推断网络通信或端点权限；相同 labels 可对应不同声明 allocation，均需保留。

## 常用命令与练习开关

```bash
python3 -m pytest -x
python3 -m pytest -k shared_draw -x
python3 -m pytest -k exact_family -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

`--all-parts` 忽略五个 Part skip；`--solution` 把导入切到参考实现。这两个开关由本目录 `conftest.py` 提供。只在计时结束后检查参考答案；退出该命令、关闭答案，再运行不带 `--solution` 的命令，检查自己的代码。参考模式的结果不能计入自己的成绩。

## 结束、复盘与重做

1. 到 60 分钟停下，记录已完成的行为、失败和提示，用 [REVIEW_TEMPLATE.md](REVIEW_TEMPLATE.md) 复盘。计时后补完单独记，不并入计时成绩。
2. 再读 [solution/EXPLANATION.md](solution/EXPLANATION.md)，核对 sampled result、exact probability 与 nested model 的区别；关掉答案，从自己的空白思路重写。
3. 重做前先选一个尚不存在的备份目录，把自己的代码和已解锁测试另存，再恢复 `_starter/`：

```bash
mkdir ../corrjury-attempt-backup
cp -R corrjury tests ../corrjury-attempt-backup/
cp -R _starter/corrjury _starter/tests .
```

确认备份可读后再覆盖。每次重做换一个备份名；恢复后五个测试重新锁住，练习时重新逐关解锁。
