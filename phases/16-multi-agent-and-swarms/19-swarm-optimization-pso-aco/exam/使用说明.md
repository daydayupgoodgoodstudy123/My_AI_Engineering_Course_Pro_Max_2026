# 16/19 分关面试题：SwarmTune

一个写好一半的本地numeric PSO／ACO replay服务，五个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关。英文题面在 [README.md](README.md)，具体合同在typed records、docstring和测试里。

题目从真实二维数学evaluator出发：修PSO primitive，保存完整binary checkpoint，再对已分配numeric job的实际Outcome做routing学习，输出观察，审计nested ant trails。deferred outcome、binary成员、显式epoch和nested graph都是本地适配；来源没有真实LLM、prompt velocity、model-weight训练或后台异步worker。来源PSO本已正确快照、clamp、最大化并只评changed candidate，本题P1是明示教学回归。

## 开始

先把整个 `exam/` 另存为自己的作答副本，在该副本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

五个skipped说明分关锁仍在。照README解除Part 1的skip，先运行并读首个失败。只需标准库和pytest，不需要API key、网络、真实模型或来源脚本。

## 规则与时间

- 总计60分钟：开场2分钟，Part 1–5分别12、10、16、10、10分钟，共58分钟编码。安排没有经过真人面试校准，请记录实际时间。
- 只改 `swarmtune/`。测试除解除对应skip外保持原样；不要改完整Given、fixture、限时断言或期望来绕过失败。可在作答副本另建自己的测试文件。
- 可以查Python官方文档。计时期间关闭 `solution/`、`INTERVIEWER.md` 和本题讲解。独立练习先写下澄清问题，再只看手册对应的英文答案。
- 解释修改的输入、输出和依据。P1只做numeric optimization；P3的requested-row roulette、explicit-epoch decay、original-allocation feedback是三个独立TODO。
- actual source evaluator保留不变。中心代入为0.84，打印的“optimum=1”不是oracle；不要求把evaluator改成另一个函数或证明全局最优。
- 使用完整Given声明的有限可表示数值域。它会保守检查potential learning／graph credit，即使事件之后被gate或path拒绝，也可能先拒绝超大输入；不要求候选人扩成任意精度算法。
- P2存完整当前RNG，不用seed代替；P5复用修好P3实际LearningDecision，不重新实现quality gate。normal-process成员读回不承诺双文件crash事务，反馈也没有自动exactly-once去重。

## 常用命令与练习开关

```bash
python3 -m pytest -x
python3 -m pytest -k part1_numeric -x
python3 -m pytest -k part3_task -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

`--all-parts` 忽略五个Part skip；`--solution` 将导入切到参考实现。两个开关来自本目录 `conftest.py`。计时结束后才检查参考模式，退出后关闭答案，再去掉 `--solution` 检查自己的代码；参考结果不能计入个人成绩。
