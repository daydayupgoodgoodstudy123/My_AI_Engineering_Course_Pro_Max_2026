# RobustCenter evidence desk

RobustCenter inspects scalar proposals, retains evaluator evidence and audits local Core/Edge following. Complete the five parts in order, editing only `robustcenter/` so that the tests pass as written.

## Pt 0 Setup

Use Python 3.10+ and pytest. Run `python3 -m pytest` from your practice copy; all five parts start skipped. The 60-minute budget has not been calibrated with human candidates.

## Pt 1 `test_signed_clusters_abstentions_mass_and_dispersion`

Remove the Part 1 skip and repair signed clusters, abstention admission and confidence-mass thresholds. Preserve the complete inspection while computing its exact confidence-pair diagnostic responsively.

## Pt 2 `test_complete_proposal_and_independent_probe_snapshots`

Persist and reopen each run's complete ordered proposal/probe snapshot. Preserve every proposal, including zero probe mass, with its own identity, original answer and actual evaluator record.

## Pt 3 `test_weighted_median_interval_ties_and_radius_support`

Compute the full weighted-median interval, select the requested tie point and audit radius support. Zero mass cannot define an interval endpoint; keep independent truth separate from agreement admission.

## Pt 4 `test_each_proposal_numeric_and_probe_evidence_frames`

Project each proposal's own identity, original answer, signed scalar/unit and self-report beside the supplied probe fields. Classification, numeric primitives, framing and async publication are supplied.

## Pt 5 `test_nested_core_and_edge_following_certificates`

Build ordered nested Core/Edge audit reports against each core's authoritative sealed decision. Audit core declarations and their own edges independently while preserving the supplied evidence-admission boundary.
