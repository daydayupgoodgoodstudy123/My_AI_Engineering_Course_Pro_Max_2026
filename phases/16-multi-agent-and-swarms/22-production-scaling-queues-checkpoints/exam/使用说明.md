## 开始前备份

建议先将整个exam目录复制为本次作答副本，再进入副本目录运行、备份与reset。以下命令仅是操作说明；本文未执行它们。先确认当前目录含outboxflow、tests、_starter和SCOPE.json，再创建本次备份：

```bash
pwd
ls outboxflow tests _starter SCOPE.json
backup_dir="../exam22-backup-$(date +%Y%m%d-%H%M%S)"
mkdir "$backup_dir"
cp -R outboxflow tests "$backup_dir/"
cp REVIEW_TEMPLATE.md "$backup_dir/"
```

在已安装pytest的练习环境运行：

```bash
python3 -m pytest -q
```

默认五关都有Part skip锁；只有删除当前关对应的skip装饰器后，该关才参与常规测试。默认被skip不代表行为正确，也不算完成。

## 结束、复盘与完整reset

先停止运行中的测试，保存pytest输出、用时和提示记录，填写REVIEW_TEMPLATE。重做前创建一个新的备份目录，将当前代码和解锁状态整体移走，再从_starter恢复；这会保留本次所有新增文件，而不会将它们残留进reset后的candidate：

```bash
reset_backup_dir="../exam22-attempt-$(date +%Y%m%d-%H%M%S)"
mkdir "$reset_backup_dir"
mv outboxflow "$reset_backup_dir/outboxflow"
mv tests "$reset_backup_dir/tests"
cp REVIEW_TEMPLATE.md "$reset_backup_dir/"
cp -R _starter/outboxflow ./outboxflow
cp -R _starter/tests ./tests
python3 -m pytest -q
```

reset恢复candidate与原始五锁测试，不改solution、Given源副本、SCOPE或复盘备份。目录名冲突时mkdir应停止；选择新的备份名称后再继续。不要在未确认备份的目录执行删除命令。
