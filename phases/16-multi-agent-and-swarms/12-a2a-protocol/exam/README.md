# PeerResult review desk

PeerResult observes peer tasks, archives attempts and adapts review artifacts under a pinned local contract. Complete the five parts in order, editing only `peerresult/` so that the tests pass as written.

## Pt 0 Setup

Use Python 3.10+ and pytest. Run `python3 -m pytest` from your practice copy; all five parts start skipped. The 60-minute budget has not been calibrated with human candidates.

## Pt 1 `test_discovered_terminal_polling_and_pending_lifecycle`

Remove the Part 1 skip and repair discovered polling, terminal receipts and pending-only observation. Preserve every task's complete first terminal result and independent deadline.

## Pt 2 `test_ordered_attempt_manifest_and_exact_artifacts`

Persist and reopen the complete ordered attempt manifest with each attempt's own artifact member. Preserve retries and metadata through snapshot replacement.

## Pt 3 `test_pinned_card_mode_and_flat_review_adapter`

Validate the pinned local card, negotiate the actual advertised artifact modality and adapt flat review results with required fields and permitted card metadata. Preserve explicit text and declared structured review values.

## Pt 4 `test_change_only_local_task_sse`

Project only observed state and artifact changes, including artifact removal, in domain order, with one final event. Typed public views, SSE encoding and async transport are supplied.

## Pt 5 `test_nested_review_file_lines_and_group_reports`

Build hierarchical review reports and validate child spans and each group's own issue memberships against its declared file. Identity resolution, ordered occurrences and tagged leaf dispatch are supplied.
