# 16/12 分关面试题：PeerResult

这是一个写好一半的本地 peer-result desk，处理发现端点、任务轮询、attempt archive、review adapter、SSE 变化事件和嵌套 file/group 审计。英文题面在 [README.md](README.md)，完整合同在测试、断言消息和 docstring 中。

## 开始

先把题包复制到自己的练习目录，读 README 与五个测试的 docstring，再运行：

```bash
python3 -m pip install pytest
python3 -m pytest
```

默认五个 skipped 表示五关依次锁住。先解除 Part 1 的 skip，运行 `python3 -m pytest -x`；这一关通过后再解除下一关。

## 规则与时间分配

- 总时长 60 分钟：开场 2 分钟，五关参考用时 12、11、15、10、10 分钟。时间与难度尚未经过真人校准。
- 只修改 `peerresult/` 的候选领域实现。测试只解除当前 skip，保留所有断言与完整正确的 GIVEN 依赖；可以另外写自己的测试。
- 可以查 Python 标准库官方文档。计时期间关闭 `solution/` 与 `INTERVIEWER.md`，边做边说明当前证据、根因与下一步判断。
- 需求不清楚时向主持人澄清；独练时先记下问题，再只查手册中对应的英文标准答案。
- 记录解锁、首次通过、运行次数与 H1/H2/H3，区分限时结果与之后补完。所有 observations 来自本地 replay，不启动 HTTP 服务、真实 agent 或网络调用。

## 五关职责

| 关 | 候选职责 | 完整正确 GIVEN |
|---|---|---|
| 1 修 | discovered URL、query-free ID、failed receipt、只 poll pending | local GET/JSON snapshots、artifact conversion、status consumer、PollDesk intake 与独立 fixture |
| 2 存 | ordered attempt manifest、每条 metadata/member 关联、完整 snapshot reopen/replace | explicit-tag text/structured codec、directory I/O、稳定 member 名 |
| 3 算 | card pin/形状校验、actual-tag modality 协商、flat issues/lines schema | P1 正确 terminal receipt、P2 tagged artifact；不提供 adapter solver |
| 4 流 | state/artifact 独立变化抑制、state→artifact→final 顺序、final once | typed public views、terminal predicate、SSE codec、async pull/publish/close |
| 5 构 | recursive GroupAudit、child file/span、own issue file/line/group 检查 | global lookup、ordered occurrences、canonical issues、tag dispatch、已建 reports 的 findings flatten |

P1 URL 使用请求中发现的 tasks endpoint，task ID 不包含 query suffix。HTTP 请求成功不代表 task completed；failed 也要保留其终态与 error artifact。每个 task 独立 deadline，deadline 当 tick 先观察，若仍未终态才 timeout；结果按输入顺序保留第一次终态 observation。只对 pending IDs 发 GET，不能跳过失败结果、覆盖早先结果或减少完整输入。

P2 archive 的 manifest 保留每次 attempt 的 task/attempt/peer/card_version、envelope identity/state/observed_at，以及对应 artifact member/tag。一个 task 的多次 retries 不能折叠成一条，每个 member 必须关联自己的 attempt。完整 codec 按 explicit tag 保存 text UTF-8 bytes 或 structured JSON；JSON-looking text 不解析，精确值无需候选重写编码。load 以 manifest 声明序恢复完整 snapshot，replacement 以当前 manifest 为准，不要求删除未被引用的旧 member 文件。archive data 只含 text 或严格 JSON 值树（list、字符串键 dict、string/int/bool/null 与有限 float）；P5 typed ReviewBundle 是另一 local domain，不承诺能存进 wire archive。

P3 有三个独立 TODO：`validate_local_card`、`negotiate_review_modality`、`adapt_review`。协议 pin 必须恰为 `a2a-0.3`，并校验本地 card 字段形状，extra card keys 可保留但不能替代 required fields。actual artifact tag 必须在 advertised modalities 中，不能取第一个 mode 猜测。成功 structured flat review 恰有 issues/lines，issues 是 list[str]，lines 是非 bool 的非负 int；保留顺序、重复 issue 与声明的 0。text 保持 opaque。必填 issues/lines 不由默认值补齐；完整合法 card 的额外 metadata 允许保留。这里不重跑 reviewer、不改 source 行数公式，也不实现 current A2A 兼容层。adapter 还消费完整 PollDesk→AttemptArchive save/reopen 的真实 structured artifact。

P4 一个 TaskProjection 观察一个 task。state 相同仍可能 artifact 改变，两种变化分别比较；artifact 从有值变为 None 也是变化，重复相等 snapshot 不制造事件。单次 observation 的事件依次为 changed state、changed artifact、terminal final，final 至多一次。完整 public views 提供独立 data 副本并保留 explicit tag/data 和 failed state，retained snapshot 不随 incoming data 后续修改；完整 SSE driver 负责发布与关闭，候选不实现这项副本逻辑、不猜内部 agent steps 或修通用 cadence。

P5 输入 structured typed ReviewBundle，递归生成每层 own findings 与 ordered child GroupAudit。child 必须与 parent 同 file 且 span 包含于 parent；每个 own issue membership 同时检查文件归属、声明 file 的物理行区间、own group span，边界含末行。未知 bundle/group schema 生成带完整 path 的 Finding，不短路其他检查。issue 的物理行边界使用它自己声明的 file，而非当前 group 的 file。line counts/coordinates 是声明的非 bool 整数，负或越界值是合法审计输入，应产出 findings。ID 解析、shared membership 的所有 occurrence、canonical counts 与 tag dispatch 已完整 GIVEN。canonical count 包含未引用的声明 issue，membership count 是所有 group refs；text leaf 也消费 P1/P2/P3 真实 polled/archived/adapted 证据。这里不是 task delegation 或预算树。

## 性能与验证边界

P1 fixture 包含 400 个 tick 0 已完成任务、一个 tick 500 完成的慢任务、一个 tick 0 failed 和一个独立 timeout，共 403 个真实 task requests。fixture 与独立 expected 在 timer 外；完整 `PollDesk.run` 和整个 `BatchResult` equality 在 timer 内，包括所有 typed artifacts、task identities、terminal states 与 first observed logical times，之后才取得 elapsed。没有真实 sleep 或 HTTP。

P1 当前限值 0.07 秒。固定完整组慢版三次为 0.702968、0.670234、0.662439 秒，参考版为 0.002720、0.002595、0.002550 秒；两侧余量分别为 9.46342 和 25.73884。六份 NEW 完整副本只把 timingassert 换成实际 elapsed 输出，慢版另恢复重复 terminal GET/JSON decode；其余完整业务 guards 和全五关功能通过，不能说慢版通过原阈值。原样 reference 五关另行通过。规定 TEMP 校验已通过五锁、参考全五关、starter 五关失败、P1 分层、28 项登记错修和 reset 一致性检查，记录在 verification.txt。独立行为记录为 6 个核心错误及 1 个不计入核心数量的同方向辅助错误：对应参考全五关通过，错误各自由目标关捕获，证据在题包外 fresh-review.json。正式检查已通过，记录见 verification.txt；正式归档保留独立验收记录。 本机结果不是任意环境墙钟上界或生产 SLA。

当前静态题包为 45 Python 文件、5 tests、40 assert、5 处 pytest.raises、5 skip 锁和 28 项登记错修。deadline、empty batch、codec 精确值、tagged views、SSE close、shared membership 等是声明的领域边界或依赖集成护栏，不能全部算作独立主要算法。Python 3.10+ 是目标环境，没有实际在该版本运行的声明；60 分钟及各关时间仍未真人校准。

## 常用命令

在自己的练习副本运行：

```bash
python3 -m pytest -x
python3 -m pytest -k pinned_card -x
python3 -m pytest --all-parts -x
python3 -m pytest --solution --all-parts
```

`--all-parts` 与 `--solution` 是本目录 `conftest.py` 的练习开关，真实面试没有。`--solution` 只在计时结束后检查参考实现，结果不能算作候选成绩。
