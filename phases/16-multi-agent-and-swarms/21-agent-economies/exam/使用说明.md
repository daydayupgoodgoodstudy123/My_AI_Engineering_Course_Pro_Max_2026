# 16/21 分关面试题：CreditEcon

一个写好一半的本地coalition credit服务。五测试用 `@pytest.mark.skip(reason="Part N")` 锁住，一次解锁一关；英文薄题面在 [README.md](README.md)，具体合同见typed records、docstring与测试。

从外给credits的statement与utility replay开始，保存完整SQLite accounting snapshot，再实现exact／sampled allocation和completed-block报告，输出CSV并构造nested direct-child team games。全部credits、bids、unit与quantum是synthetic数据，没有实际支付、链、收益或投资事实。

## 开始

先把整个 `exam/` 另存为自己的作答副本，在副本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

五个skipped表示分关锁仍在。按README解除Part 1的skip，从首个失败追查producer与正确consumer。仅需Python 3.10+、标准库和pytest，不需要API key、网络或运行来源脚本。

## 规则与时间

- 总计60分钟：开场2分钟，Part 1–5分别12、10、16、10、10分钟，共58分钟编码。真人难度／用时尚未校准，记录实际表现。
- 作答位置是 `creditecon/` 的 `primitives.py`、`store.py`、`allocation.py`、`stream.py`、`structure.py`。完整Given、fixture、期望与限时断言保持原样；测试仅解除对应skip，自己的额外测试放副本独立文件。
- 可查Python官方文档。计时期间关闭 `solution/`、`INTERVIEWER.md` 与本题讲解；独立练习先记澄清问题，再只看手册相应英文答案。
- 输入是immutable typed records，玩家最多8个，coalition按set解释。Fraction保signed exact utility／credit；actual v(empty)包含baseline和所有empty-required criteria，不能只看baseline字段。
- P1消费外给credits并replay utility，没有allocator。P3的exact subset solver、fresh seeded complete-permutation sampling、completed-block report是三个独立TODO。
- 唯一confirmed-quality gate在P1 per-use EMA；P2原样保存确认状态，P4投影actual block数据，不另决定receipt是否应获奖励。confirmed是本地独立证据字段，不代表密码学信任或现实身份验证。
- P2完整Given是exact Fraction／Decimal scalar-container codec和SQLite row resource；candidate负责完整domain mapping、顺序、replacement与typed reopen。P4完整Given是CSV quoting／driver与block_context；candidate负责own domain rows。
- sampled估计按actual completed full permutations归一。requested不是证据，0 completed给零estimates及真实residual；partial精确为completed<requested，0 requested／0 completed仍approximate=True、partial=False。sampled总和telescoping不等于每人estimate精确。
- P5每层players为direct child UIDs，utility来自所选children的primitive union；共享primitive只算一次。每层实际调用修好的P3 exact，不用primitive Shapley分组相加，也不声称Owen value或现实Sybil-proof。

## 常用命令与练习开关

```bash
python3 -m pytest -x
python3 -m pytest -k part1_supplied -x
python3 -m pytest -k part3_exact -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

`--all-parts` 忽略五个Part skip；`--solution` 将导入切到参考实现，均由 `conftest.py` 提供。计时结束才使用参考模式；退出后关闭答案，去掉 `--solution` 检查自己的实现，参考结果不能计入个人成绩。
