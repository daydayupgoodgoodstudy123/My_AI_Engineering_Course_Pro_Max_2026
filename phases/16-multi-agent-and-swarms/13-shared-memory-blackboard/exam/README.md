# BlackScope evidence desk

BlackScope retains versioned shared provenance, independent findings and derived support certificates. Complete the five parts in order, editing only `blackscope/` so that the tests pass as written.

## Pt 0 Setup

Use Python 3.10+ and pytest. Run `python3 -m pytest` from your practice copy; all five parts start skipped. The 60-minute budget has not been calibrated with human candidates.

## Pt 1 `test_first_sentence_correction_and_independent_channel`

Remove the Part 1 skip and repair first-sentence summaries, append-only corrections and independent finding publication. Preserve complete source reports while keeping first-sentence service work responsive.

## Pt 2 `test_append_only_provenance_versions_and_reopen`

Persist and reopen every original and correction version with its own complete provenance. Keep original identities and append order even when wording repeats; ledger framing and channel routing are supplied.

## Pt 3 `test_active_exact_source_version_and_consumption`

Resolve active topic-local correction lineages, attach exact-version findings and select consumable evidence. Apply the declared role and topic policy, including an empty topic view, without treating missing verification as falsehood.

## Pt 4 `test_own_entry_and_correction_json_text_sequences`

Project each entry or correction's own complete provenance through the supplied JSON Text Sequence driver. Channel classification and independent finding projection are supplied.

## Pt 5 `test_nested_required_coverage_and_distinct_external_support`

Build hierarchical support certificates that preserve required coverage and distinct verified external snapshots. Source versions remain distinct even at one URI; claim occurrence expansion and leaf-decision lookup are supplied.
