# 心智社会与多 Agent 辩论

> 明斯克1986年的前提——情报是专家组成的社会——每十年重新发现一次。 LLM 来分析。在N回合中,它们聚集在一个比 zero-shot 考特和思考六项推理和事实性任务。 **multiple agents** 和 **多轮** 社会比一个...agent 单词; 多轮交流比一投还多。

**类型:** 学习 + 构建
**语言:** Python (stdlib)
**先修要求:** 阶段16 -04(初级模型)
**时间:** ~60分钟

<a id="problem"></a>

## 问题

自我一致性——多次抽样使用一种模式,并接受多数人的答复——是你可以利用的最廉价的推理改进方法。它有效,但饱和性很快。你可以将样品增加一倍,而看不到另一次有意义的跳跃。

辩论打破 saturation。而不是从一个模型中独立得出N样本,N agents 阅读对方的推理并修改。 样本滴水( 它们不再具有i. id.) , 而汇合点往往是正确的, 因为i. d. 投票充满信心地是错误的。

<a id="concept"></a>

## 概念

<a id="the-du-et-al-2023-algorithm"></a>

### Du等人2023算法

发自ArXiv:2305.14325(ICML 2024):

1. 每一个N级 agents 提出对这一问题的初步答复。
2. 圆 R = 2. R: 每一 agent 显示其他 agents回答"考虑这些,提供最新答案"
3. 轮回后,多数投票最后答案。

论文对MMLU、GSM8K、传记、MATH和事实质量基准进行了测试,辩论始终胜过CT和自我反思。

<a id="two-independent-knobs"></a>

### 两个独立的按钮

同一报纸上的反射:

- **Agent 单数** (一回合,多数票为N) 胜过单agent 多数任务,但高原。
- **单枪匹马** (1 agent 反省是众所周知的弱点。
- **两者兼有** 产生巨大的跳跃。 agents 推动增长。

<a id="why-it-works"></a>

### 为什么它有效

两种机制:

1. **暴露在分歧中** 当 agent 看见另一个 agent逻辑链中含有不同的结论, 它必须说明理由或更新。 不论哪种方式, r+1 的上下文比 r 圆更丰富 。
2. **减少与错误有关的错误。** 在自定性情况下,所有样本都来自同一个模型,因此错误是相互关联的——你平均地说是一个充满信心的错误答案。不同的模型或不同的种子装饰。不同的模型或不同的种子。 *辩论意见* 更进一步装饰

<a id="heterogeneous-debate"></a>

### 不同寻常的辩论

A-HMAD和相关后续措施的使用 *不同的基数模型* 不同类型 agents. Llama + Claude + GPT 辩论可以减少单一文化的崩溃(Lesson 26),因为一个模式家庭的相关错误不为其他家庭所分享。

负面:参加辩论的弱模式会拖住共识,导致错误的答案(见“我们是否应该采取MAD?” ,ArXiv:2311.17371)。

<a id="nlsom--the-129-agent-extension"></a>

### NLSOM - 129号agent extension

Zhuge等人(“自然语言社会的思想风暴”,ArXiv:2305.17066)将这一理念推广到129个成员的社会。结果:专业化和自我组织规模逐渐扩大,而系统的表现超过了单一的-agent 来回答视觉问题

<a id="failure-modes"></a>

### 失效模式

- **血吸力级联** 所有 agents 推迟到 agent 辩论声势最响亮,引发对抗 agent 也表示,
- **话题流** 许多回合的辩论与最初的问题无关。 减轻: 每回合都重新输入问题。
- **计算爆炸。** N agents ×R 子弹=N-R LLM 电话,每个都有成长的背景agent5轮辩论是25次,在日益扩大的背景下。每个问题的成本可以超过10x1次。

<a id="build-it"></a>

## 动手实现

`code/main.py` 运行一个3 -agent × 3轮辩论,讨论数学问题,其中每个 agent 开头是不同的(可能是错误的)回答。 Agents 使用文字格式, 每一个“ 更新” , 平均使用文字格式的自信来计算邻居的回答。 圆形日志中可以看到一致 。

演示显示两个关键效果:

- 单轮交换动作 agents 离正确的答案更近
- 上一轮第二轮的多发子弹显示回报率下降(du等人的高原)。

Run:

```
python3 code/main.py
```

<a id="use-it"></a>

## 实际应用

`outputs/skill-debate-configurator.md` 配置新任务的辩论: agents,圆形数,异质(同一模型与混合模型),角色分配(对称对称对一对抗性)。 token 开销在跑步前

<a id="ship-it"></a>

## 交付成果

如果你的船辩论:

- **3点整有大炮** Du等人显示,3轮的收益占了大部分。成本更高,质量不高。
- **Cap agents 5点** 超过5,环境膨胀和成本占优势。
- **默认情况下,变化很大。** 至少两个不同的基模在池。
- **反向位置** One agent 促使人们不赞同,打破了矛盾
- **记录每一轮。** 隐藏中间回合的辩论系统不能调试或审计。

<a id="exercises"></a>

## 练习

1. Run `code/main.py`,然后将圆数设为5,并观察回报减少。在哪个回合,进一步的趋同会停止吗?
2. 添加第四个 agent 具有对抗作用:总是不同意目前多数意见。 这是否打破还是改进了趋同?
3. 每回合绘制协议评分( 打印) (违反 agents 什么时候打到1.0,这相当于"正确"?
4. 阅读Du等人,第4节,重写 "agents- 使用这个代码,只有"和"只圆"和"两者"的结果。
5. 读“我们是否应该采取MAD” (arXiv:2311.17371),并列出圆柱之外的两个辩论变体——例如法官领导的辩论链、对抗性辩论。

<a id="key-terms"></a>

## 关键术语

| 术语 | 人们怎么说 | 它实际上意味着什么 |
|------|----------------|------------------------|
| 思想学会 | "明斯基的主意" | 情报作为互动专家;1986年,框架现已通过 LLM debate. |
| Multi-agent debate | "Agents argue" | N agents 提议,互相批评,修改R回合,多数投票。 |
| Consensus | "他们同意" | 不是认知真相,只是零敲碎打的回答,可能是自信错误。 |
| Rounds | 换台阶 | 一轮=每轮 agent 读过其他的,并更新一次。 |
| 不同寻常的辩论 | "混合模范家庭" | 使用不同的基建模型来设计错误。 |
| 食欲级联 | "每个人都同意那响亮的歌" | 辩论失败 agents 顺从最自信的人 agent 不论正确与否 |
| NLSOM | "129-agent society" | 自然语言思想学会;Zhuge等人的缩写版。 |
| 相关错误 | 同一个模型,同一个虫子 | 为什么自相矛盾的饱和;不同观点之间的辩论会变得很复杂。 |
