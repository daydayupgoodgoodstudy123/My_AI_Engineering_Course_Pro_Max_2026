# 16/18 分关面试题：MindTrace

一个写好一半的本地epistemic replay服务，五个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关。英文题面在 [README.md](README.md)，具体合同在typed records、docstring和测试里。

内容围绕“谁看到了什么、认为别人会选什么、自己实际能选什么”：可见观察写入、独立历史存储、subject解释／预测与own选择、有序JSON Patch，以及有限高阶context查询。typed partial visibility、独立BeliefVersion、perceived candidates、SQLite和context graph都是显式本地适配。来源只有flat(other,box)观察与preference prime，不是LLM或真实ToM推理；本题不证明协调收益或认知能力。

## 开始

先把整个 `exam/` 另存为自己的作答副本，在该副本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

五个skipped说明分关锁仍在。照README只解除Part 1的skip，先运行并读首个失败。只需标准库和pytest，不需要API key、网络、真实模型或来源脚本。

## 规则与时间

- 总计60分钟：开场2分钟，Part 1–5分别12、10、16、10、10分钟，共58分钟编码。安排没有经过真人面试校准，请记录实际时间。
- 只改 `mindtrace/`。测试除解除对应skip外保持原样；不要改完整Given、fixture、限时断言或期望来绕过失败。可在作答副本另建自己的测试文件。
- 可以查Python官方文档。计时期间关闭 `solution/`、`INTERVIEWER.md` 和本题讲解。独立练习先写下澄清问题，再只看手册对应的英文答案。
- 说清每次修改的输入、输出和依据。P1的current inventory是control primitive，不提供P3 subject interpretation、perceived-domain prediction或own exclusion／fallback。
- 一个World UID／generation标识唯一immutable inventory，不能同key换available。subject prediction只使用subject perceived candidates，own choice只使用actual AvailableView；这两个候选域不能互换。
- 保存的model snapshot保留control决定前的原始population／completion语义，并关联实际可见观测。P3是在同一original world上展示alternative policy，不承接control已经领取后的结果，也不宣称优于control。
- 合法域是有限typed replay：action evidence是approach-target字符串，其他kind的fact保历史；P5 subject chain有明确max_order，允许有限请求重复context／cycles，不做无界递归。

## 常用命令与练习开关

```bash
python3 -m pytest -x
python3 -m pytest -k visible_writer -x
python3 -m pytest -k interpret_other -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

`--all-parts` 忽略五个Part skip；`--solution` 将导入切到参考实现。两个开关由本目录 `conftest.py` 提供。计时结束后才检查参考模式，退出后关闭答案，再去掉 `--solution` 检查自己的代码；参考结果不能计入个人成绩。
