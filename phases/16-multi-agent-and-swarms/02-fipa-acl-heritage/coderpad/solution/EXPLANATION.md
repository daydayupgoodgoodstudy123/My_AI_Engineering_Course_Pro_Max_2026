# 参考解释：Heritage of FIPA-ACL and Speech Acts

## 核心：JSON-RPC 请求包

先验证 envelope 类型再深拷贝 params，拒绝 Python bool 冒充整数 id。

准确合同：id exact int or nonempty string; method nonempty string; params dict. Return {'jsonrpc':'2.0','id','method','params':deepcopy}. Reject bool id, invalid method/params with ValueError. No connection or request execution.

## 加分：配置合同校验

必填缺失和未知字段独立收集；字段存在但值为 None 不在这个浅层合同的检查范围。

准确合同：required and optional are field-name lists. Return {'missing':sorted required absent keys,'unknown':sorted config keys outside required+optional,'valid':no findings}. Values are deliberately not type-checked here. Empty config can be valid.
