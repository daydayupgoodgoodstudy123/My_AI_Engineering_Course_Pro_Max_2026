# 16/17 分关面试题：SmallvilleLab

一个写好一半的本地 memory／reflection／plan 服务，五个测试用 `@pytest.mark.skip("Part N")` 锁住，一次解锁一关。英文题面在 [README.md](README.md)，具体合同在 typed records、docstring和测试里。

本题把来源的记忆、反思、计划与空间约束概念接到确定性 replay：检查邀请和记忆特征，保存各agent完整状态，实现排序、带来源反思与局部修订，再输出模拟日历并执行nested plans。stable IDs、explicit consumed set、ReflectionProposal／PlanPatch、目录快照、日历和World admission都是显式本地适配。来源邀请路径和tick5计划是脚本，检索函数与simulation脱节；本题不宣称重现无脚本社会涌现。

## 开始

先将整个 `exam/` 另存为自己的作答副本，在该副本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

五个skipped说明分关锁仍在。照README解除Part 1的skip，先运行并读首个失败。只需标准库与pytest，不需要API key、网络、真实模型或来源脚本。

## 规则与时间

- 总计60分钟：开场2分钟，Part 1–5分别12、10、16、10、10分钟，共58分钟编码。这个分配没有经过真人面试校准，实际用时需记录。
- 只改 `smallvillelab/`。测试除解除对应skip外保持原样；不要改完整Given、fixture、限时断言或期望来绕过失败。可在作答副本另建自己的测试文件。
- 可以查Python官方文档。计时期间关闭 `solution/`、`INTERVIEWER.md` 和本题讲解。自己练习先写下澄清问题，再只看手册里对应的英文答案。
- 说明修改的输入、输出和依据。P1只给availability／pending gate／lexical feature；P3的composite rank、grounded reflection和affected-plan revision由自己实现。P5接收Given绑定的current P3 segments，不重新决定哪些计划需修订。
- 合法域为有限typed replay：人口与稳定UID明确，整数tick、非负window／threshold、importance为1..10；reflection proposal和patch是声明数据。只有实际引用的可用raw observations被消费，不能由belief是否为空或最大seq推断progress。
- P4是同步的受限本地VCALENDAR／VEVENT feed，不写外部日历。P5在一个supplied simulated now按声明DFS顺序执行当前动作，不实现未来reservation或并发事务。

## 常用命令与练习开关

```bash
python3 -m pytest -x
python3 -m pytest -k population_available -x
python3 -m pytest -k composite_rank -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

`--all-parts` 忽略五个Part skip；`--solution` 把导入切到参考实现。两个开关来自本目录 `conftest.py`。计时结束后才检查参考模式，退出后关闭答案，再去掉 `--solution` 检查自己的代码；参考结果不计入个人成绩。
