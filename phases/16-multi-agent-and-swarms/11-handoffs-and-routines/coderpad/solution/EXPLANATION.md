# 参考解释：Handoffs and Routines — Stateless Orchestration

## 核心：可验证任务交接

交接应包含目标、当前状态、下一动作与可验证检查；非空字段检查不证明内容真实。

准确合同：Required nonempty string fields: objective, state, next_action. checks must be a nonempty list of nonempty strings. Return sorted missing/invalid field names (among those four). Extra fields allowed; whitespace-only strings are invalid. Do not execute next_action.

## 加分：合法状态转换

允许边应显式列出，终态不再接受新转换，包括重放到同一状态。

准确合同：Allowed edges: queued->running/canceled; running->waiting/completed/failed/canceled; waiting->running/canceled. Return target if allowed, otherwise ValueError. Terminal states cannot transition, including to themselves.
