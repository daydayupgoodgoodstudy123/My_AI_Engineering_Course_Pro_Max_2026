# 16/20 分关面试题：CTDEGrid

一个写好一半的本地scripted local-policy服务。五测试用 `@pytest.mark.skip(reason="Part N")` 锁住，一次解锁一关；英文薄题面在 [README.md](README.md)，具体合同见typed records、docstring与测试。

本题从空网格上的两个actor出发，修local-Q执行与joint collection，保存完整binary rollout，再计算固定状态的numeric mixer、观察CSV和nested expression certificate。来源代码用每步集中式assignment演示概念，没有真实Q学习、critic优化或PPO／DDPG梯度；本题Q rows、显式reward、mixer与nested audit都是明示本地适配。

## 开始

先把整个 `exam/` 另存为自己的作答副本，在副本目录打开终端：

```bash
python3 -m pip install pytest
python3 -m pytest
```

五个skipped表示分关锁仍在。按README解除Part 1的skip，先读首个失败，再定位producer与正确consumer。仅需标准库和pytest，不需要API key、网络、训练框架或来源脚本。

## 规则与时间

- 总计60分钟：开场2分钟，Part 1–5分别12、10、16、10、10分钟，共58分钟编码。真人难度／时间尚未校准，记录实际用时。
- 只改 `ctdegrid/`。测试除解除对应skip外保持原样；完整Given、fixture、期望与限时断言保持不变。自己的额外测试放作答副本的独立文件。
- 可查Python官方文档。计时期间关闭 `solution/`、`INTERVIEWER.md` 与本题讲解；独立练习先记录澄清问题，再只看手册相应英文答案。
- 说明输入、输出与修改依据。P3的numeric mix、充分结构证书、Cartesian oracle是三个独立TODO；参数对象不是已实现的算法。
- 世界是size 1..128的无障碍方格，两actor可同格；同一joint step可收两个不同pellet，同pellet按声明actor序仅奖励一次。terminal输入没有action／Q row。
- 保留原任意非负整数step。P3训练特征固定为 `(float(size), step/(step+1))`，archive与CSV中的step仍是原整数，不能用归一化值替换。
- P3／P5证书都是充分条件。证书失败不等于函数实际非单调或greedy有gap；实际有限joint-value gap由P3枚举报告。P5路径乘积用精确Fraction，逐节点数值仍按声明顺序用binary64计算。
- P2已拿到完整local records，不负责再过滤central state；P4明确允许独立training_state列。执行actor不能依赖central hint，是P1的决策合同。

## 常用命令与练习开关

```bash
python3 -m pytest -x
python3 -m pytest -k part1_local -x
python3 -m pytest -k part3_numeric -x
python3 -m pytest --all-parts
python3 -m pytest --solution --all-parts
```

`--all-parts` 忽略五个Part skip；`--solution` 将导入切到参考实现，均由 `conftest.py` 提供。计时结束才使用参考模式；退出后关闭答案，去掉 `--solution` 检查自己的实现，参考结果不能计入个人成绩。
