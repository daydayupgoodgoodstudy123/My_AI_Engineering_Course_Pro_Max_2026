## 在 GitHub 上启动此阶段

**先修要求:** 第7阶段 Transformers 和第四阶段计算机远景。

**第一课:** [Vision Transformer Patch Tokens](01-vision-transformer-patch-tokens/docs/zh.md)

从存储库根目录运行此命令：

```bash
python3 phases/12-multimodal-ai/01-vision-transformer-patch-tokens/code/main.py
```

保持指挥,退出代码, patch 网格和序列长度, parameter counts,
和一句话解释为什么更高分辨率 创造更多视觉 tokens.

**下一步行动:** 更改一个图像或 patch 大小,预测序列长度,
然后继续 [CLIP 和反向 Pretraining](02-clip-contrastive-pretraining/docs/zh.md).

浏览 [完整第12阶段课程列表](../../README.md#phase-12) 或该
[跨阶段路线图](../../ROADMAP.md).
