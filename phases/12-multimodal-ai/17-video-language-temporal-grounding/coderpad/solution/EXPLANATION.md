## 核心：视频均匀采样

覆盖首尾时间点，单帧采样单独处理，避免除以 count-1 为零。

准确合同：Require exact nonnegative integers length/count and count<=length. Return count indices spanning 0..length-1 using floor(i*(length-1)/(count-1)). count=0 -> []; count=1 -> [0]. Invalid input raises ValueError.

## 加分：边框 IoU

先算交集，再用两框面积减交集得到并集；相接边界不产生交集面积。

准确合同：Boxes are [x1,y1,x2,y2], with x2>=x1 and y2>=y1; reject other shapes/reversed bounds with ValueError. Return intersection area / union area, or 0 if union is zero. Touching edges have zero intersection.
