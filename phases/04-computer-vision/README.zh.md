## 在 GitHub 上开始此阶段

**先决条件：** 第 1 阶段第 12 课、Tensor 操作和第 3 阶段第 11 课、
PyTorch简介。第一个演示只需要NumPy。

**第一课：** [图像基础](01-image-fundamentals/docs/zh.md)

从存储库根目录运行此命令：

```bash
python3 phases/04-computer-vision/01-image-fundamentals/code/main.py
```

保留命令、退出代码、HWC 和 CHW 形状、标准化通道统计信息、
往返像素差异和插值粗糙度。该演示生成一个
确定性合成图像并且不使用网络。

**下一步操作：** 说明HWC和CHW之间哪个轴变化，然后继续
到 [ 从头开始的卷积 ](02-convolutions-from-scratch/docs/zh.md)。
