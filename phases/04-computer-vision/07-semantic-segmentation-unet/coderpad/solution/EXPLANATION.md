# 参考解释：Semantic Segmentation — U-Net

## 核心：分割 Dice

交集乘二后除以两个正例总数；两空掩码按合同记为完全一致。

准确合同：Require equal-length exact-bool masks. Dice=2*intersection/(predicted positives+expected positives); if both have no positives return 1. Invalid masks raise ValueError.

## 加分：分类混淆矩阵指标

先明确 TP/FP/FN/TN 定义，再处理零分母，禁止把整数当作 bool 标签。

准确合同：Require equal-length exact-bool lists. Return tp,fp,fn,tn,precision,recall,f1. A ratio with zero denominator is 0.0. Empty lists are valid; invalid labels raise ValueError.
