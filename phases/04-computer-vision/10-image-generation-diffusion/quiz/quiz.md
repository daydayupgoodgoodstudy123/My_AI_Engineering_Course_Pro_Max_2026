## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 前向加噪过程 | `q(x_t ∣ x_{t−1}) = N(√(1−β_t)·x_{t−1}, β_t·I)`；β 一般从 1e-4 线性增到 0.02，共 T=1000 步，最终 `x_T` 近似纯高斯噪声 |
| 2 | 闭式跳步 | 令 `α_t = 1−β_t`、`ᾱ_t = ∏α_s`，则 `x_t = √ᾱ_t·x_0 + √(1−ᾱ_t)·ε`；训练时随机挑 t 一步采样，无需模拟整条马尔可夫链 |
| 3 | ε 预测与 MSE 损失 | 网络 `ε_θ(x_t, t)` 预测加入的噪声，损失就是 `‖ε − ε_θ‖²`：没有对抗博弈、没有模式崩溃 |
| 4 | DDPM 采样 | 从 `x_T ~ N(0, I)` 出发逐步 `x_{t−1} = (1/√α_t)·(x_t − β_t/√(1−ᾱ_t)·ε) + √β_t·z`，最后一步不加噪声 |
| 5 | 噪声调度 | 步数太少则反向一步不再近似高斯；线性调度会过早把信号耗尽，余弦调度让信号衰减更均匀 |
| 6 | DDIM | 训练不变、只换采样器：确定性（η=0）、可跳步，50 步接近 1000 步 DDPM 的质量；η=1 退回 DDPM |
| 7 | 时间条件 | 用正弦时间嵌入（与 Transformer 位置编码同源）+ MLP 得到向量，加到 U-Net 的特征图上 |
| 8 | 与 GAN 的取舍 | 扩散：训练稳定、易扩展、每一步都能注入约束（文本、inpainting），但采样需要多步；GAN：一次前向、快，但难训练 |

- [ ] 实现 `q_sample`，说清 `view(-1, 1, 1, 1)` 如何让每张图使用自己的 t
- [ ] 实现 DDPM 的训练步（每张图独立随机 t）和 1000 步祖先采样器，并解释每个系数
- [ ] 实现 DDIM 采样器（含 η），能写出它访问的时间步序列，并指出最后一步的处理细节
- [ ] 实现正弦时间嵌入，把它通过 MLP 注入一个小 U-Net
- [ ] 实现余弦噪声调度，与线性调度对比 `ᾱ_t` 曲线

## 五、参考答案与解析

### Q1 — 答案：B

`x_t = √ᾱ_t·x_0 + √(1−ᾱ_t)·ε = √0.36·x_0 + √0.64·ε = 0.6·x_0 + 0.8·ε`。注意系数是 ᾱ 的**平方根**：信号系数与噪声系数的平方和为 1，`x_t` 的方差（对单位方差数据）保持为 1，这就是"variance preserving"。A、C 忘了开方。

### Q2 — 答案：C

DDPM 把网络参数化为预测噪声 ε：给定 `ε_θ` 和调度，`x_{t−1}` 的高斯均值有解析式，方差也是固定的。这样损失就退化为简单的 MSE，梯度数值性质也好。讲义原话："they predict the noise epsilon added at step t, and the math derives x_{t−1} from it"。

### Q3 — 答案：B

`√ᾱ_T ≈ 0.131`、`√(1−ᾱ_T) ≈ 0.991`：最后一步的 `x_T` 仍是"13% 原图 + 99% 噪声"，并非纯噪声。训练时模型从没见过"完全不含信号"的输入，但采样时却从纯 `N(0, I)` 起步，起点分布存在轻微偏差（对这个背景为 −1 的数据集，真实 `x_T` 的背景均值约 −0.13，而不是 0）。缩短 T 而又不把 β 加大到足够，就会出现这种"终点 SNR 不为 0"的情况。C 太绝对：线性调度在 T=1000 时 `ᾱ_T` 也只是约 4e-5，并不精确为 0；D 混淆了 ᾱ 和 1−ᾱ。

### Q4 — 答案：C

DDIM 完全不改训练，只改采样：它把反向过程写成一个（η=0 时）确定性的过程，可以在一个时间步子序列上采样，所以能跳步。A、B、D 都是讲义明确说的性质。

### Q5 — 答案：B

正弦嵌入在多个频率上编码 t：低频分量区分"早期/晚期"，高频分量区分相邻步，任意 t 都是嵌入空间中的唯一点，相邻 t 的嵌入相近，网络可以平滑泛化；维度（如 64）与 T 无关。one-hot 需要 T 维、相邻步之间毫无相似性。讲义也指出这与 Transformer 的位置编码是同一思想。

### Q6 — 答案：C

β 调度决定了训练时网络见到的 `(x_t, t)` 分布——同一个 t 在余弦调度下对应完全不同的 ᾱ_t，原模型学到的"t → 噪声水平"映射就失效了，必须重训。A、B、D 都只是换采样器或采样参数，模型权重可以直接复用（本节 quiz.json 的解析原话：A DDPM checkpoint can be used with a DDIM, DPM-Solver, or Euler sampler interchangeably）。

### Q7 — 答案：B

`t = 0` 这一步算出的 `mean` 就是最终输出的图像，此时取后验均值最合理；再加 `√β_0·z` 只会添加噪点。C 错：本节调度 `β_0 = 1e-4`，不是 0；D 错：前面的每一步仍然加噪，DDPM 依旧是随机采样。讲义伪代码也写明"z ~ N(0, I) if t > 1, else 0"。

### Q8 — 参考答案

(a) `schedule["sqrt_alphas_cumprod"]` 形状 `(T,)`；用长度 16 的整数张量 `t` 做**花式索引**，`[t]` 得到 `(16,)`，每个元素是对应图像自己的 `√ᾱ_t`；`.view(-1, 1, 1, 1)` 变成 `(16, 1, 1, 1)`，才能和 `(16, 3, 16, 16)` 的 `x0` 广播相乘——每张图的所有像素乘以同一个系数，不同图乘以不同系数。若不 `view`，`(16,)` 会和 `x0` 的**最后一维**（宽 16）对齐广播，形状不报错但语义完全错误（变成"每一列一个系数"）。

(b) `√ᾱ_100 ≈ √0.357 ≈ 0.598`，`√(1−ᾱ_100) ≈ √0.643 ≈ 0.802`。`x_100 = 0.598·(−1) + 0.802·0.5 ≈ −0.598 + 0.401 = −0.197`。

(c) 每个 batch 只覆盖一个噪声水平，梯度在不同 batch 之间剧烈变化（不同 t 的损失尺度和难度都不同），训练噪声大、收敛慢；独立采样让每个 batch 都是"所有噪声水平的混合"，梯度估计方差更低。期望意义上两者优化的是同一个目标。

### Q9 — 参考答案

(a) 形状（B=2）：

| 张量 | 形状 | 说明 |
|------|------|------|
| `timestep_embedding(t, 64)` | `(2, 64)` | 32 个 sin + 32 个 cos |
| `t_emb` | `(2, 64)` | `Linear(64, 64) → SiLU → Linear(64, 64)` |
| `t_proj` | `(2, 32, 1, 1)` | `Linear(64, 32)` 后补两个空间维 |
| `h1` | `(2, 16, 16, 16)` | 3×3 卷积，尺寸不变 |
| `h2` | `(2, 32, 8, 8)` | 4×4 步长 2 卷积下采样，再加 `t_proj` |
| `h3` | `(2, 32, 8, 8)` | 瓶颈 3×3 卷积 |
| `d1` | `(2, 16, 16, 16)` | 转置卷积 `(8−1)·2 − 2 + 4 = 16` |
| `d2` | `(2, 32, 16, 16)` | 与 skip `h1` 在通道维拼接 |
| 输出 | `(2, 3, 16, 16)` | 与输入同形状——预测的是每个像素的噪声 |

(b) `t_proj` 原本是 `(B, 32)`；`[:, :, None, None]` 插入两个长度为 1 的维度变成 `(B, 32, 1, 1)`，与 `(B, 32, 8, 8)` 的特征图相加时广播到每个空间位置：同一张图的所有位置加同一个"时间偏置"，不同通道加不同的值。

(c) 参数量：
- `t_mlp`：`(64·64 + 64) × 2 = 8,320`
- `enc1`：`3·16·9 + 16 = 448`；`enc2`：`16·32·16 + 32 = 8,224`；`mid`：`32·32·9 + 32 = 9,248`
- `dec1`（转置卷积，权重 `(in, out, k, k)`）：`32·16·16 + 16 = 8,208`；`dec2`：`32·3·9 + 3 = 867`
- `time_proj`：`64·32 + 32 = 2,080`
- 合计 **37,395**，即 `params: 37,395`。

(d) 只在瓶颈之前的 `h2` 处注入一次（讲义："time conditioning injected at the bottleneck"）。讲义说的现代做法是：正弦嵌入经 MLP 后加到**每一级** U-Net 的特征图上（通常在每个残差块里各有一个投影层），让每个分辨率的层都知道当前噪声水平。

### Q10 — 参考答案

(a) `linspace(199, 0, 21)` 步长 −9.95，`.long()` 向零截断：

```text
[199, 189, 179, 169, 159, 149, 139, 129, 119, 109, 99, 89, 79, 69, 59, 49, 39, 29, 19, 9, 0]
```

循环 `range(20)`，每次调用一次模型，共 **20 次**（`t = 0` 只作为最后一步的 `t_prev`，模型不会在 t=0 被调用）。相比 DDPM 采样器的 200 次，快 10 倍。

(b) **不是完全干净的。** 最后一步 `a_prev = ᾱ_0 = 1 − 1e-4 = 0.9999`，`x = √0.9999·x0_pred + √0.0001·eps`，还残留约 `0.01·ε` 的噪声——它对应的是"第 0 个时间步"的带噪图像，而不是 `x_0`。DDPM 采样器在 `t=0` 那一步取均值、不加噪声，输出的就是 `x_0` 的估计。改法：最后一步令 `a_prev = 1`（讲义版本写了 `if t_prev >= 0 else 1.0` 的分支想做这件事，但 `ts` 的最后一个值是 0 而不是负数，这个分支永远走不到），或直接返回最后一步的 `x0_pred`。在这个数据尺度下误差只有 0.01 量级，但概念上应当分清。

(c) `x0_pred = (x − √(1−ᾱ)·ε_θ)/√ᾱ`，若 `ε_θ = ε + δ`，则误差为 `−√(1−ᾱ)/√ᾱ · δ ≈ −0.991/0.131 · δ ≈ −7.6·δ`，被放大约 7.6 倍；在 T=1000 的线性调度末端 `√ᾱ ≈ 0.0064`，放大倍数约 157。未训练充分的模型因此会在早期步给出很离谱的 `x0_pred`，样本数值范围可能远超 [−1, 1]。常用做法是把 `x0_pred` **裁剪到数据范围** `[−1, 1]`（如 `x0_pred.clamp(-1, 1)`，diffusers 等实现中称为 clip sample；Imagen 进一步提出了按分位数的 dynamic thresholding），再用裁剪后的 `x0_pred` 反推 ε。本节代码没有做裁剪。

### Q11 — 参考答案

```python
import math
import torch

def cosine_beta_schedule(T=1000, s=0.008):
    steps = torch.arange(T + 1, dtype=torch.float64) / T
    f = torch.cos((steps + s) / (1 + s) * math.pi / 2) ** 2
    alphas_cumprod = f / f[0]                         # 归一化，使 ᾱ 从 1 开始
    betas = 1 - alphas_cumprod[1:] / alphas_cumprod[:-1]
    return betas.clamp(0, 0.999).float()             # 末端 β 可能接近 1，需要裁剪

schedule = precompute_schedule(cosine_beta_schedule(T=200))
```

- 先按讲义公式算出 `ᾱ_t = cos²((t/T + s)/(1 + s)·π/2)`（除以 `f(0)` 保证 `ᾱ` 从 1 开始），再由 `β_t = 1 − ᾱ_t/ᾱ_{t−1}` 反推每步的 β，这样就能复用 `precompute_schedule`。
- 裁剪到 0.999：最后几步 `ᾱ` 趋近 0，比值会让 β 接近 1，导致 `√(1/α_t)` 爆炸。
- 对比（用 NumPy 实际计算）：T=200 时，线性调度（1e-4→0.04）在 t = 50 / 100 / 150 的 `ᾱ` 约为 0.770 / 0.357 / 0.099，末端 0.017；余弦调度对应约为 0.841 / 0.486 / 0.139，末端约为 0。T=1000 时，线性调度 t=600 的 `ᾱ` 只有约 0.026，余弦调度约 0.339。余弦调度在前中段保留更多信号、末端真正到达纯噪声，讲义练习 3 预期它在少步采样时效果更好。

### Q12 — 参考回答要点

- **前向**：固定的马尔可夫链，每步 `x_t = √(1−β_t)·x_{t−1} + √β_t·ε`，β 很小且递增；由于高斯的叠加仍是高斯，有闭式 `x_t = √ᾱ_t·x_0 + √(1−ᾱ_t)·ε`。
- **训练**：采样 `x_0`、均匀采样 t、采样 ε，构造 `x_t`，最小化 `‖ε − ε_θ(x_t, t)‖²`。每步训练只需一次前向，与 T 无关。
- **采样**：从 `x_T ~ N(0, I)` 出发，用 `x_{t−1} = (1/√α_t)(x_t − β_t/√(1−ᾱ_t)·ε_θ) + σ_t z` 逐步去噪；这些系数来自高斯后验 `q(x_{t−1} | x_t, x_0)` 的贝叶斯公式。
- **为什么好训练**：目标是一个固定的回归问题（MSE），不存在两个网络的博弈，所以没有模式崩溃、振荡；损失曲线可解释；扩大模型和数据几乎总是有效。代价是采样需要多次前向。
- **加分点**：提到 ε 预测下的损失是变分下界（ELBO）去掉加权后的简化版；说明 β 足够小时反向一步才近似高斯，这是需要很多步的原因。

### Q13 — 参考回答要点

- **为什么预测 ε**：ε 始终是标准高斯，目标尺度在所有 t 上一致（单位方差），回归更稳定；DDPM 论文发现 ε 预测配简化损失的样本质量更好。直接预测 `x_0` 在大 t 时几乎是在"凭空猜整张图"，目标方差大。
- **三者可互换**：由 `x_t = √ᾱ·x_0 + √(1−ᾱ)·ε`，知道其一就能算出另一个：`x̂_0 = (x_t − √(1−ᾱ)·ε̂)/√ᾱ`（DDIM 代码里的 `x0_pred` 就是这么来的）。
- **v 预测**：`v = √ᾱ·ε − √(1−ᾱ)·x_0`（Salimans & Ho 提出），在高噪声和低噪声两端都表现良好，常用于蒸馏和高分辨率模型。
- **score**：`x_t` 的分数 `∇log p(x_t) = −ε/√(1−ᾱ_t)`，所以 ε 预测本质上是在做（缩放后的）分数匹配，这把 DDPM 与 score-based 模型、SDE/ODE 视角统一起来。
- **常见误区**：认为几种参数化"学的东西不同"——它们只是同一个量的不同线性组合，差别在于损失的隐式加权和数值稳定性。

### Q14 — 参考回答要点

- **为什么能少步**：DDIM 构造了一族与 DDPM 拥有相同边缘分布 `q(x_t | x_0)` 的非马尔可夫过程，因此用同一个训练好的 ε 网络即可；η=0 时反向过程是确定性的，可以看作一个 ODE 的离散化，轨迹平滑，大步长也能接近同一终点。每一步：先用 ε 估计 `x̂_0`，再沿"指向 `x_t` 的方向"`√(1−ᾱ_prev−σ²)·ε` 走到 `t_prev`。
- **η**：控制每步注入的随机噪声 `σ`。η=0 完全确定；η=1 时对应 DDPM 的随机采样。
- **额外能力**：①同一个噪声种子得到同一张图，便于复现、调参；②在噪声空间里插值得到语义平滑的图像过渡；③DDIM inversion：把真实图像沿 ODE 反向编码回噪声，再改条件重新生成，是许多图像编辑方法的基础。
- **后续**：DPM-Solver、Euler、Heun 等更高阶的 ODE 求解器进一步把步数降到 10–25；flow matching / rectified flow 直接学习更直的轨迹（第 23 节）。

### Q15 — 参考回答要点

- **考虑因素**：①T 与 β 范围共同决定 `ᾱ` 曲线；②终点 SNR 应接近 0，保证训练终点与采样起点（纯噪声）一致（Q3 就是反例）；③信号不应过早耗尽——本节 quiz.json 指出线性调度在 T=1000 时到 t≈600 已几乎无信号，后 40% 的步数浪费；④分辨率越高，相同噪声水平下图像冗余越多、越"难被破坏"，往往需要整体向更高噪声平移调度；⑤推理时打算用多少步。
- **诊断**：画 `ᾱ_t`、`SNR(t) = ᾱ_t/(1−ᾱ_t)`（取对数）随 t 的曲线；可视化 `x_t` 在若干 t 下的样子（讲义练习 1）；看按 t 分桶的训练损失；最终用少步/多步采样的 FID 对比。本节 `outputs/skill-noise-schedule-designer.md` 就是围绕"给定 T 与目标破坏程度生成 linear / cosine / sigmoid 调度 + SNR 诊断图"设计的。
- **常见选择**：低分辨率小模型可用余弦调度；改调度必须重训（Q6）。

### Q16 — 参考回答要点

- **换采样器**（零训练成本）：DDIM / DPM-Solver / Euler 把 1000 步降到 20–50 步，质量损失很小。
- **蒸馏**（需要训练）：渐进式蒸馏、consistency 模型、对抗蒸馏（如 SDXL Turbo 的 ADD）把步数压到 1–4 步，代价是训练成本和一定的多样性/可控性损失。
- **潜空间扩散**：在 VAE 压缩后的 latent 上去噪（Stable Diffusion，第 11 节），512×512 图像的计算量降到 64×64×4 的 latent 级别。
- **模型与系统**：更小/更高效的去噪网络、fp16/bf16、TensorRT/编译优化、attention 优化、批处理；classifier-free guidance 每步需要两次前向，可用蒸馏掉 guidance 的方法减半。
- **换范式**：flow matching / rectified flow（第 23 节）学习更直的轨迹，少步采样更友好。
- **取舍**：越激进的加速通常牺牲多样性、细节或提示词遵循度；需要用 FID / CLIP score 和人工评测共同把关。
