## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 向量 = 空间中的点/方向 | 一串数字就是 n 维空间里的坐标；embedding 就是"含义"的坐标 |
| 2 | 矩阵 = 线性变换 | `W @ x` 把向量从一个空间映射到另一个空间；神经网络的一层本质就是一次矩阵乘法 |
| 3 | 点积与余弦相似度 | `a·b = Σ aᵢbᵢ = |a||b|cosθ`；>0 同向、=0 正交、<0 反向，是相似度检索和 attention 的核心 |
| 4 | 线性无关 | 集合中没有任何向量能被其余向量线性组合出来；特征共线会导致多重共线性 |
| 5 | 基与秩 | 秩 = 线性无关列数 = 线性无关行数；秩亏 ⇒ 信息丢失、不可逆、解不唯一 |
| 6 | 投影 | `proj_b(a) = (a·b / b·b)·b`，残差与 b 正交；最小二乘、PCA 都是投影 |
| 7 | Gram-Schmidt 与 QR | 逐个减去在已有正交基上的投影再归一化，得到标准正交基；Q 是正交基、R 是投影系数 |
| 8 | 低秩与 LoRA | LoRA 假设权重更新位于低维子空间：`ΔW = B·A`，参数量从 d² 降到 2dr |

**Q9.** 下面的 `gram_schmidt` 实现里，`if w.magnitude() < 1e-10: continue` 这一行删掉会发生什么？请举一个会触发问题的输入。

```python
def gram_schmidt(vectors):
    orthonormal = []
    for v in vectors:
        w = v
        for u in orthonormal:
            w = w - w.project_onto(u)
        if w.magnitude() < 1e-10:
            continue
        orthonormal.append(w.normalize())
    return orthonormal
```

## 五、参考答案与解析

### Q1 — 答案：C

点积 `a·b = |a||b|cosθ`。两个非零向量点积为 0，只能是 `cosθ = 0`，即 θ = 90°，两者正交。D 错在题目已说明是非零向量。

### Q2 — 答案：B

`[2,1,0] = 2·[1,0,0] + 1·[0,1,0]`，第三个向量能由前两个线性组合得到，所以线性相关；三个向量都落在 xy 平面上，只张成 2 维子空间。C 看起来"很像"但其实线性无关（行列式 = -2 ≠ 0）；D 中两个 2 维向量不成比例，也无关。

### Q3 — 答案：B

第二行 `[2,4]` 正好是第一行的 2 倍，行化简后只剩一个非零行，秩为 1。几何上：所有列向量都在同一条直线上，矩阵把整个平面"压扁"成一条线，因此不可逆。

### Q4 — 答案：A

`proj_b(a) = (a·b / b·b)·b = (3/1)·[1,0] = [3,0]`；残差 `a - proj = [0,4]`。验证：`[0,4]·[1,0] = 0`，残差与 b 正交——这就是正交分解，也是最小二乘的几何本质。

### Q5 — 答案：A

`(2×3) @ (3,) → (2,)`。矩阵的列数必须等于向量维度，输出维度等于矩阵行数。这正是"一层神经网络把 3 维输入映射到 2 维输出"。

### Q6 — 答案：B

`cos = a·b / (|a||b|)`，除以模长后只比较方向，不受向量长度（例如文档长短、词频大小）影响。取值范围是 [-1, 1]，不一定为正，所以 C 错。如果向量已经归一化，点积 = 余弦相似度。

### Q7 — 答案：C

`ΔW = B·A`，B 为 4096×16，A 为 16×4096，参数量 = 2 × 4096 × 16 = 131,072 ≈ 131K，而全量更新是 4096² ≈ 16.8M，约为 0.8%。

### Q8 — 参考答案

输出：
```
45.0
0.0
```

`[1,0]` 与 `[1,1]` 的余弦为 `1/√2`，arccos 得 45°。夹紧（clamp）那一行是为了**浮点误差**：理论上 `cos(v1, v1) = 1`，但浮点计算可能得到 `1.0000000000000002`，而 `math.acos` 的定义域是 [-1, 1]，超出会抛 `ValueError: math domain error`。把值夹到 [-1, 1] 是数值计算中的标准防御写法。

### Q9 — 参考答案

这一行用来跳过**线性相关**的向量。如果输入中某个向量能被前面的向量组合出来，减去所有投影后 `w` 会变成（近似）零向量，接着 `w.normalize()` 会除以 0（或除以一个 1e-17 级别的数）——要么抛 `ZeroDivisionError`，要么产生一个方向完全由舍入噪声决定的"垃圾"单位向量。

触发示例：`gram_schmidt([Vector([1,0,0]), Vector([0,1,0]), Vector([2,1,0])])`。第三个向量减去投影后为 `[0,0,0]`。用 `1e-10` 而不是 `== 0` 判断，是因为浮点数几乎不会精确等于 0。

### Q10 — 参考答案

```python
def most_similar(query, candidates):
    def norm(v):
        return sum(x * x for x in v) ** 0.5

    qn = norm(query)
    best_idx, best_score = -1, float("-inf")
    for i, c in enumerate(candidates):
        cn = norm(c)
        if qn == 0 or cn == 0:          # 零向量没有方向，跳过
            continue
        score = sum(a * b for a, b in zip(query, c)) / (qn * cn)
        if score > best_score:
            best_idx, best_score = i, score
    return best_idx
```

要点：①先算模长，避免重复计算；②零向量没有方向，余弦相似度无定义，需单独处理；③真实系统中通常**预先把所有向量归一化**，检索时只算点积，再配合 ANN 索引（如 HNSW、IVF）加速。

### Q11 — 参考回答要点

- 关系：`cos(a,b) = a·b / (|a||b|)`；对**单位向量**有 `|a-b|² = 2 - 2·a·b`，所以归一化之后，"点积最大"、"余弦最大"、"欧氏距离最小"三者给出**完全相同的排序**。
- 选择：
  - 文本 embedding 一般用余弦（或先归一化再用点积 / 内积，速度最快）；
  - 向量长度本身有意义时（如推荐系统中长度代表热度/置信度）用原始点积（MIPS）；
  - 需要满足距离公理、做聚类时常用欧氏距离。
- 加分点：说明 embedding 模型训练时用的是什么相似度，检索时就应该用同一种；提到 FAISS 中 `IndexFlatIP` 与 `IndexFlatL2` 的区别。

### Q12 — 参考回答要点

- 定义：秩 = 线性无关的列（或行）的最大数目；行秩恒等于列秩。
- 秩亏的影响：`XᵀX` 奇异不可逆，正规方程没有唯一解；如果是"近似秩亏"（某些奇异值很小，即病态），解对噪声极度敏感，系数会剧烈震荡、符号翻转——这就是**多重共线性**。
- 解决：删除/合并冗余特征；岭回归（L2 正则，`XᵀX + λI` 一定可逆）；PCA / 截断 SVD 降维；用伪逆（SVD）求最小范数解。
- 加分点：能说出用条件数（最大/最小奇异值之比）或 VIF 来诊断共线性。

### Q13 — 参考回答要点

- 假设：微调时权重的**更新量** `ΔW` 是低"内在秩"的——预训练模型已经学到了通用表示，适配一个新任务只需要在少数几个方向上调整。
- 做法：冻结 `W₀`，训练 `ΔW = B·A`（B: d×r，A: r×k，r ≪ min(d,k)）；B 初始化为 0，保证训练开始时模型输出不变；用缩放系数 `α/r` 控制更新幅度。
- 好处：可训练参数降到 1% 以下；显存大幅下降；不同任务的 LoRA 适配器可以热插拔；推理时可将 `B·A` 合并回 `W₀`，没有额外延迟。
- r 的选择：常见 4–64；任务与预训练分布差异越大、数据越多，r 可以越大；r 过大接近全量微调、容易过拟合；可以通过消融实验或 AdaLoRA 等自适应方法确定。

### Q14 — 参考回答要点

- 显式构造 `XᵀX` 会把条件数**平方**：`κ(XᵀX) = κ(X)²`。X 本身稍微病态，`XᵀX` 就可能在浮点精度下几乎奇异，导致精度严重丢失。
- QR 分解 `X = QR` 后，问题变为解上三角方程 `Rβ = Qᵀy`，只涉及 `κ(X)`，数值上稳定得多；回代也很便宜。
- 更病态或秩亏时用 SVD（伪逆），可以截断小奇异值。
- 原则：工程上**永远不要显式求逆**，用 `np.linalg.lstsq` / `solve` 而不是 `inv`。

### Q15 — 参考回答要点

- 作用：`QKᵀ` 的第 (i, j) 个元素就是第 i 个 query 与第 j 个 key 的点积，衡量"第 i 个 token 应该多关注第 j 个 token"，再经 softmax 变为权重，对 V 加权求和。
- 除以 `√d`：假设 q、k 的各分量独立、均值 0、方差 1，则点积的方差为 d。d 很大时点积数值很大，softmax 进入饱和区（接近 one-hot），梯度几乎为 0。除以 `√d` 把方差拉回 1，保持训练稳定。
- 加分点：把它和本节的"点积 = 对齐程度"联系起来；提到这正是 RAG 检索与 attention 在数学上同源。
