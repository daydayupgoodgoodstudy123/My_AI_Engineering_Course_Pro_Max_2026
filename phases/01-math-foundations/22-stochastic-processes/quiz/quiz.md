## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 随机游走与 √n 规律 | `Sₙ = X₁+…+Xₙ`，每步 ±1：`E[Sₙ] = 0`，`Var(Sₙ) = n`，标准差（均方根距离）为 `√n`；由中心极限定理，`Sₙ/√n → N(0,1)` |
| 2 | 布朗运动 | 随机游走的连续极限：`B(0)=0`，增量 `B(t)−B(s) ~ N(0, t−s)` 且互不重叠的区间独立；离散模拟 `B(t+dt) = B(t) + √dt·z`；处处连续、处处不可导 |
| 3 | 赌徒破产与鞅 | 公平游走从 k 出发、在 0 和 N 处吸收，先到 N 的概率是 `k/N`；公平游走是鞅（未来期望 = 当前值） |
| 4 | 马尔可夫链 | 马尔可夫性：下一状态只依赖当前状态；转移矩阵 `P[i][j]`，每行和为 1；分布按 `πₜ₊₁ = πₜ·P` 演化 |
| 5 | 平稳分布 | `π·P = π`，即 `Pᵀ` 特征值 1 对应的特征向量（归一化）；也可以用幂迭代求；不可约 + 非周期 ⇒ 唯一且从任意初始分布收敛 |
| 6 | 吸收态、混合时间、谱间隙 | 吸收态 `P[i][i] = 1`（如 EOS token）；谱间隙 `1 − |λ₂|` 越大，混合越快 |
| 7 | LLM 采样 | 每生成一个 token 就是一次随机转移；temperature 调节锐度（→0 退化为 greedy），top-k / top-p 截断候选集合，都是在改转移概率 |
| 8 | Langevin 动力学 | `x ← x − dt·∇U(x) + √(2T·dt)·z`：梯度下降 + 校准过的噪声，平稳分布 ∝ `exp(−U/T)`；T = 0 即梯度下降；是 SGLD、score-based 模型的基础 |
| 9 | Metropolis-Hastings | 提议 → 按 `min(1, p(x')Q(x|x')/(p(x)Q(x'|x)))` 接受；对称提议时只需 `p(x')/p(x)`，归一化常数约掉；靠细致平衡保证收敛到 p；需要 burn-in、多链检查、调提议步长 |
| 10 | 扩散模型前向过程 | `xₜ = √(1−βₜ)·xₜ₋₁ + √βₜ·ε` 是一条逐步加噪的马尔可夫链，x_T 近似 `N(0, I)`；反向过程是由神经网络学出来的马尔可夫链 |

def metropolis_hastings(target_log_prob, proposal_std, x0, n_samples, seed=None):
    if n_samples < 1:
        raise ValueError("n_samples must be at least 1")
    rng = np.random.RandomState(seed)
    x = np.array(x0, dtype=float)
    samples = [x.copy()]
    accepted = 0
    for _ in range(n_samples - 1):
        x_proposed = x + rng.randn(*x.shape) * proposal_std
        log_ratio = target_log_prob(x_proposed) - target_log_prob(x)

            accepted += 1
        samples.append(x.copy())

## 五、参考答案与解析

### Q1 — 答案：B

标准差 = `√Var(Sₙ) = √10000 = 100`。但"平均距离"`E|Sₙ|` 不等于标准差：由中心极限定理 `Sₙ ≈ N(0, n)`，而正态分布的 `E|X| = σ·√(2/π) ≈ 0.80σ`，所以约为 80。用本节代码模拟 1 万条 1000 步的游走：`E|S|` 实测 25.14，理论值 `√(2000/π) ≈ 25.23`，而均方根距离是 31.63 ≈ √1000。讲义写"Expected distance from origin ~ 10 (√100)"是数量级上的说法，严格地说 √n 是**均方根距离**。D 混淆了 `E[Sₙ] = 0`（有正有负，相互抵消）与距离。

### Q2 — 答案：B

平稳时，单位时间内"流出状态 0"的概率等于"流入状态 0"的概率：`π₀·0.1 = π₁·0.3`，所以 `π₀ = 3π₁`；再由 `π₀ + π₁ = 1` 得 `[0.75, 0.25]`。用本节的 `MarkovChain(P).stationary_distribution()` 实测也是 `[0.75, 0.25]`。C 把对角元素当成了答案；D 把两个分量对调了。

### Q3 — 答案：B

`π·P = π`（π 是行向量）⇔ `Pᵀ·πᵀ = πᵀ`，所以平稳分布是 `Pᵀ` 的（右）特征向量，特征值为 1。A 错：因为每行和为 1，P 的右特征向量（特征值 1）永远是全 1 向量，不含任何信息。D 错：可约链（如有两个吸收态）有多个平稳分布，周期链（如在两个状态间来回跳）虽然有平稳分布，却不会从任意初始状态收敛到它。

### Q4 — 答案：B

距离平稳分布的误差大致按 `|λ₂|ᵗ` 衰减。链 A：`0.95ᵗ`，约 45 步才缩小到 10%；链 B：`0.4ᵗ`，3 步就缩小到约 6%。谱间隙 `1 − |λ₂|` 越大，混合越快。最大特征值 1 是所有随机矩阵共有的，对应平稳分布本身，不决定速度（C 错）。本节的天气链特征值为 `{1, 0.362, 0.138}`，谱间隙约 0.64，从"晴天"出发幂迭代 7 步后，与平稳分布的最大误差就只有约 3e-4。

### Q5 — 答案：B

平稳分布 ∝ `exp(−U/T) = exp(−(x−3)²/(4T))`。与 `exp(−(x−μ)²/(2σ²))` 对比得 `σ² = 2T`。T = 1 时方差为 2，T = 2 时方差为 4，均值不变。实测 T = 2 时样本方差约 4.18。temperature 只改变"宽窄"，不移动能量最低点——这与 LLM 中 temperature 让分布变平而 argmax 不变是同一个道理。

### Q6 — 答案：A

`p(x) = p̃(x)/Z`，于是 `p(x')/p(x) = p̃(x')/p̃(x)`，Z 被约掉。这正是 MCMC 在贝叶斯推断中不可替代的原因：后验 `p(θ|D) ∝ p(D|θ)·p(θ)`，归一化常数 `p(D)` 需要对全部参数积分，通常算不出来。B 错：对称性才是关键，不一定要高斯；C、D 与此无关。

### Q7 — 答案：B

接受率不等于采样质量。实测 10000 个样本：`std = 0.1` 时只跨越 x = 0 共 13 次（基本都发生在起点附近），99.7% 的样本落在右峰，完全没有探索到左峰；`std = 5.0` 时跨峰 1277 次，左右各约 50%。步长太小，每步几乎都被接受，但走得太慢（自相关极高）；步长太大（如 20），大多数提议落在低概率区而被拒绝（接受率 12.6%），链原地不动。调参要在两者之间取平衡。讲义提到的"最优接受率约 23%"是高维极限下的理论结果，一维时最优值更高（约 44%）。C 错：理论上会收敛，但有限步数内可能根本到不了另一个峰。

### Q8 — 答案：B

把每步展开递推，高斯噪声叠加后仍是高斯：`xₜ = √ᾱₜ·x₀ + √(1−ᾱₜ)·ε`，`ε ~ N(0, I)`。这个闭式让训练时可以直接对任意 t 采样 `xₜ`，不必逐步模拟 t 次——DDPM 训练高效的关键。用本节 `diffusion_forward` 对标准正态输入加噪 100 步，`corr(x₀, x₁₀₀)` 实测 0.277，与 `√ᾱ₁₀₀ = 0.273` 吻合。

### Q9 — 参考答案

1. 由闭式 `x_T = √ᾱ_T·x₀ + √(1−ᾱ_T)·ε`，100 步后信号并没有消失，只是被缩小到 `√ᾱ_T` 倍。这个噪声表 `Σβ ≈ 100 × (0.001 + 0.05)/2 = 2.55`，`ᾱ_T ≈ exp(−2.55) ≈ 0.075`，`√ᾱ_T ≈ 0.27`——信号仍保留约 27% 的幅度。代入信号方差约 0.62，相关系数的期望约为 `0.27×0.79 / √(0.075×0.62 + 0.925) ≈ 0.22`；只有 200 个点，抽样波动约 ±0.07，实测 0.29 与之相符。无论哪个数，都远不是"接近 0"，所以演示末尾"nearly pure noise (correlation near 0)"的说法与实际输出不符。
2. 计算代码与实测结果：

```python
import numpy as np

betas = np.linspace(0.001, 0.05, 100)
abar = np.prod(1 - betas)
print(abar, np.sqrt(abar))        # 0.0747... 0.2733...

betas_ddpm = np.linspace(1e-4, 0.02, 1000)
print(np.prod(1 - betas_ddpm))    # 4.04e-05
```

DDPM 的设置下 `√ᾱ_T ≈ 0.006`，x_T 与纯高斯噪声几乎无法区分。想让演示真正"接近纯噪声"，可以增大 `n_steps` 或 `beta_end`，让 `ᾱ_T` 足够小。
附带一点：表格里的 SNR 用 `x − signal` 当作噪声，但 `x_t` 中的信号已被缩放到 `√ᾱₜ` 倍，这部分"缩水"也被算进了噪声，所以它只是粗略指标。

### Q10 — 参考答案

1. `n_samples=1` 时通过了 `< 1` 的检查，循环执行 0 次，最后 `accepted / (n_samples - 1)` 变成 `0 / 0`，抛出 `ZeroDivisionError`（已实测）。修复：

```python
    acceptance_rate = accepted / (n_samples - 1) if n_samples > 1 else float("nan")
```

或者把校验改为 `n_samples < 2`。

2. 在**对数域**比较是数值稳定性的要求：①概率密度可能极小（高维时 `p(x)` 常低于 1e-300），直接相除会下溢成 `0/0`；②`log_ratio` 可能很大，`np.exp` 会溢出成 `inf`。`log(u) < log_ratio` 与 `u < p(x')/p(x)` 数学上等价（log 单调），并且自动包含了 `min(1, ·)`：当 `log_ratio ≥ 0` 时，`log(u) < 0 ≤ log_ratio` 恒成立，一定接受。演示中的 `np.logaddexp` 也是同样的思路，用来稳定地计算混合分布的 log 密度。
3. `target_log_prob(x)` 在 x 未变时会被重复计算。可以缓存当前点的值：

```python
    log_p_x = target_log_prob(x)
    for _ in range(n_samples - 1):
        x_proposed = x + rng.randn(*x.shape) * proposal_std
        log_p_prop = target_log_prob(x_proposed)
        if np.log(rng.rand()) < log_p_prop - log_p_x:
            x, log_p_x = x_proposed, log_p_prop
            accepted += 1
        samples.append(x.copy())
```

这样目标函数的调用次数减半——当它是一次神经网络前向或全数据集似然时，节省非常可观。

### Q11 — 参考答案

1. 令 `y = x − 3`，`σ² = 2`：

```
yₜ₊₁ = yₜ − dt·yₜ/σ² + √(2·dt)·z = (1 − dt/σ²)·yₜ + √(2dt)·z
a = 1 − 0.1/2 = 0.95,   b² = 2 × 0.1 = 0.2
```

这是一个 AR(1) 过程，平稳方差满足 `v = a²·v + b²`，所以

```
v = b² / (1 − a²) = 0.2 / (1 − 0.9025) = 2.0513
```

也可以写成通式 `v = σ²·2/(2 − dt/σ²)`。实测 2.0888 = 2.0513 再加上有限样本误差（样本强自相关，有效样本数远小于 45001）。

2. 未校正的 Langevin（ULA，即 Euler-Maruyama 离散化）有 **O(dt) 的系统偏差**：只有 dt → 0 时平稳分布才严格等于 `exp(−U/T)`。验证：dt = 0.5 时理论方差 2.286，实测约 2.309；dt = 0.01 时理论 2.005。减小偏差的办法：①减小 dt，代价是自相关更强，需要更多步；②在 Langevin 提议后加一个 Metropolis-Hastings 接受/拒绝步骤（即 MALA），消除离散化偏差；③在扩散/score 模型中使用逐步减小的步长（退火 Langevin）。另外，burn-in 5000 步对初值 0 足够：偏差按 `0.95ᵗ` 衰减，几百步后就可以忽略。

### Q12 — 参考答案

1. 平稳分布满足 `πP = π`，是 P 的**左**特征向量；转置后变成 `Pᵀ` 的右特征向量，才能用 `np.linalg.eig` 求。`eigh` 只适用于对称（厄米）矩阵，而转移矩阵一般不对称（天气链中 `P[0][1] = 0.1 ≠ P[1][0] = 0.3`），用 `eigh` 会得到错误结果。
2. 三处防护：
   - `np.real`：`eig` 对非对称矩阵返回复数数组，特征值 1 对应的向量理论上是实数，但会带 `+0j` 或极小的虚部；
   - 符号翻转：特征向量只确定到一个倍数，库可能返回全负的向量，`sum < 0` 时取反；
   - `np.clip(..., 0, None)`：把浮点误差造成的 `−1e-17` 之类的负分量截为 0，保证是合法的概率分布。
   另外 `argmin(|λ − 1|)` 而不是 `== 1`，是因为数值特征值可能是 `0.9999999999999998`。⚠️ 对可约链（特征值 1 有多重），这里只会返回其中一个平稳分布。
3. 幂迭代版本：

```python
import numpy as np

def stationary_power(P, tol=1e-12, max_iter=10000):
    P = np.asarray(P, dtype=float)
    pi = np.ones(len(P)) / len(P)          # 任意初始分布
    for _ in range(max_iter):
        new = pi @ P                        # 行向量左乘
        if np.abs(new - pi).sum() < tol:
            return new
        pi = new
    return pi

P = [[0.7, 0.1, 0.2], [0.3, 0.4, 0.3], [0.4, 0.2, 0.4]]
print(np.round(stationary_power(P), 4))    # [0.5455 0.1818 0.2727]
```

精确值为 `[6/11, 2/11, 3/11]`。幂迭代只需要矩阵-向量乘法，可以用于百万状态的稀疏链（PageRank 就是这么算的）；它的收敛速度由 `|λ₂|` 决定，正好呼应 Q4。周期链上幂迭代会振荡、不收敛，这时可以改用"懒惰链" `(I + P)/2`。

### Q13 — 参考回答要点

- **定义**：状态序列满足 `P(Xₜ₊₁ | Xₜ, Xₜ₋₁, …) = P(Xₜ₊₁ | Xₜ)`；有限状态时用转移矩阵 P（行和为 1）完整描述；分布演化 `πₜ = π₀·Pᵗ`。
- **平稳分布**：`πP = π`，表示长期来看处于各状态的时间比例。
- **条件**：有限状态链若**不可约**（任意两状态互相可达），平稳分布存在且唯一；再加上**非周期**，就能从任意初始分布收敛到它（遍历定理）。反例：两个吸收态（可约，平稳分布不唯一）；`[[0,1],[1,0]]`（周期为 2，分布永远来回振荡）。
- **求法**：①解线性方程 `π(P − I) = 0` 加上 `Σπ = 1`；②求 `Pᵀ` 特征值 1 的特征向量；③幂迭代 `π ← πP`（大规模稀疏链首选）；④长程模拟后统计频率（蒙特卡洛，误差约 `1/√n`，且受自相关影响）。
- **加分点**：收敛速度由谱间隙决定；满足细致平衡 `πᵢPᵢⱼ = πⱼPⱼᵢ` 的链称为可逆链，MCMC 就是利用这一点构造的；PageRank 是"加了随机跳转、保证不可约且非周期"的马尔可夫链。

### Q14 — 参考回答要点

- **原理**：构造转移核 `T(x→x') = Q(x'|x)·α(x, x')`，其中 `α = min(1, p(x')Q(x|x') / (p(x)Q(x'|x)))`。可以验证它满足**细致平衡** `p(x)T(x→x') = p(x')T(x'→x)`。对 x 求和/积分即得 `Σₓ p(x)T(x→x') = p(x')`，所以 p 是平稳分布。接受率中只出现 p 的比值，归一化常数被约掉。
- **收敛诊断**：
  - burn-in：丢弃前期样本（本节演示丢弃了前 10000 个）；
  - 多条链从分散的起点出发，比较链内与链间方差（R-hat 统计量，接近 1 才可信）；
  - 看 trace plot 和自相关函数，计算有效样本量（ESS）；
  - thinning 能降低存储和自相关，但不会增加有效信息。
- **调参**：提议步长决定接受率与探索速度之间的平衡；高维高斯目标下理论最优接受率约 23%，一维约 44%。
- **局限与改进**：多峰分布难以跨峰（可用并行回火 / 模拟退火）；高维随机游走提议效率低，可以利用梯度——HMC / NUTS（PyMC、NumPyro 的默认算法）、MALA。
- **常见误区**：认为"接受率越高越好"（见 Q7）；认为不做 burn-in 结果就错了（只要链足够长，影响会被稀释，但短链时影响很大）。

### Q15 — 参考回答要点

- **是不是马尔可夫过程**：如果把"状态"定义为**整个上下文前缀**，那么下一个 token 只依赖当前状态，严格满足马尔可夫性；但状态空间随长度指数增长，不能写成一个固定的转移矩阵。如果只看"上一个 token"，那就是 n-gram/bigram 那样的近似（讲义练习 2 的文本生成器）。生成到 EOS token 即进入**吸收态**。
- **temperature**：`softmax(logits/T)`。T < 1 让分布更尖锐，T > 1 更平坦，T → 0 退化为 argmax（greedy）。例如 logits `[2, 1, 0]`：T = 0.5 时概率为 `[0.867, 0.117, 0.016]`，T = 1 时 `[0.665, 0.245, 0.090]`，T = 2 时 `[0.506, 0.307, 0.186]`。它与 Langevin / Boltzmann 分布 `exp(−U/T)` 中的 T 是同一个概念（logit 相当于 −U）。
- **top-k**：只保留概率最高的 k 个 token，重新归一化。**top-p（nucleus）**：按概率从高到低累加，保留累计概率刚超过 p 的最小集合——候选数随分布形状自适应。
- **工程取舍**：事实问答、代码生成用低温或 greedy；创作类用较高温度 + top-p（常见 0.9–0.95）；温度过高会产生乱码，过低容易重复。
- **加分点**：beam search 是确定性搜索而不是采样；speculative decoding 用"提议 + 接受/拒绝"的方式保证输出分布不变，思路上与 MH 有相似之处。

### Q16 — 参考回答要点

- **前向过程**：固定（无参数）的马尔可夫链 `q(xₜ|xₜ₋₁) = N(√(1−βₜ)·xₜ₋₁, βₜI)`，逐步把数据和高斯噪声混合；闭式 `xₜ = √ᾱₜ·x₀ + √(1−ᾱₜ)·ε`。它是离散化的 Ornstein-Uhlenbeck 型扩散过程（带"回拉"的布朗运动），T 足够大时 x_T ≈ `N(0, I)`。
- **反向过程**：`p_θ(xₜ₋₁|xₜ) = N(μ_θ(xₜ, t), σₜ²I)`，同样是马尔可夫链，但均值由神经网络给出。生成时从纯噪声出发，逐步采样到 x₀。
- **为什么预测噪声**：由闭式可知，只要知道加进去的 ε，就能求出 x₀ 的估计并算出反向均值；Ho 等人发现让网络预测 ε、用简单的 MSE 训练，效果最好、实现最简单。训练时随机抽取 t，一步得到 xₜ，不用模拟整条链。
- **与 Langevin 的联系**：预测的噪声与 score `∇ₓ log p(xₜ)` 成正比（相差 `−1/√(1−ᾱₜ)`）。Song & Ermon 的 score-based 模型直接用 Langevin 动力学 `x ← x + ε·∇log p(x) + √(2ε)·z` 采样（取 `U = −log p`、`T = 1`）。DDPM 的反向一步可以看成一次带噪声的"沿 score 方向前进"。
- **加分点**：连续时间下前向过程是 SDE，反向也是 SDE；去掉噪声项可以得到确定性的概率流 ODE（DDIM、flow matching 的思路）。

### Q17 — 参考回答要点

- **SGD 噪声**：mini-batch 梯度 = 全量梯度 + 噪声；B 个样本平均后，噪声方差约按 `1/B` 缩小，标准差按 `1/√B` 缩小——正是"独立随机量相加的 √ 规律"（见 Q1）。所以 SGD 可以粗略看作带噪声的梯度下降，学习率与 batch size 共同决定有效"温度"。
- **Langevin**：`x ← x − dt·∇U + √(2T·dt)·z`，噪声是**刻意校准**的，保证平稳分布为 `exp(−U/T)`。T = 0 时就是梯度下降。
- **SGLD**（Welling & Teh, 2011）：用 mini-batch 梯度估计 `∇U`（U = 负对数后验），再加上 `√(2·lr)` 量级的高斯噪声。学习率较大时梯度噪声占主导，表现得像优化；学习率衰减后注入的噪声占主导，开始从后验中**采样**，从而以很低的成本得到贝叶斯不确定性估计。
- **区别**：SGD 的噪声方差与梯度相关、各向异性、大小不受控制，因此不能保证采样到正确的后验；Langevin/SGLD 的噪声是各向同性、按步长校准的。
- **加分点**：这种视角解释了"小 batch 泛化更好"的一种假说（噪声帮助逃离尖锐极小值）；也是模拟退火的连续版本——温度从高到低，先探索再收敛。
