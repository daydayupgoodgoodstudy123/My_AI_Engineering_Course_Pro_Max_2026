## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | SVD 的定义 | 任意 m×n 矩阵都能分解为 `A = UΣVᵀ`：U、V 正交，Σ 对角且非负、按降序排列；没有"方阵""可对角化"等前提 |
| 2 | 几何意义：旋转 → 缩放 → 旋转 | `Vᵀ` 在输入空间旋转，`Σ` 沿坐标轴拉伸，`U` 旋转到输出空间；`A·vᵢ = σᵢ·uᵢ`，单位球被映成椭球，σᵢ 是椭球半轴长 |
| 3 | 外积形式 | `A = Σᵢ σᵢ·uᵢ·vᵢᵀ`，每一项是一个秩 1 矩阵；秩 = 非零奇异值的个数 |
| 4 | 与特征分解的关系 | V 是 `AᵀA` 的特征向量、U 是 `AAᵀ` 的特征向量，`σᵢ²` 是它们的特征值；对称半正定矩阵的 SVD 与特征分解相同 |
| 5 | Eckart-Young 定理 | 保留前 k 个奇异值得到的 `A_k` 是所有秩 k 矩阵中离 A 最近的；谱范数误差 `σ_{k+1}`，Frobenius 误差 `√(σ_{k+1}² + … + σ_r²)` |
| 6 | 截断 SVD 的存储账 | 存 `U_k、Σ_k、V_k` 共 `k(m+n+1)` 个数，压缩比 `k(m+n+1)/(mn)`；k 太大时反而比原矩阵还大 |
| 7 | 伪逆 `A⁺ = VΣ⁺Uᵀ` | 非零奇异值取倒数、零（或小于阈值）保持为 0；超定 → 最小二乘解，欠定 → 最小范数解，奇异 → 仍有定义 |
| 8 | 条件数与数值稳定 | `κ = σ_max/σ_min`；通过 `AᵀA` 求 SVD 会把条件数平方，所以要直接对 A 做 SVD |
| 9 | PCA 就是中心化数据的 SVD | 主成分 = V 的列，解释方差 = `σᵢ²/(n−1)`；忘记中心化，第一主成分会被均值"占用" |
| 10 | 奇异值揭示的矩阵性质 | Frobenius 范数 `√Σσᵢ²`、谱范数 `σ₁`、核范数 `Σσᵢ`、方阵 `|det| = Πσᵢ` |

## 五、参考答案与解析

### Q1 — 答案：B

`full_matrices=False` 返回"瘦"SVD（thin / economy SVD）：令 `k = min(m, n) = 3`，则 U 为 `(m, k) = (5, 3)`，S 是**一维**长度为 k 的奇异值数组 `(3,)`（不是对角矩阵，需要 `np.diag(S)` 才能参与矩阵乘），Vt 为 `(k, n) = (3, 3)`。A 是 `full_matrices=True`（默认值）的结果，U 会补齐成 5×5。C 错在 S 的形状；D 把行列搞反了。

### Q2 — 答案：C

`AᵀA` 是对称半正定矩阵，特征值都是非负实数，奇异值就是它们的平方根，所以一定非负；"方向翻转"的信息被吸收进 U、V 的正负号里（A 错）。B 只对正规矩阵（如对称矩阵）成立，反例：`[[1,1],[0,1]]` 的特征值是 1、1，奇异值却是 1.618、0.618。D 错：秩亏矩阵就有零奇异值（如 `[[1,2],[2,4]]` 的奇异值是 5 和 0），这正是用 SVD 判断秩的依据。

### Q3 — 答案：C

Frobenius 误差是被丢弃奇异值的平方和开根：`√(3² + 1²) = √10 ≈ 3.162`。A（3）是**谱范数**误差 `σ₃`——两种范数的误差公式要分清，这是面试里的常见陷阱。

### Q4 — 答案：B

需要存 `U_k`（256×20）、`Σ_k`（20 个数）、`V_k`（256×20），合计 `k(m+n+1) = 20 × 513 = 10,260`，占 65,536 的 15.7%——与代码 `demo_image_compression` 输出的 `20  10,260  15.7%` 一致。顺带注意：k=200 时比例是 156.6%，比存原图还大，说明截断 SVD 只有在 `k < mn/(m+n+1)` 时才真的"压缩"。

### Q5 — 答案：B

欠定系统有无穷多解，伪逆选出其中 **L2 范数最小**的那个（它位于 A 的行空间里，不含零空间分量）。代码输出：`SVD minimum-norm solution: [1. 2. 3.]`，`Verify A x = b: [14. 32.]`，`Solution norm: 3.741657`。A 错：伪逆不会改变解的个数，只是做选择；C 描述的是超定（无精确解）情形；D 是 L1 正则 / 压缩感知的目标，与 SVD 无关。

### Q6 — 答案：B

`AᵀA = VΣ²Vᵀ`，条件数从 κ 变为 κ²。代码 `demo_condition_number` 的实测：A 的条件数 40002.0，`AᵀA` 的条件数 1600159885.7 ≈ 40002²。float64 只有约 16 位有效数字，κ² 把可用精度"吃掉"一倍。A 错：`AᵀA` 一定是 n×n 方阵；C 错：对称矩阵的特征值一定是实数。专用 SVD 算法（Golub-Kahan 双对角化）直接作用在 A 上，从不显式构造 `AᵀA`。

### Q7 — 答案：C

协方差 `C = XᵀX/(n−1) = V·(Σ²/(n−1))·Vᵀ`，所以主成分方向是 V 的列，方差是 `σᵢ²/(n−1)`。代码 `demo_pca_is_svd` 中两条路径的结果都是 `[6.5172 3.0647 2.1815 1.3603 0.7279]`，`Variances match: True`。

### Q8 — 答案：B

标准 SVD 要求矩阵是"满"的，把缺失值填上均值，等于告诉模型"这个用户对这部电影的真实评分就是他的平均分"，大量伪观测会把低秩结构拉向均值——这正是演示中预测值大多挤在 2.1–3.1 之间、平均绝对误差 0.453 的原因之一。讲义也指出生产中用 Funk SVD、ALS 等**只在观测项上计算损失**的方法。A、D 错：SVD 适用于任意形状、任意秩；C 错：本例数据由 3 个潜在因子生成，秩 3 与生成过程基本匹配（严格说 min-max 缩放的平移会再贡献一个小的秩 1 分量），谈不上"必然过拟合"。

### Q9 — 参考答案

1. 返回的是 **V**（形状 n×k，每列是一个右奇异向量），不是 NumPy 风格的 Vt。重构写作 `U @ np.diag(S) @ V.T`——`demo_svd_basics` 里正是 `A_ours = U_ours @ np.diag(S_ours) @ V_ours.T`，而 NumPy 那一行是 `U_np @ np.diag(S_np) @ Vt_np`。两套接口不一致，是很容易踩的坑。
2. 由外积形式 `A = Σ σᵢuᵢvᵢᵀ`，减去第一项后残差为 `Σ_{i≥2} σᵢuᵢvᵢᵀ`，它的最大奇异三元组就是原矩阵的第二个 `(σ₂, u₂, v₂)`（各项之间两两正交，互不干扰）。对 `A_residualᵀ·A_residual` 做幂迭代，收敛到的就是它的最大特征向量 v₂。这叫**紧缩（deflation）**。代价是前面每一步的误差都会累积到后面的奇异值上，且当 `σ₁ ≈ σ₂` 时幂迭代收敛很慢（每轮误差约按 `(σ₂/σ₁)²` 缩小）。
3. `power_iteration` 作用于 `AᵀA`，返回的特征值是 **σ²**。所以 `eigenvalue < 1e-10` 相当于 `σ < √1e-10 = 1e-5`。这是一个绝对阈值，矩阵整体数值很大或很小时应该改用相对阈值（如 `σ < tol·σ₁`）。

### Q10 — 参考答案

输出：

```
[0.6 1.2] 1.341641
```

A3 的奇异值是 `[5, ≈0]`，秩 1，`[1,1]`、`[3,0]`、`[0.6,1.2]` 都满足 `Ax = b`。伪逆只在第一个右奇异向量 `v₁ = [1,2]/√5` 方向上求解，零空间方向（`[2,-1]`）分量为 0，所以得到范数最小的解 `[0.6, 1.2]`（范数 `√1.8 ≈ 1.3416`）。

如果去掉阈值：NumPy 算出的第二个奇异值并不是精确的 0，而是一个 1e-16 量级的舍入噪声（本机实测 `1.04e-16`），取倒数得到约 `9.6e15`。这个巨大的系数乘上同样是噪声的 `u₂ᵀb`，会给解加上一个由舍入误差决定的零空间分量——本机实测结果变成 `[-7, 7]`，`A @ [-7, 7] = [7, 14] ≠ [3, 6]`，解完全错误。若奇异值恰好算成 0.0，则会得到 `inf`/`nan`。**结论**：伪逆的本质是"只反转可信的方向"，阈值把"数值上为零"的方向判为零，`np.linalg.pinv` 的 `rcond`、`np.linalg.lstsq` 的 `rcond` 参数都是做这件事的。

### Q11 — 参考答案

```python
import numpy as np

def choose_rank_by_energy(S, threshold=0.95):
    energy = np.cumsum(S ** 2) / np.sum(S ** 2)   # 前 k 个的累计能量占比，单调不减
    k = int(np.searchsorted(energy, threshold) + 1)
    return min(k, len(S))                          # 浮点误差下兜底

# 循环写法（等价，更直观）
def choose_rank_by_energy_loop(S, threshold=0.95):
    total = np.sum(S ** 2)
    acc = 0.0
    for k, s in enumerate(S, start=1):
        acc += s ** 2
        if acc / total >= threshold:
            return k
    return len(S)
```

threshold=0.95 时返回 **2**（k=1 只有 82.58%，k=2 达到 97.09%）；本机对同一张合成图验证，threshold=0.99 时返回 3。`np.searchsorted(energy, t)` 返回第一个 `energy[i] >= t` 的下标 i（0 起），对应 k = i + 1，这也是本节 `outputs/skill-svd.md` 中 "Quick compression" 片段的写法。注意能量用的是 **σ²**（Frobenius 范数平方），不是 σ 本身。

### Q12 — 参考回答要点

- **适用范围**：特征分解 `A = PΛP⁻¹` 只适用于方阵，且要求有 n 个线性无关的特征向量；特征值可能是复数、可能为负，P 一般不正交。SVD 适用于任意形状、任意秩的矩阵，U、V 一定正交，σ 一定非负实数。
- **联系**：`AᵀA = VΣᵀΣVᵀ`、`AAᵀ = UΣΣᵀUᵀ`。右奇异向量是 `AᵀA` 的特征向量，左奇异向量是 `AAᵀ` 的特征向量，`σᵢ²` 是二者共同的非零特征值。
- **何时相同**：A 为对称半正定矩阵时，`U = V`、`Σ = Λ`，两种分解一致（代码 `demo_geometry` 里 `[[3,1],[1,3]]` 的 U 和 Vᵀ 完全相同、σ = [4, 2] 就是特征值）。对称但不定的矩阵，奇异值是特征值的绝对值，符号被吸收进 U 或 V。
- **加分点**：指出不要通过 `AᵀA` 的特征分解来算 SVD（条件数平方）；特征分解描述"不变方向"，SVD 描述"输入正交基 → 输出正交基"的映射。
- **常见误区**：把"奇异值 = 特征值的绝对值"当成对所有方阵都成立。

### Q13 — 参考回答要点

- **定理**：对任意 k，`A_k = Σ_{i≤k} σᵢuᵢvᵢᵀ` 在所有秩 ≤ k 的矩阵中同时使谱范数误差和 Frobenius 误差最小，最小值分别为 `σ_{k+1}` 与 `√(Σ_{i>k} σᵢ²)`。
- **直觉**：外积形式把 A 拆成按"重要性"（σ）排序、彼此正交的秩 1 层；任何秩 k 矩阵都至少要漏掉一个 k+1 维子空间中的信息，而 A 在这个子空间上的最小"拉伸"不会小于 `σ_{k+1}`。
- **选 k 的方法**：①能量阈值（累计 `σ²` 占比达到 95% / 99%）；②谱间隙（signal 和 noise 之间有明显断崖，如 `demo_noise_reduction` 中前 3 个奇异值 ~224/134/126，第 4 个起骤降到噪声水平）；③下游任务交叉验证；④领域知识（已知潜在因子个数）；⑤存储预算（`k < mn/(m+n+1)` 才划算）。
- **加分点**：能解释去噪演示里"改善比例在不同噪声强度下都约 74%"——秩 3 子空间只保留了约 `3(m+n−3)/(mn) ≈ 6.6%` 的噪声能量，误差比约 `√0.066 ≈ 0.26`。
- **常见误区**：把 Frobenius 误差和谱范数误差混为一谈；以为奇异值的大小本身就代表"信号"（如果数据没中心化，第一奇异值往往只是均值）。

### Q14 — 参考回答要点

- **为什么用 SVD**：对中心化数据 X 直接做 SVD，不显式构造 `XᵀX`，条件数是 κ(X) 而不是 κ(X)²，小方差方向的精度更好；同时直接拿到 U（样本在主成分上的坐标 `UΣ`），还可以用随机化 SVD / 截断 SVD 只求前 k 个成分。
- **协方差特征分解什么时候合适**：样本数远大于特征数（n ≫ d）且 d 较小时，`XᵀX` 只有 d×d，构造它是一次 O(nd²) 的矩阵乘，后续分解很便宜，速度优势明显，精度损失通常可接受。
- **工具层面要严谨**：讲义说"sklearn 用 SVD 实现 PCA"。需要补充的是，scikit-learn 自 1.5 版起新增了 `covariance_eigh` 求解器（本机 1.9.1 的文档可查），在 `svd_solver='auto'` 下，对"特征数 < 1000 且样本数 > 10 倍特征数"的数据会选择 `covariance_eigh` 求解器，也就是协方差矩阵特征分解；其他情况再在 `randomized` 和 `full` SVD 之间选。面试时说清"取决于数据形状和求解器配置"，比绝对化的结论更可信。
- **常见误区**：忘记中心化；把 `σᵢ` 而不是 `σᵢ²/(n−1)` 当作方差；比较主成分方向时没考虑正负号不确定（代码用 `np.abs` 比较就是为此）。

### Q15 — 参考回答要点

- **验证低秩假设**：计算 `ΔW = W_ft − W_0`，做 SVD，画出奇异值谱和累计能量曲线。如果前少数 r 个奇异值就占了绝大部分能量（谱快速衰减），说明更新集中在低维子空间，低秩假设成立；也可以直接比较秩 r 截断后的 `ΔW_r` 替换回模型后的下游指标。
- **压缩一个大矩阵**：`W ≈ U_k Σ_k V_kᵀ = (U_k Σ_k)(V_kᵀ)`，把 m×n 的一层拆成 `n → k → m` 两层，参数从 `mn` 降到 `k(m+n)`（也可以把 `Σ_k` 按 `√Σ_k` 平分到两侧）。Eckart-Young 保证在给定 k 下 Frobenius 误差最小，但"矩阵误差最小"不等于"模型效果最好"，通常要微调恢复精度。
- **与 LoRA 的区别**：LoRA 不对 W 做 SVD，而是直接训练 `ΔW = B·A` 两个小矩阵（B 初始化为 0）；SVD 是用来**分析**或**初始化 / 压缩**的工具。
- **加分点**：提到预训练权重本身往往不是低秩的（谱衰减慢），所以"直接低秩压缩 W"通常比"低秩表示 ΔW"损失大；能给出参数量算术。
- **常见误区**：把"秩"与"参数量"混为一谈；忘记 k 只有在 `k(m+n) < mn` 时才省参数。

### Q16 — 参考回答要点

- **为什么不能直接 SVD**：`np.linalg.svd` 要求每个元素都有值，缺失项无论填 0 还是填均值，都会被当作真实观测，99% 的伪数据会主导分解结果；而且稠密 SVD 在百万级用户 × 物品上内存和计算都不可行。
- **方案**：把问题建模为矩阵补全——学习用户向量 `pᵤ` 与物品向量 `qᵢ`，只在**已观测**的 `(u, i)` 上最小化 `Σ(r_ui − pᵤᵀqᵢ − bᵤ − bᵢ − μ)² + λ(‖pᵤ‖² + ‖qᵢ‖²)`；用 SGD（Funk SVD）或 ALS（交替固定一侧、每一步都是带正则的最小二乘，易于并行）求解；加入用户/物品偏置项。
- **工程补充**：隐式反馈（点击、观看时长）用加权的隐式 ALS 或负采样；冷启动用内容特征或热门兜底；离线用 RMSE/Recall@K 评估，线上用 A/B 测试。
- **加分点**：说出这仍然是"潜在因子 = 低秩分解"的思想，只是损失只算观测项，并且加了正则防过拟合。
- **常见误区**：直接对填零的稀疏矩阵做截断 SVD 当推荐（只有在做"隐式共现矩阵降维"时才勉强合理）。

### Q17 — 参考回答要点

- **为什么必须有**：`A⁺ = VΣ⁺Uᵀ` 需要 `1/σᵢ`。数值上"应该为 0"的奇异值实际是 1e-16 级别的舍入噪声，取倒数后放大到 1e16，把噪声灌进解里（见 Q10 的 `[-7, 7]`）。小但非零的 σ 也会把 b 中的测量噪声放大 `1/σ` 倍。
- **怎么定**：用**相对阈值**，如 `σᵢ < rcond · σ₁` 判为 0。常见默认值与机器精度和矩阵尺寸有关（如 `max(m, n) · eps`）；如果数据本身有噪声，阈值应该参考噪声水平，而不是只看机器精度。
- **与岭回归的关系**：截断 SVD 等价于对每个方向乘"滤波因子" `fᵢ = 1`（保留）或 `0`（丢弃）；岭回归的解 `x = Σ σᵢ/(σᵢ² + λ) · (uᵢᵀb) · vᵢ`，滤波因子是平滑的 `σᵢ²/(σᵢ² + λ)`——大 σ 方向几乎不受影响，小 σ 方向被连续地压低。两者都是在用偏差换方差，属于正则化。
- **加分点**：能写出岭回归的 SVD 形式；提到 `XᵀX + λI` 一定可逆、条件数变成 `(σ₁² + λ)/(σ_min² + λ)`。
