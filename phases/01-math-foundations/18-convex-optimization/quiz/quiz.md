## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 凸集 | 集合内任意两点的连线段仍在集合内；半空间、球、任意多个凸集的交集都是凸的，"并集"一般不是 |
| 2 | 凸函数 | `f(tx + (1−t)y) ≤ t·f(x) + (1−t)·f(y)`：图像上任意两点的弦在图像上方 |
| 3 | 凸性判别 | 一维看 `f'' ≥ 0`；多维看 Hessian 处处半正定；采样检查定义只能**证伪**，不能证明 |
| 4 | 核心定理 | 凸函数的任何局部极小都是全局极小——梯度下降不会被困住 |
| 5 | Hessian 与条件数 | 特征值全正 → 向上弯；有正有负 → 鞍点；`κ = λ_max/λ_min` 越大，山谷越狭长，GD 越慢 |
| 6 | 牛顿法 | `x ← x − H⁻¹∇f`：用二次近似一步跳到其极小点；二次函数一步到位，极小点附近二次收敛，但每步 O(n³) |
| 7 | 拉格朗日乘子 | `L = f + λg`，最优点处 `∇f` 与 `∇g` 平行；把等式约束问题变成无约束的驻点问题 |
| 8 | KKT 条件 | 驻点、原始可行、对偶可行 `λᵢ ≥ 0`、互补松弛 `λᵢgᵢ = 0`；SVM 的支持向量就是 `λᵢ > 0` 的点 |
| 9 | 正则化 = 约束 | L2 ⇔ `‖w‖² ≤ t`（圆），权重收缩；L1 ⇔ `‖w‖₁ ≤ t`（菱形），顶点在坐标轴上 → 稀疏 |
| 10 | 对偶与非凸深度学习 | 对偶给出原问题下界，凸 + Slater 条件下强对偶成立（SVM → 核技巧）；神经网络非凸，但高维临界点多为鞍点、过参数化与 SGD 噪声让训练仍然可行 |

## 五、参考答案与解析

### Q1 — 答案：C

在两个不相交圆盘里各取一点，连线必然穿过中间的空隙，所以并集不凸。A 半空间、D 球都是凸集的标准例子；B "任意多个凸集的交集仍是凸集"——这也是为什么"多个线性不等式约束"定义的可行域（多面体）总是凸的。

### Q2 — 答案：C

`f = xy` 的 Hessian 是 `[[0, 1], [1, 0]]`，特征值为 ±1，不定，沿 `(1, −1)` 方向是向下弯的。A 是两个凸函数之和（凸）；B `f'' = eˣ > 0`；D 是两个线性函数的逐点最大值，凸（ReLU 本身是凸函数，神经网络的非凸来自"复合与相乘"，而不是 ReLU 单独存在）。

### Q3 — 答案：C

Hessian `[[2, 3], [3, 2]]` 的特征值为 `2 ± 3`，即 5 和 −1，一正一负，原点是鞍点。本节代码 `demo_hessian_analysis` 正好输出 `Eigenvalues: 5.0, -1.0`、`Positive semidefinite: False`。容易误选 A：对角元都是正的（2），但凸性看的是**特征值**而不是对角元，交叉项 3 足够大就会破坏正定性（判据：`2·2 − 3² = −5 < 0`）。

### Q4 — 答案：C

纯牛顿法不保证单调下降：Hessian 不正定时牛顿方向甚至可能是上升方向；即使正定，离极小点很远时二次近似也可能很差，整步跳过头。本节 Rosenbrock 演示里第 2 步函数值就从 0.26 升到 6.24（见 Q12）。工程上需要配合线搜索或信赖域（trust region）。A、B、D 都正确。

### Q5 — 答案：B

`λᵢ ≥ 0` 且 `gᵢ(x) ≤ 0`，乘积为 0 意味着二者至少一个为 0：约束不活跃（解在边界内部，`gᵢ < 0`）时乘子必须为 0；乘子大于 0 时约束必须正好卡在边界上。在 SVM 中，只有 `αᵢ > 0` 的样本（支持向量）决定决策边界，其他样本删掉也不影响解。

### Q6 — 答案：B

在二维里 `|w₁| + |w₂| ≤ t` 是一个顶点位于坐标轴上的菱形。椭圆形的损失等高线从外向内收缩时，最先接触的往往是顶点，而顶点处有一个坐标恰好为 0。圆没有"尖角"，切点几乎总在两坐标都非零的位置。A 不是本质原因；C 恰好相反，L1 在 0 处不可导（正是这个"尖角"带来了稀疏性）；D 错，L1 范数是凸函数，LASSO 是凸问题。

### Q7 — 答案：B

对二次函数，GD 在每个特征方向上按 `(1 − lr·λᵢ)` 的比例收缩。`lr = 0.9/(2c)` 时，陡峭方向（λ = 2c）收缩因子 0.1，平缓方向（λ = 2）收缩因子 `1 − 0.9/c`。所需步数约为 `ln(ε)/ln(1 − 0.9/c) ≈ c·ln(1/ε)/0.9`，与 c（即条件数）**成正比**。代码输出 c = 10 时 179 步、c = 100 时 1860 步，约 10 倍。（使用动量或共轭梯度可降到与 `√κ` 成正比。）

### Q8 — 答案：B

对任意 `λ ≥ 0` 和可行的 x，`d(λ) = min L ≤ L(x, λ) = f(x) + λg(x) ≤ f(x)`，所以对偶最优值总是原问题的下界（弱对偶），这也是"用对偶间隙检查解的质量"的依据。强对偶 `d* = p*` 需要条件：凸问题且满足 Slater 条件（存在严格可行点）是最常用的充分条件。讲义正文简写为"凸问题强对偶成立"，术语表中给出了更严谨的 Slater 条件版本。

### Q9 — 参考答案

(1) 浮点误差。对 `f(x) = x²` 这种真凸函数，当 t 接近 0 或 1、或 x 与 y 很接近时，`lhs` 与 `rhs` 理论上相等或差距极小，浮点计算可能得到 `lhs − rhs = 1e-16` 这样的正数。没有容差会把舍入误差误判为"违反凸性"。

(2) 例如 `f(x) = −cos(x/10)`：`f''(x) = cos(x/10)/100`，在 `|x| < 5π ≈ 15.7` 时为正，所以在默认采样区间 `[−5, 5]` 里它"看起来是凸的"；但它是周期函数，整体显然非凸。实测：

```python
import math, random
random.seed(0)
check_convexity(lambda x: -math.cos(x[0] / 10), 1)                    # (True, 0)
check_convexity(lambda x: -math.cos(x[0] / 10), 1, bounds=(-50, 50))  # (False, 1037)
```

扩大 `bounds` 后就能发现违反。另一类反例是只在极小区域内非凸的函数（"小凹坑"），随机采样很难恰好落进去。

(3) **报告 NOT CONVEX 是可靠的**：找到一个违反例（且 gap 明显大于容差）就构成了非凸的证据。**报告 CONVEX 并不可靠**：只说明"在采样区间、采样次数内没找到反例"。严格证明要靠二阶条件（Hessian 处处半正定）或凸函数运算规则（非负加权和、与仿射函数复合、逐点最大值等保凸）。

### Q10 — 参考答案

(1) GD 在两个坐标方向独立演化：`xₖ = 10·(1 − lr·2c)ᵏ = 10·0.1ᵏ`，很快就到 0；`yₖ = 10·(1 − lr·2)ᵏ = 10·(1 − 0.9/c)ᵏ`。c = 100 时收缩因子 0.991。停止条件 `‖∇f‖² < 1e-12`，后期由 y 主导：`(2yₖ)² < 1e-12` ⇒ `yₖ < 5×10⁻⁷` ⇒ `0.991ᵏ < 5×10⁻⁸` ⇒ `k > ln(5×10⁻⁸)/ln(0.991) ≈ 16.81/0.00904 ≈ 1859.5`，因此第 1860 步停止，与输出完全一致。

(2) `lr = 1/c` 时陡峭方向的收缩因子变成 `1 − (1/c)·2c = −1`：x 在 +10 与 −10 之间**永远来回振荡**，不发散也不收敛（实测 50 步后 x 仍是 10.0）。对二次函数，GD 稳定的条件是 `lr < 2/λ_max = 2/(2c) = 1/c`，`lr = 1/c` 正好卡在临界点。这说明：**最大特征值决定了步长上限，最小特征值决定了收敛速度**，二者之比（条件数）决定了总步数。

(3) 牛顿步 `Δx = H⁻¹∇f`。对二次函数 `f = ½xᵀHx`，`∇f = Hx`，所以 `x − H⁻¹Hx = 0`，一步到达极小点，与 c 无关。相当于牛顿法用 `H⁻¹` 把狭长的椭圆"拉圆"成了条件数为 1 的问题。

### Q11 — 参考答案

(1) 约束问题的解对应拉格朗日函数 `L(x, λ) = f(x) + λg(x)` 的**鞍点**：对 x 取极小，对 λ 取极大。所以 x 做梯度**下降** `x ← x − lr·∂L/∂x`，λ 做梯度**上升** `λ ← λ + lr_λ·∂L/∂λ = λ + lr_λ·g(x)`。直观理解：约束被违反（g > 0）时 λ 增大，惩罚加重，把 x 推回可行域。这种算法叫原始-对偶梯度法（Arrow–Hurwicz / 对偶上升的一种形式）。

(2) **都没错**，是约束的写法不同导致符号不同。`demo_lagrange_multipliers` 写成 `g = x + y − 1`，驻点条件 `2x + λ = 0` 得 λ = −1；`demo_duality_intuition` 把 `x + y ≥ 1` 写成标准形式 `1 − x − y ≤ 0`，`g` 正好取了相反数，于是 λ = +1。等式约束的乘子符号没有限制；不等式约束 `g ≤ 0` 的乘子要求 `λ ≥ 0`（对偶可行）。两者描述的是同一个"约束力"，只是方向约定不同。

(3) `gv = g_val(x)` 是在**更新 x 之前**计算的，而 `history` 里存的是**更新后**的 x。初始点 (2, 2) 处 `g = 2 + 2 − 1 = 3`，所以第 1 行的 g 对应的是上一步的 x。这是一个"记录时机错位"的小问题，读表时要注意（收敛后两者几乎相同，不影响最终结论）。

### Q12 — 参考答案

**原因**：起点 (0.5, 0.5) 处 Rosenbrock 的 Hessian 为 `[[102, −200], [−200, 200]]`，行列式 `102·200 − 200² = −19600 < 0`，是**不定**矩阵，牛顿方向不一定是下降方向；而且纯牛顿法总是走"整步"，二次近似在远离极小点时不可靠，会跳过头。第 1 步碰巧下降，第 2 步就上升了。（从经典起点 (−1.2, 1) 出发，纯牛顿法第 2 步甚至会把 f 从 4.7 推到 1411.8。）

```python
def damped_newton(f, grad_f, hessian_f, x0, steps=100, tol=1e-12,
                  alpha=1e-4, beta=0.5):
    x = list(x0)
    history = [x[:]]
    for _ in range(steps):
        g = grad_f(x)
        if sum(gi ** 2 for gi in g) < tol:
            break
        H = hessian_f(x)
        H_inv = invert_2x2(H)
        if H_inv is not None and is_positive_semidefinite_2d(H):
            d = [-v for v in mat_vec_2d(H_inv, g)]      # 牛顿方向
        else:
            d = [-gi for gi in g]                        # 退回负梯度方向
        slope = sum(gi * di for gi, di in zip(g, d))     # 方向导数，应 < 0
        if slope >= 0:
            d = [-gi for gi in g]
            slope = -sum(gi ** 2 for gi in g)
        t = 1.0
        fx = f(x)
        while f([xi + t * di for xi, di in zip(x, d)]) > fx + alpha * t * slope:
            t *= beta                                    # Armijo 条件不满足就缩短步长
            if t < 1e-12:
                break
        x = [xi + t * di for xi, di in zip(x, d)]
        history.append(x[:])
    return history
```

要点：
- **Armijo 条件** `f(x + t·d) ≤ f(x) + α·t·∇fᵀd` 保证"充分下降"；`α = 1e-4`、`β = 0.5` 是常用取值。
- 先尝试 `t = 1`（完整牛顿步），所以靠近极小点时会自动恢复二次收敛。
- Hessian 不正定时退回负梯度方向（更精细的做法是加阻尼 `H + μI` 使其正定，即 Levenberg–Marquardt 思路）。

实测从 (0.5, 0.5) 出发，9 步收敛到 (1, 1)，函数值依次为 6.5 → 3.48 → 0.086 → 0.066 → 0.014 → … → 0，**单调下降**；从 (−1.2, 1) 出发 21 步收敛。步数可能比纯牛顿多，但换来了稳健性。

### Q13 — 参考回答要点

- **定义**：目标函数是凸函数，可行域是凸集（等式约束为仿射、不等式约束 `gᵢ(x) ≤ 0` 中 gᵢ 为凸函数）。
- **为什么容易**：局部最优即全局最优；KKT 条件在满足约束规范时是充要条件，可以用来验证最优性；有成熟的多项式时间算法与收敛速率保证；对偶间隙可以作为停止判据。
- **凸的**：线性回归（MSE）、岭回归、LASSO、逻辑回归、线性 SVM（hinge loss）。**非凸的**：神经网络、k-means（离散分配）、矩阵分解（未知量相乘）、高斯混合模型的似然。
- **逻辑回归为什么凸**：负对数似然的 Hessian 为 `XᵀSX`，其中 `S = diag(pᵢ(1 − pᵢ))`，对角元非负，所以 `vᵀXᵀSXv = Σ sᵢ(xᵢᵀv)² ≥ 0`，处处半正定。
- **加分点**：凸性是"关于参数"而言的。同一个 MSE，在线性模型里关于 w 是凸的，套上一层隐藏层就不凸了。线性可分数据上的逻辑回归没有有限最优解（权重会趋于无穷），需要正则化。

### Q14 — 参考回答要点

| 维度 | 梯度下降 | 牛顿法 |
|------|---------|-------|
| 信息 | 一阶（梯度） | 二阶（Hessian） |
| 每步代价 | O(n) | 形成 Hessian O(n²) 存储，求解 O(n³) |
| 收敛速度 | 线性；步数约与条件数 κ 成正比 | 极小点附近二次收敛（误差每步大约平方） |
| 对条件数 | 敏感（本节 c 从 1 到 100，步数从 8 到 1860） | 对二次函数完全不敏感（1 步），对仿射变换不变 |
| 超参数 | 需要调学习率 | 纯牛顿没有学习率，但实用中需线搜索 / 信赖域 |

- **为什么深度学习不用**：百万参数时 Hessian 有 10¹² 个元素，求逆 ~10¹⁸ 次运算；Hessian 在非凸区域不定，牛顿方向可能指向鞍点或上升方向；mini-batch 带来的随机 Hessian 噪声很大。
- **近似二阶方法**：L-BFGS（用最近 m 个梯度差近似逆 Hessian，O(mn) 内存，常用于传统 ML，如逻辑回归、CRF）；Hessian-free（用 CG 解 `Hd = −g`，只需 Hessian-向量积，可由自动微分得到）；自然梯度 / K-FAC（用 Fisher 矩阵并做 Kronecker 分解近似）；Adam 用梯度平方的滑动平均做逐坐标缩放，常被解释为对角曲率的粗略近似。
- **常见误区**：认为"Adam 就是二阶方法"。Adam 的二阶矩是梯度平方（更接近经验 Fisher 的对角），而不是真正的 Hessian 对角，它本质上是一阶方法加自适应步长。

### Q15 — 参考回答要点

- **原问题**：`min ½‖w‖²`，s.t. `yᵢ(wᵀxᵢ + b) ≥ 1`，等价于最大化间隔 `2/‖w‖`。这是凸二次规划。
- **KKT 与支持向量**：互补松弛 `αᵢ·[1 − yᵢ(wᵀxᵢ + b)] = 0`。离边界远的点约束不活跃 → `αᵢ = 0`；`αᵢ > 0` 的点必须恰好落在间隔边界上——这些就是支持向量。驻点条件给出 `w = Σ αᵢyᵢxᵢ`，即 w 只由支持向量决定。
- **为什么用对偶**：对偶问题 `max Σαᵢ − ½ΣΣ αᵢαⱼyᵢyⱼ xᵢᵀxⱼ`，s.t. `αᵢ ≥ 0`、`Σαᵢyᵢ = 0`，变量数等于样本数，与特征维度无关；更关键的是数据**只以内积 `xᵢᵀxⱼ` 的形式出现**。
- **核技巧**：把 `xᵢᵀxⱼ` 换成核函数 `K(xᵢ, xⱼ)`（如 RBF），等价于在高维（甚至无穷维）特征空间做线性 SVM，而无需显式计算特征映射。
- **加分点**：强对偶成立（凸 + Slater）保证对偶解能还原原问题解；软间隔 SVM 中 `0 ≤ αᵢ ≤ C`，`αᵢ = C` 对应间隔内或被误分的点。sklearn 的 `SVC` 拟合后可通过 `n_support_` 查看每类支持向量个数。

### Q16 — 参考回答要点

- **几何**：L1 球是菱形（高维是"交叉多面体"），顶点和低维棱都落在坐标子空间上，损失等高线最先接触到它们的概率很高；L2 球光滑，切点一般不在坐标轴上。本节 `demo_regularization_geometry` 中，`(x−3)² + (y−2)²` 在 L2 单位圆上的解是 `(0.832, 0.555)`，两个都非零；在 L1 菱形上的解是顶点 `(1, 0)`，第二个坐标恰好为 0。
- **优化 / 次梯度**：一维 `min ½(w − z)² + λ|w|` 的解是**软阈值** `w = sign(z)·max(|z| − λ, 0)`：`|z| ≤ λ` 时直接截断为 0。若换成 L2 惩罚 `(λ/2)·w²`，解是 `w = z/(1 + λ)`，只按比例缩小，只要 `z ≠ 0` 就永远不为 0。原因是 |w| 在 0 处的次梯度是区间 `[−1, 1]`，能"吸收"一个区间内的梯度；而 w² 在 0 处梯度为 0，没有这种"吸附力"。
- **概率**：L2 ⇔ 权重的高斯先验；L1 ⇔ 拉普拉斯先验，在 0 处有尖峰，MAP 估计更容易恰好落在 0。
- **工程实践**：LASSO 用坐标下降 / 近端梯度（ISTA / FISTA）求解，而不是普通梯度下降（后者只会让权重在 0 附近抖动，不会恰好为 0）。需要组稀疏用 Group Lasso；相关特征多时用 Elastic Net（L1 + L2）。

### Q17 — 参考回答要点

- **鞍点比局部极小更常见**：高维中，一个随机临界点要成为局部极小，需要 Hessian 的 n 个特征值**全部**为正；讲义的直观估计是概率约 `2⁻ⁿ`。所以绝大多数临界点是鞍点。鞍点附近梯度很小，训练会"平台期"，但 SGD 的噪声和动量能帮助逃离。
- **坏的局部极小很少**：经验和理论（如讲义引用的 Choromanska et al. 2015）表明，大网络的局部极小值的损失大多接近全局最优。
- **过参数化**：参数多于样本时，损失面更平滑、极小值之间更连通，更宽的网络坏的局部极小更少。
- **SGD 噪声的隐式正则化**：mini-batch 噪声让优化难以停留在尖锐极小，偏向平坦区域；讲义的观点是平坦极小泛化更好。
- **工程手段**：好的初始化、归一化层、残差连接、学习率 warmup 与衰减、动量 / Adam——它们都在改善条件数或帮助穿越平台。
- **常见误区**：①认为"非凸 = 一定会卡在坏的局部极小"；②认为"找到全局最优就最好"——全局最优可能是过拟合解，讲义的建议是"不要浪费时间找全局最小，一个好的局部极小就够了"。
