## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 集中趋势与离散程度 | 均值对异常值敏感、中位数稳健；方差/标准差衡量离散；IQR = Q3 − Q1 是稳健的离散度；P50/P95/P99 用于延迟与误差的尾部分析 |
| 2 | 贝塞尔校正 | 样本方差除以 `n − 1` 才是无偏估计，因为样本均值本身"贴着"样本，偏差平方和偏小 |
| 3 | Pearson vs Spearman | Pearson 衡量**线性**关系、对异常值敏感；Spearman = 对秩做 Pearson，衡量**单调**关系；相关 ≠ 因果 |
| 4 | 协方差矩阵 | 对称、半正定、对角线是方差；PCA 就是对它做特征分解；相关矩阵 = 标准化变量的协方差矩阵 |
| 5 | p 值与置信区间 | p 值 = `P(数据至少这么极端 \| H0 为真)`，**不是** H0 为真的概率；95% CI 指"重复实验时 95% 的区间会覆盖真值" |
| 6 | t 检验三兄弟 | 单样本 `t = (x̄ − μ₀)/(s/√n)`；Welch 双样本不假设等方差；配对 t 检验 = 对差值做单样本检验 |
| 7 | 卡方检验 | `χ² = Σ(O − E)²/E`，拟合优度检验自由度 = 类别数 − 1，用于类别计数 |
| 8 | Bootstrap | 有放回重采样 B 次，用统计量的经验分布构造 CI；对中位数、AUC、F1 等任意指标都适用 |
| 9 | 效应量与实际显著性 | Cohen's d = 均值差 / 合并标准差（0.2/0.5/0.8 = 小/中/大）；n 足够大时微小差异也会"显著" |
| 10 | 多重比较、功效与 CLT | m 次检验至少一次假阳性 `1 − (1−α)^m`，Bonferroni 用 `α/m`；功效 = 1 − 第二类错误率，随 n 增大；CLT 让**样本均值**近似正态，但不适用于无穷方差或强依赖数据 |

## 五、参考答案与解析

### Q1 — 答案：B

p 值是**在 H0 成立的前提下**算出的条件概率 `P(数据至少这么极端 | H0)`，讲义称之为"统计学中最常见的误解"。A 把条件反过来了（那是 `P(H0 | 数据)`，需要贝叶斯先验才能算）；C 同理；D 混淆了 p 值与可重复性——即使效应真实存在，复现成功的概率取决于功效。

### Q2 — 答案：B

频率学派的置信区间描述的是**构造区间的方法**的长期覆盖率：真值是固定的，区间才是随机的。对某一个具体区间而言，真值要么在里面、要么不在。A 是贝叶斯"可信区间"的说法；C 混淆了参数区间与数据分布；D 无依据。

### Q3 — 答案：B

均值是"平衡点"，会被长尾拉动；中位数只看排序位置。均值 >> 中位数 = 右侧有长尾（讲义例子：收入分布）。代码中的 `[1,…,9,1000]` 均值 104.50、中位数 5.50 就是极端情形。D 错：长尾是很多真实数据（收入、延迟、文本长度）的正常形态，不能一删了之。

### Q4 — 答案：B

代码真实输出：Pearson `0.9746`、Spearman `1.0000`。`y = x²` 在 x > 0 时严格单调递增，所以秩完全一致，Spearman = 1；但它不是直线，Pearson < 1。讲义举的 `y = x³` 例子同理。

### Q5 — 答案：B

`1 − 0.95²⁰ ≈ 0.6415`；Bonferroni 阈值 `0.05 / 20 = 0.0025`（代码输出 `Bonferroni adjusted alpha: 0.0025`）。注意 `1 − (1−α)^m` 假设各检验独立；而 Bonferroni 基于联合界（union bound），不要求独立。

### Q6 — 答案：C

Cohen's d 是"均值差 / 标准差"，两者都不随 n 系统变化，所以它被设计为"与样本量无关"的效应大小度量；n 越大，d 的估计越准，但期望值不变。p 值会变小、CI 变窄（约按 `1/√n`）、功效变大——这正是"大样本让微小差异也显著"的原因（代码中 n = 100000 时 d = −0.0139 却 p = 0.0019）。

### Q7 — 答案：D

bootstrap 只是从**已有样本**里重复抽取，不会产生新信息。它估计的是"如果总体长得像这份样本"时统计量的波动；样本太小或有偏时，bootstrap 分布同样有偏、同样不可靠。A、B、C 都是讲义中强调的优点。

### Q8 — 答案：B

讲义"What CLT does NOT do"明确指出：CLT 不会让数据本身变成正态（A 错），对无穷方差的 Cauchy 分布不成立（C 错），对相关数据不能直接用（D 错）。

### Q9 — 参考答案

(a) **符号约定不同**：打印的 Mean diff 是 `b − a`；而 `paired_ttest(data1, data2)` 内部计算 `diffs = [a - b ...]`，即 `a − b`，所以 t 为负。双侧检验只看 |t|，p 值不受影响，但写报告时一定要说明方向。

(b) 实际运行 `two_sample_ttest(cv_a, cv_b)` 得到 `t ≈ −2.69`、Welch 自由度 `≈ 17.7`、`p ≈ 0.015`；配对检验是 `t = −16.5`、`p ≈ 4.9×10⁻⁸`。原因：

- 各折之间难度差别很大（A 的分数在 0.80～0.86 之间波动），但**同一折上** B 几乎总是比 A 高 0.02～0.03。
- 独立检验把"折与折之间的波动"也算进标准误，噪声很大；配对检验先求差值，折间波动被抵消，差值的标准差只有约 0.0042，所以 t 很大。
- 两个模型在**同一批折**上评估，数据天然配对，**配对检验才是正确的**。用独立检验会丢掉配对信息、损失功效（skill 文件中"Common mistakes"第一条）。

### Q10 — 参考答案

(a) 讲义的方法是**配对 bootstrap**：同一组重采样下标同时作用于两个模型。代码是**独立 bootstrap**：两组各自重采样，适合"两组样本来自不同用户/不同数据"的场景（比如 `ab_test_simulator` 里的两个独立组）。如果两个模型在同一个测试集上评估，它们在难样本上往往一起错、简单样本上一起对，误差高度正相关；独立重采样丢掉了这种相关性，差值的方差被高估，CI 偏宽，会把真实的提升判成"不显著"。

(b) 参考实现（放在 `statistics.py` 里，复用其中的 `mean` 与 `percentile`）：

```python
def paired_bootstrap_compare(correct_a, correct_b, n_bootstrap=5000, ci=95):
    n = len(correct_a)
    diffs = []
    for _ in range(n_bootstrap):
        idx = [random.randint(0, n - 1) for _ in range(n)]   # 同一组下标
        acc_a = sum(correct_a[i] for i in idx) / n
        acc_b = sum(correct_b[i] for i in idx) / n
        diffs.append(acc_b - acc_a)
    diffs.sort()
    lower_pct = (100 - ci) / 2
    lo, hi = percentile(diffs, lower_pct), percentile(diffs, 100 - lower_pct)
    return {"observed_diff": mean(correct_b) - mean(correct_a),
            "ci_lower": lo, "ci_upper": hi,
            "significant": lo > 0 or hi < 0}
```

验证：构造 1000 个测试样本，两个模型共享"样本难度"，准确率分别为 0.855 与 0.876。配对 bootstrap 的 95% CI 为 `[0.013, 0.030]`（显著）；同一数据用代码里的 `bootstrap_compare` 得到 `[−0.009, 0.050]`（不显著）——同样的 2.1 个百分点提升，结论完全相反。

### Q12 — 参考答案

(a) 真实效应几乎为 0（d = 0.01），在这么低的功效下，这次"显著"与假阳性几乎没有区别——它主要是噪声造成的。观测到的 |d| = 0.58 把效应夸大了约 58 倍（`cohens_d` 按 `A − B` 计算，负号表示观测到 B 高于 A，方向碰巧与真实情况一致，但"中等效应"这个量级完全来自噪声）。真实 d 这么小时，功效几乎等于 α：用代码函数模拟 2000 次，显著率约为 4.75%，与 5% 吻合。所以种子 42 恰好抽中了那约 5% 的情况——演示原本想表达"小样本不显著、大样本显著"，这次运行却两组都显著。

(b) 每组 n = 30 时 `t ≈ d / √(1/n₁ + 1/n₂) = d / √(2/30) ≈ d / 0.258`，双侧 α = 0.05、自由度约 58 时临界值 `t ≈ 2.00`，因此显著必须满足 `|d| > 2.00 × 0.258 ≈ 0.52`。模拟中所有显著结果的 |d| 最小值为 0.517，平均为 0.62。

含义：在低功效的研究中，"通过显著性筛选"本身就会挑出被夸大的效应（winner's curse，也叫 Type M 误差）。小样本里"显著 + 中等效应"并不可信，应该看置信区间宽度、做功效分析、在更大的样本上复现。

### Q13 — 参考回答要点

- **定义**：p 值 = H0 为真时得到至少这么极端结果的概率；95% CI = 一种长期覆盖率为 95% 的区间构造方法。
- **p = 0.2 不等于"没有差异"**：讲义原话"Fail to reject H0 ≠ H0 为真"。可能是效应很小，也可能是样本太少、功效不足。应该看 CI：如果 CI 很宽（例如 `[−3%, +5%]`），说明的是"数据不足以判断"。
- **常见误解**：p 值是 H0 为真的概率；p < 0.05 就等于效应大、重要；p 值大就证明相等；CI 内的每个值等可能。
- **加分点**：报告时同时给出 p 值、CI、效应量和样本量（skill 文件的"What to report"表）；了解等价性检验（TOST）可以用来正面论证"差异小于某个阈值"。

### Q14 — 参考回答要点

- **先估噪声**：n = 1000、准确率约 0.88 时，单个准确率的标准误 `√(0.88 × 0.12 / 1000) ≈ 0.010`，95% CI 约 ±2 个百分点——0.02 的提升与噪声同一量级。
- **用配对方法**：两个模型在同一测试集上，用配对 bootstrap（Q10）或 McNemar 检验（只看两个模型判断不一致的样本）。如果两模型的错误高度重叠，配对方法会比两个独立 CI 敏感得多。
- **看效应量与业务价值**：+2% 在业务上值多少？上线成本、延迟、可维护性如何？
- **检查评估本身**：测试集是否在调参/选模型时被反复使用（泄漏、多重比较）？类别是否不平衡（准确率失真，应看 precision/recall/F1/AUC）？是否看了切片指标和公平性？
- **最后用线上 A/B 测试验证**：离线提升不等于线上提升，提前定好主指标、α、样本量和实验时长，避免中途偷看（peeking）。
- **常见误区**：只比较两个点估计；用两个模型各自的 CI 是否重叠来判断显著性（重叠不代表不显著，配对差值的 CI 才是正确的对象）。

### Q15 — 参考回答要点

- **原理**：把经验分布当作总体的近似（plug-in 原则），从样本有放回重采样，模拟"再抽一次样本"时统计量会怎么波动；用 B 个重采样统计量的 2.5% / 97.5% 分位数作为 95% CI（百分位法，即代码中 `bootstrap_statistic` 的做法）。
- **优点**：无需分布假设，无需推导标准误公式，适用于中位数、AUC、F1、两个指标的比值等任意统计量。
- **失效或需要改造的情形**：
  - 样本太小或不具代表性——重采样无法创造信息（Q7）；
  - 极值类统计量（最大值、极端分位数）——bootstrap 分布很差；
  - 数据不独立：时间序列要用 block bootstrap；同一用户/同一文档的多条样本要**按组重采样**（讲义"常见错误"第 9 条）；
  - 两个模型共用测试集时要用配对 bootstrap（Q10）。
- **加分点**：百分位法在偏态时覆盖率不准，可用 BCa 等校正方法；B 一般取 1000～10000（讲义）。

### Q16 — 参考回答要点

- **问题**：做 m 次检验，即使所有 H0 都成立，至少一次假阳性的概率也是 `1 − (1−α)^m`，m = 20 时约 64%。
- **ML 中的形态**：在测试集上比较几十组超参数并报告最好的；在多个指标/数据集/切片上找"赢了"的那一个（讲义"Cherry-picking metrics"）；Kaggle 公榜过拟合；p-hacking（换检验方法、换子集直到 p < 0.05）。
- **Bonferroni**：阈值 α/m，控制族错误率（FWER），简单但保守，m 大时功效损失严重。
- **替代方案**：Holm-Bonferroni（逐步法，同样控制 FWER 但更不保守，skill 文件提到）；控制错误发现率（FDR）的 Benjamini-Hochberg 方法，适合大规模筛选；最根本的做法是**留一份只用一次的最终测试集**，并提前注册要比较的指标。

### Q17 — 参考回答要点

- **样本太少**：k = 5 时，Wilcoxon 符号秩检验在双侧 α = 0.05 下**永远不可能显著**——即使 5 个差值全部同号，最小精确 p 值也只有 `2/2⁵ = 0.0625`；k = 10 时最小 p 值是 `2/2¹⁰ ≈ 0.002`（代码中的 CV 数据用 SciPy 验证正是 0.00195）。配对 t 检验在 k = 5 时也只有 4 个自由度，严重依赖正态假设。
- **折之间不独立**：不同折的训练集大量重叠，分数之间正相关，普通配对 t 检验会低估方差、高估显著性。skill 文件指出可用校正后的重采样 t 检验（corrected resampled t-test）。
- **实践建议**：使用重复交叉验证（如多次不同随机种子的 k 折）增加样本；或在一个大的独立测试集上做配对 bootstrap / McNemar；无论用什么检验，都报告均值差、CI 和效应量。
- **讲义观点**：ML 实验的 n 通常很小（5 或 10 折），所以非参数检验往往更合适；但要意识到上面的"最小 p 值"限制。

### Q18 — 参考回答要点

- **公式**（双样本均值比较、正态近似）：`n ≈ 2(z₀.₉₇₅ + z₀.₈₀)² σ² / Δ² = 2 × (1.96 + 0.84)² × 100 / 9 ≈ 175`（每组）。
- **与代码对照**：代码的功效模拟中，每组 200 个样本时功效为 0.84；每组 50 个样本时只有 0.32（理论值约 0.32、0.85），即每组 50 个样本时，约 2/3 的实验会漏掉真实存在的效应（第二类错误）。
- **低功效的额外代价**：即使侥幸显著，效应量也会被高估（Q12 的 winner's curse）。
- **工程实践**：实验开始前确定最小可检测效应（MDE）、α、功效 → 算出样本量和实验时长；不要在实验中途反复看 p 值决定是否停止（会抬高假阳性率）；可以用方差缩减（如用实验前的指标做协变量调整）减少所需样本。
