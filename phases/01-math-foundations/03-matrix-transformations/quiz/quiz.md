## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 矩阵的列 = 基向量的去向 | 2×2 矩阵的第 1 列是 `[1,0]` 变换后的位置，第 2 列是 `[0,1]` 变换后的位置；知道基向量去哪，就知道整个变换 |
| 2 | 旋转 | `R(θ) = [[cosθ, -sinθ], [sinθ, cosθ]]`，正交矩阵，保持长度和夹角，`det = 1`；3D 中绕哪个轴转，哪个坐标不变 |
| 3 | 缩放 | 对角矩阵 `[[sx,0],[0,sy]]`，各轴独立伸缩，`det = sx·sy` |
| 4 | 剪切 | `[[1,k],[0,1]]` 让 x 按 `k·y` 平移，矩形变平行四边形，面积不变（`det = 1`） |
| 5 | 反射 | 关于 y 轴 `[[-1,0],[0,1]]`、关于 x 轴 `[[1,0],[0,-1]]`；`det = -1`，面积不变但方向（定向）翻转 |
| 6 | 复合变换 | 先 A 后 B 的矩阵是 `B @ A`（从右往左读）；顺序不能换；`det(BA) = det(B)·det(A)` |
| 7 | 特征值与特征向量 | `A v = λ v`：矩阵只缩放、不转动的方向；2×2 时解 `λ² - tr(A)·λ + det(A) = 0`；复数特征值意味着"有旋转、没有实特征方向" |
| 8 | 特征分解 | 有 n 个线性无关特征向量时 `A = V D V⁻¹`：转到特征坐标 → 沿各轴缩放 → 转回来 |
| 9 | 特征值的 AI 应用 | PCA = 协方差矩阵的特征向量（特征值 = 该方向方差）；RNN 中 `|λ| > 1` 爆炸、`< 1` 消失；谱聚类用拉普拉斯矩阵的特征向量 |

## 五、参考答案与解析

### Q1 — 答案：A

矩阵的**列**就是基向量的去向：第 1 列 `[2,1]`，第 2 列 `[-1,1]`，所以 `M = [[2,-1],[1,1]]`。验证：`M @ [1,0] = [2,1]` ✔，`M @ [0,1] = [-1,1]` ✔。B 是把它们当成了**行**来写（即 `Mᵀ`），这是最常见的错误。

### Q2 — 答案：B

矩阵作用在列向量的**左边**，离 `p` 最近的先执行：`H @ (S @ (R @ p))` = `H @ S @ R @ p`，从右往左读就是 R → S → H。讲义里"先 A 后 B 等于 `B @ A`"说的就是这个规则。

### Q3 — 答案：B

`det(复合) = det(反射)·det(剪切)·det(缩放) = (-1) × 1 × (3×2) = -6`。剪切不改变面积（`det = 1`），所以和 k = 5 无关；反射翻转定向，带来负号。C、D 错在把剪切系数 5 也乘进去了。

### Q4 — 答案：B

`tr = 4 + 3 = 7`，`det = 4×3 - 2×1 = 10`，特征方程 `λ² - 7λ + 10 = 0`，解得 `λ = 5` 或 `λ = 2`。检查：两根之和 = 迹 = 7，两根之积 = 行列式 = 10 ✔。A 是误把对角线元素当成特征值（只有三角矩阵才成立）；D 是把迹和行列式本身当成了根。

### Q5 — 答案：C

特征向量的定义是"只被缩放、方向不变（λ<0 时恰好反向）"的方向。旋转 90° 会把**每一个**非零向量都转走，所以不存在实特征向量，特征方程 `λ² + 1 = 0` 只有复根 `±i`。A 错：`det = 1 ≠ 0`，可逆；B 错：旋转保长度；D 错：实矩阵的特征值完全可以是复数，且必定成共轭对出现。代码里 `eigenvalues_2x2` 在判别式 < 0 时返回 `complex(real, ±imag)` 就是在处理这种情况。

### Q6 — 答案：B

沿特征方向，`W` 只做缩放，所以 100 步后分量变为 `λ¹⁰⁰`：`1.1¹⁰⁰ ≈ 13781`（约 1.4×10⁴），`0.9¹⁰⁰ ≈ 2.66×10⁻⁵`。指数效应极其敏感：特征值只比 1 大 10%，100 步就放大上万倍。这就是讲义里"一句话讲清梯度爆炸/消失"——反向传播时梯度同样要连乘（与 `W` 相关的）雅可比矩阵。A 是"线性直觉"的错误，指数增长不能取平均。

### Q7 — 答案：D

协方差矩阵的特征值就是数据在对应特征方向上的方差，所有特征值之和 = 迹 = 总方差 = 2 + 3 = 5。第一主成分对应最大特征值 3.62，比例 `3.62 / 5 ≈ 72%`。C（62%）和 A（38%）都是被特征值的小数部分（.62、.38）误导的选项；第二主成分实际只解释 `1.38 / 5 ≈ 28%`。B（50%）是误以为两个方向平分方差。另外注意：代码运行结果里 `np.linalg.eig` 返回的特征值是 `[1.38, 3.62]`——**并没有按大小排序**，做 PCA 时必须自己 `argsort`。

### Q8 — 答案：C

`[[2,1],[0,2]]` 的特征值是重根 2，但 `A - 2I = [[0,1],[0,0]]` 的零空间只有一维（只有 `[1,0]` 方向），凑不出 2 个线性无关的特征向量，`V` 必然奇异——这叫**亏损矩阵（defective matrix）**，不可对角化（只能化成 Jordan 标准形）。
- A：对称矩阵，一定可正交对角化。
- B：两个不同特征值 3 和 2，不同特征值对应的特征向量一定线性无关，可对角化（代码 `demo_eigendecomposition` 用的就是它）。
- D：本身就是对角矩阵。

### Q9 — 参考答案

输出：

```text
[[1, 1], [1, 1]] 0
[0.0, 0.0]
```

`shearing_2d(kx, ky)` 同时设置两个方向的剪切时，矩阵 `[[1,kx],[ky,1]]` 的行列式是 `1 - kx·ky`，当 `kx = ky = 1` 时恰好为 0：两列相同，整个平面被压扁到直线 `y = x` 上，`[1,-1]` 这个方向被映射成零向量，矩阵不可逆。

"剪切的行列式为 1"只对**单方向剪切**成立，即 `kx` 和 `ky` 至少有一个为 0（讲义中的 `Shx = [[1,k],[0,1]]` 和 `Shy = [[1,0],[k,1]]`）。两个方向都非零时，它其实已经不是"纯剪切"了，而是一个一般的线性变换（等价于先后做两次单方向剪切再加一点缩放）。代码里所有调用都只传了一个非零系数（如 `shearing_2d(1, 0)`、`shearing_2d(0.5, 0)`），所以 demo 没有暴露这个问题。

### Q10 — 参考答案

**(1) 推导**：特征向量要满足 `(A - λI) v = 0`。代入 `v = [b, λ - a]`：
- 第 1 行：`(a - λ)·b + b·(λ - a) = 0` ✔（恒成立）
- 第 2 行：`c·b + (d - λ)(λ - a) = bc - (λ - a)(λ - d)`。而 λ 是特征方程 `(a - λ)(d - λ) - bc = 0` 的根，即 `(λ - a)(λ - d) = bc`，所以第 2 行也等于 0 ✔。

本质是：`A - λI` 的第 1 行 `[a-λ, b]` 与特征向量正交，而 `[b, -(a-λ)]` 正是与它垂直的向量。`b ≈ 0` 时这个向量可能退化成零，所以要换用第 2 行（`c ≠ 0` 分支）；`b`、`c` 都为 0 时矩阵已是对角阵，特征向量就是坐标轴。

**(2) 两种失败**（已实际运行验证）：两种情况下特征值都是 `(2.0, 2.0)`，`eigenvector_2x2` 对两个特征值都返回 `[1.0, 0.0]`，于是 `V = [[1,1],[0,0]]`，`det_v = 0.0`，计算 `V_inv` 时抛出 `ZeroDivisionError: float division by zero`。

性质不同：
- `[[2,0],[0,2]] = 2I`：**数学上完全可对角化**（任何非零向量都是特征向量，取 `V = I` 即可），失败纯粹是**代码的局限**——函数每次只拿到一个特征值，无法知道"这是重根、第二次应该返回另一个正交方向"。
- `[[2,1],[0,2]]`：**数学上就不可对角化**（见 Q8），失败是正确的，只不过应该给出清晰的报错而不是除零异常。

修复思路：在 `demo_eigendecomposition` 里先检查 `abs(det_v) < 1e-10`；若 `A` 是数量矩阵（`b = c = 0` 且 `a = d`）则直接令 `V = I`，否则 `raise ValueError("matrix is not diagonalizable")`。

### Q11 — 参考答案

```python
import math
from transformations import rotation_2d, scaling_2d, shearing_2d, mat_mul, mat_vec_mul, det_2x2, fmt

R = rotation_2d(math.radians(30))
S = scaling_2d(1.5, 0.8)
H = shearing_2d(0.3, 0)

M = mat_mul(H, mat_mul(S, R))          # 先 R，再 S，最后 H

points = [[math.cos(2 * math.pi * k / 8), math.sin(2 * math.pi * k / 8)] for k in range(8)]
moved = [mat_vec_mul(M, p) for p in points]
for p, q in zip(points, moved):
    print(f"{fmt(p)} -> {fmt(q)}")

def polygon_area(pts):                  # 鞋带公式（shoelace）
    n = len(pts)
    s = sum(pts[i][0] * pts[(i + 1) % n][1] - pts[(i + 1) % n][0] * pts[i][1] for i in range(n))
    return abs(s) / 2

print("det(M)               =", fmt(det_2x2(M)))
print("det(H)*det(S)*det(R) =", fmt(det_2x2(H) * det_2x2(S) * det_2x2(R)))
print("area ratio           =", fmt(polygon_area(moved) / polygon_area(points)))
```

实测输出（节选）：

```text
[1.0, 0.0] -> [1.419, 0.4]
[0.7071, 0.7071] -> [0.6201, 0.7727]
[0.0, 1.0] -> [-0.5422, 0.6928]
...
det(M)               = 1.2
det(H)*det(S)*det(R) = 1.2
area ratio           = 1.2
```

要点：
- 复合顺序：`M = H @ S @ R`，写成 `mat_mul(H, mat_mul(S, R))`。
- `det(R) = 1`、`det(H) = 1`、`det(S) = 1.5 × 0.8 = 1.2`，所以复合行列式 1.2。
- 面积之比也恰好是 1.2：**行列式就是面积缩放倍数**，对任意形状都成立，不只是单位正方形。
- 圆被变成了椭圆（8 个点都落在一个椭圆上），这是"线性变换把圆映成椭圆"的直观体现，也是后面 SVD 几何意义的伏笔。

### Q12 — 参考回答要点

- **定义**：非零向量 v 满足 `A v = λ v`，v 是特征向量，λ 是特征值。求法：解特征方程 `det(A - λI) = 0`。
- **几何意义**：矩阵作用下方向不变（只被拉伸/压缩/反向）的特殊方向，λ 是这个方向上的缩放倍数。λ 为负表示反向；复数 λ 表示存在旋转成分。
- **特征分解条件**：n×n 矩阵有 n 个线性无关的特征向量（例如 n 个互不相同的特征值就足够），此时 `A = V D V⁻¹`。重根时可能不够（亏损矩阵，如 `[[2,1],[0,2]]`）。
- **对称矩阵（谱定理）**：实对称矩阵的特征值全是实数，不同特征值对应的特征向量相互正交，总能正交对角化 `A = Q Λ Qᵀ`（`Q⁻¹ = Qᵀ`，不用求逆）。协方差矩阵、Hessian、图拉普拉斯都是对称的，所以这个性质在 ML 里极其常用。
- **加分点**：`tr(A) = Σλᵢ`、`det(A) = Πλᵢ`；`Aᵏ = V Dᵏ V⁻¹`，矩阵的幂只需对特征值取幂——这正是分析 RNN 长期行为的工具。

### Q13 — 参考回答要点

- **为什么是特征向量**：PCA 要找一个单位方向 w，使数据投影后的方差 `wᵀ Σ w` 最大（Σ 为协方差矩阵）。在 `|w| = 1` 约束下用拉格朗日乘子法得 `Σ w = λ w`——最优方向就是特征向量，且此时方差恰好等于 λ。所以按特征值从大到小排序，取前 k 个特征向量就是前 k 个主成分。
- **特征值的含义**：该主成分方向上的方差；`λᵢ / Σλ` 是"解释方差比"（explained variance ratio），用来决定保留几维。
- **为什么工程上用 SVD**：
  1. 显式计算 `XᵀX` 会把条件数平方，小方差方向的精度损失严重；直接对中心化后的 X 做 SVD，右奇异向量就是主成分，`σᵢ² / (n-1)` 就是特征值。
  2. 维度很高（d ≫ n）时，构造 d×d 协方差矩阵本身就很贵；截断/随机化 SVD 只算前 k 个分量。
  3. scikit-learn 的 `PCA` 就是基于 SVD 实现的。
- **常见误区**：忘了先把数据中心化；用 `np.linalg.eig` 后忘了排序（它不保证顺序）；对对称矩阵用 `eig` 而不是 `eigh`。

### Q14 — 参考回答要点

- **原理**：简化成线性 RNN `h_t = W h_{t-1}`，展开得 `h_t = Wᵗ h_0`（W 的 t 次幂）。若 W 可对角化，`Wᵗ = V Dᵗ V⁻¹`，沿第 i 个特征方向的分量按 `λᵢᵗ` 变化：`|λ| > 1` 指数爆炸，`|λ| < 1` 指数衰减。反向传播时梯度要连乘 T 个雅可比矩阵（`Wᵀ` 乘以激活函数导数的对角阵），同样呈指数增长或衰减，于是出现**梯度爆炸 / 梯度消失**。
- **缓解手段**：
  - **梯度爆炸**：梯度裁剪（按全局范数 clip）是最直接、最常用的手段。
  - **梯度消失**：LSTM / GRU 的门控与加性的 cell state 通路，让梯度可以近似"恒等地"传回去；残差连接也是同样的思想。
  - **初始化**：正交初始化（正交矩阵所有特征值的模都为 1）、单位矩阵初始化（IRNN）。
  - **架构**：Transformer 用 attention 直接连接任意两个位置，不需要沿时间步连乘，从根本上绕开了这个问题。
- **加分点**：严格说控制梯度范数的是**奇异值**（谱范数）而不只是特征值；对于非正规（non-normal）矩阵，即使所有 `|λ| < 1`，短期内范数也可能先增长。能指出这一点说明理解很深。

### Q15 — 参考回答要点

- **不会用特征多项式求根**。原因：
  1. n 次多项式没有求根公式（n ≥ 5 时不存在一般的根式解，阿贝尔-鲁菲尼定理）；
  2. 从矩阵求多项式系数、再从系数求根，这两步都**数值极不稳定**：系数的微小舍入误差会让根大幅偏移（典型例子是 Wilkinson 多项式）。
- **实际算法**：LAPACK 先用正交相似变换把矩阵化成 Hessenberg 形（对称时是三对角形），再用带位移的 **QR 迭代**收敛到（准）上三角形，特征值在对角线上读出。复杂度约 O(n³)，且全程只用正交变换，数值稳定。
- **`eig` vs `eigh`**：
  - `np.linalg.eig`：通用方阵，特征值可能是复数，**不保证排序**，特征向量不保证正交。
  - `np.linalg.eigh`：专用于对称（Hermitian）矩阵，利用对称性更快更稳，返回**实数**特征值、按**升序**排列，特征向量正交。协方差矩阵、Hessian 都应该用 `eigh`。
- **说明**：讲义"Ship It"里说本节代码就是"驱动生产系统降维、谱聚类的同一个算法"，这是概念层面的说法——数学定义相同，但生产库用的数值算法完全不同。2×2 的公式法只适合教学。

### Q16 — 参考回答要点

- **统一表示**：旋转、缩放、剪切都是线性变换，可以用 2×2 矩阵表示并直接相乘复合。但**平移不是线性变换**（它把原点移走了），无法用 2×2 矩阵表示。工程上用**齐次坐标**：把点写成 `[x, y, 1]`，用 3×3 矩阵 `[[a, b, tx], [c, d, ty], [0, 0, 1]]` 表示"线性部分 + 平移"的仿射变换，于是所有操作都能连乘成一个矩阵，只对图像重采样一次。
- **组合顺序**：通常"先把图像中心平移到原点 → 旋转/缩放 → 平移回中心 → 再做随机平移"，即 `M = T_shift @ T_back @ R @ S @ T_to_origin`，否则会绕图像左上角旋转。
- **实现注意点**：
  1. **逆映射 + 插值**：对输出图像的每个像素，用 `M⁻¹` 找到它在原图中的位置，再做双线性插值；正向映射会产生空洞。
  2. **边界填充**：旋转后四角会露出空白，选择常数填充 / 反射填充。
  3. **标签同步**：检测框、关键点、分割掩码要用**同一个矩阵**变换（掩码用最近邻插值，避免出现非法类别值）。
  4. **一次合成**：多步变换先把矩阵乘起来再采样一次，避免多次插值导致图像越来越模糊。
- **加分点**：旋转矩阵是正交矩阵，`R⁻¹ = Rᵀ`，求逆无成本；能说出 OpenCV 的 `getRotationMatrix2D` / `warpAffine` 用的就是 2×3 仿射矩阵（齐次矩阵去掉最后一行）。
