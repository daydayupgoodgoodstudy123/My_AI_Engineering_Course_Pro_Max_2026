## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 逆 CDF 采样 | `U ~ Uniform(0,1)` 时 `F⁻¹(U)` 服从目标分布；指数分布 `x = −ln(u)/λ`；离散分布用累积和 + 查找 |
| 2 | 拒绝采样 | 从提议 q 采样，以 `p(x)/(M·q(x))` 的概率接受；归一化目标下接受率 = 1/M；高维时接受率指数下降 |
| 3 | 重要性采样 | `E_p[f] = E_q[f·p/q]`，只求期望、不需要 p 的样本；q 与 p 差得远时权重方差爆炸；自归一化版本更稳但有偏 |
| 4 | 蒙特卡洛估计 | 用样本均值近似积分/期望，误差 `O(1/√N)` 且与维度无关；估计量方差 = `Var(f)/N` |
| 5 | Metropolis-Hastings | 构造平稳分布为 p 的马尔可夫链；只需未归一化密度；细致平衡保证正确性；关注 burn-in、步长、接受率（高维约 0.234） |
| 6 | Gibbs 采样 | 依次从条件分布 `p(xᵢ \| x₋ᵢ)` 采样，接受率恒为 1；变量强相关时混合很慢 |
| 7 | 温度、top-k、top-p | logits 除以 T 再 softmax：T<1 变尖、T>1 变平、T→0 为贪心；top-k 固定候选数；top-p 取累计概率 ≥ p 的最小集合，候选数自适应 |
| 8 | 重参数化技巧 | `z = μ + σ·ε, ε ~ N(0,1)`，把随机性移到无参数的 ε 上，`∂z/∂μ = 1`、`∂z/∂σ = ε`，VAE 因此可以反向传播 |
| 9 | Gumbel-Max / Gumbel-Softmax | `argmax(log pᵢ + gᵢ)` 是精确的类别采样；把 argmax 换成带温度 τ 的 softmax 得到可微的近似；straight-through 前向用 hard、反向用 soft |
| 10 | 分层采样与扩散模型 | 把 [0,1] 等分后每层采一个点，方差不高于普通 MC（NeRF 沿光线采样即用此法）；扩散模型的每一步去噪都是一次"采噪声 + 确定性变换"的采样 |

## 五、参考答案与解析

### Q1 — 答案：A

指数分布 CDF 为 `F(x) = 1 − e^(−λx)`，反解得 `x = −ln(1 − u)/λ`；由于 `1 − U` 与 U 同分布，可以写成 `x = −ln(u)/λ`，这就是 `sample_exponential_inverse_cdf`。B 把 λ 乘错了位置（得到的均值是 λ 而不是 1/λ）；C 得到负数；D 的取值落在 (0, 1]，不是指数分布。代码验证：λ = 2 时样本均值 0.5038，理论值 0.5。

### Q2 — 答案：C

每次尝试被接受的概率是 1/M = 1/4，尝试次数服从几何分布，期望为 M = 4。所以 M 越紧（越接近 1）越好。讲义也指出：维度越高，M 越大，接受率指数级下降。

### Q3 — 答案：C

A 错：重要性采样的意义恰恰是"从 q 采样来估计 p 下的期望"。B 写反了：`w = p/q`。D 错：自归一化版本除以随机的 `Σw`，是**有偏但相合**的估计（N→∞ 时收敛），好处是方差更小，且 p 只需知道到常数倍。C 中的 ESS 公式见 skill 文件"Common mistakes"。

### Q4 — 答案：A

若 `p(x) = p̃(x)/Z`，则 `p(x')/p(x) = p̃(x')/p̃(x)`，Z 被约掉。这正是 MCMC 适合贝叶斯后验的原因——后验的归一化常数（证据）通常算不出来。代码中 `bimodal_log_pdf` 也只给出了对数密度，`log_alpha` 是两个对数密度之差。

### Q5 — 答案：B

`[2, 1] / 0.5 = [4, 2]`，`softmax = e⁴/(e⁴ + e²) = 1/(1 + e⁻²) ≈ 0.881`。T = 1 时是 0.731（A），T = 2 时是 0.622（C）。T 越小，差距被放大越多。

### Q6 — 答案：B

从大到小累加：0.5889 < 0.8；0.5889 + 0.2166 = 0.8055 ≥ 0.8，停止，保留 2 个（包含"跨过阈值"的那个 token）。代码真实输出 `p=0.80: [0.7311, 0.2689, 0, 0, 0, 0] (2 tokens)`。

### Q7 — 答案：B

链式法则：`∂z/∂σ = ε`，`∂σ/∂log_var = ½·exp(½·log_var) = ½·σ`，相乘得 `½·σ·ε`。代码 `vae_forward_demo` 中正是 `dz_dlogvar = dz_dsigma * dsigma_dlogvar`，其中 `dsigma_dlogvar = 0.5 * sigma`。A 是对 σ 的导数。

### Q8 — 答案：A

这就是 Gumbel-Max 技巧，给出**精确**的类别样本。代码用 10000 次验证：经验频率 `[0.5014, 0.2948, 0.1558, 0.0480]` 对比真实概率 `[0.5, 0.3, 0.15, 0.05]`。D 描述的是 Gumbel-**Softmax**（把 argmax 换成 softmax 后的连续松弛）。

### Q9 — 参考答案

(a) 提议是 `Uniform(−1, 2)`，`q = 1/3`；目标在 x = 0 处最大，`φ(0) ≈ 0.3989`，所以 `M ≈ 0.3989 × 3 ≈ 1.197`，`1/M ≈ 0.836`。
但代码中的 `target` 是**未截断归一化**的正态密度，它在 [−1, 2] 上的总质量只有 `Z = Φ(2) − Φ(−1) ≈ 0.8186`。接受率的一般公式是 `Z/M ≈ 0.8186 / 1.197 ≈ 0.684`，与实测 0.6824 吻合。讲义中"接受率 = 1/M"成立的前提是 p 已经归一化（那时 Z = 1）。如果把 target 除以 Z，M 也会同比变成 `M/Z`，接受率仍是 0.684——**接受率由几何形状决定，与是否归一化无关**。
附带一提：代码里计算的 `norm_const`（正是 Z 的数值积分）在函数中没有被使用，是一行死代码。

(b) 风险：网格可能错过真正的最大值（这里 x = 0 恰好不在网格上，最近的格点是 0.005），导致 M 被**低估**；此时在峰值附近会出现 `p/(M·q) > 1`，这些点的接受概率被截断为 1，采样分布在峰附近被"削平"，产生偏差（本例偏差极小）。更稳妥的做法：解析求出最大值（正态在 μ 处取最大，若 μ 在区间外则在端点处）；或把网格最大值乘一个安全系数（如 1.05），代价是接受率略降。

### Q10 — 参考答案

(a) 均值 `0.4 × (−3) + 0.6 × 3 = 0.6`；方差 = 组内方差 + 组间方差 = `1 + (0.4×9 + 0.6×9) − 0.6² = 9.64`，标准差约 3.105。`proposal_std=3.0` 最接近（0.673 / 3.097）。

(b) 两个峰相距 6 个标准差，中间是低密度区。步长 0.5 时每次只挪一小步，几乎所有提议都在当前峰内被接受（接受率高），但要穿过谷底需要连续很多次"下坡"接受，跨峰非常罕见。于是链在某个峰里停留的时间比例偏离真实的 0.4/0.6，均值偏到 0.97。**高接受率 ≠ 好的探索**：它往往意味着步子太小、样本高度自相关、有效样本量很低。步长 3.0 能一步跨越到另一个峰附近，虽然接受率降到 0.44，混合却快得多。讲义给出的经验：高维高斯提议的最优接受率约 0.234。

(c) 目标密度可能极小（如 `1e-300` 量级），直接算比值会下溢为 0 或产生 `0/0`；在对数空间里比较 `log u < log p(x') − log p(x)` 等价于 `u < p(x')/p(x)`，而且数值稳定。`random.random()` 可能返回 0.0，`math.log(0)` 会抛 `ValueError`，加上 `1e-300` 是防御（`bimodal_log_pdf` 里的 `+ 1e-300` 同理，防止对 0 取对数）。

### Q11 — 参考答案

```python
def filtered_distribution(logits, temperature=1.0, top_k=None, top_p=None):
    if temperature <= 0:                       # 贪心：退化为 one-hot
        probs = [0.0] * len(logits)
        probs[logits.index(max(logits))] = 1.0
        return probs
    probs = softmax([z / temperature for z in logits])
    order = sorted(range(len(probs)), key=lambda i: -probs[i])
    keep = order[:top_k] if top_k is not None else order
    if top_p is not None:
        total = sum(probs[i] for i in keep)
        cumsum, nucleus = 0.0, []
        for i in keep:
            cumsum += probs[i] / total         # 在 top-k 剩余集合内重新归一化后累计
            nucleus.append(i)
            if cumsum >= top_p:
                break
        keep = nucleus
    total = sum(probs[i] for i in keep)
    out = [0.0] * len(logits)
    for i in keep:
        out[i] = probs[i] / total
    return out


def sample_token(logits, temperature=1.0, top_k=None, top_p=None):
    return sample_from_probs(filtered_distribution(logits, temperature, top_k, top_p))
```

实际运行结果：

```text
top_k=3, top_p=0.8          → [0.7311, 0.2689, 0.0, 0.0, 0.0, 0.0]
temperature=0.5, top_p=0.9  → [0.8808, 0.1192, 0.0, 0.0, 0.0, 0.0]
```

- 第一种：top-3 重新归一化为 `[0.6285, 0.2312, 0.1402]`，累计到第 2 个时 0.8597 ≥ 0.8，保留 2 个。
- 第二种：T = 0.5 后分布为 `[0.8388, 0.1135, …]`，0.8388 < 0.9，加上第 2 个后 0.9523 ≥ 0.9，保留 2 个。
- 设计要点：把"算分布"和"采样"拆成两个函数，分布函数是确定性的，便于写单元测试；采样 20000 次的频率 `[0.730, 0.270]` 与第一种分布一致。

### Q12 — 参考答案

(a) 不矛盾。`O(1/√N)` 描述的是误差的**期望量级**（标准差），单次运行的误差是随机变量。理论标准差在 N = 1000 时约 0.031、N = 10000 时约 0.0097，两次运行的实际误差（0.006、0.0086）都在 1 个标准差以内，只是 N = 1000 那次运气好。

(b)

```python
def rmse_of_mc_integral(n, trials=200):
    errs = [(monte_carlo_integral(math.sin, 0, math.pi, n) - 2.0) ** 2
            for _ in range(trials)]
    return (sum(errs) / trials) ** 0.5

for n in [100, 1000, 10000]:
    r = rmse_of_mc_integral(n)
    print(n, round(r, 5), round(r * math.sqrt(n), 3))
```

实际输出：

```text
100 0.09939 0.994
1000 0.02926 0.925
10000 0.00907 0.907
```

`RMSE × √N` 基本稳定。理论值：估计量是 `π · mean(sin X)`，`X ~ U(0, π)`，`Var(sin X) = ½ − (2/π)² ≈ 0.0947`，所以 `RMSE = π·√(0.0947/N) ≈ 0.967/√N`。

(c) 普通 MC 的方差是 `Var(f)/N`，按 `1/N` 下降；对光滑函数，分层采样每层内函数近似线性，层内方差约按层宽的平方缩小，总体方差约按 `1/N³` 下降。两者之比约按 `N²` 增长：N 从 10 到 100，比值从 20 增长到 2671（约 130 倍，与 `10² = 100` 同一量级）。

### Q13 — 参考回答要点

- **Temperature**：`softmax(z/T)`。T < 1 放大 logit 差距、更确定；T > 1 拉平、更多样；T → 0 等价于贪心。它**不改变候选集合**，只改变概率质量的分配，长尾里的"垃圾 token"概率仍然非零（skill 文件："temperature alone does not remove garbage tokens"）。
- **Top-k**：只保留概率最高的 k 个再重新归一化。缺点是 k 固定：模型很确定时（一个 token 占 95%），k = 40 仍放进 39 个备选；模型不确定时（概率分散在上千个 token），k = 40 又截掉了合理选项。
- **Top-p（nucleus）**：保留累计概率 ≥ p 的最小集合，确定时只留 2～3 个，不确定时留几百个——候选数随分布形状**自适应**（Holtzman et al., 2020）。
- **组合**：常见做法是先温度缩放，再 top-k / top-p 过滤，再采样（Q11）。讲义推荐通用设置为 T = 0.7 + top-p = 0.9。
- **加分点**：贪心 / 低温度易产生重复，高温度易跑题；结构化抽取、分类等需要确定输出的任务用贪心（T = 0）。

### Q14 — 参考回答要点

- **问题**：`z ~ N(μ, σ²)` 是一次随机抽取，"抽到的值对 μ 的导数"没有定义，梯度无法穿过采样节点传到编码器。
- **技巧**：把随机性移到无参数的噪声上：`ε ~ N(0,1)`，`z = μ + σ·ε`。z 的分布不变，但对给定的 ε，z 是 μ、σ 的确定、可微函数：`∂z/∂μ = 1`，`∂z/∂σ = ε`。VAE 编码器通常输出 `log σ²`，保证 σ > 0 且数值稳定，`∂z/∂logσ² = ½σε`（Q7）。
- **意义**：讲义称这"让 VAE 变得实用"；它给出的梯度估计方差通常较低。扩散模型的每一步去噪也是"采噪声 + 确定性变换"的形式。
- **离散变量**：类别分布不能这样重参数化。可用 Gumbel-Softmax（带温度的连续松弛，τ 小更接近 one-hot 但梯度方差大），或 straight-through（前向用 hard one-hot，反向用 soft 梯度）。
- **加分点**：另一条路线是得分函数估计器（REINFORCE，`∇E[f] = E[f·∇log p]`），不要求可微采样，但方差大，这也是策略梯度方法的基础。

### Q15 — 参考回答要点

- **原理**：构造一条马尔可夫链，接受率 `α = min(1, p(x')q(x|x') / (p(x)q(x'|x)))` 保证**细致平衡** `p(x)T(x→x') = p(x')T(x'→x)`，从而 p 是链的平稳分布；只需未归一化密度（Q4）。对称提议时 q 项约掉，就是代码中的 Metropolis 版本。
- **调参**：步长太小 → 接受率高但移动慢、自相关强；步长太大 → 大部分提议被拒、链原地不动。高维随机游走的经验目标接受率约 0.234（讲义）。
- **实践**：丢弃 burn-in；必要时 thinning 降低自相关；看 trace plot；从多个不同起点跑多条链看是否收敛到同一分布；用有效样本量评估真正的信息量。多峰分布要特别警惕"只探索了一个峰"（Q10）。
- **Gibbs**：每次从完整条件分布采样，接受率为 1，适合条件分布易采样的模型（贝叶斯网络、高斯混合、Ising 模型）；但变量高度相关时只能沿坐标轴小步移动，混合很慢。
- **加分点**：高维连续后验用 HMC/NUTS（利用梯度做长距离提议，skill 文件建议接受率约 65%），工程上用 PyMC、NumPyro 等库。

### Q16 — 参考回答要点

- **为什么需要重要性采样**：PPO 用旧策略 `π_old` 收集轨迹，却要优化新策略 `π_new`；期望要换到新策略下，就要乘上权重 `r = π_new(a|s) / π_old(a|s)`——正是 `w = p/q`。
- **为什么要 clip**：新旧策略差得越远，比率越极端，少数样本权重巨大，估计方差爆炸，一次更新就可能把策略推坏。PPO 把比率限制在 `[1 − ε, 1 + ε]` 附近，相当于限制每次更新的步幅（讲义："prevent the new policy from diverging too far from the old one"）。
- **与本节的联系**：这正是"q 与 p 差异大时权重方差爆炸"的具体体现；同样可以用 ESS 之类的指标监控。
- **加分点**：TRPO 用 KL 约束达到类似目的；RLHF 中还会额外加 KL 惩罚，让策略不要偏离参考模型太远（第 14 节）。

### Q17 — 参考回答要点

- **按场景配置**（参考 skill 文件的表格）：
  - 事实问答、结构化抽取、分类：T = 0（贪心），追求确定性与可复现；结构化输出还可以配合约束解码；
  - 代码生成：低温度（约 0.2～0.5）+ top-p 0.9；
  - 闲聊：T ≈ 0.7 + top-p 0.9；
  - 创意写作、头脑风暴：T ≈ 0.9～1.5，top-p 0.95。
- **"重复啰嗦"**：常见于贪心或温度过低——适当提高温度或改用 nucleus 采样；检查是否需要重复惩罚类策略；检查停止条件和最大长度。
- **"偶尔胡言乱语"**：温度过高、没有 top-p/top-k 截断导致长尾 token 被采到——加上 top-p 过滤、降低温度；检查 softmax 前是否做了数值稳定处理。
- **评估**：离线对同一批 prompt 多次采样，衡量质量（人工 / 模型评分、任务指标）与多样性（不同序列比例、distinct-n），用统计方法比较配置（第 15 节）；线上 A/B 测试。
- **加分点**：讲义的文本生成演示中，贪心 3 次输出完全相同（`Unique sequences: 1/3`），其他方法都是 3/3——多样性与确定性的权衡一目了然。

### Q18 — 参考回答要点

- **MC 误差与维度无关**：估计量方差是 `Var(f)/N`，只与 f 的方差和样本数有关，误差 `O(1/√N)` 在 1 维和 1000 维中都成立（常数 `Var(f)` 可能随维度变化）。
- **网格法的问题**：每维取 m 个点，d 维需要 mᵈ 个点——维度灾难，高维下完全不可行。
- **方差缩减**：分层采样（方差不高于普通 MC，Q12）；重要性采样（在"贡献大"的区域多采样）；对偶变量（同时使用 U 和 1 − U）；控制变量（减去一个已知均值、与 f 相关的量）；拉丁超立方（skill 文件中的表格）。
- **在 AI 中的应用**：NeRF 沿光线做分层采样；扩散模型训练时对时间步和噪声做蒙特卡洛估计；SGD 的 mini-batch 梯度本身就是梯度的蒙特卡洛估计。
- **常见误区**：只跑一次就判断收敛速度（Q12）；以为 MC 在高维"免费"——方差本身可能随维度快速增长。
