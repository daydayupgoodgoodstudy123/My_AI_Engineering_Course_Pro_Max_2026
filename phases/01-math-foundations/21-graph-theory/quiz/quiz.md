```python
def dfs(graph, start):
    visited = set()
    order = []
    stack = [start]
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        order.append(node)
        for neighbor in reversed(graph.neighbors(node)):
            if neighbor not in visited:
                stack.append(neighbor)
    return order
```

## 五、参考答案与解析

### Q1 — 答案：A

L 每行和为 0，所以全 1 向量对应特征值 0。又因为 `L = 3I − J`（J 是全 1 矩阵），J 的特征值是 3、0、0，于是 L 的特征值是 `3−3 = 0`、`3−0 = 3`、`3−0 = 3`。用 `np.linalg.eigvalsh` 实测为 `[≈0, 3, 3]`。B 不对：三角形中 3 个节点完全对称，两个非零特征值必然相等（对比之下，3 节点路径图 `0—1—2` 的特征值是 0、1、3）；C 是度矩阵 D 的特征值；D 有两个 0，意味着两个连通分量，与三角形连通矛盾。

### Q2 — 答案：A

零特征值有 3 个 → 3 个连通分量（这正是 `demo_laplacian` 的图：三角形 + 两条孤立边）。代数连通度的标准定义是**第二小特征值 λ₂**，这里 λ₂ = 0，正好表示图不连通。讲义把 Fiedler 值描述为"最小的非零特征值"，这个说法只在连通图上与 λ₂ 一致；代码里打印的 `eigenvalues[1]` 用的也是 λ₂。B 把"第一个非零特征值"当成了代数连通度；C、D 混淆了"特征值个数"与"零特征值个数"。

### Q3 — 答案：B

BFS 按距离一层层扩展，节点第一次被发现时的层数就是最短跳数——`bfs` 返回的 `distances` 正是这个值。DFS 先沿一条路走到底，首次到达时的路径可能很绕，所以 A、C 错。Dijkstra 能用，但在所有边权相同的情况下它就退化成 BFS，没必要（D 错）。

### Q4 — 答案：A

`(A_norm @ H)[i] = Σⱼ (A[i][j] / deg(i)) · H[j]`，即邻居特征的平均。因为没有自环（`A[i][i] = 0`），节点 i 自己的特征**不在其中**——这正是 GCN 要加 `A + I` 的原因。D 是不归一化的 `A @ H`。

### Q5 — 答案：A

`(A²)[i][j] = Σₖ A[i][k]·A[k][j]`，统计的是"i → k → j"这种两步走法的条数。对角线 `(A²)[i][i]` 等于节点 i 的度（走出去再走回来）。例如路径图 0-1-2-3 的 `A²` 中 `(A²)[1][1] = 2`、`(A²)[0][2] = 1`、`(A²)[0][1] = 0`。推广：`(Aᵏ)[i][j]` 是长度为 k 的游走条数，这也是"K 层消息传递 ↔ K 跳"的代数来源。

### Q6 — 答案：A

正值 `{0, 1}`、负值 `{2, 3}`，把路径从中间（瓶颈）切开。特征向量只确定到一个非零倍数，`eigh` 可能返回 v 也可能返回 −v，取反后两组整体交换，分组本身不变，只是"簇 0""簇 1"的编号互换。所以谱聚类的标签编号没有意义，评估时要用 ARI 之类与编号无关的指标。

### Q7 — 答案：B

随机跳转保证转移矩阵不可约且非周期，从而平稳分布存在、唯一，幂迭代能收敛；同时也让"困在"某个子图或悬挂节点的随机游走能跳出去。代码里还额外把悬挂节点（出度为 0）的分数 `dangling_sum` 平均分给所有节点，保证分数总和恒为 1。C 是结果而非作用；A、D 无关。

### Q8 — 答案：B

没有自环时，一层聚合只用邻居特征，节点会"忘记自己"。加 `I` 后每个节点的度至少为 1，也顺带避免了孤立节点在 `D̂^(−1/2)` 里除以 0。A 不对：`A + I` 也不一定可逆，且 GCN 并不需要求逆。

### Q9 — 参考答案

1. 邻接表中邻居按插入顺序存放：`0:[1,2]`、`1:[0,3]`、`2:[0,3]`、`3:[1,2,4]`、`4:[3,5]`、`5:[4]`。实际输出：

```
BFS 顺序: [0, 1, 2, 3, 4, 5]
距离:     {0: 0, 1: 1, 2: 1, 3: 2, 4: 3, 5: 4}
DFS 顺序: [0, 1, 3, 2, 4, 5]
```

DFS 过程：弹出 0，逆序压入 2、1 → 弹出 1，压入 3 → 弹出 3，逆序压入 4、2 → 弹出 2（邻居都已访问）→ 弹出 4，压入 5 → 弹出 5 → 剩下的 2 已访问，跳过。

2. 去掉 `reversed` 后顺序变为 `[0, 2, 3, 4, 5, 1]`。栈是后进先出，按 `[1, 2]` 的顺序压栈会先弹出 2。加 `reversed` 是为了让迭代版 DFS 与"按邻居列表顺序递归"的递归版 DFS 访问顺序一致（先访问第一个邻居）。两种顺序都是合法的 DFS。讲义里 DFS 的手推示例先访问 2，对应的正是不加 `reversed` 的写法，与本代码不同，对照时注意。

另外注意 `if node in visited: continue`：同一个节点可能被多次压栈（例如节点 2 会被压入两次），弹出时再检查一次是迭代 DFS 的标准写法。

### Q10 — 参考答案

1. 两轮且中间没有非线性，所以 `output2 = A_norm·(A_norm·F·W₁)·W₂ = A_norm²·F·W₁W₂`。计算 `A_norm²` 的第 4 行：节点 4 的唯一邻居是 3，节点 3 的邻居是 2 和 4，所以 4 → 3 → {2, 4}，第 4 行为 `[0, 0, 0.5, 0, 0.5]`。**节点 4 两轮后只受节点 2 和它自己的原始特征影响，节点 3 不在其中。** 实测：把节点 3 的特征加 10，节点 4 的两轮输出变化为 `[0, 0]`。原因是没有自环时，两轮聚合等于"恰好走两步"的游走，而不是"两跳以内"。演示里 "2-hop neighborhood info" 的标注因此不够准确。

2. 带自环的对称归一化版本：

```python
import numpy as np

def gcn_layer(graph, features, weight_matrix):
    A_hat = graph.adjacency_matrix() + np.eye(graph.n)   # 加自环
    d_hat = A_hat.sum(axis=1)                            # 每个度至少为 1，不会除 0
    D_inv_sqrt = np.diag(1.0 / np.sqrt(d_hat))
    S = D_inv_sqrt @ A_hat @ D_inv_sqrt                  # 对称归一化
    return S @ features @ weight_matrix                  # 实际 GCN 还要再套激活函数
```

此时 `S²` 的第 4 行约为 `[0, 0, 0.118, 0.340, 0.417]`，节点 2、3、4 都参与——这才是真正的"两跳以内"。自环让每一轮都保留"原地不动"的路径，K 轮就覆盖所有长度 ≤ K 的游走。

### Q11 — 参考答案

**问题**：对 k 个簇，标准做法是取前 k 个特征向量（包含平凡的全 1 向量），等价于 **k−1 个非平凡特征向量** λ₂…λ_k。代码跳过第一个后又取了 k 个（λ₂…λ_{k+1}），多出来的第 k+1 个特征向量描述的是**簇内部**的结构，而不是簇的划分。本例中 λ = 3 是 4 重特征值，第 4 个特征向量是这个 4 维特征空间里的任意一个向量，相当于给 k-means 加了一维噪声，节点 6 就被拉到了中间那组。注意 `k == 2` 分支只用了 Fiedler 向量（1 个非平凡向量），与 `k > 2` 分支的取法前后不一致。

**修复**：

```python
    features = eigenvectors[:, 1:k]      # k-1 个非平凡特征向量；或 eigenvectors[:, :k]
```

修复后在同一张图上得到 `[1 1 1 2 2 2 0 0 0]`，三个三角形完全分开（编号顺序无所谓）。实测用 `[:, 1:k]` 在 10 个不同随机种子下都能分对，原写法只有 1 次分对。

补充两点：①代码对特征行做了单位化，这是 Ng-Jordan-Weiss 算法的步骤，原算法搭配的是归一化拉普拉斯 `L_sym`；②自写的 k-means 中若某个簇变空，新中心会保持为 0 向量，生产中应重新初始化，或直接用 `sklearn.cluster.KMeans(n_init=10)`。

### Q12 — 参考答案

1. **不准确**。在无向连通图上，不带随机跳转的随机游走平稳分布是 `π(v) = deg(v) / 2|E|`，只和度有关。PageRank 加了 15% 的均匀跳转，结果与"按度分配"非常接近。桥节点 2、7 的度是 5（团内 4 个 + 桥 1 个），其他节点是 4，这才是分数更高的原因，与"连接社区"无关。真正衡量"连接作用"的指标是**介数中心性**（betweenness centrality，经过该节点的最短路径比例）。

2. 实验：把阻尼调到接近 1，与 `degree / 总度数` 对比。

```python
import numpy as np
deg = np.array([g.degree(i) for i in range(g.n)])
print(deg / deg.sum())                     # 0.0952 ×8，0.1190 ×2
print(np.round(pagerank(g, damping=0.999999, max_iter=10000, tol=1e-12), 4))
# [0.0952 0.0952 0.119  0.0952 0.0952 0.0952 0.0952 0.119  0.0952 0.0952]
```

两者完全吻合：`5/42 ≈ 0.119`，`4/42 ≈ 0.0952`。还可以做反例：给团内某个非桥节点加一条连到新叶子节点的边，它的 PageRank 同样会上升，尽管它并不"连接社区"。

### Q13 — 参考回答要点

- **邻接矩阵**：O(n²) 空间；判断边是否存在 O(1)；可以直接做矩阵乘法、求特征值（谱方法、GCN 公式推导都依赖它）。缺点是对稀疏图极其浪费（百万节点就是 10¹² 个格子）。
- **邻接表**（本节 `self.adj = {i: {}}`，字典套字典，还能存权重）：O(V+E) 空间；遍历邻居 O(度)，BFS/DFS 是 O(V+E)。缺点是不能直接参与矩阵运算。
- **工程实践**：大图用稀疏格式。COO（边列表，如 PyTorch Geometric 的 `edge_index`，形状 `[2, E]`）便于构造和做 scatter/gather 式消息传递；CSR 便于按行（按节点）快速取邻居。消息传递实现为"沿边 gather 源节点特征 → 按目标节点 scatter-add/mean"，避免稠密 n×n 矩阵。
- **加分点**：超大图训练要做邻居采样（如 GraphSAGE）或子图采样，否则 K 层的感受野呈指数增长。

### Q14 — 参考回答要点

- **半正定**：对任意向量 x，`xᵀLx = Σ_(i,j)∈E wᵢⱼ(xᵢ − xⱼ)² ≥ 0`（边权非负）。所以 L 对称且所有特征值 ≥ 0。
- **零特征值 ↔ 连通分量**：`Lx = 0` ⇔ `xᵀLx = 0` ⇔ 每条边两端 `xᵢ = xⱼ` ⇔ x 在每个连通分量内是常数。有 c 个分量，零空间就由 c 个"分量指示向量"张成，维数为 c。
- **Fiedler 向量为什么能切图**：二分问题（最小化切边、同时两边规模均衡，即 RatioCut）是 NP 难的离散优化；把"每个节点取 ±1"放松为"取实数、与全 1 向量正交、模长固定"，最优解就是 λ₂ 对应的特征向量（Rayleigh 商最小）。它让相连节点取值尽量接近，瓶颈两侧自然分到正负两边。λ₂ 越小，切开越"便宜"。
- **常见误区**：①带权图的度矩阵必须用**权重和**，否则行和不为 0，L 不再半正定（本节代码用 `weighted_degree` 是对的）；②特征向量的符号和编号是任意的。

### Q15 — 参考回答要点

- **公式**：`H^(l+1) = σ(D̂^(−1/2) Â D̂^(−1/2) H^(l) W^(l))`，`Â = A + I`，`D̂` 是 Â 的度矩阵。
- **自环**：聚合时包含自身特征，避免"只看邻居、忘了自己"；并保证每个节点的度至少为 1。
- **对称归一化**：如果直接用 `ÂH`，高度节点的特征会被放大，多层堆叠后数值会爆炸或消失。`D̂^(−1/2)ÂD̂^(−1/2)` 的特征值在 (−1, 1] 内，且对边 (i, j) 按 `1/√(dᵢdⱼ)` 加权，兼顾双方的度。它与 `L_sym = I − D^(−1/2)AD^(−1/2)` 只差一个 I 和自环，这就是"GCN 是一阶谱滤波器的近似"的来源。
- **过平滑**：每层都在做"邻居加权平均"（一种低通滤波，相当于反复施加平滑算子）。层数很深时，同一连通分量内所有节点的表示收敛到几乎相同（主要由度决定），失去区分度。所以 GCN 通常 2–3 层；更深时需要残差连接、跳跃连接（JK-Net）、DropEdge、PairNorm 等手段。
- **加分点**：去掉非线性后，K 层 GCN 退化为 `S^K X W`（SGC 的思路），说明"传播"和"变换"可以解耦。

### Q16 — 参考回答要点

- **几度关系**：
  - 用 BFS，但不能从一端暴力扩展——社交网络平均度高，两三跳就覆盖上亿节点。
  - **双向 BFS**：从两端同时扩展，每次扩展较小的那一侧，相遇即停，搜索量大约从 `b^d` 降到 `2·b^(d/2)`。
  - 设最大跳数上限（例如 3 或 4 跳），超出就返回"较远"。
  - 高频查询可以对大 V 节点做预计算或缓存，图存储在分布式图数据库里。
- **社区发现**：
  - 讲义的谱聚类需要对 n×n 拉普拉斯做特征分解，稠密 `eigh` 是 O(n³)，十亿级根本跑不动。
  - 可行做法：稀疏矩阵 + 只求少数几个最小特征向量的迭代特征求解器（Lanczos / LOBPCG，如 `scipy.sparse.linalg.eigsh`）；或者用可扩展的启发式算法，如 Louvain/Leiden（模块度优化）、标签传播；也可以用 node2vec/GNN 学 embedding 后再聚类。
  - 工程上常先按连通分量切分（讲义提到的预处理），再在每个分量内部做。
- **常见误区**：直接把稠密邻接矩阵读进内存，或者在全图上做精确特征分解。

### Q17 — 参考回答要点

- **共同点**：self-attention 可以看成在一张**完全图**（每个 token 连向所有 token）上做消息传递：`Attention = softmax(QKᵀ/√d)·V`，其中 `softmax(QKᵀ/√d)` 是一个**行和为 1** 的"邻接矩阵"，和本节 `A_norm` 每行和为 1 完全同构；V 是消息，乘以权重后求和就是 AGGREGATE。
- **不同点**：GCN 的边权由图结构固定（`1/deg` 或 `1/√(dᵢdⱼ)`）；attention 的边权由内容动态计算，而且默认全连接。causal mask 相当于把图变成"只连向过去"的有向图；稀疏/滑动窗口 attention 则相当于人为指定一张稀疏图。
- **桥梁**：GAT（Graph Attention Networks）就是在**图的边上**做 attention——只在真实邻居之间算注意力权重。Graph Transformer 则在全连接 attention 的基础上加入图结构编码（如用拉普拉斯特征向量做位置编码）。
- **加分点**：位置编码对应"图结构信息"——Transformer 本身对 token 顺序是置换等变的，就像 GNN 对节点编号是置换等变的。
