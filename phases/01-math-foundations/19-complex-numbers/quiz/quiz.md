### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 复数与复平面 | `z = a + bi`，`i² = −1`；复数就是平面上的点 (a, b)，也是从原点出发的向量 |
| 2 | 四则运算与共轭 | 乘法 `(ac − bd) + (ad + bc)i`；共轭 `a − bi` 是关于实轴的镜像；`z·z̄ = a² + b²`；除法 = 分子分母同乘分母的共轭 |
| 3 | 极坐标形式 | `r = √(a² + b²)`、`θ = atan2(b, a)`；直角坐标适合加法，极坐标适合乘法：**模相乘、角相加** |
| 4 | 欧拉公式 | `e^(iθ) = cosθ + i·sinθ`，θ 变化时在单位圆上转圈，模恒为 1；`e^(iπ) + 1 = 0` |
| 5 | 乘法 = 旋转 | 乘以 `e^(iθ)` 等于把点绕原点转 θ，与 2×2 旋转矩阵完全等价；乘以 i 就是转 90° |
| 6 | Phasor（相量） | `e^(iωt)` 是以角频率 ω 旋转的点，实部是 `cos(ωt)`、虚部是 `sin(ωt)`；正弦信号是旋转复数的"投影" |
| 7 | 单位根 | `w_k = e^(2πik/N)`，N 个点均匀分布在单位圆上；模为 1、总和为 0，是 DFT 的基 |
| 8 | DFT / IDFT | `X[k] = Σₙ x[n]·e^(−2πikn/N)`，O(N²)；逆变换把指数符号翻转再除以 N，可完美重构 |
| 9 | 正弦位置编码 | 频率 `1/10000^(2i/d)`：低维对变化快（细粒度位置），高维对变化慢（粗粒度位置）；(sin, cos) 对就是 `e^(i·pos·ω)` 的虚部与实部 |
| 10 | RoPE | 把 q、k 的维度两两配对看成复数，乘以 `e^(i·m·θ)`；旋转后的点积只依赖相对位置 `m − n` |

## 五、参考答案与解析

### Q1 — 答案：B

`(2 + 3i)(4 − i) = 8 − 2i + 12i − 3i² = 8 + 10i + 3 = 11 + 10i`。关键是 `−3i² = +3`。A 是只把实部、虚部分别相乘的错误做法；D 忘了 −2i 这一项的符号。用代码验证：`Complex(2, 3) * Complex(4, -1)` 打印 `11.000000 + 10.000000i`。

### Q2 — 答案：B

`i = e^(iπ/2)`，模为 1、角度 90°，乘以它就是逆时针旋转 90° 而模长不变：`1 → i → −1 → −i → 1`。这也是 `i² = −1` 的几何解释：两次 90° 旋转 = 180° 旋转 = 乘以 −1。A 是共轭的效果；D 是乘以 `−i` 的效果。

### Q3 — 答案：B

`atan2(b, a)` 会根据 a、b 的符号判断象限，返回值范围是 `(−180°, 180°]`。`−1 − i` 在第三象限，返回 −135°。225° 表示同一个方向，但不是 `atan2` 的返回值。A 是用 `atan(b/a) = atan(1)` 计算的结果——除法丢掉了符号信息，这正是要用 `atan2` 的原因。

### Q4 — 答案：C

极坐标乘法：模相乘 `2·3 = 6`，角相加 `π/6 + π/3 = π/2`，所以 `z₁z₂ = 6·e^(iπ/2) = 6i`。A 把模相加了；B 把角相乘了。

### Q5 — 答案：C

令 `w = e^(2πik/N)`，和是等比数列 `Σ wⁿ`。k 是 N 的倍数时 `w = 1`，和为 N；否则 `w ≠ 1` 而 `w^N = 1`，和为 `(1 − w^N)/(1 − w) = 0`。这就是单位根的**正交性**，它让不同频率的 DFT 基向量两两正交，从而 DFT 可逆。讲义说的"N 个单位根之和为 0"是 k = 1 的特例。

### Q6 — 答案：C

`sin θ = (e^(iθ) − e^(−iθ))/(2i)`，一个实正弦同时包含 +3 和 −3 两个频率分量；在 N 点 DFT 中 −3 对应 bin `N − 3 = 29`。每个分量的幅值为 `A·N/2 = 1·32/2 = 16`。实信号的 DFT 满足共轭对称 `X[N − k] = conj(X[k])`，所以 k = 3 和 k = 29 幅值相同、相位相反。D 错在 DFT 的下标范围是 0…N−1，且幅值不是 N。

### Q7 — 答案：C

`ωᵢ = 1/10000^(2i/d)`：i = 0 时为 1，随 i 增大按几何级数减小（本节代码 d = 8 时依次为 1、0.1、0.01、0.001）。高频维度随 pos 快速振荡，区分相邻位置；低频维度变化极慢，区分远距离位置，最低频率的周期可以达到约 `2π·10000`。频率是固定的，不随 pos 变化（D 错）。

### Q8 — 答案：B

把二维对看成复数，位置 m 的 query 变为 `q·e^(imθ)`，位置 n 的 key 变为 `k·e^(inθ)`。二维实向量的点积等于 `Re(z₁·conj(z₂))`，所以旋转后的点积为 `Re(q·conj(k)·e^(i(m−n)θ))`，只依赖 `m − n`。矩阵语言是 `(R(m)q)ᵀ(R(n)k) = qᵀR(m)ᵀR(n)k = qᵀR(n − m)k`。A、C 都与相对位置无关；D 描述的是**加性**位置编码（正弦 PE、可学习 PE），而 RoPE 是**乘性**的旋转，不加到 embedding 上。

### Q9 — 参考答案

(1) 实际运行输出：

```text
  k=3         16.0000       -90.00
  k=7          8.0000       -90.00
```

(2) `A·sin(ω₀n) = (A/2i)·e^(iω₀n) − (A/2i)·e^(−iω₀n)`，正频率分量的系数是 `A/(2i) = −i·A/2`，乘上 N 后 `X[3] = −16i`，纯负虚数，相位就是 −90°。如果信号是 `cos`，系数是 `A/2`（正实数），相位为 0°。所以**相位告诉你这个频率分量是"cos 型"还是"sin 型"**（或者介于两者之间）。

(3) 实信号的 DFT 共轭对称 `X[N − k] = conj(X[k])`，后一半不含新信息，所以只看 `0 … N/2`（`N/2` 是 Nyquist 频率）。`spectrum[29] = conj(X[3]) = +16i`，幅值 16、相位 +90°；同理 `spectrum[25] = +8i`。这也是 `np.fft.rfft` 只返回 `N/2 + 1` 个点的原因。

(4) 对 `0 < k < N/2` 的 bin，`真实振幅 = 2·|X[k]|/N`：`2·16/32 = 1.0`，`2·8/32 = 0.5`。因子 2 来自"能量平分在正负两个频率上"；k = 0（直流）和 k = N/2 这两个 bin 没有镜像，只除以 N。代码里打印的 "Expected peaks ... amplitude 16.0 / 8.0" 用的就是 `amp·N/2`。

### Q10 — 参考答案

```text
2.000000 + 4.000000i
0.000000 - 2.000000i
2.000000 + 4.000000i
TypeError: float() argument must be a string or a real number, not 'complex'
TypeError: unhashable type: 'Complex'
```

- `2 * Complex(1, 2)`：`int.__mul__` 不认识 `Complex`，返回 `NotImplemented`，Python 转而调用右操作数的 `Complex.__rmul__(2)`，得到 `2 + 4i`。没有 `__rmul__` 就会报 `TypeError`。
- `1 - Complex(1, 2)`：同理走 `__rsub__`，它返回 `Complex(other − self.real, −self.imag)` = `0 − 2i`。注意减法不满足交换律，所以 `__rsub__` 不能简单复用 `__sub__`。
- `Complex(1, 2) + (1 + 2j)`：`__add__` 中 `isinstance(other, (int, float))` 不成立，直接访问 `other.real` / `other.imag`——内置 `complex` 恰好也有这两个属性（**鸭子类型**），于是"碰巧"正确。
- `(1 + 2j) + Complex(1, 2)`：内置 `complex.__add__` 返回 `NotImplemented`，转到 `Complex.__radd__`，它调用 `Complex(other)`，而 `__init__` 里 `float(1 + 2j)` 不允许，抛出 `TypeError`。同一个运算换个顺序结果就不同——这是自定义数值类型的常见坑。
- `{Complex(1, 2)}`：类定义了 `__eq__` 却没定义 `__hash__`，Python 会把 `__hash__` 设为 `None`，实例不可哈希，不能放进 `set` 或当 `dict` 的键。由于 `__eq__` 用了 1e-10 的容差比较，也很难写出与之一致的 `__hash__`（相等的对象必须哈希相同）。

### Q11 — 参考答案

```python
import math, random

def fft(signal):
    N = len(signal)
    if N == 1:
        x0 = signal[0]
        return [x0 if isinstance(x0, Complex) else Complex(x0)]
    if N % 2 != 0:
        raise ValueError("length must be a power of 2")
    even = fft(signal[0::2])        # 偶数下标子序列
    odd = fft(signal[1::2])         # 奇数下标子序列
    result = [Complex(0)] * N
    for k in range(N // 2):
        t = euler(-2 * math.pi * k / N) * odd[k]   # 旋转因子 (twiddle factor)
        result[k] = even[k] + t
        result[k + N // 2] = even[k] - t
    return result

random.seed(0)
sig = [random.uniform(-1, 1) for _ in range(64)]
A, B = dft(sig), fft(sig)
print(max((a - b).magnitude() for a, b in zip(A, B)))   # 约 1.6e-13
```

原理（Cooley–Tukey）：把求和按 n 的奇偶拆开，`X[k] = E[k] + w^k·O[k]`，其中 `w = e^(−2πi/N)`，E、O 分别是偶数项、奇数项的 N/2 点 DFT。利用单位根的两个性质：
- **周期性**：E、O 的周期是 N/2，所以 `k + N/2` 时可以复用同一个 `E[k]`、`O[k]`；
- **对称性**：`w^(k+N/2) = −w^k`，所以 `X[k + N/2] = E[k] − w^k·O[k]`，一次乘法得到两个输出（"蝴蝶"运算）。

递推式 `T(N) = 2T(N/2) + O(N)` ⇒ `T(N) = O(N log N)`。N = 1024 时，DFT 约 10⁶ 次复数乘法，FFT 约 5×10³ 次。误差 1e-13 量级来自浮点运算顺序不同，属正常。⚠️ `[Complex(0)] * N` 让列表的 N 个元素指向**同一个对象**，这里没问题是因为随后每个位置都被重新赋值，而不是原地修改。

### Q12 — 参考答案

```python
def rope(vec, pos, base=10000.0):
    d = len(vec)
    out = []
    for i in range(d // 2):
        theta = pos * base ** (-2 * i / d)
        z = Complex(vec[2 * i], vec[2 * i + 1]) * euler(theta)   # 一次复数乘法 = 一次二维旋转
        out.extend([z.real, z.imag])
    return out

def dot(a, b):
    return sum(x * y for x, y in zip(a, b))

q = [0.3, -1.2, 0.8, 0.5]
k = [1.0, 0.4, -0.7, 0.9]
for m, n in [(5, 2), (13, 10), (103, 100), (2, 5)]:
    print(m, n, round(dot(rope(q, m), rope(k, n)), 10))
```

实测输出：

```text
5 2 0.2866217415
13 10 0.2866217415
103 100 0.2866217415
2 5 -0.1501254502
```

- 前三组 `m − n = 3`，点积完全相同——**绝对位置被抵消，只剩相对位置**。
- (2, 5) 的 `m − n = −3`，结果不同：RoPE 区分"在前 3 个位置"和"在后 3 个位置"，依赖的是**有符号**的相对距离。
- 模长：`‖q‖ = 1.5556349186…`，`‖rope(q, 7)‖` 相同（只差最后一位浮点误差）——旋转是正交变换，不改变向量长度，因此不会改变 q、k 的"强度"，只改变方向。
- 工程实现中不会逐元素用 Python 循环，而是预先缓存每个位置的 `cos`、`sin` 表，用逐元素乘加向量化完成（或直接用 `torch.view_as_complex` 做复数乘法）。

### Q13 — 参考回答要点

- **欧拉公式**：可由泰勒级数证明——把 `iθ` 代入 `eˣ = Σ xⁿ/n!`，偶数次项（i 的偶次幂为 ±1）组成 `cos θ`，奇数次项组成 `i·sin θ`。几何上，θ 从 0 增加到 2π 时 `e^(iθ)` 正好绕单位圆一圈。
- **乘法 = 旋转**：极坐标下 `r₁e^(iθ₁)·r₂e^(iθ₂) = r₁r₂·e^(i(θ₁+θ₂))`，模相乘、角相加；当 `|z₂| = 1` 时就是纯旋转。
- **与旋转矩阵的对应**：`(x + iy)(cosθ + i·sinθ) = (x·cosθ − y·sinθ) + i(x·sinθ + y·cosθ)`，正好是 `[[cosθ, −sinθ], [sinθ, cosθ]] @ [x, y]`。更一般地，复数 `a + bi` 对应矩阵 `[[a, −b], [b, a]]`（旋转 + 缩放），复数乘法对应矩阵乘法。本节代码对 5 个角度、3 个点验证，两种方式最大误差 `0.00e+00`。
- **加分点**：二维旋转可交换（角度相加的顺序无关），所以复数乘法可交换；三维旋转不可交换，要用四元数或 3×3 旋转矩阵。

### Q14 — 参考回答要点

- **做法**：对每个注意力头，把 q、k 的 d 维两两配对成 d/2 个复数（或二维子空间）；位置 m 的第 i 对乘以 `e^(i·m·θᵢ)`，`θᵢ = base^(−2i/d)`（base 常取 10000）。只作用于 q、k，**不作用于 v**，也不加到 embedding 上。
- **为什么是相对位置**：`⟨R(m)q, R(n)k⟩ = Re(Σᵢ qᵢ·conj(kᵢ)·e^(i(m−n)θᵢ))`，注意力分数只依赖 `m − n`（Q8、Q12）。
- **与正弦 PE 的区别**：

| 维度 | 正弦位置编码 | RoPE |
|------|------------|------|
| 作用方式 | 加到输入 embedding 上（加性） | 旋转每层的 q、k（乘性） |
| 编码内容 | 绝对位置；相对位置需模型自己"学出来" | 点积天然只依赖相对位置 |
| 作用位置 | 只在输入层 | 每一层注意力都施加 |
| 是否改变模长 | 改变（向量相加） | 不改变（正交变换） |

- **共同点**：频率设计相同（几何级数、多尺度），都可看作在不同频率上放置"旋转的相量"。
- **加分点**：长上下文扩展常通过修改 RoPE 的频率实现，例如位置插值（把位置按比例压缩到训练长度内）、调大 base（NTK-aware 缩放）等；RoPE 已被当前大量开源 LLM 采用（参见阶段 10 的开源模型架构解析）。

### Q15 — 参考回答要点

- **关系**：FFT 不是新的变换，而是计算 DFT 的**快速算法**，结果与 DFT 完全相同（误差仅为浮点舍入）。DFT 直接计算 O(N²)，FFT O(N log N)。
- **依赖的单位根性质**：`w_N² = w_{N/2}`（折半：偶数下标子问题就是 N/2 点 DFT）；`w_N^(k+N/2) = −w_N^k`（对称：一次乘法得到两个输出）；周期性（子问题结果复用）。递推 `T(N) = 2T(N/2) + O(N)`。
- **AI 中的应用**：
  - 语音：STFT → 频谱图 → Mel 特征，是 ASR / TTS 模型的标准输入（见阶段 06）；
  - 卷积定理：时域卷积 = 频域逐点相乘，大卷积核 / 长序列卷积可用 FFT 加速；
  - 位置编码：正弦 PE 与 RoPE 的频率设计都源于"多频率相量"的思想；
  - 也有模型直接用 FFT 混合 token（如 FNet 用傅里叶变换替换自注意力层）。
- **常见误区**：认为 FFT 是近似算法；认为 FFT 只能处理 2 的幂长度（工程库支持任意长度，2 的幂只是最快）。

### Q16 — 参考回答要点

1. **加载与预处理**：读取波形，转单声道，减去均值（去掉直流分量）。
2. **分帧加窗**：整段做 FFT 只能看到"整体有哪些频率"；分析随时间变化的频率要分帧（如 25 ms 帧、10 ms 帧移）并加 Hann 窗——这就是 STFT。
3. **变换**：实信号用 `np.fft.rfft`，只返回 `N/2 + 1` 个非冗余 bin。
4. **频率轴**：`np.fft.rfftfreq(N, d=1/sr)`（或 `fftfreq`），bin k 对应频率 `k·sr/N`，分辨率 `sr/N`；最高可表示频率是 Nyquist `sr/2 = 8 kHz`。
5. **幅度换算**：`|X[k]|·2/N` 得到正弦振幅（直流与 Nyquist bin 除以 N）；常取 `20·log10` 转成分贝。

**易错点**：
- **频谱泄漏**：信号在窗口内不是整数个周期时，能量会泄漏到相邻 bin。讲义 "Use It" 的例子用 `np.linspace(0, 1, 128)` 采样，**包含了端点**，128 个点并不恰好覆盖 5 个完整周期，FFT 后 bin 5 附近的 bin 也出现非零值；改用 `np.arange(128)/128`（或 `linspace(..., endpoint=False)`）就是干净的单峰。实际信号无法保证整周期，所以要加窗。
- **混叠**：高于 Nyquist 的成分会折叠到低频，采样前需要低通滤波。
- **把双边谱当单边谱读**：`fft` 后半部分是负频率的镜像（Q9）。
- **相位解读**：噪声大的 bin 相位没有意义，先看幅度再看相位。

### Q17 — 参考回答要点

- **核心原因**：成对的 (sin, cos) 构成复数 `e^(i·pos·ω)` 的虚部与实部。平移 k 个位置等于乘以固定的 `e^(i·k·ω)`：

```text
[sin((pos+k)ω)]   [ cos(kω)  sin(kω)] [sin(pos·ω)]
[cos((pos+k)ω)] = [-sin(kω)  cos(kω)] [cos(pos·ω)]
```

  即 `PE(pos + k)` 是 `PE(pos)` 的一个**只依赖 k 的线性变换（旋转）**，模型可以用线性层学到"往前 / 往后看 k 个位置"。
- **只用 sin 不行**：`sin((pos + k)ω) = sin(pos·ω)cos(kω) + cos(pos·ω)sin(kω)`，需要 `cos(pos·ω)` 才能表示，单独的 sin 无法通过固定线性变换得到平移后的值；而且只用 sin 时，`sin(pos·ω)` 在一个周期内会出现两个位置取值相同的情况，配上 cos 后 (sin, cos) 在单位圆上唯一确定角度。
- **模长恒定**：每一对 `sin² + cos² = 1`，所有位置的 PE 向量模长相同，不会因为位置大而数值爆炸。
- **加分点**：RoPE 把这个"平移 = 旋转"的性质从输入层直接搬进了注意力点积里，是 Q14 的自然延伸。
- **常见误区**：讲义和代码里都说 "(sin, cos) 是实部与虚部"，严格地说 **cos 是实部、sin 是虚部**（`e^(iθ) = cosθ + i·sinθ`），PE 中 sin 放在偶数维、cos 放在奇数维只是排列顺序。
