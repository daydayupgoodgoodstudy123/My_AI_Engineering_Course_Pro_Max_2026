## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 维度灾难 | 高维下随机点两两距离趋于相同、体积集中在角落、维持同样样本密度所需数据量指数增长 |
| 2 | PCA 五步 | 中心化 → 协方差矩阵 → 特征分解 → 按特征值降序排序 → 投影到前 k 个特征向量 |
| 3 | 主成分的含义 | 协方差矩阵的特征向量（两两正交的方向），对应特征值 = 数据在该方向上的方差 |
| 4 | 解释方差比 | `λₖ / Σλ`；累计达到 0.90–0.95 即可；也可看肘部或下游任务性能来选 k |
| 5 | 重构与重构误差 | `X̂ = Z·W + mean`；丢掉的特征值之和决定误差；高重构误差可用于异常检测 |
| 6 | t-SNE | 保持邻域概率，用于 2D/3D 可视化；随机、O(n²)、簇间距离无意义；perplexity 控制邻居数（常用 5–50） |
| 7 | UMAP | 基于近似 kNN 图，更快、全局结构保持更好；`n_neighbors` 与 `min_dist` 是关键参数 |
| 8 | Kernel PCA | 用核技巧在高维特征空间做 PCA；需在特征空间中心化核矩阵；RBF 核可分开同心圆；代价是 n×n 核矩阵 |
| 9 | 工程用法 | PCA 用于预处理和压缩；t-SNE/UMAP 只用于可视化；特征向量符号不唯一，对比结果要取绝对值 |

## 五、参考答案与解析

### Q1 — 答案：B

协方差描述的是"围绕均值的波动"。不中心化时，`XᵀX/n = Cov + μμᵀ`，多出来的 `μμᵀ` 项会把第一主成分拉向均值向量 μ 的方向——你得到的是"数据离原点最远的方向"，而不是"数据波动最大的方向"。代码中 `fit` 先 `X - self.mean`，`transform` 也用训练时的均值中心化，正是为此。（注：`np.cov` 内部本身也会减均值，但手动中心化让 `transform` / `inverse_transform` 的逻辑保持一致。）

### Q2 — 答案：B

总方差 = 4+3+2+1 = 10；前两个占 `(4+3)/10 = 0.7`；丢失 `(2+1)/10 = 0.3`。这就是讲义中"Fraction lost = 被丢弃特征值之和 / 全部特征值之和"。

### Q3 — 答案：C

t-SNE 优化的是局部邻域概率的匹配，簇间距离和簇的大小都会被扭曲（A 错）；它是随机算法，不同随机种子得到不同布局（B 错，代码中设了 `random_state=42` 才能复现）；朴素实现 O(n²)，讲义建议少于约 1 万个样本（D 错）。它也没有对新样本的 `transform`，因此不适合作为预处理。

### Q4 — 答案：B

若 `Cv = λv`，则 `C(-v) = λ(-v)`，所以 `-v` 同样是特征向量。不同的特征分解 / SVD 实现会给出不同符号，投影坐标因此可能整列取反。比较时先取绝对值即可消除这一不确定性（`sign-invariant`）。用 sklearn 自带 8×8 digits 数据替代 MNIST 运行时，两者的解释方差比完全一致、符号无关差异为 `0.0000000000`。

### Q5 — 答案：B

RBF 核 `k(x,y) = exp(-γ‖x-y‖²)`。γ 很小时，所有点之间的核值都接近 1 且随距离变化平缓，前几个核主成分近似于原始坐标的线性/低阶结构，分不开两个环（实测 γ=0.1 时线性分类准确率只有约 50%）；γ 很大时，核矩阵趋近单位矩阵，每个点只与极近的点相似，主成分变得"碎片化"（γ=5.0 时分离度只有 0.0619）。γ=0.5 时第一主成分上内环取值约 `[-0.55, -0.12]`、外环约 `[0.26, 0.42]`，完全分开。γ 必须结合数据尺度（两环半径 1 和 3）来调。

### Q6 — 答案：B

PCA 找的是方差最大的方向，而方差依赖单位：收入的方差在 10¹⁰ 量级，年龄只有 10² 量级，第一主成分几乎就是"收入轴"。通常先做标准化（每个特征除以标准差，等价于对相关系数矩阵做 PCA）。PCA 本身不会自动标准化（C 错），本节代码与 sklearn 的 `PCA` 都只做中心化。

### Q7 — 答案：A

每个维度切 10 格，2 维有 10² 个格子，20 维有 10²⁰ 个格子，要让每个格子里的样本数相同，数据量需要扩大 `10²⁰ / 10² = 10¹⁸` 倍。这就是"所需数据随维度指数增长"。

### Q8 — 答案：B

在全部数据上 `fit` PCA，测试集的均值和协方差信息就"泄漏"进了训练流程，评估结果会偏乐观。正确做法是 A / D：只在训练数据上拟合（代码 `demo_pca_preprocessing` 中 `pca_k.fit_transform(X_train)` + `pca_k.transform(X_test)` 正是如此），用 Pipeline 配合交叉验证（C）选 k。

### Q9 — 参考答案

(a) 数据由 5 个独立的潜在因子线性混合而来，再叠加很小的噪声，所以协方差矩阵有 5 个大特征值（实测约 46.8、24.4、17.9、13.9、6.2）和 15 个约等于噪声方差 `0.1² = 0.01` 的小特征值。k<5 时还丢着信号方向，误差大；k=5 时信号全部保留，剩下的只是噪声，误差降到"噪声地板"；再增加主成分只是在拟合噪声，误差下降极其有限。这就是讲义说的"effectively 5-dimensional"。

(b) 设丢弃的特征值之和为 `S`。`np.cov` 用 `n-1` 归一化，`Σᵢ‖xᵢ - x̂ᵢ‖² = (n-1)·S`，而 MSE 对 `n×d` 个元素取平均：

```
MSE = (n-1)·S / (n·d)
```

k=5 时 `S ≈ 15 × 0.0099 ≈ 0.15`，`MSE ≈ 299 × 0.15 / (300 × 20) ≈ 0.0075`，与输出一致（逐个 k 验证，该公式与实测 MSE 精确到小数点后 6 位都相同）。讲义里"Reconstruction error = sum of eigenvalues NOT included"是这个关系去掉常数因子后的简写。

(c) k=20 等于特征数，`components` 是完整的 20×20 正交矩阵 W，`WᵀW = I`，重构 `(X-μ)WᵀW + μ = X`，误差只剩浮点舍入（打印为 0.0000）。

### Q10 — 参考答案

(a) 先除以 `√λ`，再乘以 `λ`，净效果是**特征向量乘以 `√λ`**：返回 `vᵢ·√λᵢ`。

(b) 设中心化核矩阵 `K_c = VΛVᵀ`。特征空间中第 i 个主轴的展开系数为 `αᵢ = vᵢ/√λᵢ`（这样主轴的范数为 1）。训练样本在该主轴上的投影是 `K_c·αᵢ = K_c·vᵢ/√λᵢ = λᵢvᵢ/√λᵢ = √λᵢ·vᵢ`，正是函数的返回值。实测该函数与 `sklearn.decomposition.KernelPCA(kernel="rbf", gamma=0.5)` 的 `fit_transform` 结果符号无关的最大差异约 `6e-15`，说明实现正确。

(c) 不准确。除以 `√λ` 得到的是**对偶系数 α**（用来对新样本做投影：`k(x_new, X)·α`），而训练样本的投影是 `√λ·v`。代码"先除再乘"的写法其实同时体现了这两步，只是中间结果 α 没有保存下来，因而函数**无法对新样本做 transform**。

(d) 在 `poly` 分支中 `gamma` 被当作多项式的**次数 d**（讲义表格中 `(x·y + c)^d` 的 d），而在 RBF 分支中它是带宽参数。同一个参数名承载两种含义，容易误用；更清晰的接口应分别命名为 `gamma` 和 `degree`。

### Q11 — 参考答案

```python
import numpy as np
from dim_reduction import PCA


def n_components_for(X, threshold=0.95):
    full = PCA(n_components=X.shape[1]).fit(X)          # 保留全部成分，拿到完整的方差比
    cum = np.cumsum(full.explained_variance_ratio_)     # 累计解释方差
    return int(np.searchsorted(cum, threshold) + 1)     # 第一个 >= threshold 的位置，+1 变成个数


def reconstruction_scores(pca, X):
    X_rec = pca.inverse_transform(pca.transform(X))
    return np.mean((X - X_rec) ** 2, axis=1)            # axis=1：每个样本一个分数


np.random.seed(42)
base = np.random.randn(300, 5)
mixing = np.random.randn(5, 20)
X = base @ mixing + np.random.randn(300, 20) * 0.1

print(n_components_for(X, 0.95), n_components_for(X, 0.99), n_components_for(X, 0.999))
# 5 5 9

pca = PCA(5).fit(X)
X_new = np.vstack([
    np.random.randn(3, 5) @ mixing + np.random.randn(3, 20) * 0.1,   # 3 个正常样本
    np.random.randn(1, 20) * 3,                                      # 1 个不在子空间上的样本
])
print(reconstruction_scores(pca, X_new))
# 约 [0.0066, 0.0092, 0.0072, 7.77]
```

要点：

- 0.95 和 0.99 都选出 5，与数据的真实结构一致；把阈值提高到 0.999 会选到 9——**阈值过高时会开始拟合噪声**，这时应结合肘部或下游指标判断。
- 正常样本的分数在 0.007 左右（训练集分数中位数约 0.0071、99 分位约 0.0138），随机样本约 7.77，高出三个数量级。实际系统中通常用训练集重构误差的高分位数（如 99%）作为阈值。
- `np.searchsorted` 在有序数组中二分查找插入位置；`axis=1` 表示沿特征维度求平均。

### Q12 — 参考答案

**能分开。** 加上 `r² = x² + y²` 后，内环的 r² 约为 1、外环约为 9。这个新特征的方差约 16.4，而原始 x、y 坐标的方差只有约 2.6，所以线性 PCA 的第一主成分几乎就是 r² 轴（实测主成分向量约 `[-0.001, -0.002, 1.0]`，解释方差比约 0.76）。投影后内环取值约 `[-4.57, -3.38]`、外环约 `[2.28, 6.10]`，完全分离。

与核技巧的关系：Kernel PCA 做的正是"先把数据映射到一个更高维的特征空间 φ(x)，在那里做线性 PCA"。区别在于：

- 手工映射要你**知道**该加什么特征（这里恰好知道是半径）；
- 核技巧只需要定义内积 `k(x,y) = φ(x)·φ(y)`，不必显式写出 φ——RBF 核对应的 φ 甚至是无限维的。

同时也要注意：PCA 是**无监督**的，它能分开两个环只是因为"区分两个环的方向"恰好也是"方差最大的方向"。如果类别差异不在高方差方向上，PCA 照样会把它丢掉——需要类别信息时应考虑 LDA 等有监督方法。

### Q13 — 参考回答要点

- 目标：找单位向量 w，使投影方差 `Var(Xw) = wᵀCw` 最大（C 为协方差矩阵）。用拉格朗日乘子法处理约束 `‖w‖ = 1`：`∇(wᵀCw - λ(wᵀw - 1)) = 0 ⇒ Cw = λw`。所以 w 是 C 的特征向量，且此时投影方差 `wᵀCw = λ`，取最大特征值对应的特征向量即为第一主成分；后续主成分在与前面正交的约束下依次取次大特征值。
- 步骤：中心化 → 协方差 → 对称矩阵特征分解（`np.linalg.eigh`）→ 降序排序 → 取前 k 个 → `Z = (X-μ)Wₖᵀ`。
- 为什么用 SVD：对中心化后的 `X_c = UΣVᵀ`，V 的列就是主成分，特征值 `λ = σ²/(n-1)`。SVD 不需要显式构造 `XᵀX`，避免把条件数平方带来的精度损失；d 很大（如 784 甚至上万）时也不必形成 d×d 矩阵；还有截断 / 随机化 SVD（randomized SVD）可以只算前 k 个分量，适合大规模数据。sklearn 的 PCA 就是基于 SVD 实现的。
- 加分点：PCA 的结果等价于"最小化重构误差的最优 k 维线性子空间"（Eckart–Young 定理），把"最大方差"和"最小重构误差"两种视角统一起来；提到增量 PCA（IncrementalPCA）可用于内存放不下的数据。

### Q14 — 参考回答要点

| | PCA | t-SNE | UMAP |
|---|---|---|---|
| 类型 | 线性 | 非线性 | 非线性 |
| 保持 | 全局方差 | 局部邻域 | 局部 + 部分全局结构 |
| 确定性 | 确定（除符号） | 随机 | 随机（可设种子） |
| 新样本 transform | 有 | 原生没有 | 有（近似） |
| 规模 | 百万级 | 建议 < 1 万 | 可到百万级 |
| 用途 | 预处理、压缩、去噪 | 可视化 | 可视化，也可作为某些下游任务的特征 |

- 为什么簇大小和间距不可解读：t-SNE 为每个点自适应地选择高斯带宽（使有效邻居数等于 perplexity），密集区域和稀疏区域被"拉平"，所以簇的大小不反映原空间的离散程度；它只惩罚"近邻被拉远"，对"远点之间的距离"约束很弱，所以簇间距离不可靠。低维端使用重尾的 t 分布，会进一步把簇推开。
- perplexity：可理解为每个点考虑的"有效邻居数"。太小（如 5）只看极局部结构，容易出现很多碎小的簇；太大（如 100）更关注全局，簇可能被合并或变模糊。常用 5–50，应多试几个值并对比（讲义练习 2）。
- 工程建议：先用 PCA 降到约 50 维再做 t-SNE/UMAP（代码 `demo_tsne` 就是这样做的），既去噪又加速。
- 常见误区：用 t-SNE 输出作为分类特征；根据 t-SNE 图里两个簇离得近就断定它们语义相近。

### Q15 — 参考回答要点

- 方案：
  1. 从库中采样（如 100 万条）拟合 PCA，查看累计解释方差曲线，候选 k = 256 / 384 / 512。
  2. 对全部向量做 `(x - μ)Wₖᵀ`，**降维后重新 L2 归一化**，再建 ANN 索引；查询向量用同样的 μ、W 变换。
  3. PCA 是线性正交投影，降维后点积 / 余弦是原相似度在子空间上的近似。
- 评估：不要只看解释方差，要看**检索指标**——在标注集上比较 Recall@k、nDCG、MRR，以及与全维结果的 top-k 重合率；同时测延迟与内存。
- 其他选择与对比：
  - **Matryoshka 表示**：如果 embedding 模型本身按 Matryoshka 方式训练（课程 阶段 11 · 04 提到 OpenAI text-embedding-3 支持 `dimensions` 参数），直接截断前 N 维即可，通常比事后 PCA 更好。
  - **量化**：标量量化（float32 → int8）、乘积量化（PQ）、二值量化，与降维可以叠加使用。
  - **换更小的 embedding 模型**。
- 风险：embedding 分布漂移后 PCA 需要重新拟合，所有向量都得重算；长尾、少数类查询可能恰好依赖低方差方向，降维后召回下降最明显，要做分桶评估。
- 加分点：PCA 白化（除以 √λ）有时能改善各向异性 embedding 的检索效果，但会放大噪声方向，需要实验验证。

### Q16 — 参考回答要点

- 定义（讲义三点）：距离失去区分度、体积集中在角落（边界）、所需数据随维度指数增长。
- 为什么最近邻失效：对 d 维独立同分布的随机点，`‖x-y‖²` 是 d 个独立项之和，其均值随 d 线性增长，标准差只按 `√d` 增长，相对波动 `∝ 1/√d → 0`。于是"最近"和"最远"的距离之比趋近 1（讲义表格中 1000 维时约 1.02），kNN 的"近"失去意义。
- 为什么 embedding 检索依然有效：
  - 真实数据不是均匀撒在高维空间里，而是集中在**低维流形**上（讲义："The actual information lives on a much smaller surface"），**内在维度**远低于名义维度；
  - embedding 经过训练，语义相关的样本被刻意拉近、无关样本被推远，距离分布并非随机点那样集中；
  - 检索只需要**排序**正确，不需要距离的绝对值有意义。
- 工程启示：特征选择 / 降维、正则化、增加数据；ANN 索引（HNSW、IVF）在高维仍需要调参，召回率要实测。

### Q17 — 参考回答要点

- 为什么中心化：PCA 要求数据在特征空间中均值为 0，但我们无法显式计算 φ(x) 来减去均值，只能在核矩阵上等价地操作。
- 公式：`K_c = K - 1ₙK - K1ₙ + 1ₙK1ₙ`，其中 `1ₙ` 是所有元素为 `1/n` 的 n×n 矩阵，对应代码 `K - one_n @ K - K @ one_n + one_n @ K @ one_n`。它等价于 `(φ(xᵢ) - φ̄)·(φ(xⱼ) - φ̄)`。
- 瓶颈：
  1. **内存** O(n²)：10 万样本的 float64 核矩阵约 80 GB；
  2. **计算** 完整特征分解 O(n³)；
  3. **新样本**需要和全部训练样本计算核值；
  4. **不可直接重构**（pre-image 问题），解释性差；
  5. **超参数**（核类型、gamma）敏感。
- 缓解：Nyström 近似（用 m ≪ n 个地标点近似核矩阵）、随机傅里叶特征（Random Fourier Features）近似 RBF 核后再做线性 PCA、只求前 k 个特征向量的迭代算法（如 Lanczos / ARPACK）、对样本做子采样；gamma 通过下游任务交叉验证选取。
- 加分点：说明它与 SVM 核技巧同源（课程阶段 02 · 05）；指出本节 `kernel_pca` 返回的是训练集投影 `√λ·v`，要支持新样本需保存 `α = v/√λ` 和训练集，并对新样本的核向量做同样的中心化。
