## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | `Ax = b` 的两种读法 | 行视角：每个方程是一个超平面，解是交点；列视角：找 A 各列的线性组合凑出 b。b 不在列空间里就没有精确解 |
| 2 | 高斯消元 + 部分主元 | 消成上三角再回代，O(n³)；每列选绝对值最大的元素当主元，避免除以小数放大舍入误差 |
| 3 | LU 分解（`PA = LU`） | L 存消元乘子、U 是消元结果、P 记录行交换；分解一次 O(n³)，之后每个新 b 只要前代 + 回代 O(n²) |
| 4 | Cholesky 分解 | 对称正定矩阵 `A = LLᵀ`，约为 LU 一半的计算量和存储；`log det A = 2·Σ log Lᵢᵢ` |
| 5 | QR 分解 | `A = QR`，`QᵀQ = I`，解 `Rx = Qᵀb`；不形成 `AᵀA`，最小二乘更稳定 |
| 6 | 最小二乘与正规方程 | 超定方程组最小化 `‖Ax − b‖²`，梯度置零得 `AᵀAx = Aᵀb`——这就是线性回归的闭式解 |
| 7 | 岭回归 | `(XᵀX + λI)w = Xᵀy`；λ > 0 时矩阵一定对称正定，可用 Cholesky，同时改善条件数、收缩权重 |
| 8 | 伪逆（Moore–Penrose） | `A⁺ = VΣ⁺Uᵀ`（SVD）；唯一解时给出该解，无解时给出最小二乘解，无穷多解时给出范数最小的解 |
| 9 | 条件数 | `κ(A) = σ_max / σ_min`；大约会丢掉 `log₁₀ κ` 位有效数字；`κ(XᵀX) = κ(X)²` |
| 10 | 共轭梯度（CG） | 对称正定大型稀疏系统的迭代解法，精确算术下至多 n 步；收敛速度取决于条件数 |

### 核心技能（能动手做到）

- [ ] 实现 Cholesky 分解，与 `np.linalg.cholesky` 对比，并用对角线计算 log det
- [ ] 用正规方程、Cholesky、`np.linalg.lstsq`、sklearn 四种方式拟合同一个线性回归，确认权重一致
- [ ] 构造近共线特征，计算 `κ(X)` 与 `κ(XᵀX)`，再用 `λI` 正则把条件数降下来
- [ ] 实现共轭梯度，观察条件数与迭代次数的关系，并能解释为什么浮点下可能超过 n 步
- [ ] 给定场景（一次求解 / 多次求解 / 对称正定 / 超定 / 秩亏 / 超大稀疏）能选出合适的求解器

**Q10.** 运行 `demo_conjugate_gradient()` 得到：

```text

CG iterations: 50 (max possible: 50)
Max diff from direct solve: 7.01e-03
Residual norm: 4.40e-02
Condition number: 898.69
```

讲义说 CG"至多 n 步得到精确解"，为什么这里 50 步后残差还有 4.4e-2？请修改下面的 `conjugate_gradient`，让它 (a) 默认迭代上限更合理，(b) 返回是否收敛的标志，(c) 当 `b` 为零向量时不会产生 `nan`。

```python
def conjugate_gradient(A, b, tol=1e-10, max_iter=None):
    n = len(b)
    if max_iter is None:
        max_iter = n

    x = np.zeros(n)
    r = b.astype(float) - A @ x
    p = r.copy()
    rs_old = r @ r

    for k in range(max_iter):
        Ap = A @ p
        alpha = rs_old / (p @ Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rs_new = r @ r
        if np.sqrt(rs_new) < tol:
            return x, k + 1
        beta = rs_new / rs_old
        p = r + beta * p
        rs_old = rs_new

    return x, max_iter
```

## 五、参考答案与解析

### Q1 — 答案：B

列视角下 `Ax = x₁a₁ + x₂a₂ + … + xₙaₙ`，即"用 A 的列能否线性组合出 b"。能组合出来（b 在列空间里）就有解，否则没有精确解，只能找列空间中离 b 最近的点——这正是最小二乘。A 错：行数少于列数（欠定）通常是解太多而不是无解；C、D 都与是否有解没有直接关系。

### Q2 — 答案：C

若主元为 0 会直接除零；若主元很小，乘子 `m = A[i][k] / A[k][k]` 会很大，把上一行的舍入误差放大后叠加到下面各行。部分主元每次把该列绝对值最大的元素换到主元位置，保证 `|m| ≤ 1`。它不改变 O(n³) 复杂度（A 错），也不省略回代（B 错）。

### Q3 — 答案：C

LU 分解一次约 `(2/3)n³` 次运算，之后每个 b 只要两次三角求解，各 O(n²)。A 每次都付 O(n³)，浪费；B 显式求逆计算量更大（约 2n³），而且数值精度不如三角求解，工程上原则是"不显式求逆"；D 对一般矩阵不适用（CG 要求对称正定），且每个 b 都要重新迭代。

### Q4 — 答案：B

Cholesky 要求**对称正定**。B 对称，特征值为 `(9 ± √17)/2 ≈ 6.56, 2.44`，都大于 0，正定，且讲义给出了分解 `[[2,0],[1,2]]`。A 对称但特征值为 3 和 −1，不正定（算到第二个对角元时 `s = 1 − 4 = −3 < 0`）；C 特征值 ±1，第一个对角元就是 0；D 不对称。

注意一个陷阱：本节的 `cholesky()` 只读取下三角，不检查对称性。把 D 传进去不会报错，但得到的 L 满足 `LLᵀ = [[2,1],[1,4]] ≠ A`，结果是错的。

### Q5 — 答案：B

经验法则：大约丢失 `log₁₀ κ` 位有效数字。float64 约 15–16 位，κ = 10⁸ 丢 8 位，剩约 7–8 位。D 把"丢掉的位数"和"剩下的位数"搞反了；C 是 κ 接近 10¹⁶ 时的情况。

### Q6 — 答案：C

若 `X = UΣVᵀ`，则 `XᵀX = VΣ²Vᵀ`，奇异值全部平方，`κ(XᵀX) = (σ_max/σ_min)² = κ(X)² = 10¹²`。这意味着在 float64 下只剩约 4 位可信——这是 QR / SVD 优于正规方程的根本原因。代码中随机 100×5 矩阵的输出 `kappa(X)=1.38`、`kappa(X^T X)=1.90`（≈1.38²）正好验证了这一点。

### Q7 — 答案：B

伪逆给出**最小范数最小二乘解**：先在所有使 `‖Ax − b‖` 最小的 x 中，再挑 `‖x‖` 最小的那个。它通过 SVD 定义，对任何矩阵都存在，所以 D 错。

### Q8 — 答案：B

对称半正定矩阵加 `λI`，所有特征值整体平移 λ：`κ = (100 + 1)/(0.001 + 1) ≈ 100.9`。原来的条件数是 100/0.001 = 10⁵，正则化把它降了三个数量级。小特征值被"托底"是改善的关键：λ 对大特征值几乎无影响，对接近 0 的特征值影响巨大。

### Q9 — 参考答案

(1) **两者都对**，区别在于是否选主元。讲义的手算例子没有做行交换；代码实现了部分主元：第 0 列绝对值最大的是 4（第 2 行），所以先把 `[4, 3, 3]` 换到第一行；第二步剩余子矩阵第 1 列中 1.5 比 −0.5 大，又交换一次。最终得到的是 `PA = LU` 而不是 `A = LU`，可以验证 `P @ A = [[4,3,3],[2,3,1],[2,1,1]]`。L 中所有乘子满足 `|Lᵢⱼ| ≤ 1`，这正是部分主元带来的稳定性。两种分解解出来都是 `x = [2, 2, 2]`。

(2) L 的第 `0..k−1` 列存的是**之前各步已经算好的乘子**，它们"属于"具体的行，行被交换了，乘子也必须跟着换。第 `k` 列及以后还没填（只有对角线上的 1），如果整行交换，会把对角线的 1 换走，L 就不再是单位下三角矩阵了。

(3) P 是置换矩阵，属于正交矩阵，`P⁻¹ = Pᵀ`。由 `PA = LU` 两边左乘 `Pᵀ` 得 `A = PᵀLU`。代码打印的 "PA = LU reconstruction error" 实际检查的是 `A − PᵀLU`，两者等价。

### Q10 — 参考答案

**原因**："至多 n 步"只在**精确算术**下成立。浮点运算中，CG 生成的搜索方向会逐渐失去彼此的 A-共轭性（以及残差之间的正交性），有效地"忘记"已经搜索过的方向，于是需要更多迭代。该矩阵 `κ ≈ 899`，CG 的经验迭代量级约为 `O(√κ · log(1/ε))`，在 1e-10 的容差下超过 50 很正常。实测把上限改为 100 后，第 69 步收敛，残差约 1.9e-11。原代码的问题在于：到达上限时只返回 `(x, max_iter)`，调用方无法分辨"恰好第 n 步收敛"和"根本没收敛"。另外 `b = 0` 时 `rs_old = 0`、`p @ Ap = 0`，`alpha = 0/0` 得到 `nan`。

```python
import numpy as np

def conjugate_gradient(A, b, tol=1e-10, max_iter=None):
    n = len(b)
    if max_iter is None:
        max_iter = 10 * n                 # 给浮点误差留余量

    x = np.zeros(n)
    r = b.astype(float) - A @ x
    p = r.copy()
    rs_old = r @ r
    if np.sqrt(rs_old) < tol:             # 初始残差已足够小（含 b = 0）
        return x, 0, True

    for k in range(max_iter):
        Ap = A @ p
        alpha = rs_old / (p @ Ap)
        x = x + alpha * p
        r = r - alpha * Ap
        rs_new = r @ r
        if np.sqrt(rs_new) < tol:
            return x, k + 1, True
        p = r + (rs_new / rs_old) * p
        rs_old = rs_new

    return x, max_iter, False             # 明确告诉调用方：没收敛
```

在同一个 50 维系统上，新版本返回 `(x, 69, True)`；`b = 0` 时返回 `(0 向量, 0, True)`。工程中还常用**相对**容差 `‖r‖ < tol · ‖b‖`，避免 b 的量级影响停止判据。

### Q11 — 参考答案

```python
import numpy as np

def qr_least_squares(A, b):
    Q, R = np.linalg.qr(A)          # 精简 QR：Q 为 m×n，R 为 n×n 上三角
    c = Q.T @ b
    n = R.shape[1]
    x = np.zeros(n)
    for i in range(n - 1, -1, -1):  # 回代，与 gaussian_elimination 的回代一样
        x[i] = (c[i] - R[i, i + 1:] @ x[i + 1:]) / R[i, i]
    return x

A = np.array([[1, 1], [1, 2], [1, 3], [1, 4]], dtype=float)
b = np.array([3, 5, 6, 8], dtype=float)
print(qr_least_squares(A, b))       # [1.5 1.6]
```

输出 `[1.5 1.6]`，与 `least_squares_normal(A, b)`、`np.linalg.lstsq` 一致。**讲义写的 `x = [1.5, 1.7]` 是笔误**：代入正规方程 `4·1.5 + 10·1.6 = 22`、`10·1.5 + 30·1.6 = 63` 恰好成立，而 1.7 不满足。

为什么 QR 更稳：`Ax ≈ b` 两边左乘 `Qᵀ` 得 `Rx = Qᵀb`，`R` 的条件数等于 `κ(A)`，没有形成 `AᵀA`，因此不会把条件数平方。代价是 O(mn²)，比 Cholesky 解正规方程略贵。

### Q12 — 参考答案

(1) 返回 `inf`，但 `1e-20 · I` 的真实条件数是 **1**（`np.linalg.cond` 也给出 1.0）。问题在于 `1e-15` 是**绝对**阈值，而条件数是尺度无关的量：把矩阵整体缩放不改变 κ，却会让最小奇异值跨过绝对阈值。改法：用相对阈值，例如 `if S[-1] <= S[0] * np.finfo(float).eps * max(A.shape): return float("inf")`，或者直接用 `np.linalg.cond(A)`。

(2) `det(0.1·I₁₀₀₀) = 0.1¹⁰⁰⁰ = 10⁻¹⁰⁰⁰`，远小于 float64 能表示的最小正数，`np.linalg.det` 直接**下溢为 0.0**，取对数得 `-inf`。而 Cholesky 方式是先对每个对角元取对数再求和：`2 · 1000 · log(√0.1) ≈ −2302.585`，完全正常。高斯过程的边际似然需要 `log det K`，K 动辄上千维，必须用对数域累加（或 `np.linalg.slogdet`），而 Cholesky 分解本来就要做（用来解 `Kα = y`），对角线是"顺手"拿到的。

### Q13 — 参考回答要点

- **推导**：`L(w) = ‖Xw − y‖² = wᵀXᵀXw − 2wᵀXᵀy + yᵀy`，`∇L = 2XᵀXw − 2Xᵀy = 0` ⇒ `XᵀXw = Xᵀy`；XᵀX 可逆时 `w = (XᵀX)⁻¹Xᵀy`。
- **不显式求逆**：①求逆比解方程更贵（约 2n³ vs 分解 + 两次三角求解）；②精度更差；③正规方程本身已把条件数平方，再求逆雪上加霜。应该用 `solve` / `lstsq`。
- **怎么选**：
  - 特征数 n 小、条件良好：形成 `XᵀX` 后 Cholesky（最快，本节 `demo_linear_regression_full` 就这么做）；
  - 要求数值稳定：对 X 做 QR，解 `Rw = Qᵀy`；
  - 可能秩亏 / 严重病态：SVD（伪逆），可截断小奇异值，得到最小范数解；
  - 样本和特征都极大：SGD、CG 等迭代法，不形成稠密矩阵。
- **加分点**：知道 sklearn 的 `LinearRegression` 走的是基于 SVD 的最小二乘求解（`scipy.linalg.lstsq`），而不是显式求逆；`Ridge` 有 `cholesky`、`svd`、`sparse_cg` 等多种 solver 可选。
- **常见误区**：认为"闭式解一定比梯度下降好"——当 n 达到数万以上时，O(n³) 的分解和 O(n²) 的存储都不可接受。

### Q14 — 参考回答要点

- **定义**：`κ(A) = ‖A‖·‖A⁻¹‖`，在 2-范数下等于 `σ_max/σ_min`，衡量输入的相对扰动被放大到输出的倍数；经验上丢失约 `log₁₀ κ` 位有效数字。
- **为什么平方**：`X = UΣVᵀ` ⇒ `XᵀX = VΣ²Vᵀ`，奇异值平方，故 `κ(XᵀX) = κ(X)²`。本节代码中近共线特征的输出 `kappa(X) = 2.03e+08`、`kappa(X^T X) = 6.86e+15`——后者已逼近 float64 的极限（理论值 ≈ 4e16，算出来的值本身已被舍入误差"截断"）。
- **诊断**：系数不稳定、符号与业务直觉相反、换一小批数据系数大变 → 怀疑多重共线性。计算 `κ(X)`（建议先标准化特征），看奇异值谱；或算 VIF、特征相关矩阵。
- **处理**：删除 / 合并冗余特征；岭回归（本节演示 λ = 0.01 就把 κ 从 ~10¹⁵ 降到约 1.7×10⁴）；PCA / 截断 SVD 降维；改用 QR / SVD 求解器。
- **常见误区**：以为"预测准就行，不用管条件数"。病态时预测值可能仍然不错（预测落在列空间内），但**系数本身没有可解释性**，做特征重要性分析会被误导。

### Q15 — 参考回答要点

- **一定有解**：对任意 v ≠ 0，`vᵀ(XᵀX + λI)v = ‖Xv‖² + λ‖v‖² > 0`（λ > 0），所以矩阵对称正定、必然可逆，并且可以用 Cholesky——本节 `ridge_regression` 正是 `cholesky` + `cholesky_solve`。
- **数值角度**：特征值整体加 λ，条件数从 `μ_max/μ_min` 变成 `(μ_max + λ)/(μ_min + λ)`（μ 为 XᵀX 的特征值），病态被缓解。
- **统计角度**：目标函数变为 `‖Xw − y‖² + λ‖w‖²`，把权重往 0 收缩，**用一点偏差换取方差的大幅下降**，抑制过拟合。本节输出中 λ 从 0 增到 10，`‖w‖` 从 2.284 降到 2.013，训练残差从 0.870 升到 2.489，正是这种取舍。
- **贝叶斯角度**：给权重加高斯先验 `w ~ N(0, τ²I)`、噪声为高斯时，最大后验（MAP）估计就是岭回归，`λ = σ²/τ²`。
- **工程实践**：λ 用交叉验证选；截距项通常**不**参与惩罚（本节代码把全 1 列也一起惩罚了，sklearn 对比时也用了 `fit_intercept=False` 保持一致）；特征需先标准化，否则惩罚对不同尺度的特征不公平。

### Q16 — 参考回答要点

- **为什么 Cholesky**：核矩阵 `K`（加上噪声项 `σ²I`）对称正定。GP 需要两样东西：预测均值要解 `Kα = y`；边际似然要 `log det K`。一次 Cholesky `K = LLᵀ`（约 n³/3）同时解决两件事：两次三角求解得到 α，`log det K = 2·Σ log Lᵢᵢ`。比 LU 省一半，且数值稳定，不需要选主元。
- **分解失败怎么办**：理论上正定，但浮点下最小特征值可能被舍入成负数（点很密、length-scale 很大时尤其常见）。标准做法是加 **jitter**：`K + εI`（ε 如 1e-6，逐步放大重试）；或增大噪声方差、去掉重复点；更极端时用特征分解截断负特征值。
- **加分点**：大规模 GP 的 O(n³) 不可承受，会用稀疏 / 诱导点近似，或用 CG + 随机迹估计来做矩阵求解与 log det（"用矩阵-向量乘代替分解"的思路）。
- **常见误区**：用 `np.linalg.inv(K)` 和 `np.linalg.det(K)`——前者慢且不稳，后者高维时上溢 / 下溢（见 Q12）。

### Q17 — 参考回答要点

- **为什么不用直接法**：LU / Cholesky 对稀疏矩阵会产生**填充（fill-in）**，因子可能变得稠密，内存和 O(n³) 时间都不可接受。
- **方案**：共轭梯度（对称正定）。它只需要**矩阵-向量乘** `A @ p`，可以用稀疏格式（CSR），甚至完全不显式存储 A（matrix-free，例如 Hessian-vector product 由自动微分给出）。每步代价约 O(nnz)，总代价约 `O(k · nnz)`。
- **加速收敛**：迭代次数与 `√κ` 相关，所以用**预条件**（Jacobi 对角预条件、不完全 Cholesky / 不完全 LU）把 `M⁻¹A` 的特征值聚到一起；必要时加正则（`+λI`）改善条件数。
- **工程细节**：用相对残差 `‖r‖/‖b‖` 作为停止判据；设置迭代上限并返回是否收敛（参考 Q10 的修改）；浮点下 CG 可能需要多于 n 步。非对称系统换 GMRES / BiCGSTAB。
- **和 ML 的联系**：Newton-CG / Hessian-free 优化、大规模核方法、图上的半监督学习（拉普拉斯系统）。
- **加分点**：能说出"CG 等价于在 Krylov 子空间上最小化 `½xᵀAx − bᵀx`"，因此它既是线性求解器也是一个二次优化器，衔接下一节凸优化。
