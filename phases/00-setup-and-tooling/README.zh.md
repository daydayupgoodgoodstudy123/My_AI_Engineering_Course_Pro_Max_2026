# 第 0 阶段：设置和工具

> 让您的环境为接下来的一切做好准备。

<a id="start-this-phase-on-github"></a>

## 在 GitHub 上启动此阶段

**先决条件：** 无。您需要 Git 和 Python 3.11 或更高版本才能开始。其他
仅当您的路线需要时才会安装工具。

**第一课：** [开发环境](01-dev-environment/docs/zh.md)

从存储库根目录运行路由感知预检：

```bash
python3 phases/00-setup-and-tooling/01-dev-environment/code/verify.py --route beginner
```

保留命令、存储库根工作目录、退出代码、所需检查
结果，以及打印的 `Next:` 命令。选择性的失误并不是失败。

**下一步操作：** 修复每个必需的故障，重新运行直到命令退出0，
然后继续[Git和协作](02-git-and-collaboration/docs/zh.md)。

浏览 [ 完整第 0 阶段课程列表](../../README.md#phase-0) 或
[跨阶段路线图](../../ROADMAP.md)。
