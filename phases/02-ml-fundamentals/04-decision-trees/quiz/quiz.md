## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 决策树的本质 | 用一串"特征 ≤ 阈值？"的问题把特征空间递归切成轴对齐的矩形区域，每个叶子给一个常数预测 |
| 2 | Gini 与熵 | `Gini = 1 − Σpₖ²`，`熵 = −Σpₖ·log₂pₖ`；纯节点都为 0；k 类均匀时分别取最大值 `1 − 1/k` 与 `log₂k` |
| 3 | 信息增益 | `IG = 父节点不纯度 − 按样本数加权的子节点不纯度`；每个节点贪心地选 IG 最大的（特征, 阈值） |
| 4 | 贪心分裂 | 阈值取相邻不同取值的中点；全局最优树是 NP-hard 问题，贪心不保证最优但实践中效果好 |
| 5 | 剪枝 | 预剪枝：max_depth、min_samples_split/leaf、最小增益；后剪枝：代价复杂度剪枝（sklearn 的 `ccp_alpha`） |
| 6 | 回归树 | 分裂准则换成方差减小，叶子取均值，得到分段常数函数，无法外推 |
| 7 | Bagging | 有放回抽样 n 次，每棵树约见到 63.2%（`1 − 1/e`）的不同样本，其余为袋外（OOB）样本 |
| 8 | 特征随机化 | 每次分裂只看随机的一部分特征（分类常用 `√d`、回归常用 `d/3`），降低树与树之间的相关性 |
| 9 | 随机森林为何有效 | 平均 B 个相关系数为 ρ 的模型，方差为 `ρσ² + (1−ρ)σ²/B`：树越多、越不相关，方差越小，偏差基本不变 |
| 10 | 特征重要性 | MDI（不纯度下降之和）训练时顺带得到，但偏向高基数/连续特征；置换重要性更可靠但更慢 |

## 五、参考答案与解析

### Q1 — 答案：B

k 类均匀时每类比例 `p = 1/k`：`Gini = 1 − k·(1/k)² = 1 − 1/k`；`熵 = −k·(1/k)·log₂(1/k) = log₂k`。二分类时正好是 0.5 和 1.0（A 只对 k=2 成立）。代码的 `demo_split_criteria` 中 4 类均匀分布输出 `Gini 0.7500`、`Entropy 2.0000`，与公式一致。

### Q2 — 答案：B

父节点：`Gini = 1 − (0.4² + 0.3² + 0.3²) = 1 − 0.34 = 0.66`。左子节点全是 cat，Gini = 0；右子节点 dog、bird 各半，Gini = 0.5。加权：`0.4×0 + 0.6×0.5 = 0.30`。IG = `0.66 − 0.30 = 0.36`。A 是父节点 Gini，C 是加权子节点 Gini，D 是用**熵**算出的信息增益（代码输出 `IG(Entropy) = 0.9710`）——两种准则的数值尺度不同，不能直接比较大小，但它们对三个候选分裂的**排序**一致。

### Q3 — 答案：B

决策树只依赖每个特征上样本的**排序**：严格单调变换不改变排序，所以每个候选分裂对应的样本划分集合不变，不纯度和选择结果都相同，训练样本的划分方式不变。这是树模型"不需要特征缩放"的原因。细节：阈值取的是变换后空间里的中点，对落在两个相邻训练值之间的新样本，预测可能有细微差别。A 错：树不靠梯度下降，不存在收敛问题。

### Q4 — 答案：B

某个样本一次都没被抽到的概率是 `(1 − 1/n)ⁿ → 1/e ≈ 0.368`，所以被抽到的不同样本约占 `1 − 1/e ≈ 63.2%`（讲义："About 63%"）。约 36.8% 没被抽到的就是袋外（OOB）样本，可以直接用来估计泛化误差，无需另外留验证集。C 的 86.5% 是 `1 − e⁻²`，对应抽 2n 次的情况。

### Q5 — 答案：C

如果某个特征特别强，每棵树都会在根节点用它分裂，树与树高度相似，平均起来几乎没有收益。每次分裂只看部分特征，迫使不同的树走不同的路径，降低相关性 ρ；由 `ρσ² + (1−ρ)σ²/B` 可知，ρ 越小，平均后方差越小。代价是单棵树的偏差可能略微上升，所以 B 错。加速只是附带效果。

### Q6 — 答案：B

增加树的数量只是在用更多样本去逼近"无穷多棵树的平均"，不会增加模型复杂度，所以测试误差不会因为树多而系统性上升（讲义练习 3 的结论）。但要注意：在小测试集上，具体某次运行的准确率仍会波动——本节代码的输出中 50 棵树时测试准确率是 0.8833、100 棵时又回到 0.95，这是不同随机种子 + 60 个测试样本带来的噪声，不是"树多导致过拟合"。C 错：偏差主要由单棵树的深度等决定，加树不降偏差。

### Q7 — 答案：B

MDI 统计的是**训练过程中**各特征带来的不纯度下降。取值唯一的 ID 列有 n−1 个可切分点，深树可以用它把剩下的少量混杂样本切开，每次都在训练集上"显得"降低了不纯度，累积起来重要性就不低。这些下降其实是在拟合噪声，对新数据毫无用处。讲义："biased toward high-cardinality features and features with many possible split points"。解决：用留出数据上的置换重要性（见 Q12），或限制树深/最小叶子样本数。

### Q8 — 答案：B

树把输入空间切成区间，每个叶子输出训练样本的均值。x = 10 会落到"x 大于最后一个阈值"的那个最右侧叶子，预测就是那里训练样本的均值；随机森林是若干个这样的常数的平均，仍是常数。树模型**不能外推**——这与线性回归形成鲜明对比，在时间序列预测等存在趋势的场景尤其要注意。

### Q9 — 参考答案

(a)
- `[0.5, 0.5]`：`x0 ≤ −1.1527`？否 → `x1 ≤ −1.7344`？否 → `x0 ≤ 1.4495`？是 → **0**。
- `[-2, 3]`：`x0 ≤ −1.1527`？是 → `x1 ≤ 2.5769`？否 → `x1 ≤ 2.6542`？否 → **2**。
- `[2, -2]`：`x0 ≤ −1.1527`？否 → `x1 ≤ −1.7344`？是 → `x0 ≤ 2.7600`？是 → **2**。

（实际调用 `tree.predict([[0.5,0.5],[-2,3],[2,-2]])` 得到 `[0, 2, 2]`。对照数据生成规则：`[0.5,0.5]` 满足 `x1² + x2² < 3` → 类 0；另两个点 `x1 + x2` 都不大于 1 → 类 2，与树一致。）

(b) 不是 bug。
- 父节点 `{0:3, 2:42}`，n=45：`Gini = 1 − (3/45)² − (42/45)² ≈ 0.1244`。
- 左 `{2:29}`：Gini = 0。右 `{0:3, 2:13}`，n=16：`Gini = 1 − (3/16)² − (13/16)² ≈ 0.3047`。
- 加权子 Gini：`(16/45) × 0.3047 ≈ 0.1083`；增益 `≈ 0.1244 − 0.1083 = 0.0161 > 0`。

分裂准则优化的是**不纯度**而不是"多数类是否改变"：这次分裂把 29 个样本分进了一个纯节点，不纯度确实下降了，只是两边多数类都还是 2，所以**对预测结果没有任何影响**。代码只在 `best_gain <= 0` 时停止，因此会接受这种分裂。去掉的方法：设置最小增益阈值（如 sklearn 的 `min_impurity_decrease`）；建树后做后处理，把两个叶子预测相同的节点合并；或用代价复杂度后剪枝（`ccp_alpha`），这类"增益很小却多一片叶子"的子树会最先被剪掉。

### Q10 — 参考答案

**问题：数据泄漏。** 代码先对全量数据做 bootstrap（有放回抽样），得到的 `X_sub` 里大量样本是重复的；之后再把 `X_sub` 切成训练集和测试集，同一个原始样本的副本很容易同时出现在两边。实测 5 次试验中，40 个测试点里分别有 27、23、18、25、24 个与训练集中的某个点**完全相同**。测试集相当于有一半以上是"做过的原题"，准确率自然虚高（0.94/0.965 vs. 干净切分下的约 0.85）。

**第二个问题：结论没有被数据支持。** 两者标准差都是 0.0200，打印出的"Forests are more stable (lower variance)"并不能从这 5 次结果中得出；5 次试验、每次 40 个测试样本，本身也太少，噪声很大。

**修改方案：**

```python
X, y = generate_classification_data(200, seed=42)
X_train, y_train, X_test, y_test = train_test_split(X, y)   # 先切分，测试集固定不动

single_accs, forest_accs = [], []
for trial in range(20):
    random.seed(trial * 10)
    idx = [random.randint(0, len(X_train) - 1) for _ in range(len(X_train))]
    X_tr = [X_train[i] for i in idx]       # 只在训练集内部做扰动
    y_tr = [y_train[i] for i in idx]
    tree = DecisionTree(max_depth=5); tree.fit(X_tr, y_tr)
    single_accs.append(accuracy(y_test, tree.predict(X_test)))
    rf = RandomForest(n_trees=30, max_depth=5); rf.fit(X_tr, y_tr)
    forest_accs.append(accuracy(y_test, rf.predict(X_test)))
```

要点：先切分、只在训练集内部扰动；测试集固定且与训练集无交集；增加试验次数。更直接衡量"稳定性"的方法是比较不同扰动下模型对同一批测试点**预测结果的一致程度**，而不仅是准确率的标准差。

### Q11 — 参考答案

(a) 每个特征有约 m−1 个候选阈值，每个阈值都要用两个列表推导**扫描全部 m 个样本**，再计算不纯度（O(m)）。所以单个特征 O(m²)，一次分裂 O(d·m²)。整棵树每一层的节点合起来覆盖 m 个样本，深度为 D 时总代价约 O(D·d·m²) 量级。这就是本节脚本要跑好几秒的主要原因。

(b)

```python
def best_threshold_fast(X, y, feature_idx):
    n = len(y)
    pairs = sorted((X[i][feature_idx], y[i]) for i in range(n))   # O(m log m)
    total = {}
    for _, label in pairs:
        total[label] = total.get(label, 0) + 1
    parent = 1.0 - sum((c / n) ** 2 for c in total.values())

    left = {}
    best_gain, best_thr = -1.0, None
    for i in range(n - 1):                      # 线性扫描
        v, label = pairs[i]
        left[label] = left.get(label, 0) + 1    # 第 i 个样本移到左边
        nxt = pairs[i + 1][0]
        if v == nxt:                            # 相同取值不能从中间切开
            continue
        n_l, n_r = i + 1, n - i - 1
        g_l = 1.0 - sum((c / n_l) ** 2 for c in left.values())
        g_r = 1.0 - sum(((total[k] - left.get(k, 0)) / n_r) ** 2 for k in total)
        gain = parent - (n_l / n) * g_l - (n_r / n) * g_r
        if gain > best_gain:
            best_gain, best_thr = gain, (v + nxt) / 2.0
    return best_gain, best_thr
```

关键思路：排序后，阈值从左往右移动时每次只有一个样本从右边移到左边，维护两侧的类别计数即可 O(k) 算出新的 Gini（k 为类别数），无需重扫。验证：在 `demo_decision_tree` 的训练集上，对两个特征分别调用并取增益最大者，得到 `(0.11956, -1.1527, 特征 0)`，与原 `_best_split` 返回的 `(0, -1.1527, 0.11956)` 完全一致，而耗时约从 12ms 降到 0.5ms。sklearn、XGBoost 等实现都基于这一思路（LightGBM 进一步用直方图分桶）。

### Q12 — 参考答案

```python
def permutation_importance(model, X, y, n_repeats=5, seed=0):
    rng = random.Random(seed)              # 独立的随机数生成器，不影响全局 random
    base = accuracy(y, model.predict(X))
    n_features = len(X[0])
    importances = []
    for j in range(n_features):
        drops = []
        for _ in range(n_repeats):
            col = [row[j] for row in X]
            rng.shuffle(col)
            # 构造新行，不修改原始 X
            X_perm = [row[:j] + [v] + row[j + 1:] for row, v in zip(X, col)]
            drops.append(base - accuracy(y, model.predict(X_perm)))
        importances.append(sum(drops) / n_repeats)
    return importances
```

在类似 `demo_feature_importance` 的数据上（两个有效特征 + 两个高斯噪声，300 训练 / 100 留出，30 棵不限深度的树）实测：MDI 约为 `[0.418, 0.497, 0.049, 0.036]`，噪声特征仍分到 4%–5%；留出集上的置换重要性约为 `[0.33, 0.31, 0.0, 0.0]`，噪声特征精确为 0。

为什么用留出数据：置换重要性回答的是"这个特征对**泛化**有多大贡献"。在训练集上，模型可能已经记住了噪声特征与标签的偶然关联，打乱它也会掉分，从而重新引入 MDI 的偏差。另外两点：每个特征重复多次取平均，以降低打乱带来的随机性；高度相关的两个特征会互相"替补"，打乱其中一个时掉分不明显，导致两者重要性都被低估。

### Q13 — 参考回答要点

- **流程**：对当前节点的样本，遍历每个候选特征的每个候选阈值（相邻不同取值的中点），计算分裂后子节点的加权不纯度，选**不纯度下降最大**的（特征, 阈值）；然后对左右子节点递归，直到触发停止条件。这是贪心算法，全局最优树是 NP-hard。
- **Gini vs 熵**：
  - Gini `1 − Σp²`：随机抽一个样本、按节点类别分布随机打标签时的误分概率；不需要算对数，稍快。
  - 熵 `−Σp·log₂p`：信息论中的不确定性；对类别分布的变化稍敏感一些。
  - 两者曲线形状非常接近，实践中得到的树几乎一样（本节代码中准确率差异只有 1–2 个测试样本）。
- **为什么不用错误率**：错误率 `1 − max p` 是分段线性的，不够"敏感"——很多能让节点变得更纯的分裂并不改变子节点的多数类，错误率下降为 0，这些分裂就会被拒绝，可能错过后续很好的分裂。Gini 和熵是严格凹函数，任何让子节点类别分布与父节点不同的分裂都会带来正的增益（Q9(b) 就是一例）。错误率更适合用于剪枝阶段的评估。
- **加分点**：知道 ID3（信息增益）、C4.5（信息增益比，修正对多取值特征的偏好）、CART（Gini，二叉树，也支持回归）三种经典算法的区别。

### Q14 — 参考回答要点

- **方差公式**：B 个同分布、方差为 σ²、两两相关系数为 ρ 的预测器取平均，方差为 `ρσ² + (1−ρ)σ²/B`。B 增大时第二项趋于 0，剩下 `ρσ²`；所以既要多棵树，也要降低 ρ——这就是 bootstrap + 特征随机化的作用。
- **偏差**：平均后的期望等于单棵树的期望，偏差不变。所以随机森林通常用**深而低偏差、高方差**的树作基学习器，让平均去消除方差。特征随机化可能使单棵树偏差略升，但换来更大的方差下降。
- **Bagging vs Boosting**：
  - Bagging（随机森林）：并行训练，每个模型独立、看 bootstrap 样本，目标是**降方差**；对超参数不敏感，难以过拟合。
  - Boosting（AdaBoost、GBDT）：串行训练，每个新模型拟合前面模型的残差/负梯度（或重新加权的样本），目标是**降偏差**；基学习器常是浅树；精度通常更高，但树太多、学习率太大时会过拟合，需要调参和早停。
- **加分点**：提到 OOB 误差可以免费估计泛化性能；随机森林在 B 很大时 OOB 误差近似于留一交叉验证。

### Q15 — 参考回答要点

- **单棵树防过拟合**：
  - 预剪枝：`max_depth`、`min_samples_split`、`min_samples_leaf`、`min_impurity_decrease`、`max_leaf_nodes`；
  - 后剪枝：代价复杂度剪枝，最小化 `误差 + α·叶子数`，用交叉验证选 α（sklearn 的 `ccp_alpha`）；也可以做 reduced error pruning（验证误差不升就剪）。
  - 讲义：后剪枝通常效果更好，因为预剪枝可能过早停掉"当前收益小但后续有大收益"的分裂。
- **随机森林调参重点**：
  - `max_features`：最重要，控制树间相关性（分类常从 `sqrt` 开始，回归常用 `1/3` 或更大）；
  - `n_estimators`：越多越稳，到收益饱和即可（看 OOB 误差曲线）；
  - `min_samples_leaf` / `max_depth`：数据噪声大时适当限制，能平滑预测、提升概率质量；
  - `class_weight`：类别不平衡时；
  - `max_samples`（每棵树抽多少样本）：大数据集上可调小以加速。
- **常见误区**：在随机森林上过度调 `max_depth`——随机森林通常对深度不敏感，默认不限深度往往就不错；真正影响大的是 `max_features`。

### Q16 — 参考回答要点

- **MDI 的坑**：
  1. 偏向高基数/连续特征（可切分点多），ID 类、噪声连续特征会被高估；
  2. 基于**训练集**计算，反映的是"训练时用得多"，不是"对泛化有用"；
  3. 相关特征会**分摊**重要性：两个高度相关的特征可能各得一半，看起来都不重要。
- **置换重要性**：在留出集上打乱单列看性能下降，直接衡量对泛化的贡献；缺点是慢，且相关特征之间会互相替补导致低估，打乱还可能制造现实中不存在的特征组合。
- **更可靠的做法**：用置换重要性做主要依据；对相关特征按组打乱（group permutation）；用 SHAP（TreeSHAP）得到每个样本、每个特征的贡献，既有全局排名又能解释单个预测；用 drop-column（删掉特征重训）做最终确认。
- **重要提醒**：特征重要性描述的是**模型**依赖什么，不等于因果关系。

### Q17 — 参考回答要点

- **树模型的优势**（讲义 + 补充）：
  - 表格特征往往是异质的（单位、分布各不相同），树只看排序，不需要缩放；
  - 能自然捕捉非线性和特征交互，处理不规则、分段式的关系（神经网络倾向于学习平滑函数）；
  - 对无关特征较稳健（不选就是了）；
  - 中小数据集上不容易过拟合、调参成本低、训练快、可解释。
  - 讲义引用的 Grinsztajn et al.（2022）系统比较了表格数据上树模型与深度学习的表现。
- **神经网络的主场**：图像、文本、音频等有空间/序列结构的数据，以及需要端到端学习表示或融合多模态的场景。
- **RF vs GBDT 怎么选**：
  - 先用随机森林做**强基线**：几乎不用调参、不易过拟合、可用 OOB 评估；
  - 追求精度时上 GBDT（XGBoost/LightGBM/CatBoost）：通常更准，但需要调学习率、树数、深度、正则，并配合早停；
  - 大量类别特征 → CatBoost 或 LightGBM 的原生类别支持；数据量很大 → LightGBM（直方图 + leaf-wise 生长）；
  - 噪声很大、样本很少、需要稳健 → 随机森林。
- **加分点**：强调要看"数据量 × 特征类型 × 延迟/可解释性要求"综合决策，并用交叉验证说话。

### Q18 — 参考回答要点

- **本节实现**：只支持数值特征，分裂形式固定为 `x[feature] <= threshold`；类别特征必须先编码；遇到 `None`/NaN 会在比较时出错或得到无意义的结果。讲义说树"无需预处理即可处理混合类型"，是就**部分实现**而言的。
- **类别特征的常见做法**：
  - one-hot：简单，但高基数时树会很深、每次只能分出一个类别；
  - 有序编码 / 目标编码：把类别映射为数值后按阈值切分；目标编码要防泄漏（用交叉拟合）；
  - 原生支持：LightGBM、CatBoost 等可以直接寻找类别的最优子集划分；R 的 rpart 等 CART 实现也支持。
- **缺失值的常见做法**：
  - 预处理填充（中位数 / 众数 / 特殊值），或额外加一列"是否缺失"指示特征；
  - 分裂时学习缺失值的默认方向（XGBoost、LightGBM 的做法，较新版本的 sklearn 决策树也已支持）；
  - CART 的代理分裂（surrogate split）：用与主分裂最相似的其他特征来决定缺失样本走哪边。
- **常见误区**：对高基数类别做 one-hot 后直接喂随机森林，导致重要性被稀释、树结构臃肿。
