## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 偏差（Bias） | 在许多不同训练集上训练同一种模型，**平均预测**与真实函数的差距；模型假设太死板 → 系统性偏离 → 欠拟合 |
| 2 | 方差（Variance） | 换一批训练数据，预测会**抖动**多少；模型太灵活 → 追着噪声跑 → 过拟合 |
| 3 | 误差分解 | 平方损失下：`期望误差 = Bias² + Variance + σ²`，期望是对"训练集的随机性"取的；σ² 是数据噪声，任何模型都消不掉 |
| 4 | 复杂度 U 形曲线 | 复杂度↑：Bias² 下降、Variance 上升，总误差先降后升，谷底是最佳复杂度 |
| 5 | 正则化 = 用偏差换方差 | L2 收缩权重、L1 置零做特征选择、Dropout、Early stopping；强度越大，偏差越大、方差越小 |
| 6 | 诊断表 | 训练高 + 测试高 + 差距小 → 高偏差；训练低 + 测试高 + 差距大 → 高方差；训练降而测试升 → 正在过拟合，用 early stopping |
| 7 | 学习曲线 vs 验证曲线 | 前者固定模型、扫训练集大小，回答"加数据有没有用"；后者固定数据、扫复杂度参数，回答"换模型有没有用" |
| 8 | 更多数据只降方差 | 数据量增加，方差下降，但偏差基本不变；高偏差问题加数据无效 |
| 9 | Bagging 降方差、Boosting 降偏差 | N 个独立预测平均后方差为 σ²/N；模型相关时降幅小于 1/N。基模型高方差用 bagging，高偏差用 boosting |
| 10 | Double Descent | 容量远超插值阈值（参数量 ≈ 样本量）后测试误差会再次下降；最危险的位置恰在阈值附近 |

## 五、参考答案与解析

### Q1 — 答案：B

偏差是"平均意义上的系统性偏离"：`Bias² = (E[f̂(x)] − f(x))²`，期望取自不同的训练集。A 是训练误差，它同时受偏差、方差、噪声影响；C 是泛化差距，更接近方差的信号；D 是不可约噪声 σ²。

### Q2 — 答案：B

不可约误差 = 噪声方差 σ² = 0.5² = **0.25**。即使模型恰好等于真实函数 `f(x)`，预测新样本时仍会有 `E[(y − f(x))²] = σ²` 的误差。代码输出中 Noise 列恒为 0.2500，`n_train=500` 时总误差 0.2535 已经非常接近这个下限。D 错：复杂度再高也只能让训练误差趋于 0，测试误差不可能低于 σ²。

### Q3 — 答案：B

代码 `demo_data_size_effect()` 的实测结果：Bias² 从 0.0013（n=50）到 0.0012（n=500）几乎不变，Variance 从 0.0251 降到 0.0023。偏差来自模型族本身（5 阶多项式无法完美表示 `sin`），与数据量无关；方差来自"有限样本的随机性"，数据越多越小。

### Q4 — 答案：C

正则化是"用偏差换方差"：方差下降（A 对）、偏差上升（B 对），λ 极大时所有非截距系数被压到接近 0，模型退化为常数（D 对）。总误差是 U 形的，先降后升，所以"一定单调下降"是错的。代码 `demo_regularization_effect()` 中 10 阶多项式的总误差在 λ=1 时最低（0.8903），λ=100 时又升到 1.2438。

### Q5 — 答案：B

讲义原话：模型并不真正独立（都看到相似的数据），所以降幅小于 1/N。更精确地，若每个模型方差为 σ²、两两相关系数为 ρ，则平均后的方差为 `ρσ² + (1−ρ)σ²/N`，N 再大也降不到 ρσ² 以下。随机森林通过特征子采样降低 ρ，就是为了让第一项变小。

### Q6 — 答案：B

讲义指出：double descent 在线性模型、决策树、神经网络中都会出现（A 错）；经典理论"没错但不完整"（C 错）；正则化能平滑峰值但不能消除（D 错）。实践建议是要么远低于阈值并配合显式正则化，要么远超阈值，**最差的位置就在阈值附近**。

### Q7 — 答案：B

训练、验证误差都高且接近是高偏差。讲义的实践规则：基模型高方差（深树、高阶多项式）用 bagging；基模型高偏差（浅树桩、简单线性模型）用 boosting。Bagging 不降偏差（A 错）；Dropout 是降方差手段（C 错）；高偏差时加数据无效（D 错）。

### Q8 — 参考答案

(1) **不是实验验证，而是代数恒等式**。记某个测试点上第 b 次的预测为 `p_b`，平均预测为 `p̄`，真值为 `f`。则

```text
mean_b (p_b − f)² = mean_b (p_b − p̄ + p̄ − f)²
                  = mean_b (p_b − p̄)² + (p̄ − f)² + 2(p̄ − f)·mean_b (p_b − p̄)
                  = Variance + Bias²            （最后一项因 mean_b (p_b − p̄) = 0 而消失）
```

`np.var` 默认 `ddof=0`，正好是 `mean_b (p_b − p̄)²`，所以对每个测试点都**精确**成立；再对测试点取平均、两边同时加上 `noise_std ** 2`，`Total` 与 `B+V+N` 必然逐位相等。注意 `total_error` 里的噪声项是**直接加上去的理论值**，并没有用带噪声的标签去测。（讲义 Step 3 的代码片段里 `total_error` 没有 `+ noise_std ** 2`，并说"应当近似等于"，与源码不一致。）

(2) 真正的验证：每次训练后，用**带噪声的新标签**测误差，再与 B+V+N 对比。

```python
rs = np.random.RandomState(42)
x_test = np.linspace(-2.5, 2.5, 100)
f_test = true_function(x_test)
errs = []
for b in range(200):
    x, y = generate_data(30, seed=rs.randint(0, 100000))
    w = fit_polynomial(x, y, 5)
    y_noisy = f_test + rs.normal(0, 0.5, 100)          # 每轮重新采样测试噪声
    errs.append(np.mean((predict_polynomial(x_test, w) - y_noisy) ** 2))
print(np.mean(errs))
```

实测约 **0.3016**，与分解表中 5 阶的 B+V+N = 0.3007 非常接近，此时才是"实验与理论吻合"。

### Q9 — 参考答案

原因有两点：

1. **测试标签没有噪声**：`y_test = true_function(x_test)`，测试误差只包含 Bias² + Variance；训练标签带 σ² = 0.25 的噪声，训练误差的下限约为 σ²·(1 − p/n)。两者的"地板"不同，直接相减没有意义。5 阶模型在 n=300 时 Test MSE 只有 0.0051，就是因为它测的是"离真实函数多远"，而不是"离带噪声的观测多远"。

### Q10 — 参考答案

(1) 设计矩阵第 0 列是 `x⁰ = 1`，对应**截距**。`penalty[0, 0] = 0` 表示不惩罚截距。截距只是把整条曲线上下平移，惩罚它会让模型倾向于"均值为 0"的预测——如果 y 的均值不为 0，就会引入与模型复杂度无关的、纯粹人为的偏差。这与 sklearn 的 `Ridge`（默认 `fit_intercept=True`，截距不参与惩罚）的约定一致。

(2) 12 阶多项式有 13 个参数，只有 10 个样本，属于**欠定**问题：方程数少于未知数，有无穷多组系数可以精确穿过全部 10 个点，所以训练误差为 0（实测约 1e-21）。

- `XᵀX` 是 13×13 但秩最多为 10，理论上奇异。`np.linalg.solve` 要么抛 `LinAlgError`，要么（更常见）因为浮点误差"勉强解出"一个数值上毫无意义、系数巨大的解。
- `np.linalg.lstsq` 基于 SVD，在欠定时返回**最小范数解**（所有精确解中 `‖w‖₂` 最小的那个）。这正是讲义 double descent 一节说的"隐式正则化"的一个最简单例子：算法在众多插值解中挑了"最简单"的一个。
- 即便如此，这个插值解在 10 个点之间仍可能剧烈振荡，所以同一行的 Test MSE 达到了 4×10⁹ 量级。

### Q11 — 参考答案

**原因分析**：

1. **特征尺度相差悬殊**：x ∈ [−3, 3] 时，`x¹⁵` 可达 3¹⁵ ≈ 1.4×10⁷，而 `x` 本身不超过 3。Ridge 的惩罚 `λ‖w‖²` 对每个系数一视同仁，但高次项只需要极小的系数就能产生巨大的预测摆动，惩罚几乎管不住它们；反倒是承载主要信号的低次项被压缩。所以 alpha 增大时偏差上升了，方差却降不下来。
2. **均值被少数"灾难样本"主导**：当某次抽到的训练集在边缘附近恰好没有点（实验中 alpha=10、100 时最差的那次训练集 x 最大值只有 2.04，而测试网格延伸到 2.5），高次项在这段空白里外推失控，单次 MSE 可达数千。实测 alpha=10 时 200 次的**中位数** MSE 只有约 0.37，**最大值**约 2847。Variance 是对 200 次取平均，几个极端值就决定了整列数字，这也是方差随 alpha 不单调的原因。
3. 这**不是** `np.linalg.solve` 的精度问题：把 Ridge 改写成增广最小二乘（在 X 下方拼 `√λ·I`，再用 `lstsq` 求解），结果几乎一模一样。

**修复**：先把 x 缩放到 [−1, 1] 再拟合，最后把系数换算回原尺度（`predict_polynomial` 无需改动）。

```python
def fit_polynomial_scaled(x_train, y_train, degree, lam=0.0, scale=3.0):
    w = fit_polynomial(x_train / scale, y_train, degree, lam)
    return w / scale ** np.arange(degree + 1)     # u = x/s ⇒ w_d = v_d / s^d
```

用它替换 15 阶 Ridge 中的拟合函数后的实测：

| Alpha | Bias² | Variance | 占主导 |
|-------|-------|----------|-------|
| 0.001 | 0.0016 | 0.0733 | VARIANCE |
| 0.1 | 0.0845 | 0.0423 | BIAS |
| 10 | 0.7852 | 0.0392 | BIAS |
| 100 | 1.2531 | 0.0426 | BIAS |

偏差随 alpha 单调上升、方差稳定在很小的量级，alpha 大时偏差占主导——与理论一致。工程上的对应做法是 `make_pipeline(PolynomialFeatures(d), StandardScaler(), Ridge(alpha))`：**任何带范数惩罚的模型，都要先把特征放到同一尺度上**。

### Q12 — 参考回答要点

- **设定**：`y = f(x) + ε`，`E[ε] = 0`，`Var(ε) = σ²`，ε 与训练集独立；`f̂` 依赖于随机的训练集 D。
- **推导**（固定 x，期望对 D 和 ε 取）：

```text
E[(y − f̂)²] = E[(f + ε − f̂)²]
            = E[ε²] + E[(f − f̂)²] + 2E[ε(f − f̂)]        ← ε 与 f̂ 独立且均值 0，交叉项为 0
            = σ² + E[(f − E f̂ + E f̂ − f̂)²]
            = σ² + (f − E f̂)² + E[(f̂ − E f̂)²] + 2(f − E f̂)·E[E f̂ − f̂]   ← 最后一项期望为 0
            = σ² + Bias² + Variance
```

- **含义**：Bias² 是模型族的"表达能力不足"；Variance 是"对训练样本的敏感度"；σ² 是数据本身的随机性。
- **两个交叉项消失的原因**：一个靠噪声与模型独立且零均值，一个靠 `E[f̂ − E f̂] = 0`。
- **加分点**：这是**对训练集取期望**的结论，针对的是平方损失；对 0-1 损失不存在这样干净的加性分解（有多种推广定义）。实际中 E[f̂] 无法直接得到，只能像本节代码那样用重复采样或 bootstrap 近似。

### Q13 — 参考回答要点

- **Bagging**：对 bootstrap 样本训练多个模型再平均。平均不会改变期望预测（每个基模型的期望近似相同），所以偏差基本不变；但平均能抵消各模型的随机波动，方差下降。适合低偏差、高方差的基模型（深树）。
- **Boosting**：顺序训练，每个新模型拟合当前集成的残差 / 加权错误，逐步扩充模型的表达能力，本质是在降偏差；加太多轮会开始拟合噪声，方差上升，需要 early stopping、学习率（shrinkage）、子采样等正则化。适合高偏差的弱学习器（树桩）。
- **随机森林的特征子采样**：平均后方差为 `ρσ² + (1−ρ)σ²/N`。只做 bagging 时，强特征会让每棵树的顶部分裂几乎一样，ρ 很高；每次分裂只在随机特征子集中选，能降低树之间的相关性 ρ，进一步压低方差。
- **常见误区**：认为"bagging 也能降偏差"；认为"boosting 不会过拟合"。

### Q14 — 参考回答要点

- **现象**：随着容量增加，测试误差先呈经典 U 形，在插值阈值（参数量 ≈ 样本量，模型刚好能把训练集拟合到 0 误差）附近出现峰值，继续增大容量后测试误差再次下降，可能低于经典的最优点。讲义还提到 sample-wise（在插值区加数据反而可能变差）和 epoch-wise（训练轮数）两种形式。
- **机制**：在阈值处，能插值的解几乎唯一，模型被迫去穿过每一个带噪声的点，方差最大；远超阈值时，插值解有无穷多个，梯度下降等算法带有隐式正则化，倾向于挑"最简单"（如最小范数）的那个，因此泛化反而变好。Q10 中 `lstsq` 返回最小范数解就是一个微型例子。
- **与大模型的关系**：现代神经网络 / LLM 处在严重过参数化的区域，所以"参数比样本多"不必然意味着过拟合。
- **是否推翻**：没有。讲义原话是"经典权衡没有错，但不完整"——在欠参数化区域经典 U 形仍成立。
- **实践含义**：不要停在阈值附近；要么远低于它并加显式正则化，要么远超它。

### Q15 — 参考回答要点

- **A（99% / 80%）**：差距 19 个点，高方差。
  - 先排除评估问题：训练/验证分布是否一致、是否有泄漏或重复样本；
  - 画学习曲线：差距仍在随数据缩小 → 收集/增强数据；差距不再缩小 → 正则化（L2、Dropout、early stopping）、降低模型复杂度、特征选择、bagging 集成。
- **B（75% / 74%）**：差距很小但离目标很远，高偏差。
  - 加数据没用（学习曲线会平坦）；
  - 增加模型容量（更深/更宽、树模型换 GBDT）、增加特征或交互特征、减小正则化、确认训练已收敛（训练更久）。
- **加分点**：先估计"可达上限"——例如人工标注一致率、贝叶斯误差。如果人类也只有 80% 一致，那 90% 的目标本身不现实；A 与上限的差距才是方差，上限与 100% 的差距是不可约误差。
- **常见误区**：一看到效果不好就"加数据"；只看单次划分就下结论。

### Q16 — 参考回答要点

- **诊断**：训练 loss 趋近 0、验证 loss 在某个点后上升，是讲义诊断表中的"训练误差下降、测试误差上升 → 正在过拟合"，属于高方差：相对于 2000 条样本，可调参数和训练轮数提供的有效容量过大，模型开始记忆训练样本。
- **调整的旋钮**（都对应"用偏差换方差"）：
  1. **Early stopping**：保留验证 loss 最低的 checkpoint（第 2 个 epoch 附近），减少 epoch 数；
  2. **降低有效容量**：减小 LoRA 的秩 r、减少注入 LoRA 的模块；
  3. **正则化**：加大 weight decay、LoRA dropout；
  4. **降低学习率**或缩短训练步数；
  5. **数据侧**：扩充或增强数据、去重、检查训练集里是否有重复或模板化过强的样本。
- **注意**：验证 loss 上升不一定等于下游任务指标下降，要同时看任务指标；验证集要与真实使用场景同分布。
- **加分点**：把 LoRA 的秩、epoch 数、weight decay 都看作"验证曲线"上的复杂度参数，用小规模扫描找到谷底，而不是凭经验固定。
