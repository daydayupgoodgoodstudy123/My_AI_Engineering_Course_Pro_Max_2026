# 参考解释：Bias-Variance Tradeoff

## 核心：回归误差与形状

逐项误差平方后平均；分母是样本数，空输入不能默认为零误差。

准确合同：Return mean squared error of equal-length nonempty numeric lists. Unequal lengths or empty inputs raise ValueError.

## 加分：均值与总体方差

先求均值，再以总体样本数计算方差；不要无意换成样本方差。

准确合同：Return {'mean':arithmetic mean,'variance':population variance,'min':minimum,'max':maximum} for a nonempty numeric list. Empty input raises ValueError.
