## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 线性模型 | `ŷ = wᵀx + b`：w 是"x 每增加 1，y 变化多少"，b 是 x=0 时的预测值；多特征时拟合的是超平面 |
| 2 | MSE 损失 | `MSE = (1/n)·Σ(ŷ−y)²`：平方让大误差被重罚，且处处可导；对线性模型它是一个凸"碗" |
| 3 | 梯度 | `∂MSE/∂w = (2/n)·Σ(ŷ−y)·x`，`∂MSE/∂b = (2/n)·Σ(ŷ−y)`；本质是"误差 × 输入" |
| 4 | 梯度下降与学习率 | `w ← w − lr·∂w`；lr 太大会震荡发散，太小收敛极慢 |
| 5 | 正规方程（闭式解） | `w = (XᵀX)⁻¹Xᵀy`；一元时 `w = Σ(x−x̄)(y−ȳ)/Σ(x−x̄)²`，`b = ȳ − w·x̄`；求逆约 O(d³) |
| 6 | 特征缩放 | 特征量纲差异大 → 损失等高线被拉长（条件数大）→ GD 收敛慢；标准化不改变 OLS 的最优预测 |
| 7 | 多项式回归 | 用 `x, x², x³…` 作特征，模型对**参数**仍是线性的；阶数越高越容易过拟合 |
| 8 | R² | `R² = 1 − SS_res/SS_tot`：1 完美、0 等于只猜均值、<0 比猜均值还差 |
| 9 | Ridge（L2 正则） | `Cost = MSE + α·Σwᵢ²`，梯度多一项 `2αw`，把权重往 0 收缩但不会精确为 0；不惩罚 b |

### 核心技能（能动手做到）

- [ ] 纯 Python 从零实现梯度下降线性回归，并能**手推** `∂MSE/∂w`、`∂MSE/∂b`
- [ ] 用一元闭式解（协方差/方差）求出最优 w、b，并以此判断梯度下降**是否已经收敛**
- [ ] 实现 `standardize`，训练多元回归后把"标准化空间"的权重**换算回原始单位**，并能解释每个权重的业务含义
- [ ] 手写 `r_squared`，能解释 R² 为 0 和为负数的含义，以及噪声如何限制 R² 的上限
- [ ] 构造多项式特征，比较不同阶数在训练集与测试集上的 R²，识别过拟合
- [ ] 实现 Ridge 的梯度（`+ 2αw`），并用 NumPy 闭式解 `(XᵀX/n + αI)⁻¹Xᵀy/n` 验证结果一致

## 五、参考答案与解析

### Q1 — 答案：B

MSE 对线性模型是凸的碗形，没有局部最小值，所以 C 错。cost 单调变大直至溢出，是学习率超过稳定上限的典型表现：每一步都跨过谷底，落到对面更高的位置，误差被不断放大。对于二次损失，稳定条件是 `lr < 2/λ_max`（λ_max 是 Hessian 最大特征值）。A 只会导致"还没降到底"，不会导致发散。

### Q2 — 答案：C

`R² = 1 − SS_res/SS_tot`。SS_tot 是"永远预测均值"的误差平方和，若模型的残差平方和比它还大，R² 就是负数。在**训练集**上，带截距的最小二乘解的 R² 不会为负；但在测试集上、或模型没训练好（比如 GD 没收敛、外推到训练范围之外）时完全可能为负。讲义："R² < 0.0: the model is worse than predicting the mean"。

### Q3 — 答案：B

"线性"指的是**对参数线性**。把 `x, x², x³` 看成三个新特征，模型就是 `w₁f₁ + w₂f₂ + w₃f₃ + b`，MSE 依然是参数的凸二次函数，梯度公式、正规方程全部照用。A 错：图像是曲线；D 错：标准化与是否线性无关。

### Q4 — 答案：B

正规方程需要构造 d×d 的 `XᵀX` 并求解，内存 O(d²)、时间约 O(n·d² + d³)。d = 100 万时，`XᵀX` 有 10¹² 个元素，根本存不下，更别说求逆；而梯度下降每步只需 O(n·d)（稀疏时更少），还能流式、分批处理。A、C、D 规模很小，正规方程一步就能得到精确解，反而更合适。

### Q5 — 答案：B

标准化只是对特征做了可逆的仿射变换，无正则的 OLS 在变换前后能表达的函数集合完全相同，所以**最优预测值不变**、R² 不变（C 错），只是权重数值按尺度换算了（D 错）。它的价值在于让损失曲面更"圆"，梯度下降可以用更大的学习率、更少的步数收敛。注意：加了正则（Ridge/Lasso）之后标准化**会**改变结果，因为惩罚项对各维一视同仁。

### Q6 — 答案：C（这是错误说法）

把权重精确压到 0、实现特征选择的是 **Lasso（L1）**。Ridge 只会让权重整体变小、趋向 0 但一般不等于 0。A 正确（α→∞ 时权重→0）；B 正确（惩罚 b 会让模型无法拟合 y 的整体平移，本节代码的梯度里 `grad_b` 也没有正则项）；D 正确（惩罚 `Σw²` 对尺度敏感，量纲大的特征权重天然小，不标准化会导致惩罚不公平）。

### Q7 — 答案：B

MSE 对误差做平方：误差 10 的惩罚是误差 1 的 100 倍（讲义原话），离群点的巨大残差会主导总损失，拟合线被拽向它们。MAE 是线性惩罚，对离群点更稳健。从统计上看，MSE 估计的是条件**均值**，MAE 估计的是条件**中位数**——中位数对极端值不敏感。

### Q8 — 答案：C

把 `x = x̄` 代入：`ŷ = w·x̄ + b = w·x̄ + ȳ − w·x̄ = ȳ`。所以最小二乘直线（带截距时）必过均值点 (x̄, ȳ)。这也解释了为什么"先中心化再拟合"时截距就是 ȳ（中心化后的 x̄ = 0）。

### Q9 — 参考答案

(a) 闭式解 `3.0756x + 6.9853` 才是这份训练数据上 MSE 的**精确最小值**（用 `np.linalg.lstsq` 也得到 `[3.07563, 6.98535]`）。梯度下降结果与之有差距，是因为它**没有收敛**——这是优化误差，不是噪声造成的统计误差。两者都偏离真实的 `3.0, 7.0`，那部分才是噪声导致的。

(b) x 的取值在 0–10 之间、均值约 5，没有中心化。此时损失关于 (w, b) 的 Hessian `(2/n)·AᵀA`（A 的列是 x 和 1）特征值约为 64.7 和 0.53，条件数约 121。lr=0.005 时，"慢方向"每步只缩小 `1 − 0.005×0.53 ≈ 0.9973`，1000 步后仍残留约 7% 的误差。这个慢方向主要对应 b（以及 w、b 的此消彼长），所以 b 从 0 只走到 6.54。

(c) 任选其二：
- **中心化/标准化 x**：用 `x − x̄` 训练，Hessian 变成对角阵，w 和 b 解耦，1000 轮就能收敛到 `w = 3.0756`，再换算 `b = b' − w·x̄ ≈ 6.984`（实测）；
- **加大学习率**：稳定上限约为 `2/64.7 ≈ 0.031`，例如取 0.02 能大幅加速；
- **增加轮数**：保持 lr=0.005，约 3000 轮后得到 `w ≈ 3.0760, b ≈ 6.9832`，5000 轮基本与闭式解重合；
- 直接用闭式解，或用带动量 / Adam 的优化器。

### Q10 — 参考答案

(a) 标准化后每一列 x 的均值为 0，y_scaled 的均值也为 0。偏置的梯度：

`grad_b = (2/n)·Σᵢ(Σⱼ wⱼxᵢⱼ + b − yᵢ) = (2/n)·[Σⱼ wⱼ·(Σᵢxᵢⱼ) + n·b − Σᵢyᵢ] = 2b`

b 初始为 0，梯度就是 0，于是 b 永远停在 0（只差浮点误差）。这与 Q8 一致：中心化后截距等于 ȳ = 0。

(b)

```python
def unscale(weights, bias, x_means, x_stds, y_mean, y_std):
    # 标准化空间：(y - ym)/ys = Σ w_j * (x_j - m_j)/s_j + bias
    # 两边乘 ys 再移项，得到原始空间的系数
    orig_w = [w * y_std / s for w, s in zip(weights, x_stds)]
    orig_b = y_mean + bias * y_std - sum(ow * m for ow, m in zip(orig_w, x_means))
    return orig_w, orig_b

orig_w, orig_b = unscale(multi_model.weights, multi_model.bias,
                         x_means, x_stds, y_mean_val, y_std_val)
print([round(w, 2) for w in orig_w], round(orig_b, 2))
```

用 NumPy 最小二乘在原始数据上验证，结果约为 `[53.72, 10144.54, -1008.03]`、截距约 `46191.76`，与真实的 `50, 10000, -1000, 50000` 很接近（差异来自 σ=20000 的噪声和只有 100 个样本）。

解读：标准化权重 0.77 的意思是"面积每增加 1 个标准差（约 761 平方英尺），房价增加 0.77 个标准差"——适合比较**特征之间的相对重要性**；换算回原始单位后才是"每平方英尺约 54 元"这种业务可读的结论。

### Q11 — 参考答案

(a) 损失 `L = (1/n)·|Xw + b − y|² + α·|w|²`。由于 X、y 都已中心化，最优 b = 0，对 w 求导令其为 0：`(2/n)·Xᵀ(Xw − y) + 2αw = 0`，即：

```python
import numpy as np
Xs = np.array(X_scaled); ys = np.array(y_scaled); n = len(ys)
w = np.linalg.solve(Xs.T @ Xs / n + 0.1 * np.eye(3), Xs.T @ ys / n)
print(w)   # [0.70520052  0.26470219 -0.25578691]
```

与梯度下降的 `[0.7052, 0.2647, -0.2558]` 完全一致，说明 GD 已收敛。

(b) sklearn 的 Ridge 最小化的是 `|y − Xw|² + alpha·|w|²`（**误差平方和**，不除以 n）。把本节的损失整体乘以 n：`|Xw − y|² + n·α·|w|²`，所以 `alpha_sklearn = n × 0.1 = 100 × 0.1 = 10`。这是一个常见坑：不同实现对正则系数的缩放约定不同，直接照搬数值会得到不同的模型。

(c) 梯度少了因子 2，等价于在优化 `MSE + (α/2)·Σw²`。训练仍会收敛，但收敛到的是"正则强度减半"的解：权重收缩得更少，更接近普通最小二乘的 `[0.7716, 0.2773, -0.2739]`。同时打印出来的 `cost`（仍按 `α·Σw²` 计算）与实际被优化的目标不一致——这种"损失和梯度不匹配"的 bug 不会报错，只能靠**梯度检验**（数值差分对比解析梯度）发现。

### Q12 — 参考答案

1. **噪声限制了 R² 的上限**：x 只在 [0, 4.9] 区间，真实曲线的方差约 1.29，而噪声方差是 1（σ=1）。即便直接用真实曲线 `0.5x² − 2x + 3` 去预测，这份数据上的 R² 也只有约 0.676。R² 低不一定是模型不对，可能是数据本来就很"吵"。
2. **梯度下降没收敛**：日志里 cost 在第 1500 轮仍在下降（0.441 → 0.389）。用最小二乘直接解 2 阶模型，训练 R² 应为约 0.678，而 GD 只到 0.6408。`x, x²`（以及 5 阶时的 `x³…x⁵`）在 [0,1] 上高度相关，损失曲面非常狭长，GD 很慢。
3. **训练集 R² 随阶数单调不减**：5 阶模型包含 2 阶模型（令高次项系数为 0 即可），所以在训练集上最优 R² 一定不低于 2 阶（闭式解约 0.711 vs 0.678）。多出的部分是在拟合噪声。

结论：**不能**据此说 5 阶更好。判断要看**测试集**（或交叉验证）上的表现；训练集 R² 只会随复杂度上升，不能用于选模型。

### Q13 — 参考回答要点

- **推导**：把 b 并入 w（X 增加一列全 1），`L(w) = |Xw − y|²`。求导 `∇L = 2Xᵀ(Xw − y) = 0`，得 `XᵀXw = Xᵀy`，若 XᵀX 可逆则 `w = (XᵀX)⁻¹Xᵀy`。几何意义：`Xw` 是 y 在 X 列空间上的正交投影，残差与每一列正交。
- **选择**：
  - 正规方程：d 小（几千以内）、数据放得进内存，一步得到精确解，无需调学习率；代价约 O(n·d² + d³)。
  - 梯度下降：d 很大、数据量大、需要流式/在线更新，或损失没有闭式解（换成逻辑回归、加 L1 等）时。
- **不可逆**：原因是特征共线（秩亏）或 d > n。解决：加 L2 正则（`XᵀX + λI` 必定可逆）、删除冗余特征、用伪逆/SVD 求最小范数解。
- **工程实践**：永远不要显式 `inv(XᵀX)`，用 `np.linalg.lstsq`（基于 SVD/QR）或 `solve`，因为构造 XᵀX 会让条件数平方，数值不稳定。
- **常见误区**：说"正规方程只适合小数据"——其实 n 大但 d 小时正规方程仍然很好用（见 Q18），瓶颈在 d 而不在 n。

### Q14 — 参考回答要点

- **最大似然解释**：假设 `y = wᵀx + b + ε`，`ε ~ N(0, σ²)` 独立同分布。则 `p(y|x) ∝ exp(−(y − wᵀx − b)²/(2σ²))`，对数似然 = `−(1/(2σ²))·Σ(y − ŷ)² + 常数`。**最大化似然 ⇔ 最小化平方误差和**。所以 MSE 隐含"高斯噪声"假设。
- **其他好处**：处处可导、凸、有闭式解；估计的是条件均值。
- **何时换**：
  - 数据有较多离群点、噪声重尾 → MAE（对应拉普拉斯噪声，估计条件中位数），但在 0 点不可导；
  - Huber 损失：误差小时是平方、误差大时是线性，兼顾可导性和稳健性；
  - 业务关心的是相对误差（如销量预测）→ 对 y 取对数后再用 MSE，或用 MAPE 类指标评估。
- **加分点**：指出"损失函数 = 你对噪声分布的假设"，这一观点在逻辑回归（伯努利分布 → 交叉熵）里会再次出现。

### Q15 — 参考回答要点

- **形式**：L2（Ridge）惩罚 `α·Σwᵢ²`，L1（Lasso）惩罚 `α·Σ|wᵢ|`。
- **效果**：L2 让所有权重平滑地缩小，几乎不会为 0，适合"所有特征都有点用、且彼此相关"；L1 会把一部分权重精确压到 0，实现特征选择。
- **为什么 L1 稀疏**：
  - 几何：约束区域 `Σ|wᵢ| ≤ t` 是菱形（高维是"尖角多面体"），损失的椭圆等高线最先碰到的往往是坐标轴上的尖角，那里某些坐标为 0；L2 的约束区域是圆，切点一般不在轴上。
  - 梯度：L2 的梯度 `2αw` 随 w 变小而变小，越接近 0 推力越弱；L1 的（次）梯度恒为 `α·sign(w)`，即使 w 很小也以恒定力度推向 0。
- **贝叶斯视角**：L2 等价于给权重加**高斯先验**，L1 等价于**拉普拉斯先验**；带正则的最小二乘就是 MAP 估计。
- **工程**：两者都要求先标准化；Elastic Net 结合两者，在相关特征成组出现时比 Lasso 稳定；深度学习里的 weight decay 就是 L2。
- **常见误区**：认为 L2 也能做特征选择；或忘了偏置项不应被正则化。

### Q16 — 参考回答要点

- **经典假设**：
  1. 线性：y 与特征的关系（在给定特征变换后）是线性的；
  2. 误差独立（时间序列中常被违反——自相关）；
  3. 同方差：误差方差不随 x 变化；
  4. 误差近似正态（对系数的置信区间/显著性检验重要，对点预测不那么关键）；
  5. 特征之间没有完全共线。
- **诊断**：残差 vs 预测值散点图（出现弯曲 → 非线性；出现喇叭口 → 异方差）、残差 Q-Q 图、按时间排序看残差自相关；用 VIF 或 `XᵀX` 的条件数诊断共线性。
- **多重共线性的后果**：预测性能可能还行，但单个系数方差巨大、符号可能反直觉、换一点数据系数就剧烈变化，**系数不可解释**。
- **处理**：删除或合并冗余特征、PCA 降维、Ridge 正则；如果只关心预测、不解释系数，影响较小。
- **加分点**：异方差可用对 y 取对数、加权最小二乘；非线性可加多项式/交互特征，或换树模型。

### Q17 — 参考回答要点

不对，至少有三个问题：

- **训练集 R² 对加特征是单调不减的**：加入特征后，最小二乘总可以令新特征系数为 0 而回到原解，所以训练 R² 不会下降。哪怕加 10 列纯随机噪声，R² 也会上升一点。
- **应该看验证集/测试集 R²** 或交叉验证结果；或者用**调整 R²**（adjusted R²）：`1 − (1 − R²)·(n − 1)/(n − p − 1)`，对特征数 p 进行惩罚。
- 还要检查新特征是否存在**数据泄漏**（比如包含了目标的未来信息），否则验证集上也会虚高。
- **加分点**：指出这与 Q12 中"5 阶多项式训练 R² 更高"是同一现象；可以用 AIC/BIC 或 Lasso 来做更有原则的特征选择。

### Q18 — 参考回答要点

- **方案一：一遍扫描累积充分统计量**。d = 50 时，`XᵀX` 只有 51×51（含截距列）、`Xᵀy` 只有 51 维。分块读入数据，逐块累加 `XᵀX += X_bᵀX_b`、`Xᵀy += X_bᵀy_b`，最后在内存里解一个 51×51 的线性方程组（用 `solve`，或加一点 λI 保证稳定）。时间 O(n·d²)，内存 O(d²)，天然可以 map-reduce 并行：每台机器算局部的 `XᵀX`、`Xᵀy`，最后求和。
- **方案二：小批量 SGD**。流式读取数据，每个 batch 更新一次参数；适合需要在线更新、或之后要换成没有闭式解的损失的情况。要做特征标准化（可以先扫一遍算均值方差，或用流式统计），并配合学习率衰减。
- **注意**：标准化统计量也可以一遍扫描算出（累加 Σx、Σx²），数值上用 Welford 算法更稳；特征强相关时 XᵀX 病态，需要加 Ridge 或用 QR 类方法。
- **加分点**：能说出"瓶颈在 d 不在 n"——n 再大，只要 d 小，闭式解都很便宜；而 d 很大（如稀疏高维）时才必须用迭代法。
