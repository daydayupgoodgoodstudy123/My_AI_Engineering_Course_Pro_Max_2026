## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 最大间隔（maximum margin） | 在所有能分开两类的超平面里，选离两边最近点最远的那个；间隔宽度 = `2/‖w‖` |
| 2 | 硬间隔优化问题 | `min ½‖w‖²  s.t. yᵢ(wᵀxᵢ+b) ≥ 1`，是凸二次规划（QP），有唯一全局最优 |
| 3 | 支持向量（support vectors） | 落在间隔边界上（软间隔下还包括间隔内/分错的点）的样本，只有它们决定边界 |
| 4 | 软间隔与 C | 引入松弛变量 `ξᵢ`：`min ½‖w‖² + C·Σξᵢ`；C 大 → 惩罚违例重、间隔窄、易过拟合；C 小 → 间隔宽、正则强 |
| 5 | Hinge loss | `max(0, 1 − y·f(x))`：`y·f(x) ≥ 1` 时恰好为 0，否则线性惩罚；与 logistic loss（永不为 0）对比 |
| 6 | 原始问题 + 梯度下降 | `L = (λ/2)‖w‖² + (1/n)Σ hinge`，次梯度更新，每个 epoch `O(n·d)`；`λ` 与 C 的关系 `λ = 1/(C·n)` |
| 7 | 对偶问题与核技巧 | 对偶目标只依赖点积 `xᵢ·xⱼ`，把它换成核函数 `K(xᵢ,xⱼ)` 就能学非线性边界，而不必显式升维 |
| 8 | 三种常用核 | 线性 `x·z`；多项式 `(x·z + c)^d`；RBF `exp(−γ‖x−z‖²)`（无穷维、局部相似度） |
| 9 | SVR 与适用场景 | SVR 用宽 ε 的"管道"，管内零损失；SVM 适合小样本、高维稀疏（TF-IDF 文本）数据，不适合超大数据集 |

**Q11.** 代码中"支持向量"的判定方式如下：

```python
def find_support_vectors(self, X, y, tol=0.1):
    svs = []
    for i in range(len(X)):
        margin = y[i] * (dot(self.w, X[i]) + self.b)
        if abs(margin - 1.0) < tol:
            svs.append(i)
    return svs
```

## 五、参考答案与解析

### Q1 — 答案：B

间隔宽度 = `2/‖w‖`，`‖w‖ = √(3²+4²) = 5`，所以宽度 = `2/5 = 0.4`。A 是单侧距离 `1/‖w‖`（边界到任一间隔边界的距离）；C、D 把 `‖w‖` 和间隔弄反了。记住：**‖w‖ 越小，间隔越宽**——所以"最大化间隔"等价于"最小化 ½‖w‖²"。

### Q2 — 答案：A

`max(0, 1−1.5) = 0`（安全区，零损失）；`max(0, 1−0.8) = 0.2`（分对了但在间隔内，仍有惩罚）；`max(0, 1−(−0.2)) = 1.2`（分错）。B 错在以为"分对就没损失"——hinge loss 要求的是 `y·f(x) ≥ 1`，不是 `≥ 0`，这正是"间隔"思想在损失函数里的体现。

### Q3 — 答案：B

C 是"违例罚款"的单价。C 大 → 宁可把间隔收窄也不愿有违例 → 正则弱、可能过拟合；C 小 → 允许违例换取宽间隔 → 正则强。在代码里体现为 `lam = 1/(C·n)`：C 越大 λ 越小。D 错：C 增大时间隔变窄，落在间隔内的点通常**变少**，支持向量一般减少（本节运行结果中，代码用近似规则统计的 SV 数从 64 降到 31～33）。C 和核函数选择无关。

### Q4 — 答案：B

`γ` 越大，`exp(−γ‖x−z‖²)` 随距离衰减越快，每个支持向量只能影响紧贴着它的一小块区域，边界会绕着单个样本打转，训练准确率很高但泛化差。γ 很小时（A）才趋于平滑；C 描述的是 γ→0 的情形。

### Q5 — 答案：A

对偶目标 `Σαᵢ − ½ΣᵢΣⱼ αᵢαⱼyᵢyⱼ(xᵢ·xⱼ)` 以及预测函数 `f(x) = Σαᵢyᵢ(xᵢ·x) + b` 都只用到点积，所以可以把点积整体替换为 `K(xᵢ,xⱼ) = φ(xᵢ)·φ(xⱼ)`，**永远不需要显式算出 φ(x)**（B 错）。C 错：核函数必须满足 Mercer 条件（核矩阵半正定），见 Q16。

### Q6 — 答案：D

KKT 互补松弛条件给出：`yᵢf(xᵢ) > 1` ⇒ `αᵢ = 0`（不贡献）；`yᵢf(xᵢ) = 1` ⇒ `0 ≤ αᵢ ≤ C`（典型的"间隔上"支持向量）；`yᵢf(xᵢ) < 1`（间隔内或分错）⇒ `αᵢ = C`。所以 A、B、C 都可能是支持向量，只有 D 不是。这也说明：**软间隔下，支持向量不只是"刚好在边界上的点"**。

### Q7 — 答案：B

SVM 的间隔是欧氏几何意义上的距离，RBF 核又直接用 `‖x−z‖²`。如果一个特征以"元"为单位（范围几万）、另一个以"比例"为单位（0～1），前者会完全主导距离和 `‖w‖`。缩放不改变 hinge loss 的凸性（C 错），也没有"必须在 [0,1]"这种限制（A 错）。

### Q8 — 答案：C

讲义明确：kernel SVM 训练复杂度大约在 `O(n²)` 到 `O(n³)`，大数据集慢、GPU 收益有限，而且图像需要手工特征；500 万张原始像素图片是深度学习（CNN/ViT）的主场。A（高维稀疏文本）、B（小样本表格）、D（one-class SVM 异常检测）都是讲义列出的 SVM 仍然占优的场景。

### Q9 — 参考答案

```

0.6065    # exp(-0.5 · 1)   ，‖x−z‖² = 1
```

线性核和多项式核衡量的是**投影/对齐程度**，同方向越远点积越大，`(5+1)² = 36`、`(5+1)³ = 216`；RBF 核衡量的是**距离上的局部相似度**，`[5,0]` 与 `[1,0]` 相距 4，平方距离 16，`e⁻⁸` 几乎为 0。这正是"RBF = 局部模板匹配，多项式 = 全局特征交互"的直观区别，也解释了为什么 RBF 的 γ 本质上是一个"邻域半径"。

### Q10 — 参考答案

（1）推导：讲义的软间隔目标是 `J₁ = ½‖w‖² + C·Σᵢ hingeᵢ`。两边同时除以正常数 `C·n`（不改变最优解）：

```
J₁ / (C·n) = (1/(2·C·n))·‖w‖² + (1/n)·Σᵢ hingeᵢ
```

与 `J₂ = (λ/2)‖w‖² + (1/n)Σ hingeᵢ` 对比系数：`λ/2 = 1/(2Cn)` ⇒ **`λ = 1/(C·n)`**。这也是 Pegasos 等 SGD-SVM 文献里常见的换算。

（2）不一致。表格里间隔宽度随 C 增大单调变窄（6.28 → 1.39），这部分符合理论；但**测试准确率随 C 增大反而上升**（0.867 → 0.900），训练准确率还略降——与"小 C 泛化更好"的打印结论相反。原因：

- 数据是"线性边界 + 高斯噪声"生成的，模型只是 2 维线性分类器，容量极低，**根本没有过拟合的空间**；此时 C 太小（λ≈4.2）反而是强欠拟合：`w` 被压得很小，几乎所有点都落在间隔内参与梯度，边界被"平均化"。
- 测试集只有 60 个样本，1 个样本 = 1.67 个百分点，表中差异只有 2～3 个样本，统计上并不显著。
- "大 C 过拟合"要在**高容量**模型（RBF 核 + 大 γ、或高维特征）上才看得明显。结论：解读实验一定要以数据为准，不要被代码里写死的 `print` 带偏。

### Q11 — 参考答案

（1）`fit` 里只要 `margin < 1` 就会用 `−yᵢxᵢ` 更新 `w` 和 `b`，所以真正"塑造边界"的是**所有** `yᵢf(xᵢ) < 1` 的点（对应对偶里 `αᵢ > 0`）。`abs(margin − 1) < 0.5` 的判定：

- **漏掉**了 `margin ≤ 0.5` 的点，包括所有分错的点——它们恰恰是梯度最大的样本（对偶中 `αᵢ = C`）。
- **多算**了 `1 ≤ margin < 1.5` 的点——它们 hinge loss 为 0，对更新毫无贡献。

在同一份数据上实测：`margin < 1` 的点有 22 个（其中 5 个分错），而 `tol=0.5` 统计出的 26 个里有 15 个其实 `margin ≥ 1`。所以 "26 / 160" 只是"靠近间隔边界的点"，不等于严格意义上的支持向量。

（2）参考实现：

```python
def active_points(svm, X, y):
    """返回会触发 hinge 梯度的样本：y·f(x) < 1（与 fit 中的 else 分支一致）"""
    return [
        i for i in range(len(X))
        if y[i] * (dot(svm.w, X[i]) + svm.b) < 1
    ]
```

如果想要更细的分类，可以再拆成 `margin <= 0`（分错）、`0 < margin < 1`（间隔内）、`|margin − 1| < tol`（间隔上）三组。注意判定条件要与 `fit` 中 `if margin >= 1` 的分支**严格对应**。

### Q13 — 参考回答要点

- **损失函数**：SVM 用 hinge loss `max(0, 1−yf)`，在 `yf ≥ 1` 时恰好为 0；LR 用 logistic loss `log(1+e^(−yf))`，处处为正、处处可导。两者在 `yf` 很负时都近似线性增长。
- **解的结构**：hinge 产生稀疏解（只有支持向量的 `α > 0`），LR 用到所有样本。
- **输出**：LR 天然输出概率；SVM 输出的是到超平面的有符号"分数"，要概率需要额外校准（如 Platt scaling，sklearn `SVC(probability=True)` 内部做交叉验证校准，训练变慢）。
- **非线性**：SVM 的对偶形式与核技巧结合得很自然；LR 也能核化，但不稀疏，实践中少用。
- **怎么选**：需要概率/风险评分、要做阈值调优 → LR；小样本、高维稀疏、追求间隔鲁棒性 → 线性 SVM；非线性且样本 < 1 万 → RBF SVM。两者在线性可分附近效果往往接近，以交叉验证为准。
- **加分点**：指出两者与 0-1 损失的关系——hinge 是 0-1 损失的凸上界；logistic loss 同样是 0-1 损失的凸替代（surrogate），只是更"平滑"、永不为 0。

### Q14 — 参考回答要点

- **为什么用对偶**：①对偶变量个数 = 样本数 n，与特征维度 d 无关，d 很大（或无穷维）时更划算；②对偶目标只含点积，可以直接核化；③约束变成简单的盒约束 `0 ≤ αᵢ ≤ C` 加一个等式约束，适合 SMO（每次只优化两个 α）这类专用算法。
- **KKT 条件 → 支持向量**：互补松弛 `αᵢ·[yᵢf(xᵢ) − 1 + ξᵢ] = 0`。凡是 `yᵢf(xᵢ) > 1` 的点 `αᵢ = 0`；`αᵢ > 0` 的点就是支持向量，`w = Σαᵢyᵢxᵢ` 只由它们组成。
- **核技巧**：预测 `f(x) = Σᵢ αᵢyᵢK(xᵢ, x) + b`，只需对支持向量求核值。原始问题里 `w` 位于 φ 空间（可能无穷维），无法显式存储，所以核化天然发生在对偶。
- **常见误区**：认为"对偶一定更快"——对于海量样本、低维特征，原始问题 + SGD（`O(n·d)`/epoch，如 `LinearSVC`）反而快得多。

### Q15 — 参考回答要点

- **调参**：先标准化；`C` 与 `γ` 在对数网格上联合搜索（如 C ∈ {0.01…1000}、γ ∈ {0.001…10}），用交叉验证选；sklearn 的 `gamma="scale"`（`1/(n_features·X.var())`）是合理起点。最优值落在网格边缘就继续往外扩。两者有耦合：γ 大时往往需要更小的 C 来抑制过拟合。
- **诊断**：训练准确率高、验证低 → 降 γ 或降 C；两者都低 → 升 γ 或升 C；支持向量占比极高通常意味着欠拟合或正则过强。
- **扩展到 1000 万**：kernel SVM 需要 `O(n²)` 级别的核矩阵运算，不可行。可选：①线性 SVM（`LinearSVC` / SGD 版 hinge loss）+ 更好的特征；②核近似：随机傅里叶特征（sklearn `RBFSampler`）或 Nyström（`Nystroem`）把 RBF 核近似成显式低维特征，再接线性 SVM；③换模型：梯度提升树（表格数据）或神经网络。
- **加分点**：提到大数据下用子采样先确定 C、γ 的大致范围，再在全量上训练线性近似模型。

### Q16 — 参考回答要点

- **条件**：合法核必须对应某个特征映射的内积 `K(x,z) = φ(x)·φ(z)`，等价地（Mercer 条件）对任意有限样本集，核矩阵 `Kᵢⱼ = K(xᵢ,xⱼ)` 都**对称半正定**。只有这样对偶问题才是凸的、有全局最优。
- **构造规则**：两个合法核的和、正系数倍、乘积仍是合法核；`exp(合法核)` 也是。多项式核、RBF 核都可以这样验证。
- **`‖x − z‖` 不行**：它是距离而不是相似度——自身与自身为 0、越远越大，核矩阵对角线全为 0，一般不是半正定的（例如两个不同点时，矩阵 `[[0,d],[d,0]]` 的特征值为 `±d`，有负特征值）。正确做法是把距离"包"进一个衰减函数，如 RBF `exp(−γ‖x−z‖²)`。
- **加分点**：sigmoid 核 `tanh(a·x·z + c)` 在很多参数下并不半正定，sklearn 里能用但理论上不保证凸。

### Q17 — 参考回答要点

- **为什么强 baseline**：TF-IDF 特征维度高（几万～几十万）且稀疏，在高维空间中类别往往接近线性可分；线性 SVM 训练是 `O(n·d)`，推理只是一次稀疏点积，毫秒级；权重 `w` 每一维对应一个词，可直接解释"哪些词把工单推向哪个类"。
- **多分类**：一对多（OvR，训练 20 个二分类器，取分数最高）或一对一（OvO，训练 `20×19/2 = 190` 个）。sklearn 中 `LinearSVC` 默认 OvR，`SVC` 内部用 OvO。
- **置信度**：SVM 分数不是概率，可用 `CalibratedClassifierCV`（Platt / isotonic）做校准；或者直接换 LR。
- **工程要点**：`Pipeline(TfidfVectorizer → LinearSVC)` 保证训练/推理一致；类别不均衡时用 `class_weight="balanced"`；用宏平均 F1 而不是准确率评估。
- **加分点**：和 LLM 方案对比——先用线性 SVM 做基线和兜底，再评估 embedding + 分类器或 LLM 零样本是否值得额外成本。

### Q18 — 参考回答要点

- **对一半**：远离边界、被正确分类的离群点（`yf > 1`）确实 `α = 0`，完全不影响边界——这一点比 LR 鲁棒。
- **但**：分错的离群点或落在间隔内的点会获得最大的权重 `αᵢ = C`，hinge loss 对它们是**线性**增长的（不像平方损失那样二次爆炸，但也无上界）。C 很大时，少数错误标注的点就能把边界拉偏。硬间隔 SVM（C→∞）遇到一个错标点甚至可能无解。
- **对策**：调小 C；清洗标签噪声；使用对离群点更鲁棒的截断损失（如 ramp loss）——但会失去凸性。
- **常见误区**：把"稀疏"误解成"鲁棒"。稀疏说的是不影响边界的点很多，不代表影响边界的那几个点不会是坏点。
