## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 规则编程 vs 机器学习 | 传统编程是"规则 + 数据 → 输出"；ML 是"数据 + 期望输出 → 规则（模型）"，模型就是用参数编码的规则 |
| 2 | 三大学习范式 | 监督学习有输入-输出对；无监督学习只有输入、自己找结构；强化学习靠环境奖励学策略 |
| 3 | 半监督与自监督 | 半监督 = 少量标签 + 大量无标签（伪标签、标签传播、一致性正则）；自监督 = 从数据本身构造标签（BERT 掩码预测、GPT 下一个 token、SimCLR 对比学习） |
| 4 | 分类 vs 回归 | 分类回答"哪一类"（交叉熵），回归回答"多少"（MSE/MAE）；同一业务问题可以有两种建模方式 |
| 5 | ML 工作流 | 收集 → 清洗探索 → 特征工程 → 切分 → 训练 → 评估 →（回到特征）→ 部署 → 监控 →（数据漂移时回到收集） |
| 6 | 训练/验证/测试集 | 训练集学参数、验证集调超参与选模型、测试集只在最后看一次；小数据用 k 折交叉验证 |
| 7 | 过拟合与欠拟合 | 过拟合：训练好、测试差（记住了噪声）；欠拟合：训练测试都差（模型太简单） |
| 8 | 偏差-方差权衡 | `总误差 = 偏差² + 方差 + 不可约噪声`；复杂度升高 → 偏差降、方差升 |
| 9 | 基线与无免费午餐 | 任何模型都要和随机/多数类基线比较；没有一种算法在所有问题上都最好 |
| 10 | 最近质心分类器 | fit = 每类求均值，predict = 分给最近的质心；决策边界是线性的，怕多簇、非线性边界和特征尺度不一 |

## 五、参考答案与解析

### Q1 — 答案：C

掩码语言模型（BERT）的"标签"就是被遮住的原词，来自数据本身，不需要人工标注，这正是自监督。A 是标准监督学习（人工标签）；B 是无监督聚类；D 是强化学习（奖励信号）。讲义强调：自监督在技术上也是"预测某个东西"，只是标签是自动生成的。

### Q2 — 答案：C

训练 99%、验证 60% 是典型的**过拟合**（高方差）。A、B、D 都是讲义列出的过拟合修复手段：更多数据、正则化、早停。C 增加模型复杂度是**欠拟合**的修复方法，用在过拟合上只会让方差更大、差距更大。

### Q3 — 答案：B

反复看测试集并据此挑模型，等于把测试集当成了验证集——测试集信息通过"选择"泄漏进了建模过程，报告的数字是**乐观有偏**的。讲义原话："The test set is sacred. You look at it exactly once." 正确做法：在验证集（或交叉验证）上选模型，最后只在测试集上评估一次。

### Q4 — 答案：C

手写数字识别的规则很难手写（笔迹千变万化），且有大量标注数据（MNIST），是 ML 的经典场景。A、B 是规则简单且明确的确定性计算，用 ML 只会增加复杂度和出错概率；D 只有 10 个样本，讲义明确说"数据太少训练不出有意义的模型，先去收集数据"。

### Q5 — 答案：B

讲义表格原例："degree-20 polynomial for 10 points → Low bias, High variance → Overfitting"。参数比数据点还多，曲线可以穿过每一个训练点（训练误差≈0），但换一批数据结果会剧烈变化。D 错：不可约噪声是数据本身的随机性，任何模型都消除不了。

### Q6 — 答案：A

到两个质心距离相等的点的集合，就是连线的垂直平分线（推导见 Q15）。B 错，那是"到一个点距离为常数"；C 是 KNN、决策树等非线性模型才有的能力；D 错，最近质心**没有超参数**（讲义："No gradient descent, no iteration, no hyperparameters"），k 是 KNN 的超参。

### Q7 — 答案：B

欧氏距离对每一维平方后相加，收入的量级是年龄的上万倍，距离几乎全部由收入决定。而收入与标签无关，相当于用一列噪声做分类，准确率接近随机。D 错：最近质心没有可学习的特征权重，所有维度一视同仁。修复方法是标准化（见 Q12）。讲义 Step 4 原话："Features have very different scales (distance is dominated by the largest-scale feature)"。

### Q8 — 答案：B

accuracy 只在预测类别"翻转"时才变化，对模型参数是分段常数，梯度几乎处处为 0（在翻转点不可导），梯度下降拿不到任何"往哪个方向改"的信号。交叉熵是概率的光滑函数，能给出有效梯度，并且是 accuracy 的一个可优化"代理"。这也说明讲义"分类 vs 回归"表格里把 accuracy 写在 Loss function 一行并不严谨——accuracy 是**评估指标**，不是训练损失。

### Q9 — 参考答案

输出：

```text
[[ 1.  0.]
 [11. 10.]]
['cat' 'dog']
```

- 质心：`cat` 类是 `[0,0]` 和 `[2,0]` 的均值 `[1,0]`；`dog` 类是 `[11,10]`。
- `[5,4]` 到 `[1,0]` 的距离 `√32 ≈ 5.66`，到 `[11,10]` 的距离 `√72 ≈ 8.49`，归 `cat`；`[7,6]` 正好相反，归 `dog`。
- `distances` 的形状是 `(2, 2)` —— **(类别数, 样本数)**：列表推导对每个质心产生一行"所有样本到该质心的距离"。所以要用 `argmin(axis=0)` 沿"类别"方向取最小。
- `argmin` 返回的是**下标** 0/1，不是类别本身。`self.classes` 由 `np.unique(y)` 得到（已排序的真实类别值），用下标去索引它，才能支持字符串标签、或 `[3, 7]` 这样不从 0 开始的整数标签。直接返回 `argmin` 在本例会得到 `[0 1]` 而不是 `['cat' 'dog']`。

### Q10 — 参考答案

(a) 三个函数都把 `seed=42` 写死了：
- `generate_classification_data` 里 `rng.randn` 调用的次数与 separation 无关，随后的 `rng.permutation` 拿到的随机状态完全一样，所以**打乱后的 `y` 每次都相同**（separation 只改变 `X` 的平移量）；
- `train_test_split(seed=42)` 的切分下标相同，`y_test` 也就相同；
- `random_baseline(seed=42)` 生成的随机预测也相同。

预测相同、真实标签相同，准确率当然恒为 0.467。这不是 bug，反而说明固定种子带来了**可复现性**；但也提醒你：单个种子下的随机基线只是一个样本，严谨的做法是多跑几个种子取平均（期望值约 0.5）。

(b) 不是 bug。测试集只有 90 个样本，准确率每差一个样本就变动约 1.1 个百分点，抽样波动很大；这次恰好抽到的测试点离边界较远。最近质心模型极其简单（只有 2×2=4 个参数），几乎不会过拟合，所以训练、测试准确率本就应该接近，测试略高完全在噪声范围内。真正值得警惕的是反过来"训练远高于测试"。

### Q11 — 参考答案

`distances` 形状是 `(2, 90)`，`argmin(axis=1)` 变成"对每个类别，找离它最近的**样本**下标"，得到长度为 2、取值在 0–89 之间的数组（实测是 `[20, 6]`）。再用它去索引只有 2 个元素的 `self.classes`，抛出：

```text
IndexError: index 20 is out of bounds for axis 0 with size 2
```

（如果碰巧两个下标都是 0 或 1，则不会报错，而是返回一个长度为 2 的错误结果——更隐蔽。）

广播版：

```python
def predict(self, X):
    # X: (n, d) -> (n, 1, d)；centroids: (k, d) -> (1, k, d)
    diff = X[:, None, :] - self.centroids[None, :, :]   # (n, k, d)
    distances = np.sqrt((diff ** 2).sum(axis=2))        # (n, k)
    return self.classes[distances.argmin(axis=1)]       # 每个样本取最近的类别
```

注意这里距离矩阵是 `(样本数, 类别数)`，所以 argmin 要沿 `axis=1`——**轴的含义取决于你怎么摆矩阵**，这正是本题的教训。代价：中间张量 `(n, k, d)` 占内存 O(n·k·d)，n 很大时应分批，或用展开式 `|x|² - 2x·c + |c|²` 化成矩阵乘法。另外 argmin 只关心大小顺序，`sqrt` 可以省掉。

### Q12 — 参考答案

```python
import numpy as np
from ml_intro import NearestCentroid

class StandardizedNearestCentroid:
    def __init__(self):
        self.inner = NearestCentroid()
        self.mean = None
        self.std = None

    def _transform(self, X):
        return (X - self.mean) / self.std

    def fit(self, X, y):
        self.mean = X.mean(axis=0)
        self.std = X.std(axis=0)
        self.std[self.std == 0] = 1.0      # 常数列避免除以 0
        self.inner.fit(self._transform(X), y)

    def predict(self, X):
        return self.inner.predict(self._transform(X))

    def score(self, X, y):
        return np.mean(self.predict(X) == y)
```

为什么只能用训练集统计量：测试集代表"上线后才会看到的新数据"，预测时你不可能提前知道未来所有数据的均值和方差。如果用全量数据算均值/标准差，测试集的信息就泄漏进了预处理，评估结果偏乐观——这是**数据泄漏（data leakage）**的经典形式。正确流程：`fit` 时在训练集上算好，`predict` 时原样复用。sklearn 里的 `StandardScaler().fit(X_train)` + `transform(X_test)`，或 `Pipeline`，都是在保证这一点。

（实测：把第二个特征换成量级 ×1000 的纯噪声后，原始最近质心测试准确率约 0.56；标准化后回升到约 0.83。噪声特征虽然还在，但不再"压倒"有用特征。）

### Q13 — 参考回答要点

- **定义**：
  - 监督学习：有 (输入, 标签) 对，学习映射；分类与回归。
  - 无监督学习：只有输入，找结构；聚类、降维。
  - 强化学习：智能体在环境中行动，根据奖励学习最大化累计回报的策略。
  - 自监督学习：从数据本身自动构造监督信号（下一个 token、掩码词、对比学习），本质是"标签免费的监督学习"。
- **LLM 训练流程对应**：
  - 预训练：在海量文本上做 next-token prediction → **自监督**；
  - 指令微调 SFT：用人工写的 (指令, 回答) 对 → **监督学习**；
  - RLHF：先用人类偏好数据训练奖励模型（监督），再用强化学习优化策略 → **强化学习**。
- **加分点**：指出讲义的观点——半监督/自监督不是和三大类并列的新类别，而是组合了监督和无监督思想的策略；能举出伪标签、一致性正则等半监督手段。
- **常见误区**：把自监督说成"无监督"。严格来说它有明确的预测目标和损失，只是标签不需要人工。

### Q14 — 参考回答要点

- **诊断**：对比训练误差与验证误差。
  - 训练误差高、验证误差也高 → 欠拟合（高偏差）；
  - 训练误差低、验证误差明显更高 → 过拟合（高方差）；
  - 学习曲线：随训练数据增加，过拟合模型的验证误差会持续下降、两条曲线间距缩小；欠拟合模型两条曲线很快收敛到一个高位，再加数据也没用。
- **原理**：在平方损失下 `期望误差 = 偏差² + 方差 + 不可约噪声`。模型越复杂，偏差越小、方差越大，目标是找到二者之和的最低点。
- **修复**：
  - 过拟合：更多数据、降低复杂度、正则化（L1/L2）、dropout、early stopping、数据增强、集成（bagging）；
  - 欠拟合：更复杂的模型、更多/更好的特征、减小正则、训练更久。
- **加分点**：提到深度学习中的"双下降"现象，说明经典 U 形曲线并非总成立；以及先排查数据问题（标签噪声、泄漏）再谈模型。
- **常见误区**：看到验证效果差就一味加大模型——要先判断是偏差问题还是方差问题。

### Q15 — 参考回答要点

- **推导**：设两类质心为 μ₀、μ₁，预测为类 0 当且仅当 `|x−μ₀|² < |x−μ₁|²`。展开：
  `|x|² − 2x·μ₀ + |μ₀|² < |x|² − 2x·μ₁ + |μ₁|²`
  两边的 `|x|²` 抵消，得到 `2(μ₁−μ₀)·x < |μ₁|² − |μ₀|²`。
  这是关于 x 的**线性不等式**，边界 `w·x = b`（`w = 2(μ₁−μ₀)`）是一个超平面，并且就是 μ₀μ₁ 连线的垂直平分面。多分类时是若干这样的超平面围成的分段线性区域（Voronoi 划分）。
- **何时最优**：如果每一类都是**协方差相同且各向同性**（`σ²I`）的高斯分布、类先验相等，那么"离哪个均值近"就等价于"哪个类的后验概率大"，最近质心就是贝叶斯最优分类器（可看作 LDA 的特例）。本节的合成数据恰好就是这种情况，所以这么简单的模型能拿到 90%+。
- **何时失效**（讲义 Step 4）：
  - 一类有多个簇 → KNN（[第 06 节](../../06-knn-and-distances/docs/zh.md)）；
  - 非线性边界 → 决策树（[第 04 节](../../04-decision-trees/docs/zh.md)）、核 SVM；
  - 特征尺度不一 → 特征缩放（[第 08 节](../../08-feature-engineering/docs/zh.md)）。
- **加分点**：指出 argmin 不需要开方；各类协方差不同时最优边界变成二次曲面（QDA）。

### Q16 — 参考回答要点

- **为什么三份**：训练集用来拟合参数；如果用测试集选超参/选模型，测试集就被"用掉"了，最终数字偏乐观。所以需要单独的验证集做选择，测试集只做一次最终的无偏估计。典型比例 70/15/15。
- **k 折交叉验证**：数据少时，单次切分的验证结果方差很大；把数据分成 k 份轮流做验证集、取平均，估计更稳定，代价是训练 k 次。常见 k=5 或 10。分类问题用分层（stratified）切分保持类别比例。
- **时间序列**：不能随机打乱切分，否则会"用未来预测过去"（时间泄漏）。应按时间顺序切：训练集在前、验证在中、测试在后，交叉验证用滚动/扩展窗口。
- **加分点**：提到同一用户/同一实体的样本要分到同一侧（分组切分），否则模型记住用户 ID 也能拿高分；预处理（标准化、填充缺失值）的统计量只能在训练集上拟合。

### Q17 — 参考回答要点

可以按本节 `outputs/prompt-ml-problem-framer.md` 的思路逐步收窄：

1. **学习类型**：有历史上"是否流失"的记录 → 监督学习、二分类。
2. **精确定义目标**："预测某个活跃用户在未来 30 天内是否取消订阅"，而不是笼统的"预测用户行为"。还要定义清楚"流失"（取消订阅？30 天未登录？）。
3. **特征**：登录频率、近期使用时长变化、客服工单数、付费历史、套餐类型等。逐个确认**预测时刻是否可用**——比如"退订原因"只在流失后才产生，用了就是泄漏。
4. **指标**：流失通常是少数类，不能只看 accuracy；用 PR-AUC、召回率@固定精确率，或直接用业务指标（挽回用户带来的收入 − 挽留成本）。
5. **基线**：多数类基线、"最近 7 天未登录即判流失"的规则基线。模型必须明显超过规则基线才值得上线。
6. **风险**：类别不平衡、数据泄漏、数据漂移（产品改版后行为分布变化，需要监控和定期重训）。
- **加分点**：主动问"预测出来之后做什么动作"——如果没有可执行的挽留手段，预测再准也没价值；甚至可以进一步建模"干预效果"（uplift）。

### Q18 — 参考回答要点

"取决于和什么比"——单独一个 95% 没有意义：

- **先看基线**：如果 95% 的样本都是负类（如欺诈检测），全预测"非欺诈"的多数类基线就有 95%，模型等于什么都没学到。本节代码同时报告随机基线和多数类基线，就是这个道理。
- **再看指标是否合适**：类别不平衡时看精确率、召回率、F1、PR-AUC、混淆矩阵；不同错误的代价不同（漏掉癌症 vs 误报）时，要看代价加权的指标。
- **看训练/测试差距**：判断是否过拟合；看测试集是否被反复使用过、是否存在泄漏。
- **看业务需求**：规则方法能做到多少？95% 能否满足上线标准？与人类水平比如何？
- **常见误区**：只报 accuracy、不报基线；把高 accuracy 当成"模型好"的证据。
