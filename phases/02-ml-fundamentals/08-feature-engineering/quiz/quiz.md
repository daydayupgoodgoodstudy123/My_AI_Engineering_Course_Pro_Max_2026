## 五、参考答案与解析

### Q1 — 答案：D

树模型按单个特征的阈值切分，任何单调变换（包括线性缩放）都不改变样本在该特征上的排序，因此切分结果不变。A、B、C 都依赖欧氏距离（讲义："Put features on the same range so distance-based algorithms (K-Means, KNN, SVM) treat all features equally"），不缩放时量纲大的特征会主导距离。

### Q2 — 答案：B

城市是**无序**类别。label encoding 会让线性模型以为"广州 = 2 × 上海"、存在大小顺序（讲义："Introduces false ordering"）。one-hot 让每个城市有独立的系数。对线性模型通常去掉一列作为基准（避免完全共线，见 Q12），sklearn 中对应 `OneHotEncoder(drop="first")`。

### Q3 — 答案：C

`w = 2/(2+10) = 1/6 ≈ 0.167`，`encoding = 0.167×100 + 0.833×50 ≈ 16.7 + 41.7 = 58.3`。样本太少时，类别均值不可信，编码被"拉回"全局均值。样本越多，`w` 越接近 1，编码越接近该类别自己的均值。`smoothing` 就是"需要多少样本才开始相信类别均值"的旋钮。

### Q4 — 答案：B

`IDF = log(N/df) = log(N/N) = log 1 = 0`，所以 TF-IDF = 0：出现在所有文档里的词没有区分度。B 正确。这也是本节公式的一个特点（也是缺点），sklearn 的平滑 IDF 会额外加 1，避免这类词权重恰好为 0（见 Q10）。

### Q5 — 答案：B

讲义："The fact that data is missing can itself be informative." 例如某些问卷字段，缺失往往与用户特征相关（非随机缺失）。填充之后这个信息就消失了，所以要**先**记录指示列再填充。D 错：指示列和填充是互补的，模型仍然需要一个数值来代替缺失值。

### Q6 — 答案：D

`log(−5 + 1) = log(−4)` 无定义，Python 的 `math.log` 会抛 `ValueError: math domain error`。对含负值的特征，可以先平移、使用 `sign(x)·log(1+|x|)`，或使用 Yeo-Johnson 变换。A、B、C 都是讲义列出的用途。

### Q7 — 答案：C

A 错：相关系数只度量**线性**关系，`y = x²`（x 关于 0 对称分布）时相关系数约为 0，但两者完全相关。B 错：互信息能检测任意形式的统计依赖。D 错：方差阈值只看特征自身的方差，不看目标，属于无监督过滤。C 正确——补充：在常见的"过滤 / 包裹 / 嵌入"三分法中，Lasso 属于**嵌入法**（选择发生在训练过程中），RFE 属于**包裹法**；讲义把两者都归在"基于模型（Wrapper methods (model-based)）"一类，这是一种较粗的划分。

### Q8 — 答案：B

在全量数据上计算类别目标均值，测试集的标签信息就混进了训练特征——这是 target encoding 最典型的泄漏（讲义："Must be computed only on training data and applied to test data"）。A、C、D 都是正确做法。注意：即使只用训练集，target encoding 对训练集自身也会有"自我泄漏"，所以还需要平滑、留一法或 K 折编码（见 Q11）。

### Q9 — 参考答案

```
[0, 1, 2, 3, 4, 4]
[2, 3, 4, 9, 6]
[2, 3, 4, 9, 6]
[2, 3, 5, 4, 9, 25, 6, 10, 15]
```

（1）宽度 `(50−0)/5 = 10`。最大值 50 算出 `int(50/10) = 5`，超出了合法下标 0～4。`min(..., n_bins − 1)` 把它"钳"进最后一个箱。删掉后最大值会单独落在第 6 个箱（编号 5），箱数变得不一致。

（2）不符合。函数只有 `if degree >= 2` 一个分支，只生成平方项和两两交互项，`degree=3` 时和 `degree=2` 完全一样，**没有** `x³`、`x1²·x2` 等三次项——参数被静默忽略了。讲义写的是 "Creates x^2, x^3, x1*x2 terms"，但实现只支持二次。生产中用 `sklearn.preprocessing.PolynomialFeatures(degree=3)`。另外注意特征数量增长：3 个输入的二次展开已是 9 列，d 个特征的二次展开为 `d + d(d+1)/2` 列。

### Q10 — 参考答案

（1）第 0 篇共 5 个词，每个词出现 1 次，`TF = 1/5 = 0.2`。文档频率：`house` 只在第 0 篇（df=1）；`large` 在第 0、2 篇（df=2）；`with` 在第 0、2、3 篇（df=3）。

| 词 | IDF = ln(5/df) | TF-IDF = 0.2 × IDF |
|----|---------------|--------------------|
| house | ln 5 ≈ 1.6094 | **0.3219** |
| large | ln 2.5 ≈ 0.9163 | **0.1833** |
| with | ln(5/3) ≈ 0.5108 | **0.1022** |

`pool` 与 `house` 同为 0.3219；`modern`（df=2）与 `large` 同为 0.1833。"with" 这种功能词出现在更多文档里，权重最低。

（2）代码是 `sorted(tf_vocab.keys(), key=..., reverse=True)`。Python 的排序是**稳定的**，即使 `reverse=True`，相等元素也保持原有相对顺序。`tf_vocab` 按词首次出现的顺序插入：`large, modern, house, with, pool, ...`，所以并列的 `house/pool` 中 `house` 在前，并列的 `large/modern` 中 `large` 在前。

（3）平滑 IDF 的好处：①分子分母各加 1，相当于假设存在一篇"包含所有词"的虚拟文档，避免 df=0（推理时遇到的新词）导致除零；②末尾 +1 使出现在所有文档中的词权重不为 0 而是一个较小的正数，不会被完全抹掉。此外 sklearn 默认还会对每个文档向量做 L2 归一化，消除文档长度的影响。

### Q11 — 参考答案

```python
def loo_target_encode(feature_values, target_values, smoothing=10):
    n = len(target_values)
    global_mean = sum(target_values) / n
    stats = {}                                   # 类别 -> [目标和, 计数]
    for f, t in zip(feature_values, target_values):
        s = stats.setdefault(f, [0.0, 0])
        s[0] += t
        s[1] += 1

    encoded = []
    for f, t in zip(feature_values, target_values):
        s, c = stats[f]
        s_loo, c_loo = s - t, c - 1              # 去掉自己
        if c_loo == 0:                           # 该类别只有自己一行
            encoded.append(global_mean)
            continue
        w = c_loo / (c_loo + smoothing)
        encoded.append(w * (s_loo / c_loo) + (1 - w) * global_mean)
    return encoded
```

验证：`loo_target_encode(['a','a','b','b','b','b'], [100,100,0,0,0,30], smoothing=0)` 返回 `[100, 100, 10, 10, 10, 0]`——b 类中目标为 0 的三行，编码是其余三行（0、0、30）的均值 10；目标为 30 的那行，编码是 0。

**ID 列为什么是灾难**：每个 ID 只出现一次，`smoothing=0` 时类别均值就是该行自己的目标值，编码 = 标签本身。实测用 `make_housing_data` 的 200 行，ID 列朴素编码后与价格的相关系数为 **1.0**——模型在训练集上"完美"，在测试集上（全是没见过的 ID）毫无用处。留一法下每个 ID 去掉自己后没有其他样本，编码退化为全局均值常数，相关系数为 0，泄漏消失。

**加分点**：留一法本身仍有隐患——同一类别内，编码随自身目标单调**递减**（上例 b 类中目标 30 的行编码最低），强模型可以反向利用；工程上更常用 **K 折 target encoding**（用其他折的数据给当前折编码）加平滑。

### Q12 — 参考答案

（1）`remove_correlated` 只检查**两两**之间的 Pearson 相关。one-hot 的共线是"三列加起来恒等于 1"，属于**多列之间**的线性关系，任意两列之间只是中等负相关（约 −0.5），远低于 0.9 的阈值。检测多列共线要看整个设计矩阵的秩/条件数，或用方差膨胀因子（VIF：把每列对其余列做回归，`VIF = 1/(1−R²)`，完全共线时 R² = 1、VIF → ∞）。

（2）影响与处理：
- **线性回归（带截距）**：截距列 = 三个 one-hot 列之和，设计矩阵秩亏，`XᵀX` 不可逆，系数不唯一（"虚拟变量陷阱"）。处理：去掉一列作为基准（`drop="first"`），或使用 L2 正则（`XᵀX + λI` 一定可逆）。
- **随机森林 / 树模型**：不受影响，多一列只是多一个可切分的选项。
- 这个例子说明：过滤法是**启发式**的，阈值和检测方式决定了它能发现什么。

### Q13 — 参考回答要点

| 方法 | 公式 | 特点 |
|------|------|------|
| 标准化（z-score） | `(x − μ)/σ` | 均值 0、标准差 1；不限定范围；受离群点影响（μ、σ 被拉偏） |
| Min-Max | `(x − min)/(max − min)` | 映射到 [0,1]；对离群点非常敏感（一个极端值会把其余数据压缩到很窄的区间）；适合有界输入（如像素） |
| Robust Scaling | `(x − 中位数)/IQR` | 用中位数和四分位距，对离群点稳健（讲义练习 1） |

- **需要缩放**：基于距离的（KNN、K-Means、RBF-SVM）、基于梯度下降的（线性/逻辑回归、神经网络——缩放影响收敛速度）、带正则化的线性模型（L1/L2 惩罚对系数尺度敏感）、PCA（按方差找方向）。
- **不需要**：决策树、随机森林、梯度提升树；朴素贝叶斯（各特征分别估计分布）。
- **关键原则**：统计量只在训练集上 `fit`，再 `transform` 验证/测试集；放进 `Pipeline` 中避免交叉验证泄漏。
- **常见误区**：以为标准化会把数据变成正态分布——它只做平移和缩放，不改变分布形状。

### Q14 — 参考回答要点

| 方法 | 做法 | 优点 | 缺点 |
|------|------|------|------|
| one-hot | 每个取值一列 | 简单、无假设 | 维度爆炸，稀疏；新取值无法处理 |
| 频率/计数编码 | 用出现次数代替类别 | 一列、无泄漏 | 不同类别可能计数相同 |
| target encoding | 类别 → 目标均值（平滑） | 一列、信息量大 | 泄漏风险；需平滑 + K 折 / 留一法；低频类别不稳定 |
| 特征哈希 | `hash(值) mod M` 映射到 M 维 | 固定维度、可处理新值 | 哈希冲突、不可解释 |
| 低频合并 | 出现次数 < 阈值的归为 "其他" | 降维、稳健 | 丢失长尾信息 |
| embedding | 在神经网络中学一个稠密向量 | 能学到类别间的相似性 | 需要深度模型与足够数据 |

- 本节提供的 prompt（`outputs/prompt-feature-engineer.md`）给出的经验划分：低基数（<10）用 one-hot，中等（10–100）用带平滑的 target encoding，高基数（100+）考虑哈希、embedding 或合并稀有类别。
- **加分点**：树模型（如 LightGBM、CatBoost）有原生类别特征处理；CatBoost 用"有序 target statistics"专门规避 target encoding 的泄漏。

### Q15 — 参考回答要点

- **定义**（讲义）：训练时使用了预测时无法获得的信息，导致评估结果虚高。
- **常见形式**：
  1. **预处理泄漏**：在全量数据上计算均值/标准差/目标均值/PCA，再切分。
  2. **目标泄漏**：特征本身是标签的结果或代理，例如用"是否已退款"预测"是否会投诉"，或在结果发生之后才记录的字段。
  3. **时间泄漏**：随机切分时间序列，用未来预测过去；特征窗口包含了预测时刻之后的数据。
  4. **重复/近重复样本**：同一用户或同一图片的多份副本同时出现在训练集和测试集。
  5. **调参泄漏**：在测试集上反复调参、挑选模型，测试集实际上变成了验证集。
- **防范**：先切分再做一切 `fit`；用 `Pipeline` 在每折内部拟合预处理；时间序列按时间切分；按用户等分组切分（GroupKFold）；保留一份只看一次的最终测试集；对"好得不真实"的特征重要性保持警惕。
- **加分点**：举出本节的例子——ID 列朴素 target encoding 与价格的相关系数为 1.0。

### Q16 — 参考回答要点

| 类别 | 原理 | 例子 | 优缺点 |
|------|------|------|-------|
| 过滤法（filter） | 用统计量独立于模型评估特征 | 方差阈值、相关系数、互信息、卡方检验 | 快、与模型无关；忽略特征间的组合作用 |
| 包裹法（wrapper） | 用模型表现评估特征子集 | 递归特征消除（RFE）、前向/后向逐步选择 | 考虑特征组合；计算量大、易对验证集过拟合 |
| 嵌入法（embedded） | 选择发生在模型训练过程中 | L1/Lasso、树模型的特征重要性 | 效率与效果折中；结果依赖模型 |

- **互信息 vs 相关系数**：相关系数只衡量线性关系，取值 [−1,1]；互信息 `I(X;Y) = Σ p(x,y)·log(p(x,y)/(p(x)p(y)))` 衡量任意统计依赖，独立时为 0，单位是 nats（自然对数）或 bits。本节运行结果：sqft 的互信息 0.3886 远高于其他特征，与相关系数 0.82 的结论一致。
- **互信息的代价**：连续特征需要分箱或核密度估计，结果依赖箱数；本节用 10 个等宽箱。sklearn 的 `mutual_info_classif` 对连续特征使用基于 k 近邻的估计。
- **常见误区**：只做单变量筛选——两个单独看都无用的特征，组合起来可能非常有用（经典的 XOR 例子）。

### Q17 — 参考回答要点

- **时间**：小时、星期几、是否周末/节假日、是否饭点高峰；小时和星期用 `sin/cos` 周期编码（讲义附带的 prompt 提到 cyclical encoding），避免 23 点与 0 点"相距很远"。
- **空间**：用户与商家的球面距离（haversine）、所在商圈/网格 ID；距离可以取对数。
- **商家**：历史平均出餐时长、当前排队订单数——商家 ID 是高基数特征，用"截至下单时刻"的历史统计做 target encoding，严格避免使用未来数据。
- **骑手**：当前手上订单数、历史平均速度、熟悉该区域程度。
- **天气**：雨雪等级、温度；与距离的交互（雨天的长距离订单更慢）。
- **订单**：金额、菜品数量；菜品文本可用 TF-IDF 或关键词标记"需要现做的菜"。
- **缺失**：天气或定位缺失时加指示列。
- **泄漏防范**：所有统计特征只能用下单时刻之前的数据；按时间切分训练/验证集。
- **加分点**：先做一个只有距离 + 时段的基线，再逐组加特征，观察验证集误差的边际收益；用 SHAP 或排列重要性检查特征是否"好得可疑"。

### Q18 — 参考回答要点

- **变化**：在图像、语音、文本等非结构化数据上，深度学习自动学习表示，手工特征（如 SIFT、MFCC、n-gram）的重要性大幅下降；讲义附带的 prompt 也提到长文本可以考虑 embedding。
- **仍然重要**：
  1. 表格数据：业务系统中大量问题仍以梯度提升树 + 特征工程为主力，领域特征往往比换模型更有效。
  2. 深度模型同样需要"输入工程"：归一化、缺失处理、类别 embedding、时间特征。
  3. LLM 应用中，类似的思想表现为 prompt / 上下文工程：给模型什么信息、以什么结构给，决定了效果上限。
  4. 数据泄漏、训练-推理一致性（同一套预处理代码）等原则在任何模型中都适用。
- **新玩法**：用 LLM 从非结构化文本中抽取结构化特征（如从评论中抽取"是否提到配送慢"），再交给传统模型。
- **常见误区**：认为"模型足够大就不需要关心数据表示"。表示决定了模型"能看到什么"。
