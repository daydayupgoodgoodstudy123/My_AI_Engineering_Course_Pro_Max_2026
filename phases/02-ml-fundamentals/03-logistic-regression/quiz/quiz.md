## 一、学完本节你应该掌握

### 核心知识点

| # | 知识点 | 一句话要点 |
|---|--------|-----------|
| 1 | 线性回归为什么不适合分类 | 输出无界（会 <0 或 >1），且远离边界的离群点会把整条线拽偏 |
| 2 | sigmoid 函数 | `σ(z) = 1/(1+e⁻ᶻ)`，值域 (0,1)，`σ(0)=0.5`，导数 `σ' = σ(1−σ)`，最大值 0.25 |
| 3 | 逻辑回归模型 | `p = σ(wᵀx + b) = P(y=1|x)`；等价地，对数几率 `log(p/(1−p)) = wᵀx + b` 是线性的 |
| 4 | 二元交叉熵（BCE） | `L = −(1/n)·Σ[y·log p + (1−y)·log(1−p)]`；对"自信地答错"施以巨大惩罚，关于 w 是凸的 |
| 5 | 梯度形式 | `∂L/∂w = (1/n)·Σ(p−y)·x`，`∂L/∂b = (1/n)·Σ(p−y)`：与线性回归同形，只是 p 换成了 sigmoid 输出 |
| 6 | 决策边界 | `wᵀx + b = 0`（此处 p=0.5），永远是线性的；要弯曲边界就加多项式特征或换非线性模型 |
| 7 | Softmax 多分类 | 每类一个权重向量，`softmax(zᵢ) = e^{zᵢ}/Σe^{zⱼ}`，概率和为 1；配合类别交叉熵，梯度仍是 `p − y` |
| 8 | 混淆矩阵与指标 | Precision = TP/(TP+FP)，Recall = TP/(TP+FN)，F1 是二者的调和平均；不平衡时 accuracy 会骗人 |
| 9 | 阈值调节 | 阈值调低 → 召回升、精确率降；阈值是业务决策，不是模型参数 |
| 10 | 数值稳定 | sigmoid 输入截断防 `exp` 溢出；log 前把 p 夹到 `[1e-15, 1−1e-15]`；softmax 先减最大值 |

## 五、参考答案与解析

### Q1 — 答案：B

`σ'(z) = σ(z)·(1 − σ(z))`，`σ(0) = 0.5`，所以 `σ'(0) = 0.5 × 0.5 = 0.25`。这也是 sigmoid 导数的**最大值**——这一点在深度学习里很重要：多层 sigmoid 连乘时梯度每层至少缩小 4 倍，导致梯度消失。

### Q2 — 答案：B

逻辑回归的线性部分建模的是对数几率（logit）：`log(p/(1−p)) = w₁x₁ + w₂x₂ + b`。x₁ 增加 1，logit 增加 w₁，几率乘以 `e^{w₁}`。p 本身的变化量**不是常数**——在 p≈0.5 附近变化最快，在 p 接近 0 或 1 时几乎不变，所以 A、C 都错。这种"几率比（odds ratio）"解释是逻辑回归在医疗、金融等领域受欢迎的原因。

### Q3 — 答案：B

讲义指出 MSE + sigmoid 会得到非凸的损失面。另一个关键原因是梯度：BCE 对 z 的梯度是 `p − y`；MSE 对 z 的梯度是 `2(p − y)·p(1−p)`。当 y=1 而 p=0.01（严重答错）时，BCE 梯度是 −0.99，MSE 梯度只有约 −0.0196——**错得越离谱学得越慢**，正好反了。A 错：MSE 可以算，只是效果差；D 错：交叉熵与类别是否平衡无关。

### Q4 — 答案：B

漏诊 = FN，代价高 → 优先 Recall。降低阈值让更多样本被判为阳性，FN 减少、Recall 上升，代价是 FP 增多、Precision 下降（多做一些复查）。讲义："Recall: when false negatives are costly (cancer screening...)"。D 阈值 1.0 会把所有人判成阴性，Recall = 0。

### Q5 — 答案：C

Precision = 40/(40+10) = 0.8；Recall = 40/(40+40) = 0.5；F1 = 2×0.8×0.5/(0.8+0.5) = 0.8/1.3 ≈ 0.615。A 是 accuracy（950/1000），在 8% 正样本的不平衡数据上看起来很高，却掩盖了"漏掉一半正样本"的事实；B 是算术平均 0.65——调和平均总是 ≤ 算术平均，并且更偏向较小的那个值。

### Q6 — 答案：B

`e^{zᵢ+c} / Σe^{zⱼ+c} = e^c·e^{zᵢ} / (e^c·Σe^{zⱼ}) = e^{zᵢ}/Σe^{zⱼ}`，常数因子 `e^c` 约掉了。这正是代码里"先减最大值"技巧的理论依据：取 `c = −max(z)`，结果不变，但所有指数的参数都 ≤ 0，`exp` 不会溢出。实测 `softmax([1000, 1001, 1002])` 与 `softmax([0, 1, 2])` 输出完全相同。

### Q7 — 答案：C

逻辑回归的边界永远是 `wᵀx + b = 0` 的直线，任何直线都无法把同心圆分开，训练再久（A）、改阈值（B）都没用；softmax（D）对每对类别的边界也是线性的。加入 `x₁²、x₂²` 后，边界 `w₁x₁² + w₂x₂² + b = 0` 在原空间里就是圆/椭圆，问题变得线性可分。这正是讲义练习 1 的内容：模型在**新特征上**仍是线性的。

### Q8 — 答案：B

可分时，只要把 w 沿着某个正确分开数据的方向放大，所有样本的 p 都更接近正确标签，BCE 会继续下降、无限趋近 0，但不存在有限的最小点，权重范数一直增长。讲义说 BCE "convex... guaranteeing a single global minimum"，严格来说要加上"存在有限最优解"的前提。实际中用 L2 正则（sklearn 的 `LogisticRegression` 默认 `C=1.0` 的 L2）或早停来解决。本节数据在训练集上有 2 个样本被分错（训练准确率 0.9875），所以不是严格可分，但继续训练到 5000 轮时权重仍会从约 `[0.99, 0.76]` 增长到约 `[1.70, 1.37]`。

### Q9 — 参考答案

(a) `z = 0.9886×4.0 + 0.7629×3.0 − 5.9623 = 3.9544 + 2.2887 − 5.9623 ≈ 0.2808`，`p = σ(0.2808) ≈ 0.570`（实测 0.5698），≥ 0.5 → 类 1。

(b) 令 `x₁ = x₂ = t`：`(0.9886 + 0.7629)·t − 5.9623 = 0` → `t = 5.9623 / 1.7515 ≈ 3.404`，交点约为 `(3.40, 3.40)`。所以 `[3.0, 3.0]` 在边界的类 0 一侧（p=0.33 < 0.5），`[3.5, 3.5]` 刚越过边界（p=0.54），完全一致。两类真实中心是 (2,2) 和 (5,5)，中点为 (3.5,3.5)；学到的边界略偏向类 0 一侧，且由于 w₁ ≠ w₂，边界并不严格垂直于对角线（斜率 −1.2958 而非 −1）——这是有限样本加上 GD 尚未收敛的结果。

### Q10 — 参考答案

(a) `sigmoid(-1000)` 要计算 `math.exp(1000)`，超过 float 上限（约 1.8e308），抛出 `OverflowError: math range error`。`sigmoid(1000)` 计算的是 `math.exp(-1000)`，下溢为 0.0，结果是 1.0，不会报错。所以截断主要是防**负方向**的溢出。（NumPy 的 `np.exp` 不会抛异常而是返回 `inf` 并给出警告，`1/(1+inf) = 0.0` 仍然能用。）

(b) 数学上是 (0,1)，但 float64 精度有限：当 `z ≳ 37` 时，`e^{−z}` 小于机器精度的一半，`1 + e^{−z}` 被舍入成恰好 1.0，于是 `sigmoid(40) == 1.0` 为 True（实测 `sigmoid(36)` 还不等于 1.0，`sigmoid(37)` 就等于了）。此时若 y=0，就要计算 `math.log(1 − 1.0) = math.log(0)`，抛出 `ValueError: math domain error`。夹到 `[1e-15, 1−1e-15]` 后，单个样本的损失最多约 `−log(1e-15) ≈ 34.5`，不会出错。更稳定的生产写法是直接用 logits 计算：`BCE = max(z,0) − z·y + log(1 + e^{−|z|})`（PyTorch 的 `BCEWithLogitsLoss` 就是这么做的）。

(c) 先减去最大分数，所有指数参数都 ≤ 0，`exp` 的结果在 (0, 1] 之间，不会上溢；且最大项恰好是 `e⁰ = 1`，保证分母 ≥ 1，不会因全部下溢而除以 0。由 Q6 可知结果不变。

### Q11 — 参考答案

(a) 测试集正类 21 个、负类 19 个。
- 阈值 0.3：Recall=1.0 → TP=21、FN=0；Precision=21/(21+FP)=0.9130 → FP=2；TN=19−2=17。验证 accuracy=(21+17)/40=0.95 ✓。
- 阈值 0.7：Precision=1.0 → FP=0、TN=19；Recall=TP/21=0.9048 → TP=19、FN=2。验证 accuracy=(19+19)/40=0.95 ✓。

(b) 阈值升高，只有模型非常有把握的样本才会被判为正类：判为正的样本变少、"质量"变高，FP 减少 → Precision 升；但一些概率在 0.5–0.7 之间的真正类被判成了负类，FN 增多 → Recall 降。

(c) 阈值也是一个需要"调"的超参数。在测试集上挑选，就把测试集用于了模型选择，测试集上的分数会偏乐观（这里 0.4 和 0.5 都是满分，正是小测试集上过拟合阈值的风险）。正确做法：在验证集或交叉验证上根据业务目标（如"Recall ≥ 0.95 时 Precision 最大"）选阈值，最后在测试集上只评估一次。

### Q12 — 参考答案

```python
def roc_auc(y_true, scores):
    pos = [s for s, t in zip(scores, y_true) if t == 1]
    neg = [s for s, t in zip(scores, y_true) if t == 0]
    if not pos or not neg:
        raise ValueError("AUC 需要同时存在正负样本")
    wins = 0.0
    for sp in pos:
        for sn in neg:
            if sp > sn:
                wins += 1
            elif sp == sn:
                wins += 0.5
    return wins / (len(pos) * len(neg))

train_scores = [model.predict_proba(x) for x in X_train]
print(f"Train AUC: {roc_auc(y_train, train_scores):.4f}")
```

实测训练集 AUC ≈ 0.9986（与 `sklearn.metrics.roc_auc_score` 一致）；测试集上正负样本被完美分开，AUC = 1.0。

与 accuracy 的区别：accuracy 依赖一个**固定阈值**，只看最终 0/1 是否正确；AUC 只看**排序**——是否把正样本的分数排在负样本前面，与阈值无关，等价于在所有阈值上综合评估。所以 AUC 适合比较"打分模型"的区分能力，但不反映概率是否校准，也不告诉你该用哪个阈值。上面的双重循环是 O(P·N)；生产实现先排序，用秩和（Mann–Whitney U 统计量）在 O(n log n) 内算完。

### Q13 — 参考回答要点

- **建模**：把标签看成伯努利随机变量，`P(y=1|x) = p = σ(wᵀx + b)`，于是 `P(y|x) = p^y·(1−p)^{1−y}`。
- **似然**：n 个独立样本的似然 `∏ pᵢ^{yᵢ}(1−pᵢ)^{1−yᵢ}`，取对数并取负、除以 n，就是 BCE：`L = −(1/n)·Σ[yᵢ log pᵢ + (1−yᵢ) log(1−pᵢ)]`。**最小化交叉熵 ⇔ 最大化似然**。
- **梯度**：对单个样本，`∂L/∂p = −y/p + (1−y)/(1−p)`，`∂p/∂z = p(1−p)`，相乘得 `∂L/∂z = p − y`（`σ'` 因子被完美抵消）；再乘 `∂z/∂w = x`，得 `∂L/∂w = (p − y)·x`，平均后即代码中的 `dw[j] / n`。
- **凸性**：Hessian `= (1/n)·Σ pᵢ(1−pᵢ)·xᵢxᵢᵀ`，半正定，所以损失是凸的；没有闭式解，需要迭代（GD、牛顿法/IRLS、L-BFGS）。
- **加分点**：与线性回归对照——高斯噪声 → MSE，伯努利 → 交叉熵，都是"损失 = 负对数似然"；这一思路推广出广义线性模型（GLM）。

### Q14 — 参考回答要点

- **线性分类器**：预测为 1 当且仅当 `p ≥ 0.5` ⇔ `wᵀx + b ≥ 0`，sigmoid 是单调函数，不改变判决边界，所以边界是超平面。sigmoid 的"非线性"只作用在输出概率上，不作用在边界形状上。
- **非线性的办法**：特征工程（多项式、交互特征、分箱）、核方法，或换树模型/神经网络。
- **概率可信吗**：在模型假设大致成立、样本充足、无强正则时，逻辑回归的概率通常**校准得比较好**（因为它直接优化对数似然），这是它比 SVM、朴素贝叶斯、未校准的树模型更受欢迎的原因之一。但以下情况会失真：强正则化、类别重采样/加权后训练（概率被系统性抬高，需要还原先验）、训练与线上分布不一致。
- **如何检查/修正**：可靠性图（reliability diagram）、Brier score；用 Platt scaling 或 isotonic 回归在验证集上做校准。
- **常见误区**：认为"输出 0.9 就意味着 90% 会发生"而不做校准验证。

### Q15 — 参考回答要点

- **Precision**：判为正的里面有多少是真的正，关心"误报"。
- **Recall（TPR）**：真正的正样本里抓到了多少，关心"漏报"。
- **F1**：二者的调和平均，偏向较小者；适合需要单一数字、且正类是关注重点的场景。
- **ROC-AUC**：ROC 曲线的横轴是 FPR = FP/(FP+TN)，纵轴是 TPR；AUC = 随机正样本得分高于随机负样本的概率，与阈值无关。
- **PR-AUC（平均精确率 AP）**：Precision–Recall 曲线下面积，随机基线等于正样本比例。
- **1:100 时**：重点看 PR-AUC 和业务阈值下的 Precision/Recall。原因：负样本极多时，FPR 的分母 (FP+TN) 很大，即使 FP 数量很多，FPR 依然很小，ROC-AUC 容易显得很乐观；PR 曲线直接反映"报出来的正样本里有多少是真的"，对少数类的表现更敏感。
- **加分点**：最终还是要回到业务代价——例如"在人工审核能力每天 500 单的约束下，召回最多的欺诈"，即 Recall@K 或 Precision@K。

### Q16 — 参考回答要点

1. **指标先行**：不看 accuracy（全判正常就有 99%）；用 PR-AUC、Recall@固定 Precision、或代价加权指标；切分时用分层抽样，且按时间切分防泄漏。
2. **处理不平衡**：
   - 类权重：`class_weight="balanced"` 或在损失里给正样本更大的权重；
   - 重采样：对负样本下采样 / 对正样本过采样（SMOTE 等），只能在训练集上做；
   - 下采样或加权后预测概率会偏高，若需要真实概率，要按采样率做先验校正或重新校准。
3. **阈值调节**：不要用默认 0.5；在验证集上根据业务代价选阈值。
4. **特征与正则**：标准化；欺诈的信号常是非线性/交叉的（"深夜 + 新设备 + 大额"），需要交叉特征、分箱；L1/L2 正则防止在少量正样本上过拟合。
5. **基线与升级**：逻辑回归做强基线，再尝试 GBDT；上线后监控分布漂移（欺诈手法会变）。
- **常见误区**：在重采样后的数据上评估、或在切分前就做过采样（复制的正样本同时出现在训练和测试中）。

### Q17 — 参考回答要点

- **关系**：二分类时 softmax 有两个分数 z₀、z₁，`P(y=1) = e^{z₁}/(e^{z₀}+e^{z₁}) = σ(z₁ − z₀)`，就是 sigmoid。所以 sigmoid 是 2 类 softmax 的特例；也说明 softmax 的参数有冗余（所有类的权重同时加同一向量，输出不变）。
- **softmax（多项逻辑回归）vs OvR**：
  - softmax：一个模型联合训练，各类概率相互竞争、和为 1，适合"互斥的单标签"多分类；
  - OvR：训练 k 个独立的二分类器，每个输出一个独立概率，加起来不一定为 1，需要再取 argmax；实现简单、可并行，但各分类器的分数尺度不一定可比，且每个子问题都是不平衡的。
- **多标签**（一张图同时有"猫"和"沙发"）：标签不互斥，应对每个标签用**独立的 sigmoid + BCE**，而不是 softmax（softmax 会强迫各标签竞争）。
- **加分点**：联系大模型——语言模型输出层就是在整个词表上做 softmax，训练目标就是本节的类别交叉熵；"温度"就是在 softmax 前把 logits 除以 T。

### Q18 — 参考回答要点

- **为什么长期是主力**：
  - 推理就是一次稀疏点积，延迟极低、易于大规模服务；
  - 能处理上亿维的稀疏 one-hot / 哈希特征，配合 L1 得到稀疏模型，节省内存；
  - 输出概率校准较好，可以直接用于出价（eCPM = pCTR × 出价）；
  - 可解释、易调试；支持在线学习（如 FTRL 这类在线优化算法），快速适应新数据。
- **短板**：本身只能学线性关系，特征交叉全靠人工设计（"用户性别 × 广告类目"），组合爆炸、依赖专家经验。
- **弥补方式**：人工交叉特征 + 特征哈希；GBDT 生成叶子节点特征再喂给 LR（GBDT+LR）；因子分解机 FM/FFM 自动学习二阶交叉；进一步发展到 Wide & Deep、DeepFM 等深度模型——其中 "Wide" 部分本质上就是逻辑回归。
- **加分点**：提到样本负采样后要做概率校正；线上线下特征一致性；用 AUC 和校准指标（如 pCTR 与真实 CTR 之比）一起监控。
