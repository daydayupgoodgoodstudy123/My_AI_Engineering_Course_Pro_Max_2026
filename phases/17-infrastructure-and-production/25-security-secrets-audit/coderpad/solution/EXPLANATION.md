# 参考解释：Security — Secrets, API Key Rotation, Audit Logs, Guardrails

## 核心：结构化日志脱敏

命中敏感 key 时替换整个值；其他容器递归复制，不修改原日志。

准确合同：Recursively copy JSON values; replace the entire value of any dict key whose casefolded spelling is token,password,api_key,authorization with '[REDACTED]'. Other scalar values stay unchanged. This key-based policy does not discover secrets embedded in free text.

## 加分：独立权限与批准

批准不能绕过独立 capability 授权；allow 也不代表已经执行或被 OS 隔离。

准确合同：If capability is absent from granted return 'deny' even if approved. Otherwise side_effect=True and approved=False returns 'ask'; otherwise 'allow'. side_effect and approved must be exact bool, else ValueError. No action executes.
