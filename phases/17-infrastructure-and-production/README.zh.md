## 在 GitHub 上开始此阶段

**先修要求:** 第11阶段 LLM 工程和13阶段工具与协议。

**第一课:** [Managed LLM Platforms](01-managed-llm-platforms/docs/zh.md)

从存储库根目录运行此命令：

```bash
python3 phases/17-infrastructure-and-production/01-managed-llm-platforms/code/main.py
```

保持命令,退出代码,成本和潜伏比较, 冗余提升,
以及一份简短的决定记录 列出你选择后的工作量假设

**下一步行动:** 改变一个工作量或服务级协议输入,解释新的选择
然后继续 [Inference 平台经济学](02-inference-platform-economics/docs/zh.md).

浏览 [整个第17阶段课程列表](../../README.md#phase-17) 或该
