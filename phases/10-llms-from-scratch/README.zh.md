# 第10阶段: LLMs 从剪辑

> 建立、培训和理解大型语言模式。

<a id="start-this-phase-on-github"></a>

## 启动此阶段于 GitHub

**先修要求:** 第5阶段 国家土地规划基础。 Transformers 强烈的
在建模课程之前建议。

**第一课:** [Tokenizers](01-tokenizers/docs/zh.md)

从存储库根目录运行此命令：

```bash
python3 phases/10-llms-from-scratch/01-tokenizers/code/main.py
```

保留命令、 退出代码、 编码/ 解码回程结果、 学习合并
计数,压缩比率。 `tiktoken` 是一个可选比较。

**下一步行动 :** 加上一个字, 微小的物质还没有看到, 检查它的碎片,
然后继续 [建造a Tokenizer 从剪辑](02-building-a-tokenizer/docs/zh.md).

浏览 [完整第10阶段课程列表](../../README.md#phase-10) 或该
[跨阶段路线图](../../ROADMAP.md).
