## 在 GitHub 上开始此阶段

**先决条件：** 第 2 阶段第 14 课，朴素贝叶斯。 Python 3.11+ 就足够了
第一课。

**第一课：** [文本处理](01-text-processing/docs/zh.md)

从存储库根目录运行此命令：

```bash
python3 phases/05-nlp-foundations-to-advanced/01-text-processing/code/main.py
```

保留命令、退出代码、token 列表、词干、引理以及一个示例，其中
词干提取失去了意义，但词形还原却保留了意义。

**下一步操作：** 添加一个带有标点符号的句子和一个不规则动词，
检查结果，然后继续 [Bag of Words 和 TF-IDF](02-bag-of-words-tfidf/docs/zh.md)。
